**SOFTWARE ENGINEER, SECURITY**

You form hypotheses about why data is helping or misleading the model, build the systems to test them, run ablations, and read the rollouts to find the bug, shortcut or mismatch behind a result. Every flaw you catch, or miss, shows up in what the next Grok models learn.

**RESPONSIBILITIES:**

* Build AI augmented code review to get involved in important systems at the right time
* Build a least-privilege and JIT system for cloud access that enables engineers and enforces least privileges
* Implement a safe environment for agents to engage with code
* Implement a framework for securely handling agent manipulation of user systems (e.g., MCP tool calls and command execution)
* Implement a paved road for preventing inappropriate data from being logged

**BASIC QUALIFICATIONS:**

* Experience building or scaling secure systems in fast-moving environments

**PREFERRED SKILLS AND EXPERIENCE:**

* A strong software engineer first, with security as your superpower
* Think like both a builder and an attacker: you anticipate vulnerabilities before they become issues
* Care about developer experience, building solutions that are secure and frictionless
* Comfortable moving quickly, owning problems end to end, and iterating with limited guidance
* Strong opinions on secure defaults, but can balance pragmatism with rigor
* Enjoy working on small, high-talent teams where impact is magnified
* Motivated by protecting developers and users, and you see security as an enabler

**ADDITIONAL REQUIREMENTS:**

* If there appears to be a fit, we'll reach out to schedule 2-3 short technicals. After, we'll schedule an onsite in our office, where you'll work on a small project, discuss ideas, and meet the team
