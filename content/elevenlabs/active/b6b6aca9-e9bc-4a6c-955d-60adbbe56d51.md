## About the role

ElevenLabs spends meaningfully on paid acquisition, and that spend is only as good as the data behind it. We are looking for an engineer to own our measurement layer end to end: the tag manager setup, the tracking and attribution scripts on our sites, and the server-to-server conversion tracking that feeds our ad platforms.

Day to day you will work closely with the paid marketing team: fixing tracking bugs as they come in, setting up tracking for new landing pages and campaigns, and debugging discrepancies between platform-reported conversions and our internal data. Longer term, you will define how tracking should properly work here and build the monitoring so we catch breakage in hours, not weeks.

This role sits between frontend engineering, data engineering, and marketing. You will add and improve tracking scripts without hurting pagespeed, keep our server-side GTM container healthy, make sure consent and regional restrictions are correctly enforced, and ensure the right channels get credit for the right conversions. Your work directly decides how a large paid budget gets allocated.

## What you will do

* Own our tag manager setup end to end, including the server-side GTM container, and review any changes other teams want to make
* Work with the paid marketing team daily: fix tracking bugs, set up tracking for new landing pages and campaigns, and debug discrepancies between platform-reported conversions and our internal data
* Build and maintain server-to-server conversion tracking (Meta CAPI, Google Enhanced Conversions, and similar) and validate pixel vs server deduplication
* Improve tracking script performance and correctness, keeping script impact on pagespeed and Core Web Vitals within budget
* Make sure consent handling and regional restrictions are correctly enforced across markets
* Define event schema and UTM conventions, and document them so tracking for new campaigns is correct by default
* Build monitoring and alerting for the measurement stack so we catch broken tracking within hours, not weeks
* Review PRs that add conversion events to the main app, and work with product engineering on tracking integrations

## Requirements

* Strong JavaScript/TypeScript, comfortable working in both frontend code and a production application codebase
* Hands-on experience with Google Tag Manager, including server-side GTM, and at least one conversion API (Meta CAPI, Google Enhanced Conversions, or similar) implemented server-to-server
* Experience debugging attribution discrepancies end to end: pixel vs server deduplication, UTM conventions, event schema design
* Solid understanding of web performance and how to add tracking without degrading Core Web Vitals
* Working knowledge of consent and privacy requirements (Consent Mode v2, regional restrictions) and SQL for validating tracking data in the warehouse
