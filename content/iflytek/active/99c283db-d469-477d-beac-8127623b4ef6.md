## 职位描述

岗位职责

1. 参与产品的 AI Agent 研发，服务于办公、学习、内容创作、信息管理、跨语言沟通及智能硬件等场景。

2. 参与任务规划、记忆、Tool Calling/MCP、RAG、多模态检索、工作流编排及多 Agent 协作等核心能力建设。

3. 建设 Agent 评测、Tracing 与可观测能力，优化准确性、稳定性、时延、成本及用户体验。

4. 探索语音、文档、图片等多模态交互，以及端云协同、隐私保护与安全执行。

5. 使用 AI 工具辅助研发，与跨团队协作推动产品落地。

任职要求

1. 重点院校本科及以上学历，计算机、软件工程、人工智能等相关专业优先。

2. 熟练掌握 Python、Java、Go、C++、JavaScript/TypeScript 中至少一种，具备良好的软件工程基础。

3. 了解大模型应用范式，如 Prompt/Context Engineering、Tool Calling、RAG、结构化输出等；有 AI Agent 或大模型应用项目经验。

4. 具备问题拆解、沟通协作与持续学习能力，关注用户体验和工程质量。

加分项：有 Agent Demo、开源项目或相关竞赛成果；有 MCP、多 Agent、语音、多模态、OCR、端侧推理或智能硬件开发经验。
