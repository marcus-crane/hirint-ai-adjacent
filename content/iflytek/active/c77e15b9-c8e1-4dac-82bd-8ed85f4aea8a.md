## 职位描述

1、负责 Agent 产品、平台及 Harness 核心能力的测试开发，制定测试方案并建设自动化测试工具。

2、建设 Agent 评测与回归体系，覆盖任务执行、上下文管理、工具调用、异常恢复和多轮运行稳定性。

3、分析模型、上下文、工具及 Harness 的执行轨迹，定位失败原因并推动问题解决。

4、与研发、模型和产品团队协作，将评测能力接入产品迭代和版本发布流程，持续提升 Agent 质量。

## 任职要求

1、具备扎实的编程和软件工程能力，熟练掌握 至少一种语言。

2、具备测试开发、自动化测试、服务端研发或平台工程相关经验，能够独立完成测试工具或测试平台开发。

3、对 LLM 和 Agent 有浓厚兴趣，了解 Agent Loop、Tool Use、Context、Memory、MCP 等基本概念。

4、具备较强的学习能力和动手能力，能够快速理解AI系统，并完成方案设计、开发和验证。

5、具备较强的问题分析能力，能够结合日志、指标和执行轨迹定位复杂问题，推动问题闭环。

6、具备良好的沟通协作能力和质量意识，关注异常场景、边界条件、稳定性和使用体验。

加分项

1、有 Agent 产品、Agent 平台、Harness、Coding Agent 或生成式 AI 产品相关测试开发经验。

2、建设过自动化测试框架、评测平台、回归系统或质量监控体系。

3、有高质量个人项目、开源贡献或其他能够体现学习和动手能力的代表性成果。
