## 职位描述

1、推进 OpenRouter 等平台上线：整理模型参数、slug、价格、容量、上下文长度、API 兼容性、模型页文案和发布节奏。

2、设计用量分析口径：按场景、渠道、API key、用户、session、trace 标签拆分调用量、token、成本、留存、错误和延迟。

3、建立海外开发者渠道：维护 OpenRouter、Hugging Face、GitHub、Reddit、Hacker News、Discord、X、LinkedIn、Medium、Dev.to 等阵地。

4、产出可直接使用的内容：模型发布稿、接入教程、代码示例、benchmark 解读、FAQ、案例文章和 demo 脚本。

5、组织开发者试用：邀请工具作者、开源项目、AI coding / Agent 用户试模型，收集问题，推动二次传播。

6、跟踪竞品动作：持续看 Anthropic、DeepSeek、OpenAI、Mistral、Qwen 等公司的发布节奏、模型页、内容打法和社区反馈。

## 任职要求

1、2 年以上海外运营、开发者运营、技术内容、AI 产品运营或 DevRel 经验。

2、英文读写强，能在海外社区自然沟通，能写短帖、长文、教程和 FAQ。

3、熟悉 LLM / API 基本概念：token、context、streaming、tool calling、JSON mode、rate limit、latency、cost。

4、能读 API 文档，能和工程团队对齐接入细节，能把技术事实转成清楚的对外表达。

5、数据意识强，能用表格、BI或观测工具拆用量、场景、渠道、转化和留存。

6、对开发者社区敏感，能判断哪些反馈代表真实需求，哪些只是噪声。

加分项

1、做过 OpenRouter、Hugging Face、GitHub、Discord、Reddit、Hacker News、X、LinkedIn 任一平台的模型或开发者增长。

2、有 LLM / Agent / Coding 工具 / B2D 产品的上线、增长或社区经验。

3、用过 Langfuse、PostHog、ClickHouse、Snowflake、Grafana、Datadog、W&B、LangSmith 等工具。

4、写过技术博客、英文教程、开源 README、模型卡或 benchmark 报告。

5、有海外 KOL、开源作者、开发者社群或 AI 工具团队资源。

能自己做 demo、录短视频、组织 AMA / office hour / 线上发布。
