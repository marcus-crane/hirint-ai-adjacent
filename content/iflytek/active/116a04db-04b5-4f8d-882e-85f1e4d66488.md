## 职位描述

1、构建代码大模型从0-1的项目生成能力，提升大模型在代码生成、代码补全、代码解释、代码调试、代码重构等方面的能力；研究多语言代码理解、跨语言代码翻译、代码知识库构建等技术方向

2、构建代码质量评估体系，持续优化模型的代码生成质量

3、负责代码大模型的预训练、SFT、RLHF 等全流程技术方案设计与实现

4、跟踪国际前沿代码大模型研究进展，快速将最新技术转化为产品能力

5、研究基于代码大模型的智能体（Agent）技术，实现复杂编程任务的自动化，探索大模型与开发工具、调试器、版本控制系统的深度集成，推动代码大模型在软件工程全流程中的落地应用

## 任职要求

1、对AI大模型、代码大模型、Harness、Agent等方面的研究有较高的品味和深入的思考；具备扎实的独立分析问题、解决问题的能力；能够快速将想法实现，具备高效的实验迭代和验证能力。

2、熟悉大模型预训练、微调、强化学习等基本概念与常用算法（如 PPO、DPO、GRPO、Actor-Critic 等），有相关实践经验者优先。

3、熟练深度学习框架，具备良好的工程代码实现能力。

4、理解Agent的核心范式（如 ReAct、Function Calling、Tool Use、Planning 等），有 Agent 系统或工具调用相关开发/研究经验者优先。

5、善于跨团队沟通，能与数据、工程、产品等团队高效配合。

加分项：

1、在AI相关顶会（NeurIPS、ICML、ICLR、ACL 、EMNLP等）发表过一作论文。

2、深度使用过AI 编程/Agent 工具，对模型与 Agent 的能力边界有实践认知。

3、参与过知名开源项目（尤其是 Agent / LLM 相关框架）或有活跃的 GitHub 贡献，有着良好的开源实践和协作经验。

4、参与过代码、算法类竞赛并获得奖项者优先"
