## 职位描述

1、负责 Coding Agent、桌面 Agent、模型服务平台等产品的 UI 设计，输出高保真界面、交互原型及设计标注。

2、根据产品流程设计页面布局、信息层级和操作反馈，重点处理任务输入、执行进度、工具调用、权限确认、异常提示和结果展示等界面。

3、建立并维护产品设计系统，统一颜色、字体、图标、组件、间距和动效规范，支持 Web、桌面端及 IDE 插件等不同产品形态。

参与官网、模型介绍页、产品发布页和开发者文档的视觉设计，保证产品界面与对外品牌表达一致。

4、负责模型发布海报、社交媒体图片、活动主视觉、演示文稿和产品 Demo 包装等平面物料。

5、与产品经理、前端工程师共同完成设计评审和上线验收，检查界面还原度、响应式布局和不同状态下的显示效果。

6、使用AI 设计工具快速探索视觉方案，提高图像制作、页面设计和素材生产效率。

## 任职要求

1、3年以上 UI、视觉或交互设计经验，有完整的软件产品或互联网产品上线经历。

2、具备扎实的视觉基本功，对字体、版式、色彩、图标和信息层级有成熟判断。

3、熟练使用Photoshop、Illustrator 等设计工具，能够独立完成从视觉探索到设计交付的全过程。

4、具备基本的 UX 思维，能够根据产品流程补充页面状态、操作反馈和异常场景。

5、有设计系统或组件库实践经验，理解组件状态和前端实现约束。

6、能够与产品和研发团队直接沟通，跟进设计方案实现并处理上线前的视觉问题。

7、对 AI 产品有长期兴趣，深度使用过Agent 产品。

8、作品集能够体现真实项目中的个人贡献、设计判断和最终上线效果。

加分项

1、有 AI 产品、开发者工具、IDE、企业软件或数据平台设计经验。

2、有桌面端、深色界面或高信息密度产品设计经验。

3、能使用 After Effects、Blender、C4D 或其他工具制作动效及三维视觉。

4、了解 HTML、CSS、React，能够使用工具制作页面原型。

5、参与过品牌视觉体系从0到1的建立。

6、有海外产品、英文网站或国际化界面设计经验。

7、有个人设计项目、开源作品或可直接体验的产品。

作品集要求

请提供3至5个代表项目，建议包含：

1、至少2个 Web、桌面端或移动端 UI 项目。

2、至少1个品牌、官网或发布活动视觉项目。

3、项目中的个人职责及关键设计判断。

4、最终上线页面、产品截图或可访问链接。

5、作品集会重点评估视觉完成度、信息层级、界面一致性和真实交付能力。

岗位优势

1、直接参与 Coding Agent 和桌面 Agent 的产品视觉定义。

2、设计成果能够快速进入真实产品和模型发布项目。

3、与产品、模型及工程团队直接协作，减少多层沟通。

4、同时覆盖产品 UI 和全球发布场景，积累 AI 产品设计经验。
