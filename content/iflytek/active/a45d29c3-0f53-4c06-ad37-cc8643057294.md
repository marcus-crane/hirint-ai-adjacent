## 职位描述

1、参与 Agent Harness / 运行时核心能力研发，包括 Agent Loop、任务理解与拆解、计划生成与调度、工具选择与调用、执行状态管理、异常恢复和结果校验等关键链路。

2、参与 Agent 产品工程化建设，包括上下文构建、工具/插件接入、MCP 集成、执行环境、权限控制、日志追踪、评测体系、可观测性和服务化能力建设。

3、与模型、算法和产品团队协作，基于真实任务、执行日志、用户反馈和评测结果，持续优化 Agent 的任务完成率、可靠性、可控性、成本和用户体验，推动模型能力与 Harness 能力共同进化。

4、持续跟进 Agent 领域优秀产品、开源框架和前沿技术演进，包括 AI Coding、MCP、Context Engineering、Harness Engineering、多智能体协作、工作流编排等方向，完成技术调研、原型验证、效果评估和工程落地探索。

## 任职要求

1、硕士及以上学历，计算机、软件工程、信号处理、自动化、应用数学等相关专业。

2、熟悉至少一门编程语言，具备扎实的工程实现能力。

3、具备 Vibe Coding 经验，熟练使用 AI Coding / Agent 工具进行软件开发，能够在 AI 辅助下快速理解陌生技术栈，并完成有质量保证的代码实现、调试验证和工程集成。

4、是 Agent 产品的高强度用户，对 Agent Harness、模型行为、工具调用、上下文管理、任务执行体验和开发者体验有较强兴趣与判断力。

5、熟悉 LLM 与 Agent 基本机制，包括 Agent Loop、Tool Use、Reasoning、Planning、MCP、Memory、Subagent、Multi-Agent、RAG、Context Engineering 等相关知识。

6、有 Agent Harness、AI Coding 工具、插件系统、MCP、工作流编排、多智能体协作、评测系统或开源项目经验者优先。
