## 职位描述

岗位职责：

1、负责包括大模型在内的多种AI技术落地的工程方案的子系统详细设计，保障系统的高可用、可扩展性

2、负责实现核心服务的高质量编码，确保代码的可维护性和性能

3、主导关键技术问题的攻关，提供创新的技术解决方案。

3、与模型、算法和产品团队协作，基于真实任务、执行日志、用户反馈和评测结果，持续优化 Agent 的任务完成率、可靠性、可控性、成本和用户体验，推动模型能力与 Harness 能力共同进化。

4、持续跟进 Agent 领域优秀产品、开源框架和前沿技术演进，包括 AI Coding、MCP、Context Engineering、Harness Engineering、多智能体协作、工作流编排等方向，完成技术调研、原型验证、效果评估和工程落地探索。

## 任职要求

任职资格

1、计算机科学或相关专业本科及以上学历。

2、熟悉Java或golang编程语言，具备扎实的工程实现能力。

3、具备 Vibe Coding 经验，熟练使用 AI Coding / Agent 工具进行软件开发，能够在 AI 辅助下快速理解陌生技术栈，并完成有质量保证的代码实现、调试验证和工程集成。

4、熟悉 LLM 与 Agent 基本机制，包括 Agent Loop、Tool Use、Reasoning、Planning、MCP、Memory、Subagent、Multi-Agent、RAG、Context Engineering 等相关知识。

5、有 Agent Harness、AI Coding 工具、插件系统、MCP、工作流编排、多智能体协作、评测系统或开源项目经验者优先。
