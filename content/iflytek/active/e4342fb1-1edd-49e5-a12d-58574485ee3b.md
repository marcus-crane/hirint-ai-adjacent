## 职位描述

1、参与设计 Harness 产品的技术架构与选型，包括 Agent Loop、工具协议、上下文管理、记忆系统等核心模块。

2、参与长程任务运行机制的设计与优化。

3、参与 Harness 产品的工程开发，承担从原型到上线的端到端交付。

4、与模型团队的研究员、工程师深度协同，推动模型与 Harness 的共同演进，让模型更适合 Harness，也让 Harness 更能释放模型能力。

5、把内部真实任务，包括团队自己的开发、文档、运营工作，当作 Harness 与模型训练的反馈源，把工程问题转化为可训练的信号。

6、在 OpenAI / Anthropic API 兼容、第三方 Harness 适配等方向上承担具体落地，确保 day-0 进入主流开发者工作流。

7、阅读、归纳用户反馈，对 Harness 体验持续打磨；有兴趣且力所能及时，协助维护开发者社群。

8、协助项目管理相关工作。

## 任职要求

1、本科及以上学历，2 年以上软件开发经验，技术过硬，技术视野广。特别优秀的候选人可放宽年限。

2、熟练使用 AI Agent 工具进行软件开发，学习能力强，能在 AI 辅助下进入没有直接经验的语言、技术栈、框架，并稳定交付有质量的代码。

3、是 Agent 产品的高强度用户，把代码类与通用类 Agent 真实融入自己的工作和生活；对模型行为有品味、有判断力，对开发者体验有强感知。

4、熟悉 LLM 与 Agent 的基本机制和技术原理：LLM API、KV Cache、Agent Loop、Tool Use、Reasoning、Planning、Skills、MCP、Memory、Subagent、Multi-Agent；对 Prompt / Context / Harness Engineering 有较深入理解。

加分项

1、AI 行业相关软件开发经验，尤其是 Coding Agent、IDE 集成、CLI 工具方向。

2、在小团队中作为研发工程师快速迭代产品上线的经验。

3、个人开源作品，或在开源社区有深度贡献。

4、与研究员深度协作过，或有科研经验，对实验设计与 evals 有判断力。

5、能用英文与开源社区、海外开发者、用户社群直接沟通。

6、在 OpenRouter、LMArena 等社区有过 provider 接入或 benchmark 跑分相关经验。

7、计算机科学、编程、数据科学领域有含金量的比赛奖项。

8、计算机科学及其他学术领域有含金量的论文发表。

9、其他超乎常人的、与此工作相关的才能。
