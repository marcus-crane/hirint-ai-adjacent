Overview

The Autonomous Pilot Integration team builds and maintains a reusable core pilot and applies it to real programs and platforms. We combine Hivemind SDK, Perception, and Autonomy Capabilities components into complete mission solutions, adapt them to vehicle and operator interfaces, and validate behavior in simulation, labs, and representative tests. This role contributes to both reusable pilot software and program-specific autonomy applications.

As an entry-level engineer, you will work with experienced engineers on well-defined software, configuration, and test tasks. You will learn how mission behavior, platform control, sensors, and C2 work together without being expected to own an interface, release, or test event independently.

What you'll do:  
\* Implement C++ changes to program-specific mission behavior, autonomy configuration, diagnostics, or an assigned platform-interface component with guidance.  
\* Develop and adapt supported pilot behaviors and reference configurations for defined missions or platforms, contributing reusable improvements to the core pilot with guidance.  
\* Run builds and unit or integration tests; help reproduce issues using simulation, logs, and telemetry.  
\* Assist with validation of command, status, sensor, and mission data flows in lab or SIL/HIL environments.  
\* Document setup steps, interface assumptions, test findings, and reproducible failures for the program team.  
\* Work with the Autonomy Capabilities team on planning and other capability interfaces, and with Integration & Test and platform teams on platform interfaces, compute, and test environments.
