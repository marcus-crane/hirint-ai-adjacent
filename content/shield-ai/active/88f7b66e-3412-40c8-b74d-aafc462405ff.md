The Ground Control Station (GCS) Software team extends the Hivemind Commander platform to support mission planning, command and control, and post-mission debrief for operators of unmanned systems. Our full-stack engineers build web-based operator experiences and supporting services that bring program and platform capabilities into Commander.

As an Engineer II, you will build and test Hivemind Commander extensions across the user interface and backend. You will deliver assigned planning, C2, and debrief workflows using established platform patterns and interface contracts, with senior engineers guiding architecture, major interface decisions, and release readiness.

What you'll do:  
\* Build and test full-stack extensions to Hivemind Commander for mission planning, live C2, and post-mission debrief.  
\* Develop operator workflows for planning and reviewing missions, visualizing telemetry and platform status, issuing supported commands, and exploring recorded mission data.  
\* Connect extension interfaces to Commander and ground-service APIs using established contracts; handle live updates, data validation, error states, and operator-visible feedback.  
\* Implement supporting service endpoints and data flows for mission, command/status, and debrief information, with attention to reliability and traceability of operator actions.  
\* Add frontend, backend, and integration tests, including representative telemetry playback or simulated operator workflows where appropriate.  
\* Diagnose extension issues across browser behavior, API responses, service logs, and network connections in representative test environments.  
\* Collaborate with Commander platform, UX, autonomy, and test teammates to clarify requirements, verify integration points, and support lab or field-test preparation.  
\* Document extension behavior, test evidence, interface assumptions, and operator-visible limitations.
