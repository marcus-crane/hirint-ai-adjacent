Job Description

We are seeking a Software Engineer I to join the HMS Solutions Engineering Integration & Testing team. You will help build and maintain software that tests external system interfaces, runs realistic message exchanges, and turns test results into useful engineering information.  
This is a hands-on role for a new graduate or early-career engineer interested in software development, integration, automated testing, and autonomous systems. You will work with experienced software and systems engineers to build Python tools, interact with complex software systems, and improve system-level testing.

What you'll do  
\* Develop and maintain Python software used to set up tests, exercise system interfaces, check messages, and create reports.  
\* Create automated tests that simulate external systems and evaluate a system under test.  
\* Use interface documents and message schemas to create test inputs and expected results.  
\* Investigate failures using logs, messages, configuration files, network traffic, and test results.  
\* Contribute to parsers, validation tools, command-line tools, and reporting workflows.  
\* Help maintain reliable Linux and container-based development and test environments.  
\* Write tests, take part in code reviews, and create clear setup and troubleshooting documentation.  
\* Work with software, systems, autonomy, and integration engineers to understand behavior and resolve defects.

### Required Qualifications

\* Currently pursuing a Bachelor's, Master's, or PhD in Computer Science, Robotics, Electrical Engineering, Aerospace Engineering, or a related field, graduating between December 2026 and August 2027.  
\* Foundational Python experience from coursework, internships, research, personal projects, or professional work.  
\* Understanding of basic software practices, including debugging, source control, code review, and automated testing.  
\* Familiarity with Linux and command-line tools.  
\* Familiarity with structured data formats such as XML, JSON, or YAML.  
\* Ability to read technical documents, solve problems, and explain your work clearly.  
\* Strong attention to detail and a willingness to learn in a team environment.  
\* Ability to obtain and maintain an active U.S. Secret security clearance

### Preferred Qualifications

\* Project, internship, or research experience in software testing, systems integration, robotics, autonomous systems, or simulation.  
\* Experience with Python test tools such as pytest or unittest.  
\* Familiarity with C++ or with testing systems written in more than one language.  
\* Exposure to XML schemas, interface control documents, or message-based systems.  
\* Experience with Git, continuous integration, or container tools such as Docker or Podman.  
\* Familiarity with networking, publish-subscribe messaging, message brokers, or distributed systems.
