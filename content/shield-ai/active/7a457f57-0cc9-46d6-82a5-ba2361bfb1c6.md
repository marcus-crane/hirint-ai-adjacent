### Job Description:

We are looking for a Senior Software Engineer, Engineering Tooling & Observability to build the tools that help engineers develop, understand, and diagnose complex software systems.

You will work close to the systems our engineers are building, developing tooling that makes those systems easier to understand and work with. This includes C++ and Python applications, developer-facing observability, web services, React-based user interfaces, visualisations, and engineering workflows.

A major focus of the role is developer-facing observability. Bringing together logs, telemetry, events, faults, and system state so engineers can quickly move from "something went wrong" to "I understand what happened and where to investigate."

You will be comfortable working within complex C++ software systems and understanding how they behave, while looking for opportunities to turn that understanding into better tools for other engineers. This could mean understanding how a component exposes diagnostic information, building services that aggregate it, or designing how that information should be presented to an engineer investigating a problem.

The role sits at the intersection of systems software, developer experience, observability, and engineering tooling. We treat internal tooling as a product. Usability, reliability, maintainability, performance, and the experience of the engineers using it all matter.

Our scope is focused on internal tooling products, Developer Experience, engineering-facing web services, UI/UX for system tooling, and licensing services. This is not a general DevOps or CI/CD engineering role. CI/CD platforms, build and release automation, pipeline infrastructure, build performance, and test execution pipelines sit outside the team's scope.

### What you'll do:

As a contributor to the Australian Engineering group, you will be responsible for:

* Design, build, and maintain engineering tools that help developers understand and diagnose complex software systems.
* Build tooling that brings together logs, telemetry, events, faults, diagnostics, and system state to make system behaviour easier to investigate.
* Build C++ and Python applications, libraries, services, and integrations that interact with complex onboard and distributed software systems.
* Create tools that correlate information across software components, processes, and machines to help engineers understand what happened and where to investigate.
* Build user interfaces and interactive visualisations using React and modern web technologies to explore system behaviour and engineering data.
* Design effective workflows for debugging, fault investigation, system introspection, and engineering analysis.
* Develop APIs and web services that support engineering tooling products and expose system data in useful ways.
* Improve the Developer Experience (DX) of working with complex systems by identifying engineering friction and turning it into effective tooling.
* Work directly with software, autonomy, systems, and test engineers to identify high-value problems and develop practical solutions.
* Treat internal tooling as a product, incorporating feedback from engineers and continuously improving usability and effectiveness.
* Establish reusable UI components, UX patterns, libraries, and engineering standards for system tooling.
* Contribute to the architecture and technical direction of the Engineering Tooling capability.

### Required qualifications:

* Experience building tools for software engineers or other technical users.
