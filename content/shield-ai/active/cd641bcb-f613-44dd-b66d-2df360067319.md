The HMS Perception team builds software that helps autonomous systems understand the world using sensor data, computer vision, tracking, sensor fusion, and AI/ML. Our work moves from data and algorithms through simulation, lab testing, and fielded systems.

As an entry-level engineer, you will develop and validate well-defined perception features, tools, or tests alongside experienced engineers. This full-time role builds on coursework or internship experience; you will complete assigned changes and document results with regular guidance rather than own a perception subsystem end to end.

What you'll do:  
\* Implement small, well-defined C++ changes to perception software, data processing, evaluation tools, or tests.  
\* Help analyze camera, EO/IR, radar, IMU, GPS, or simulated sensor data using established workflows.  
\* Run tests and repeatable experiments; investigate data-quality and software failures with guidance.  
\* Support object detection, tracking, sensor fusion, localization, or multimodal AI/ML evaluation as assigned.  
\* Document assumptions, metrics, results, and reproducible setup steps; participate in code and design reviews.  
\* Collaborate with perception, autonomy, platform, simulation, and test engineers.

We are seeking Autonomous Software Engineers for full-time roles starting in 2027! This is a paid, in-person, full-time position for students graduating during the 2026-2027 academic year. We are now reviewing applications for positions starting after graduation in 2027.

### Required Qualifications

* Currently pursuing a Bachelor's, Master's, or PhD in Computer Science, Robotics, Electrical Engineering, Aerospace Engineering, or a related field, graduating between December 2026 and August 2027.
* Foundational C++ or Python programming demonstrated through coursework, projects, research, internships, or work experience.
* Coursework or project exposure to computer vision, machine learning, robotics, estimation, sensor fusion, or related work.
* Familiarity with Linux, Git, debugging, and basic software-development or data-analysis workflows.
* Ability to communicate findings, ask questions, and improve work through feedback.
* Must be able to work in-person full-time.
* Ability to obtain a SECRET clearance.

### Preferred Qualifications

* Experience with OpenCV, PyTorch, ROS, or similar perception or robotics tools.
* Projects involving image/video processing, tracking, multimodal data, coordinate transformations, or sensor calibration.
* Experience with automated tests, simulation, visualization, or evaluation workflows.
