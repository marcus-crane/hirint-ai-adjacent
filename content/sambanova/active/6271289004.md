SambaNova is a leader in next-generation AI infrastructure, delivering a full-stack inference platform for customers worldwide. At the core of SambaNova's technology is the RDU (Reconfigurable Dataflow Unit) — a chip built on a dataflow architecture rather than the traditional GPU model. Its decode performance is especially strong for agentic workloads like multi-turn agents, code generation, and long-running applications. RDUs are packaged into SambaRack, rack-scale hardware that lets customers deploy state-of-the-art models with better performance, greater energy efficiency, and faster time to value.

# ML Infrastructure Engineer Intern

**About the Team**

The ML Infrastructure team builds and operates the inference stack that serves SambaNova's models on our RDU accelerators. We cover request scheduling, caching, decoding techniques, public APIs, and the accuracy testing that every inference feature must pass before it ships.

**About the Role**

As an ML Infrastructure Engineer Intern, you'll write Python for our inference serving stack, including our vLLM integration and public APIs. You'll help build features like speculative decoding, prompt caching, or tool calling on the RDU, and add accuracy and regression tests that catch problems before customers do. A dedicated mentor will guide you throughout the internship.

**Responsibilities**

* Help implement inference features on the RDU such as speculative decoding, constrained decoding, tool calling, prompt caching, or long-context inference Help adapt vLLM and related serving frameworks to the RDU architecture Contribute to endpoints in the public inference API
* Write accuracy verification and regression tests for inference features Investigate latency, throughput, and reliability issues with guidance from your mentor Present your project results to the team at the end of your internship

**Required Qualifications**

* Currently pursuing a B.S., M.S., or Ph.D. in Computer Science, Electrical Engineering, or a related field
* Solid programming skills in Python
* Understanding of algorithms, data structures, concurrency, and systems design Coursework or project experience in distributed systems or machine learning Familiarity with LLM serving frameworks such as vLLM, SGLang, or TensorRT-LLM Familiarity with inference techniques such as speculative decoding, KV caching, or continuous batching
* Experience with PyTorch

**Preferred Qualifications**

* Pursuing an M.S. or Ph.D. in Computer Science, Electrical Engineering, or a related field
* Experience building or maintaining APIs or backend services
* Prior internship or research experience in ML systems or backend infrastructure Familiarity with disaggregated systems, such as prefill/decode
* Open source project ownership or contributions
