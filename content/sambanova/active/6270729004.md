SambaNova is a leader in next-generation AI infrastructure, delivering a full-stack inference platform for customers worldwide. At the core of SambaNova's technology is the RDU (Reconfigurable Dataflow Unit) — a chip built on a dataflow architecture rather than the traditional GPU model. Its decode performance is especially strong for agentic workloads like multi-turn agents, code generation, and long-running applications. RDUs are packaged into SambaRack, rack-scale hardware that lets customers deploy state-of-the-art models with better performance, greater energy efficiency, and faster time to value.

**About the Team**

The compiler team at SambaNova powers the RDU through a unique compilation strategy. By fusing kernels into dataflow graphs that run across the entire accelerator architecture, we avoid sequential kernel launches and eliminate the memory traffic that bottlenecks conventional hardware. This is a key differentiator and unlike any other product on the market.

**About the Role**

As a Compiler Engineer Intern, you'll work on a scoped project in a core area of our compiler, such as the IR and pass infrastructure, model lowering and partitioning, tensor tiling, memory management, or mapping operations onto the fabric. Compiler and hardware design are closely linked here, and you'll see how compiler decisions affect chip performance. You'll write real code in C++ and Python, debug at a low level, and work with the runtime and hardware teams. A dedicated mentor and senior engineers will review your code and guide you through your project.

**Responsibilities**

* Implement and test passes in the compiler's IR and pass infrastructure Help lower and partition machine learning models for execution on the RDU Contribute to tensor tiling and memory management for on-chip memory Explore how operations are mapped onto the RDU fabric to improve model performance
* Debug compiler and performance issues in C++ and Python with guidance from your mentor
* Present your project results to the team at the end of your internship
