SambaNova is a leader in next-generation AI infrastructure, delivering a full-stack inference platform for customers worldwide. At the core of SambaNova's technology is the RDU (Reconfigurable Dataflow Unit) — a chip built on a dataflow architecture rather than the traditional GPU model. Its decode performance is especially strong for agentic workloads like multi-turn agents, code generation, and long-running applications. RDUs are packaged into SambaRack, rack-scale hardware that lets customers deploy state-of-the-art models with better performance, greater energy efficiency, and faster time to value.

**About the Team**

The Runtime team owns the lowest level of the SambaNova software stack, the layer that talks directly to the hardware. We build the user libraries, drivers, networking, and system tools that run ML training and inference across SambaStack and SambaCloud.

**About the Role**

As a Runtime Engineer Intern, you'll write code in C/C++/Rust and Python on a scoped project across drivers, user space libraries, networking, or system tools. You'll get exposure to driver bring-up on next generation silicon, help test runtime features on large multi-node systems, and learn how to track down performance bottlenecks alongside the hardware and compiler teams. A dedicated mentor will guide you throughout the internship.

**Responsibilities**

* Contribute to kernel drivers for next generation SambaNova silicon
* Help build user space libraries that make efficient use of hardware resources Investigate networking bottlenecks within and across nodes
* Build or extend tools for profiling, debugging, and job and hardware management Help test runtime features on large multi-node systems
* Work with the hardware and compiler teams to diagnose performance issues Present your project results to the team at the end of your internship

**Required Qualifications**

* Currently pursuing a B.S., M.S., or Ph.D. in Computer Science, Computer Engineering, or a related field
* Solid programming skills in C/C++/Rust and Python
* Coursework or project experience with high speed networking such as RDMA, RoCE, or InfiniBand
* Familiarity with distributed communication libraries such as MPI, NCCL, or UCX
* Exposure to writing Linux kernel drivers or other system level software Experience with Linux anddebugging tools such as GDB

**Preferred Qualifications**

* Pursuing an M.S. or Ph.D. in Computer Science, Computer Engineering, or a related field
* Familiarity with PCIe
* Experience with profiling or performance analysis tools
* Prior internship or research experience in systems software, networking, or performance engineering
* Open source project ownership or contributions
