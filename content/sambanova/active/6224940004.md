SambaNova is a leader in next-generation AI infrastructure, delivering a full-stack inference platform for customers worldwide. At the core of SambaNova's technology is the RDU (Reconfigurable Dataflow Unit) — a chip built on a dataflow architecture rather than the traditional GPU model. Its decode performance is especially strong for agentic workloads like multi-turn agents, code generation, and long-running applications. RDUs are packaged into SambaRack, rack-scale hardware that lets customers deploy state-of-the-art models with better performance, greater energy efficiency, and faster time to value.

### **About the Team**

The Cloud Platform team runs the production inference service that serves SambaNova's models to customers on RDU accelerators. We handle deployment, monitoring, capacity planning, and incident response across regions in the United States, Asia, Europe, and Latin America.

### **About the Role**

As a new grad Cloud Platform Engineer, you'll write automation and infrastructure code that keeps our inference service fast and available. You'll build monitoring and dashboards, manage Kubernetes clusters and Terraform modules, help stand up new regions, and join a shared on-call rotation once you're ramped up.

### **Responsibilities**

* Build monitoring, alerting, and dashboards in Prometheus, Grafana, and Datadog
* Manage cloud and on-prem infrastructure as code with Terraform and Ansible
* Operate and maintain Kubernetes clusters that run our inference workloads
* Help automate setup of AI infrastructure in new regions
* Build CI/CD pipelines that deploy new model versions and service updates safely
* Participate in a shared on-call rotation and incident response

### **Required Qualifications**

* B.S. in Computer Science, Computer Engineering, or related field
* Strong programming or scripting skills in Python, Go, or a similar language
* Familiarity with Linux and command line tools
* Coursework or project experience in distributed systems, networking, or cloud computing
* Understanding of networking fundamentals, including TCP/IP, DNS, and HTTP
* Experience with Docker and Kubernetes
* Experience with a public cloud provider such as AWS, GCP, or Azure
* Experience with Terraform or other infrastructure as code tools
* Experience with monitoring tools such as Prometheus or Grafana
* Experience with CI/CD tools such as GitHub Actions, Jenkins, or ArgoCD

### **Preferred Qualifications**

* M.S. in Computer Science, Computer Engineering, or related field
* Familiarity with model serving frameworks such as vLLM or SGLang
* Internship experience in site reliability, DevOps, or backend infrastructure
* Open source project ownership or contributions
