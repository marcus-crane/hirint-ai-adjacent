SambaNova is a leader in next-generation AI infrastructure, delivering a full-stack inference platform for customers worldwide. At the core of SambaNova's technology is the RDU (Reconfigurable Dataflow Unit) — a chip built on a dataflow architecture rather than the traditional GPU model. Its decode performance is especially strong for agentic workloads like multi-turn agents, code generation, and long-running applications. RDUs are packaged into SambaRack, rack-scale hardware that lets customers deploy state-of-the-art models with better performance, greater energy efficiency, and faster time to value.

**About the Team**

The Runtime team owns the lowest level of the SambaNova software stack, the layer that talks directly to the hardware. We build the user libraries, drivers, networking, and system tools that run ML training and inference across SambaStack and SambaCloud.

**About the Role**

As a new grad Runtime Engineer, you'll write production code in C/C++/Rust and Python across drivers, user space libraries, networking, and system tools. You'll help bring up drivers on next generation silicon, test and deploy runtime features on large multi-node systems, and track down performance bottlenecks with the hardware and compiler teams.

**Responsibilities**

* Develop and maintain kernel drivers for next generation SambaNova silicon
* Build user space libraries that make efficient use of hardware resources
* Find and fix networking bottlenecks within and across nodes
* Build tools for profiling, debugging, and job and hardware management
* Test and deploy runtime features on large multi-node systems
* Work with the hardware and compiler teams to diagnose and fix performance issues

**Required Qualifications**

* B.S. in Computer Science, Computer Engineering, or related field
* Strong programming skills in C/C++/Rust and Python
* Experience with high speed networking such as RDMA, RoCE, or InfiniBand
* Experience with distributed communication libraries such as MPI, NCCL, or UCX
* Experience writing Linux kernel drivers or other system level software
* Experience with Linux and debugging tools such as GDB

**Preferred Qualifications**

* M.S. or Ph.D. in Computer Science, Computer Engineering, or related field
* Familiarity with PCIe
* Experience with profiling or performance analysis tools
* Internship or research experience in systems software, networking, or performance engineering
* Open source project ownership or contributions
