SambaNova is a leader in next-generation AI infrastructure, delivering a full-stack inference platform for customers worldwide. At the core of SambaNova's technology is the RDU (Reconfigurable Dataflow Unit) — a chip built on a dataflow architecture rather than the traditional GPU model. Its decode performance is especially strong for agentic workloads like multi-turn agents, code generation, and long-running applications. RDUs are packaged into SambaRack, rack-scale hardware that lets customers deploy state-of-the-art models with better performance, greater energy efficiency, and faster time to value.

**About the Team**

The Post-Silicon Validation team brings up, debugs, and validates the high-speed IO and memory subsystems in SambaNova systems. We characterize and stress test silicon, root-cause issues across silicon, board, and software, and build our own debug tools and automation.

**About the Role**

As a new grad Post-Silicon Validation Engineer, you'll test new RDU silicon in the lab. You'll run characterization and stress tests on interfaces like PCIe, Ethernet, and HBM, write Python scripts to automate testing and analyze results, and help debug issues with the design, firmware, and system teams.

**Responsibilities**

* Run functional, characterization, stress, and performance tests on high-speed IO and memory subsystems
* Write scripts to automate validation, debug, and data analysis
* Help debug issues across silicon, board, and software with design, firmware, and system teams
* Use lab equipment such as oscilloscopes and protocol analyzers to diagnose failures
* Support bring-up of new silicon and systems
* Feed findings back to pre-silicon verification to improve coverage

**Required Qualifications**

* B.S. in Electrical Engineering, Computer Engineering, or related field
* Coursework or project experience in digital design, computer architecture, or high-speed interfaces
* Scripting experience in Python or bash
* Strong analytical and data analysis skills

**Preferred Qualifications**

* M.S. in Electrical Engineering, Computer Engineering, or related field
* Familiarity with PCIe, Ethernet, HBM, CXL, or UCIe
* Hands-on lab experience with oscilloscopes, protocol analyzers, or BERTs
* Familiarity with SerDes concepts
* Ability to read and debug C/C++
* Internship experience in validation, bring-up, or hardware test
