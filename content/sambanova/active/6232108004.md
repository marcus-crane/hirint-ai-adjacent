SambaNova is a leader in next-generation AI infrastructure, delivering a full-stack inference platform for customers worldwide. At the core of SambaNova's technology is the RDU (Reconfigurable Dataflow Unit) — a chip built on a dataflow architecture rather than the traditional GPU model. Its decode performance is especially strong for agentic workloads like multi-turn agents, code generation, and long-running applications. RDUs are packaged into SambaRack, rack-scale hardware that lets customers deploy state-of-the-art models with better performance, greater energy efficiency, and faster time to value.

### **About the team**

We take frontier open-weight models (dense, mixture-of-experts with hundreds of experts, hybrid Mamba/attention, sliding-window attention, multi-token prediction) from Hugging Face to production serving on SambaNova's RDU dataflow accelerators. That means compiling them, proving them numerically correct against the reference, serving them with the full feature set, and merging the work into a shared stack so the next model is cheaper.

### **About the role**

You will bring new open-weight LLMs, including dense, mixture-of-experts, and hybrid Mamba/attention architectures, up on SambaNova’s RDU dataflow accelerators and into production serving. That means adapting the model, mapping it across chips and hosts, compiling it, and validating it numerically against the reference. You also build inference features like continuous batching, speculative decoding, and FP8/FP4 as shared modules, so each new model costs less to bring up.

### **Responsibilities**

* Bring up new LLM architectures end to end: model adaptation, checkpoint conversion, multi-chip / multi-host mapping, compile, strict numerical validation, production serving with latency / throughput numbers.
* Build inference features once as shared modules: continuous batching over a paged KV pool, prompt caching, chunked and incremental prefill, dynamic tensor shapes, speculative decoding (EAGLE-3, drafters, MTP), FP8 / FP4, tensor and expert parallelism.
* Debug where model, compiler and hardware meet; land each fix in the right shared component.
