SambaNova is a leader in next-generation AI infrastructure, delivering a full-stack inference platform for customers worldwide. At the core of SambaNova's technology is the RDU (Reconfigurable Dataflow Unit) — a chip built on a dataflow architecture rather than the traditional GPU model. Its decode performance is especially strong for agentic workloads like multi-turn agents, code generation, and long-running applications. RDUs are packaged into SambaRack, rack-scale hardware that lets customers deploy state-of-the-art models with better performance, greater energy efficiency, and faster time to value.

# **Cloud Platform Engineer Intern**

**San Jose, California Office**

### **About the Team**

The Cloud Platform team runs the production inference service that serves SambaNova's models to customers on RDU accelerators. We handle deployment, monitoring, capacity planning, and incident response across regions in the United States, Asia, Europe, and Latin America.

### **About the Role**

As a Cloud Platform Engineer Intern, you'll write automation and infrastructure code that keeps our inference service fast and available. You'll build monitoring and dashboards, work with Kubernetes clusters and Terraform modules, help with standing up new regions, and shadow our on-call rotation to see how incidents are handled. A dedicated mentor will guide you throughout the internship.

### **Responsibilities**

* Build monitoring, alerting, and dashboards in Prometheus, Grafana, and Datadog Help manage cloud and on-prem infrastructure as code with Terraform and Ansible Work with the Kubernetes clusters that run our inference workloads
* Help automate setup ofAI infrastructure in new regions
* Contribute to CI/CD pipelines that deploy new model versions and service updates safely
* Shadow the on-call rotation and incident response
* Present your project results to the team at the end of your internship

### **Required Qualifications**

* Currently pursuing a B.S. or M.S. in Computer Science, Computer Engineering, or a related field
* Solid programming or scripting skills in Python, Go, or a similar language Familiarity with Linux and command line tools
* Coursework or project experience in distributed systems, networking, or cloud computing
* Understanding of networking fundamentals, including TCP/IP, DNS, and HTTP Familiarity with Docker and Kubernetes
* Exposure to a public cloud provider such as AWS, GCP, orAzure
* Exposure to Terraform or other infrastructure as code tools
* Exposure to monitoring tools such as Prometheus or Grafana
* Exposure to CI/CD tools such as GitHub Actions, Jenkins, orArgoCD

### **Preferred Qualifications**

* Pursuing an M.S. in Computer Science, Computer Engineering, or a related field Familiarity with model serving frameworks such as vLLM or SGLang
* Prior internship experience in site reliability, DevOps, or backend infrastructure
* Open source project ownership or contributions
