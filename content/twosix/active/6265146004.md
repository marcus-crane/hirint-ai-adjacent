At Two Six Technologies, we build, deploy, and implement innovative products that solve the world’s most complex challenges today. Through unrivaled collaboration and unwavering trust, we push the boundaries of what’s possible to empower our team and support our customers in building a safer global future.

Two Six Technologies is looking for a Senior Test Engineer to join a key program team focused on delivering high-quality, mission-critical software solutions.

**Location: Herndon, VA**

**What you will do:**

* Design, implement, and maintain automated tests for functional, end-to-end, regression, and performance testing
* Execute manual tests as a supplement with automation
* Develop and refine test scripts using tools like Selenium (Java) and scripting languages such as Bash or PowerShell
* Investigate software issues, reproduce defects, and create bug reports and/or feature requests
* Collaborate with development teams to identify root causes and drive timely resolutions
* Participate in test planning and reviews for new features and product enhancements
* Work closely with teams responsible for interdependent components across the system
* Ensure test coverage and integration testing across multiple services or environments

**What you will need:**

* 10+ years of experience in software testing and quality assurance
* 5+ years of hands-on experience with automated testing and test automation frameworks
* Strong knowledge of testing methodologies, QA processes, and best practices
* Experience working in Agile/Scrum environments
* Proficiency with automated tools such as Selenium (Java)
* Ability to write and refine scripts in Bash, PowerShell, or similar scripting languages
* Strong troubleshooting skills and attention to detail
* Excellent communication and collaboration skills

**Nice If You Have Experience with:**

* AI-assisted test case generation -- Use AI to generate test scenarios from requirements and user stories.
* AI-assisted test automation -- Use AI tools to help create, maintain, and troubleshoot automated tests.
* Experience with Git and Continuous Integration tools (e.g., Jenkins, GitLab CI)
* Familiarity with both Linux and Windows environments
* Experience in an AWS cloud-based environment
* Knowledge of Java, JMeter, or performance testing tools
* Exposure to Playwright (Node.js-based framework)
* Understanding of Docker and containerized testing environments

**Clearance Requirement:**  
•    Active TS/SCI with Polygraph
