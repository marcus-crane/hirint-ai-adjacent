**Overview of Opportunity**

We are seeking a Release Train Engineer to serve in a dual capacity: supporting core feature development (~60%) while acting as the primary Release Engineer / Pipeline Guardian (~40%).

In this role, you will write clean, production-ready code while maintaining ownership of our software delivery pipeline. You will orchestrate release flows across DEV, TEST, and PROD environments, establish pipeline execution standards, enforce dependency management, and ensure frontend/backend compatibility during deployments.

This position is ideal for an engineer looking to grow into release architecture, DevOps coordination, and software delivery management.

**What you will do:**

* **Full Stack Software Engineering (~60%)**
  + Design, implement, and maintain scalable feature code across the full technology stack.
  + Develop, test, and deploy new code and efficient software solutions
  + Participate in code reviews and ensure high-quality and reusable code.
  + Troubleshoot and debug issues in the application, including performance optimization and error handling
  + Provide continuous maintenance, support, and enhancements in existing systems and platforms.
  + Strong proficiency with Go programming language and best practices (or other modern programming languages)
  + Collaborate with engineering team members to ensure code quality and system performance.

* **Release Engineering & Pipeline Governance (~40%)**
  + Review and sequence incoming MRs to minimize deployment risks, verify BE/FE compatibility, and streamline delivery schedules.
  + Coordinate and execute deployment cycles across DEV, TEST, and PROD environments, targeting a 1–2 day stabilization window between stages.
  + Validate post-deployment installation integrity, resolve database/index mapping issues, and perform smoke tests on core functionality.
  + Inspect exception dashboards post-release to identify, troubleshoot, and resolve deployment-related issues alongside development teams.
  + Communicate post-deployment procedures (e.g., manual scripts, data re-processing) and maintain release documentation.

**What you will need:**

* 3+ years of professional software development experience across frontend and backend technologies.
* Mastery of Git workflows, complex merge strategies, conflict resolution, and release branching strategies.
* Active Top Secret (TS) clearance with willingness to undergo a Counterintelligence (CI) Polygraph.
* Familiarity with CI/CD tools, build automation, and code-review workflows.
* Strong interpersonal and organizational skills to coordinate releases under pressure and resolve engineering bottlenecks diplomatically.

**Nice to haves:**

* Background supporting operational software systems, intelligence analysis tools, or government mission software.
* Hands-on experience with database index configurations, automated test suites (e.g., Cypress), and application monitoring dashboards.
* Basic understanding of infrastructure-as-code, deployment scripting, or containerized environments.
* SAFe RTE, AWS Certified Developer, or related Agile/DevOps certifications.

**Security Clearance:**

* Active TS/SCI with Polygraph.
