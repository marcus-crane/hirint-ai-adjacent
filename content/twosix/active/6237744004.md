**Overview of Opportunity**

Two Six Technologies is seeking a Cybersecurity Researcher to join a mission-driven team focused on network exploitation and security research. This is a hands-on role supporting national security operations through technical analysis, vulnerability discovery, and system defense. You'll work alongside senior engineers and researchers to develop tools, techniques, and insights that shape the future of cyber capabilities.

**What You Will Do:**

* Analyze and characterize network traffic to identify vulnerabilities, anomalies, and adversary behaviors
* Support the development of detection techniques and countermeasures for network-based threats
* Perform network protocol analysis and reverse engineering of communication systems
* Discover and assess unpublished software and network vulnerabilities
* Conduct research and develop tools to support full-spectrum cyber operations
* Collaborate with technical teams to improve system security and advise on mitigations
* Contribute to internal toolsets for traffic analysis, parsing, and vulnerability research
* Support code analysis, rapid prototyping, and capability development

**What You Will Need:**

* Bachelor’s degree in Computer Science, Cybersecurity, Computer Engineering, or a related technical field
* Understanding of core networking concepts (TCP/IP, DNS, HTTP/S, routing, etc.)
* Familiarity with traffic analysis tools (e.g., Wireshark, Zeek, tcpdump)
* Programming experience in Python, C, C++, or similar languages
* Experience working in Linux/UNIX environments and using command-line tools
* Exposure to vulnerability research, protocol analysis, or network security through labs, projects, or prior work
* Familiarity with version control systems (e.g., Git)
* Clearance Eligible

**Nice to Have:**

* Hands-on experience with protocol analysis or network exploitation
* Familiarity with reverse engineering tools and techniques
* Experience using static/dynamic code analysis or binary analysis tools
* Exposure to container technologies (e.g., Docker)
* Understanding of scripting for packet parsing and automation
* Strong communication skills for documenting findings and collaborating with technical teams
* DoD 8570 certification (e.g., Security+, CySA+), or willingness to obtain
