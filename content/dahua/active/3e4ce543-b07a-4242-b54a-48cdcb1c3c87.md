## 职位描述

1、负责国内海外各区重点项目竞争性测试及入围工作，协调相关资源参与，负责项目全周期管理/测试/跟进，保障项目顺利完成，对项目的技术结果负责；

2、积极响应市场等一线问题反馈，做好区域项目问题管理及分析定位。针对重大问题风险，能够拉通资源专项会议讨论，快速提供有效的解决方案；

3、撰写准确、易读的产品技术培训文档（现场安装指导、常见问题等），面向一二线技术，完成对应的技术赋能培训；

4、定期汇总产品相关问题，做好项目案例复盘和总结，协调内部资源落实改进措施并形成回溯文档，推动产品质量改善和流程优化；

5、负责云 AI 能力（智能云存储、视频检索、智能体/Agent、大模型 API 等）在客户侧的接入联调，协助客户完成场景化验证与效果预期对齐；

6、参与云上业务系统的监控告警、日志分析与容量巡检，识别隐患并推动整改；参与运维工作的标准化、自动化与工具化建设，通过脚本或工具替代重复性人工操作，提升支撑效率与平台稳定性。

## 任职要求

1、本科及以上学历，计算机、通信、电子、软件工程、机械工程等工科专业优先；

2、具有云产品、物联网云平台、安防或相关领域的技术支持、交付或运维经验者优先；

3、有较强的组织协调能力，沟通表达能力和团队协作精神，有强责任心和执行力；

4、计算机操作能力强，熟练掌握Windows、Linux、数据库相关操作命令，熟悉SecureCRT、Wireshark等工具；

5、理解大模型与 AI 应用的基本概念与工作机制，包括提示工程（Prompt）、上下文窗口、检索增强生成（RAG）、工具调用（Function Calling / MCP）、智能体（Agent）、模型微调与推理部署，能独立完成大模型 API 或 AI 能力的接入联调；

6、具备 AI 效果问题的初步定界能力，能够基于日志、输入输出样本与链路数据判断问题归属，而非直接转交研发；

7、主观能动性强，抗压能力强，能适应高频出差。
