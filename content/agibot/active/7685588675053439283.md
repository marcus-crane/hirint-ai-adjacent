## 职位描述

1.负责机器人操作系统构建、部署、测试及运维相关 Web 平台和数据看板的设计、开发与维护。

2.负责平台前后端功能建设，包括任务编排、状态展示、日志查询、测试报告、质量指标及告警等能力。

3.对接 CI/CD、测试框架及内部工具，推动构建、测试和部署流程自动化、可视化。

4.持续优化平台的稳定性、易用性和可维护性，提升验证效率与交付质量。

5.与构建、测试、运维及研发团队协作，将实际业务流程沉淀为平台能力。

## 任职要求

1.3年以上后端或全栈开发经验，具备独立完成 Web 系统设计与开发的能力。

2.熟练掌握 Python、Java、Go 中至少一种后端开发语言，了解常见 Web 框架、数据库及 API 设计。

3.熟悉 JavaScript、CSS、Vue 等前端技术，能够独立完成平台页面和数据看板开发。

4.具备良好的工程能力，熟悉 Git、Linux、容器化部署及基本的系统运维知识。

5.具备较强的问题分析、跨团队沟通和业务抽象能力。

加分项

有飞书开放平台、机器人、审批、文档或多维表格集成经验。

了解机器人操作系统、自动驾驶或嵌入式系统的构建、部署与测试流程。

熟悉 Pytest、Allure 等自动化测试及报告框架。

熟悉 Jenkins、GitLab CI 等流水线的工作机制，有 CI/CD 平台集成经验。

有 DevOps、测试平台、质量看板或内部研发效能平台建设经验。
