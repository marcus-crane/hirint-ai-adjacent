## 职位描述

岗位介绍

面向双足人形机器人的操作与移动操作协同，负责云平台与机器人端之间的软件模块开发，以及机载模型推理部署与算法集成。打通云端服务、机器人推理与动作执行链路，与算法、云平台及运控团队协作，提升模型迭代效率、系统性能和真机运行可靠性。

岗位职责

1. 云端与机器人协同：负责云平台与机器人端之间的通信及服务接口开发，支持任务下发、状态回传、模型与配置同步，保障云端服务与机器人端的可靠协同。

2. 机载推理部署：负责 VLA、VLM 及操作策略在机器人端的部署与运行集成，建设模型加载、推理服务及版本更新能力，支持算法在真机上的快速验证与迭代。

3. 算法集成与执行接口：完成感知、导航、操作策略及运控模块的软件对接，开发数据处理与技能执行接口，打通观测输入、模型推理和动作执行链路。

4. 性能与稳定性优化：分析并优化云端通信、机载推理及执行链路的延迟与资源占用，完善异常处理和恢复机制；结合实际瓶颈开展推理加速与量化优化。

5. 部署与调试工具：完善软件和模型的打包、配置、发布及回滚流程，建设日志、运行监控、数据回放与远程诊断工具，提高部署和问题定位效率。

6. 系统联调与验证：协同云平台、算法及运控团队开展端到端联调与真机测试，定位跨模块问题，完善功能、性能和稳定性回归验证。

## 任职要求

任职要求

1. 计算机、软件工程、自动化、电子工程或相关专业本科及以上学历，具有机器人软件、系统软件或端云协同开发经验。

2. 熟练掌握 C++、Python 和 Linux 开发，熟悉多线程、进程间通信及网络编程，具备良好的软件工程基础。

3. 具有服务接口开发与系统集成经验，理解通信协议、连接管理、数据一致性及异常恢复等基本问题。

4. 熟悉 ROS/ROS2 或同类机器人中间件，或具有模型推理服务、端侧运行时的开发与集成经验。

5. 具备较强的调试与问题定位能力，能够利用日志、数据回放和性能分析工具解决跨模块问题。

6. 重视代码质量、测试、版本管理与部署可复现性，能够与云平台、算法及硬件团队协作完成工程交付。

加分项

- 具有机器人云端协同、远程任务管理、模型下发或设备软件更新经验。

- 具有 NVIDIA Jetson Orin、Jetson Thor 等端侧计算平台的开发与部署经验。

- 具有 VLA、VLM 或机器人操作策略部署经验，熟悉 TensorRT、ONNX Runtime 等推理框架。

- 具有模型量化、推理加速、CUDA 开发或 GPU 性能分析经验。

- 具有人形机器人、移动操作机器人或机械臂的软件集成与真机联调经验。

- 具有容器化部署、持续集成、远程诊断或从 0 到 1 搭建端侧软件链路的经验。
