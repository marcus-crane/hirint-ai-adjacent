## 职位描述

岗位职责

1. 负责平台前后端功能开发与维护，覆盖数据采集、数据处理、数据集管理、训练评测、模型管理和部署等核心模块，独立完成需求分析、接口设计、页面开发及联调验证。

2. 使用 Go、Python 开发平台业务服务，建设稳定的 API 和公共组件，对接机器人设备、算法服务及任务执行节点，完善参数校验、权限控制、异常处理和接口兼容机制。

3. 开发数据上传与导入、处理流程配置、任务提交与进度查看、日志查询、失败重试和结果展示等功能，让复杂任务的执行状态清晰、可追踪、可操作。

4. 完善数据与模型资产功能，支持检索、筛选、分页、预览、版本管理及访问授权，保证页面展示、数据库记录与实际存储内容的一致性。

5. 负责平台 Web 界面与交互优化，建设可复用组件，推进首页、导航、表单及中英文国际化迭代，提升数据浏览和任务操作效率。

6. 持续优化前后端性能，定位慢接口、重复查询、阻塞调用及大列表加载等问题，合理使用数据库分页、批量查询、缓存和后台异步处理。

7. 参与测试、版本发布、线上问题排查及交付联调，编写接口和使用文档，将业务需求沉淀为稳定、可维护的平台功能。

## 任职要求

任职要求

1. 计算机或相关专业本科及以上学历，有 Web 平台开发经验，能够独立完成业务模块的前后端开发与交付。

2. 熟悉 TypeScript / JavaScript，掌握 React、Vue 等至少一种主流框架，理解组件化、状态管理、异步请求及前端工程化，能够根据原型实现页面和交互。

3. 熟练掌握 Go 或 Python，能够使用另一门语言阅读和维护代码；熟悉 Gin、FastAPI 等至少一种后端框架及 HTTP / REST API 开发。

4. 熟悉关系型数据库、SQL 和常见缓存机制，具备数据建模、索引设计、查询优化及事务处理能力。

5. 理解异步任务、并发控制和状态机，能够处理重复提交、状态更新、任务超时及失败恢复等实际问题。

6. 熟悉 Linux、Git、Docker 及基本测试和发布流程，具备结合前端、接口、日志和数据库定位问题的能力。

7. 具备产品意识和沟通能力，能够理解算法、采集及运营人员的工作流程，持续改善平台易用性。

加分项

- 有 AI 平台、数据管理平台、训练评测平台或机器人相关开发经验。

- 有视频预览、数据可视化、大文件上传、实时日志或任务进度展示经验。

- 有多租户权限、国际化、自动化测试或私有化交付经验。
