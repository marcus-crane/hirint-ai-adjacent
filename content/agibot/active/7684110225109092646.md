## 职位描述

1. 与各地算法团队联合，共同定义机器人操作能力的技术方案；负责其中抓取位姿生成、灵巧手操作、双臂协同、接触密集型任务等模块的方案设计与实现；

2. 负责任务级规划与执行框架的设计与实现，将上层语义指令分解为可执行的动作序列，并处理执行失败后的重规划；

3. 负责接触力控制与柔顺控制算法的研发与调优，提升机器人在装配、开门、插拔、擦拭等接触任务中的稳定性与安全性；

4. 负责操作技能库的构建与维护，将验证过的操作能力封装为参数化、可组合的技能接口，供 VLA 模型与上层 Agent 调用；

5. 在真机上完成操作任务的验证与迭代；与 VLA、感知、运控团队协作明确模块输入输出边界，完成端到端任务链路的联调与优化。

## 任职要求

1. 硕士及以上学历，机器人、自动化、计算机、机械电子等相关专业；

2. 熟悉机器人运动学与动力学、轨迹规划、阻抗 / 导纳控制等操作相关基础理论；

3. 熟悉以下一个或多个方向：

1. 灵巧手 / 多指手操作与抓取规划；

2. 接触力控制、柔顺控制、力位混合控制；

3. 任务与运动联合规划（TAMP）、行为树 / 状态机等任务执行框架；

4. 模仿学习或强化学习在操作任务上的应用；

4. 熟练使用 C++ / Python，有 ROS / ROS2 及 MuJoCo、Isaac Lab 等仿真环境使用经验；

5. 有真机操作任务调试经验，理解仿真与真机之间的差异及其处理方法；

6. 有操作功能完整交付或量产落地经验者优先；
