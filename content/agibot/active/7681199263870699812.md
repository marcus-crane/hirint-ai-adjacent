## 职位描述

岗位职责：

1. 场景化解决方案输出：包括但不限于数据采集、商业服务、科研教育、工业智造、特种作业等场景，能够设计出高质量解决方案；

2. 客户需求与售前支持：对接 B 端 / G 端 客户，开展需求调研、现场勘察、技术交流、方案汇报、招投标技术应答等工作；

3. 跨部门协同： 联动销售 / 产品 / 软件 /算法等团队 ，推动方案从需求→方案→招投标→交付→验收全流程，树立行业标杆案例；

4. 需求与市场桥梁：作为市场 - 产品需求对接窗口，收集细分场景领域产品需求与缺陷，推动产品改进与新功能立项；

5. 行业生态与竞品分析：跟踪行业与竞品动态，拓展生态合作伙伴，输出细分领域生态产品需求与差异化竞争方案。

## 任职要求

任职要求：

1. 经验要求：3年以上机器人 / AI / 自动化 / 智能制造 / 自动驾驶等行业解决方案经验，有重大项目架构设计 / 解决方案经验优先；

2. 教育背景：本科及以上学历，理工科相关专业，人工智能 / 机器人 / 电子工程 / 车辆工程等优先；

3. 对具身智能控制、应用场景及未来发展趋势有认知，逻辑清晰，沟通协调与需求架构能力强；

4. 能独立完成方案撰写、客户演示、跨部门协调，具备良好文档能力与现场表达力；

5. 具备较强的责任心、良好的团队合作和学习能力，可接受频繁短期出差。

加分项：

1. 有从 0-1 构建方案并落地标杆案例；

2. 灵巧手 / 具身智能行业经验；

3. 英语流利，可对接国际合作伙伴。

承担主要目标/关键任务

1. 售前支持：支持输出解决方案，配合销售市场部门项目拓展

2. 方案体系：建立标准版解决方案体系，打造标杆项目案例，沉淀可复用方案资产

3. 配套赋能：完善生态合作、应标资料等配套文件，推动项目方案落地
