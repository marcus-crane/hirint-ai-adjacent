## 职位描述

岗位介绍

面向双足人形机器人的双臂操作、移动操作协同与长程任务，开展 VLA、WAM、RL及 Agent 的算法研发。融合真机、Ego、UMI 等多源示教与交互数据，打通数据构建、模型预训练、后训练到真机评测的完整链路，持续提升机器人的任务理解、动作决策、技能泛化与失败恢复能力。

## 任职要求

岗位职责

1. VLA / WAM 研发： 研究视觉、语言、状态与动作的联合表示，训练并优化操作策略与世界动作模型；探索动作生成、未来状态预测及模型辅助决策，提升机器人在双臂操作与移动操作任务中的泛化能力。

2. 多源数据与预训练： 融合 Ego、UMI、真机遥操作与自主交互数据，设计动作表示、监督信号、数据配比与训练目标；探索跨数据源、跨本体迁移，系统评估数据规模、质量与混合策略对模型能力的影响。

3. 后训练与强化学习： 开展任务微调、模仿学习及离线或在线强化学习，结合奖励建模、任务成功判别、人类纠正与失败轨迹利用，提升任务成功率、执行鲁棒性与交互效率。

4. VLM 与教师模型蒸馏： 利用 GPT 等教师模型生成任务语义、子目标、推理步骤与评估信号，研究面向具身任务的知识蒸馏方法；建立生成数据的质量筛选与验证机制，将教师模型能力迁移至可部署的具身模型。

5. 具身 Agent 与长程任务： 研究任务分解、技能调用、状态记忆、执行反馈与失败恢复，探索思维链（CoT）与动作决策的结合，在推理质量、决策延迟与任务表现之间取得平衡；协同感知、导航及运控团队完成技能执行接口的设计与集成。

6. 模型评测与真机闭环： 开展模型训练、消融实验及仿真与真机评测，建立覆盖任务成功率、泛化能力、长程任务完成率与失败恢复能力的评测体系；关联数据版本、训练配置、模型权重与部署结果，通过失败分析驱动模型迭代，并协同部署团队完成真机部署与回归验证。

任职要求

1. 计算机、人工智能、机器人、自动化或相关专业硕士及以上学历，具备深度学习或机器人学习算法研发经验。

2. 熟练掌握 Python 与 PyTorch，能独立完成模型实现、训练调试、实验分析与评测。

3. 在 VLA、多模态模型、世界模型、动作生成、强化学习或具身 Agent 中至少一个方向有深入实践，能将研究方法转化为可验证的模型能力。

4. 熟悉预训练与后训练的基本方法，能分析数据分布、模型结构、动作表示及训练目标对模型效果的影响。

5. 具备完整的算法实验经验，重视基线对比、消融分析、训练与评测数据隔离及实验复现，能通过失败案例定位问题并提出改进方案。

加分项

- 有双足人形机器人双臂操作、移动操作或长程任务的真机落地经验。

- 有 Ego、UMI 或遥操作数据的使用经验，熟悉从人类示教到机器人操作策略的迁移方法。

- 具备基于 Diffusion Policy、Flow Matching 或 VLA 的机器人操作策略训练、微调与优化经验。

- 有机器人策略强化学习后训练、奖励建模或人在环学习（Human-in-the-Loop）经验。

- 有 VLM 蒸馏、GPT 等教师模型辅助监督、CoT 与动作学习结合、工具调用或具身 Agent 研发经验。

- 在机器人、计算机视觉或机器学习领域顶级会议（RSS、CoRL、ICRA、IROS、CVPR、ICCV、ECCV、NeurIPS、ICML、ICLR）发表过相关论文。
