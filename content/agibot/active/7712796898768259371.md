## 职位描述

1. 交互平台建设： 负责公司统一机器人交互 SDK 和接入平台的架构设计与落地，建设标准化、模块化的交互基础设施，支撑不同机器人产品和业务线快速接入，探索平台能力的产品化及对外输出。

2. 端侧核心架构： 负责机器人端侧核心模块设计与开发，包括通信框架、设备接入与网关、技能管理、任务调度与执行管理等，提升系统的稳定性、可扩展性和工程交付效率。

3. AI 交互技术演进： 负责语音交互全链路架构与工程落地，推动大模型、Agent、多模态等 AI 技术与机器人交互、技能执行系统深度融合。

4. 技术规划与团队建设： 主导关键技术选型、架构演进和核心技术攻关，协同算法、硬件及业务团队推动产品落地，并逐步承担小团队的技术管理和人才培养工作。

## 任职要求

1. 计算机、软件工程、自动化、机器人等相关专业，本科及以上学历，3-5年以上研发经验，有机器人、智能座舱或智能语音行业经验者优先。

2. 精通 C/C++、Linux，熟悉 ROS/ROS2，有机器人端侧软件开发、系统架构设计或 SDK/中间件建设经验。

3. 熟悉通信框架、进程间通信、任务调度、状态机等技术，有复杂端侧系统或平台从0到1建设经验。

4. 熟悉语音交互全链路，包括唤醒、VAD、ASR、TTS、对话管理等，有车载语音、机器人语音或智能语音产品落地经验。

5. 熟悉大模型及 Agent 技术，了解 Function Calling、Tool Use、任务规划等机制，有大模型与语音交互或机器人技能系统结合的实践经验者优先。

6. 具备良好的系统架构能力和工程落地能力，既能做技术规划，也能深入核心代码解决复杂问题；有小团队管理或技术负责人经验者优先。

7. 对新技术保持敏感，具备良好的沟通协作能力、学习能力和技术前瞻性。了解或实践过 Rust 者加分。
