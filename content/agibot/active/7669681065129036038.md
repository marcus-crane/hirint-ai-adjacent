## 职位描述

职位描述

1. 本岗位聚焦机器人开放平台，是连接客户、二次开发合作伙伴与平台能力的核心技术桥梁，既负责技术支持与赋能，也承担通用场景二次开发与落地部署工作，推动机器人在各行业场景的规模化应用。

2. 客户 / 伙伴技术支持：对接机器人开放平台客户与合作伙伴，提供接口使用答疑、问题排查与开发指导，涵盖运动控制、导航调度、交互音视频等全系列接口，降低二次开发门槛；

3. 通用场景开发部署：基于平台接口，完成展厅导览、展会婚庆、导购等通用场景的二次开发与部署态优化，实现功能落地、性能调优与标准化交付；

## 任职要求

职位要求

1. 本科在读，计算机、自动化、机器人工程、机电一体化等相关专业，大四优先，有充足实习时长（至少 3 个月，可全职实习优先）；

2. 了解 Linux 基础操作，掌握 Python 或 C++ 其中一门编程语言，有基础项目开发经验；了解 ROS/ROS2、机器人导航、运动控制基础概念者加分；

3. 具备基础逻辑排查能力，善于查阅技术文档，沟通表达顺畅，能够清晰记录、反馈开发过程中遇到的技术问题；

4. 做事细致有耐心，责任心强，能接受重复性调试、文档整理工作，具备良好团队协作意识；

5. 加分项：接触过人形机器人、服务机器人二次开发；使用过机器人开放平台接口；有展厅 / 导购类机器人项目实训、课程设计经验。
