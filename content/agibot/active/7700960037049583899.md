## 职位描述

岗位使命：

作为交付运营负责人，你将对数据交付的端到端结果负责：从客户项目启动、需求评审、排产，到代采商生产、数据处理、审核质检、交付上传与客户验收，确保每一条里程碑链按时、按质、按量跑通。你的目标是让交付从「靠人盯」升级为「靠体系跑」——支撑月产能数百万小时级的规模化交付。

核心职责

1.端到端交付管理：建立并运营客户项目全生命周期里程碑链（启动 → 需求评审 → 排产 → 外采 → 数据处理 → 人工审核/质检 → 交付上传 → 客户验收），对交付准时率、验收通过率负责；建立延期与风险的提前预警机制；

2.代采商网络运营：管理多家并行代采商的产能分配、场景定点、爬坡节奏与绩效结算，构建「价格—质量—产能」多维度的供应商评价与汰换体系，主导缺口场景的攻坚补位；

3.质量与验收体系：落地数据验收标准（合规、真实、标准、不串、多点等要素），联动 AutoQA 与人工审核质检流程，对交付数据的合格率、返修率负责，推动质量问题的前置预防而非事后补救；

4.产能规划与供需平衡：基于设备产能模型与客户需求预测做排产与资源调度，平衡自有产能、代采产能与设备池分配，支撑产能爬坡决策；

5.流程与数字化建设：把交付运营 SOP、看板与复盘机制沉淀为线上化系统（多维表格 / 业务系统），让进度、质量、成本可实时可视、可追溯；

6.跨部门协同：与销售/AM、产品、研发、质检、采购、财务紧密协同，打通需求—交付—结算的完整链路；

7.团队搭建与管理：从 0 到 1 搭建交付运营团队，定义岗位、培养骨干、建立考核机制。

## 任职要求

任职要求

硬性条件

1.本科及以上学历，5 年以上运营 / 交付管理 / 供应链管理经验，其中 2 年以上团队管理经验；

2.有 B 端项目制交付或服务外包管理的完整闭环经验，主导过多供应商 / 多团队并行交付的体系搭建；

3.强数据能力：能独立搭建产能测算、成本模型与经营分析看板，熟练使用 Excel / BI 工具，用数据说话是工作习惯；

4.强抗压与强推进力：能在需求多变、 Deadline 紧绷的环境下同时推进多条线，把模糊问题拆解为可执行动作；

5.优秀的跨部门沟通与谈判能力，能与客户、供应商、内部研发说同一种语言。

加分项

1.有 AI 数据服务行业经验（数据标注 / 数据采集 / 数据集交付），了解数据质检与验收逻辑；

2.有机器人、智能硬件或具身智能行业背景；

3.有众包平台 / 共享经济平台的供给侧运营经验；

4.有海外项目交付或跨时区协作经验。

5.紧密协同：销售/AM（客户项目与验收）、产品与研发（设备与数据引擎）、质检（AutoQA 与人工审核）、采购（代采商寻源与商务）、财务（结算与成本）；
