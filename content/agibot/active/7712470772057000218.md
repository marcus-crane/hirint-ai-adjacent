## 职位描述

1. 负责机器人智能交互端侧 Agent 开发工作，包括 Agent Harness 层开发；动作编排、表情组、技能、全身控制等 skills 开发和调用；以及智能语音交互 pipeline 开发等

2. 负责不同平台适配和迁移工作，包括但不限于rk3588、orin、x86等平台开发适配工作

3. 负责语音链路性能分析和优化，包括CPU、内存优化、内存泄露、端到端耗时优化等；

4. 熟悉ros2，对机器人端侧架构有一定了解和设计能力，能够和其他端侧软件模块进行接口定义和封装

5. 负责软件的调试、测试和优化，以提高机器人交互架构执行的稳定性和效率。

6. 编写技术文档和用户手册，为团队成员提供培训和指导。

7. 与跨职能团队合作，确保项目按时完成并达到预期的质量标准。

## 任职要求

1. 计算机科学、软件工程或相关领域的学士或硕士学位。

2. 2-5年 及以上工程开发经验，负责过语音交互产品的设计与开发，具备语音交互产品的接口设计与功能开发能力优先；

3. 了解语音（唤醒、ASR、TTS、声纹）及自然语言处理（NLU、DM、NLG）等基本技术和原理优先，具有独立分析定位语音链路中问题的能力；

4. 理解 Agent Harness 的作用，能够设计或优化模型调用、上下文组织、工具执行、状态维护和反馈处理机制。

5. 熟练掌握C++语音编程，熟悉常见设计模式，有扎实的面向对象设计和实现能力；

6. 具有良好的编码风格，熟悉常用的质量保证工具与技术，保证代码的质量与稳定性；

7. 抗压能力强，有ownership能够端到端负责业务模块；

8. 具有良好的沟通能力、团队合作精神，能够与产品、开发、测试等进行有效的沟通。
