## 职位描述

1. 3FS 深度定制与优化：基于 DeepSeek 开源的 3FS（Fire-Flyer File System）架构，进行深度的二次开发与性能调优。重点优化 FUSE 客户端、元数据服务（Meta Service）及存储引擎（Storage Service），完善基于对象存储的缓存机制，结合 IB / RoCE 高性能网络，实现低延迟、高吞吐的数据访问能力，消除 AI 训练与推理场景中的 I/O 瓶颈。

2. 异构资源存储化：探索并落地 GPU 直通存储（GPUDirect Storage, GDS）技术，基于 3FS 框架扩展存储后端，设计并实现一个轻量级共享存储层。旨在高效利用集群中 GPU 节点上的闲置 NVMe 数据盘，显著降低基础设施成本。

3. 存储栈内核级调优：针对大规模分布式存储系统进行全栈优化，包括 RDMA 协议栈参数调优、VFS/FUSE 内核交互逻辑优化以及内存管理策略调整，确保在高并发、大数据量场景下系统的稳定性与 SLA。

4. 技术演进与落地：跟进高性能计算（HPC）及云原生存储的前沿架构，将业务痛点（如 Checkpointing 慢、小文件加载难）转化为具体的存储解决方案，并推动在生产环境落地。

## 任职要求

1. 编程能力：精通 C/C++ 或 Rust（具备 Rust 工程经验者优先），具备深厚的 Python/Go 开发能力；拥有扎实的计算机系统基础（操作系统、编译原理、计算机网络）。

2. 高性能网络：深入理解 InfiniBand (IB) 或 RoCE 网络架构，具有 RDMA、Zero-copy、Kernel Bypass 等相关技术的实战研发经验。

3. 分布式存储内核：熟悉主流分布式存储架构（如 Ceph、Lustre、DAOS 等），了解 Alluxio、JuiceFS 等缓存层设计；有对象存储（S3 兼容）或文件系统（POSIX）的深度开发经验；有 3FS 或其他高性能文件系统源码阅读经验者优先。

4. 硬件与系统底层：熟悉 NVMe 协议及 SSD 特性，了解 PCIe P2P、DMA 等技术；有 Linux 内核开发或存储驱动开发经验者优先。

5. AI 基础设施经验：熟悉 AI 训练/推理流程，深刻理解 Checkpointing、Dataset Loading 对存储的性能诉求，具备相关优化经验。
