## 职位描述

承担研发平台和自动化工具开发、日常云运维交付和一线保障。

岗位职责

- 建设 GitLab 研发流水线，维护代码仓库、权限和 CI Runner。开发团队共用的 CI/CD 模板，自动完成代码检查、测试和镜像构建，支持 Infra 服务的灰度发布与回滚。

- 维护训练、评测和推理共用的基础镜像及镜像仓库。关联代码提交、镜像版本和任务配置，让实验环境可复现，并优化多架构镜像的构建、分发和拉取速度。

- 开发算力与云资源自助工具，让研发人员按项目申请 GPU、存储和网络。把权限、配额、预算告警和闲置资源回收纳入流程，减少工单往返。

- 受理云资源和账号权限工单，办理云主机、存储及网络资源的开通、变更与回收，更新台账并对接云厂商完成交付。每月初核对云服务费用，处理账单差异，提交 OA 报账并跟进审批。

- 建设 GPU 和 Kubernetes 集群的监控与诊断工具，关联作业日志、调度事件和节点指标。承担一线技术支持、日常巡检和 On-call 轮值，响应用户请求和告警，收集日志、处理常见故障。对复杂故障协调研发团队或云厂商恢复服务，验证恢复结果，并将重复故障做成自动检查和恢复流程。

- 将 AI Agent 接入流水线日志、告警和排障手册，自动收集故障证据、给出可验证的排查建议。与算法和平台团队复盘，用环境准备时长、故障定位耗时和重复工单量衡量改进。

任职要求

- 本科及以上学历，计算机相关专业，具备 3 年以上公有云运维经验，有运维开发、研发平台或 SRE 项目经历。

- 具备扎实的编程能力，熟练使用 Go、Python 等至少一门语言，能独立开发、测试、上线并持续维护团队使用的工具或服务。

- 有 Git 协作和 CI/CD 实践，能编写流水线、排查 Runner 与构建问题。熟悉 Dockerfile、镜像仓库，能使用 Kubernetes 和 Helm 完成部署、验证与回滚。

- 熟悉 Linux、Kubernetes 及公有云网络、存储与权限。能独立执行云资源变更、巡检和值班排障，结合指标、日志和事件定位问题，并按流程核对资源台账与云账单、跟进工单和报账。

- 会使用 AI Agent 辅助编码和排障，能通过测试、日志或复现验证它给出的代码、配置与诊断结论。

加分项

- 有 GPU 训练或推理集群实践，开发过 Kubernetes Operator、监控采集器或节点健康检查工具，或参与过相关开源项目。

- 做过团队实际使用的研发自助平台、镜像分发优化或运维 Agent，能用上线前后的数据说明节省了多少等待或排障时间。

- 有多云资源治理、权限或成本优化经验，熟悉 Terraform、Ansible 等基础设施自动化工具。
