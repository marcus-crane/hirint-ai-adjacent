## 职位描述

1. 与各地算法团队联合，共同定义面向全尺寸人形机器人的自主导航技术方案；负责其中导航决策、轨迹预测与动态避障相关模块的方案设计与实现；

2. 负责 VLM-Nav / VLN 相关算法研发，构建视觉-语言-动作闭环能力，实现自然语言指令理解、语义目标定位、路径规划及自主执行；

3. 负责导航 Planner 模型的研发，探索并应用 Transformer、Diffusion、World Model 等新一代规划算法，实现 Waypoint 预测、轨迹生成及复杂环境下的自主决策；

4. 与感知团队协同定义环境表征接口，基于 BEV、Occupancy、语义地图等表征完成导航决策；与运动控制团队协同定义导航—运控接口，保障规划轨迹在双足平台上的可执行性；

5. 在真机上完成导航能力的验证与迭代，持续提升复杂地形、人群环境及动态场景下的运动稳定性与导航成功率。

## 任职要求

1. 硕士及以上学历，计算机、机器人、人工智能等相关专业，博士优先；

2. 熟悉机器人导航、Embodied AI、VLM / VLA、VLN 等相关方向，具有较扎实的算法基础；

3. 熟悉以下一个或多个方向：

1. 端到端自主导航（End-to-End Navigation）；

2. Planner 模型（Transformer、Diffusion、World Model 等）；

3. 轨迹预测与运动规划（Trajectory Prediction、Motion Planning）；

4. VLM-Nav / Vision-Language Navigation；

4. 熟悉深度学习框架（PyTorch 等），具备模型训练、调优、部署及性能优化经验；

5. 具备较强的问题分析及工程实现能力，能够独立完成算法设计、实验验证、性能分析及真机问题定位；

6. 有导航算法真机落地或量产交付经验者优先；
