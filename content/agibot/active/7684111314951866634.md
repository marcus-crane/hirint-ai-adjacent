## 职位描述

1. 与各地算法团队联合，共同定义人形机器人学习型运动控制的技术方案，负责控制策略的预研、训练与验证；

2. 负责深度强化学习运动控制策略的训练、调优与评估；探索并复现前沿运控方法，包括但不限于感知运控、生成式运控、loco-manipulation 等方向，评估其在产品场景下的适用性；

3. 负责研究成果向量产项目的交付与转化，输出可复现的训练流程、模型与评估报告，配合业务完成工程化落地与上线；

4. 支持 Skill 参数化、组合执行以及不同场景下的泛化，为上层 VLA 模型与 Agent 提供稳定、清晰、可调用的机器人运动能力接口。

## 任职要求

1. 本科及以上学历，控制工程与控制理论、机械电子、计算机、自动化等相关专业；

2. 熟悉人型机器人深度强化学习运动控制的训练和调优，有实机经验；

3. 掌握 C++、Python 编程语言，熟练使用 Isaac Lab、mjlab、MuJoCo 等仿真器；

4. 发表过相关论文（T-RO、RSS、CoRL、RA-L、ICRA、IROS、ICLR 等）或有机器人竞赛（如 RoboMaster、RoboCup、DARPA 挑战赛等）经验优先录取。
