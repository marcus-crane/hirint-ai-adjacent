## 职位描述

一、岗位定位

我们是支撑全公司模型 “训得动、推得省、卖得出” 的性能中台。本岗不是传统意义上的行政型 PM，而是懂技术的项目负责人：把 “训练集群 MFU、云端推理单位成本、端侧实时性与功耗” 这三条性能主线，拆成可度量、可交付、可复盘的工程目标，并推动算法、业务、基建、芯片厂商多方协同执行到位。你不需要自己写完所有代码，但必须能看懂 profiling、能判断技术路线对错、能为一次优化算出它值多少钱。

二、岗位职责

1. 训练侧性能与稳定性

负责万卡级集群训练效能项目：MFU 提升、显存与通信优化、并行策略（DP/TP/PP/EP）选型与调优目标管理。

负责长稳与容错专项：节点故障率治理、checkpoint 异步化与快速恢复、免重调度换节点、训练任务 SLA。

统筹具身统一训练框架、后训练（SFT/RL 微调）、数据蒸馏与仿真链路的性能需求排期与验收。

2. 云端推理与成本

负责 MaaS/token 服务性能与成本双目标：TTFT、TPOT、吞吐、P99 时延的指标定义、基线与达标路径。

推动 PD 分离、KV Cache（含多模态前缀缓存）利用率、投机解码、低精度量化等关键技术的落地节奏与收益核算。

参与算力经营：自建池与外部供应商的流量调度、潮汐削峰填谷、cache 亲和性约束下的成本最优方案。

3. 端侧与端云协同

负责机器人本体推理优化的项目化管理：算子替换、多核并行、前后处理融合、量化与功耗达标。

拉通云端与端侧的模型切分、降级与一致性策略，明确端云分工与验收口径。

4. 机制与度量建设

建立跨团队统一的性能指标体系与看板（时延、吞吐、资源利用率、单位 token 成本、稳定性），让优化收益可量化、可归因。

建立需求准入、收益评估、灰度验证、复盘沉淀的闭环流程；输出技术决策记录与风险台账。

对接芯片 / 云厂商等外部伙伴，管理适配进度与联调验收。

## 任职要求

三、任职要求

必备

硕士及以上，计算机 / 电子 / 自动化 / 机械电子等相关专业；5 年以上 AI 系统工程、推理或训练优化相关经验，其中 2 年以上跨团队项目主导经验。

熟悉大模型推理或训练至少一侧的完整链路，能与工程师就并行策略、KV Cache、投机解码、量化、算子与编译等议题进行实质性技术对话。

具备强数据意识：习惯用 profiling 与线上指标定位瓶颈，能量化 “优化前 / 后” 的收益（时延、吞吐、成本、功耗），拒绝 “感觉变快了” 式结论。

具备跨组织推动力：能在算法、业务、基建、供应商之间对齐目标、拆解依赖、处理冲突并按时交付。

具备成本与商业视角：理解单位算力 / 单位 token 的成本结构，能做投入产出测算。

加分

有千卡以上集群训练稳定性、checkpoint / 容错体系或国产加速卡适配经验。

有公有云 MaaS、token 服务商业化或算力资源调度（削峰填谷、多供应商）实操经验。

有机器人、自动驾驶、具身智能等端侧实时推理与功耗优化经验。

有从 0 到 1 搭建性能度量体系或研发效能平台的经历。

四、前 6 个月成功标准

输出训练、云端推理、端侧三条主线的性能基线报告与季度目标树，指标口径全公司对齐。

至少主导 2 个高价值专项闭环（如训练 MFU 提升、推理单位成本下降），收益经业务侧复核确认。

建立常态化跨团队协同机制，关键依赖项的排期与风险可视、可追踪。

完成一轮外部伙伴（芯片 / 云厂商）适配与联调的节奏管理，形成可复用的协作范式。

五、我们提供

真实规模战场：万卡级训练集群、对内对外并行的 token 服务、机器人本体的端侧推理，三条线都能摸到硬件底。

直接对业务结果负责的空间：性能即成本，优化直接体现在毛利与产品体验上。

小团队高密度协作（30 人规模、扁平结构），跨调度、框架、算子、通信、内存、编译全栈可见。
