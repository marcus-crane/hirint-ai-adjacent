## 职位描述

1. 面向实际业务场景开发机器人端应用，将算法、运动控制及交互能力整合为可运行、可交付的功能。

2. 设计并实现基于 ROS/ROS2 的模块接口与通信流程，推进感知、导航、语音交互等子系统的接入和联调。

3. 打通机器人与云端平台的数据链路，支持任务下发、状态上报、日志采集及配置同步。

4. 跟进软件从开发到现场运行的全过程，完成部署、升级和问题处理，支持项目验收与交付。

5. 与算法、运控、硬件及平台团队共同分析系统问题，持续优化通信效率、运行性能和稳定性，并沉淀接口规范与调试、部署文档。

## 任职要求

1. 本科及以上学历，计算机、自动化、机器人、电子信息等相关专业。

2. 具备 3 年以上 Linux 软件开发经验，能够使用 C++ 或 Python 独立完成模块开发与调试。

3. 有 ROS/ROS2 开发实践，理解节点通信及 Topic、Service、Action、TF 等机制，能够开展模块对接和系统联调。

4. 掌握 TCP/UDP、HTTP、WebSocket 或 DDS 等通信方式中的至少一种，具备接口开发和通信问题定位能力。

5. 能够使用 Git、CMake、Shell 等工具完成版本管理、构建和部署，具备良好的代码与文档习惯。

6. 能够主动推动跨团队问题解决，适应机器人项目的现场调试及交付工作。

加分项

1. 参与过人形机器人、机械臂、AGV/AMR 或服务机器人的应用开发与系统集成。

2. 在 NVIDIA Jetson/Orin 或其他 ARM 计算平台上有开发、部署或调优经验。

3. 有客户现场实施经验，参与过机器人项目从集成调试到验收交付的完整过程。
