## 职位描述

用学习方法让全尺寸人形机器人在真实世界里稳定地动、灵巧地做、自然地交流，研究成果要落到真机和产品上。

你将负责(四个方向，按背景选一)

方向一：具身基础模型

- 研究并训练面向人形机器人的VLA、世界模型或动作生成模型，覆盖感知、语言、动作的统一表征。

- 设计数据配方：真机遥操作、仿真、人类视频的混合与配比，跨本体迁移。

- 研究大模型在机器人上的推理效率：动作分块、蒸馏、端侧部署。

- 和数据平台、评测系统一起定义训练与评测闭环。

方向二：人形机器人全身运控

- 基于强化学习和模仿学习，研究全尺寸人形的行走、跑跳、抗扰、起身、地形适应。

- 全身运动跟踪与动作重定向：从动捕、视频中学习自然动作，并稳定迁移到真机。

- 解决 sim2real：域随机化、系统辨识、执行器建模。

- 把运控策略做成能被上层模型调用的技能接口。

方向三：全身灵巧操作

- 研究人形机器人双臂加灵巧手的操作策略，包括抓取、装配、工具使用、移动中操作。

- 融合视觉、触觉、力觉，解决接触丰富、高精度、双手协同等难题。

- 设计遥操作与数据采集方案，提升演示数据的质量和效率。

- 研究操作策略的泛化：新物体、新场景、新任务。

方向四：交互算法 / 系统

- 研究表情生成、口型同步、眼神与注视、全双工语音对话。

- 研究从语音或多模态意图生成面部和肢体动作的学习方法，并做到低延迟、可控。

- 搭建端到端交互系统：语音识别、对话、合成、表情、动作的时序对齐与延迟优化。

- 建立交互质量的评测方法，覆盖自然度、同步误差和用户主观评分。

任职要求

- 机器人、计算机、自动化、电子或相关专业硕士及以上；博士优先。

- 熟练使用 Python 和 PyTorch，能独立复现和改进前沿论文。

- 至少满足一项：

- 在 CoRL、RSS、ICRA、IROS、CVPR、NeurIPS、ICLR、Science Robotics等会议或期刊发表过相关一作论文；

- 有在真实机器人上完成并迁移学习策略的工作；

- 有开源影响力的项目。

- 具备所选方向的核心基础：

- 具身基模：大模型训练、多模态表征。

- 全身运控：强化学习、机器人动力学。

- 灵巧操作：模仿学习、接触建模。

- 交互：语音与面部生成、实时系统。

- 愿意下真机调试，能把问题分解到数据、模型、控制、硬件各层。

加分项

- 有人形机器人、四足机器人或灵巧手的真机部署经验，做过从零到一的系统。

- 熟悉 Isaac Lab、MuJoCo、Genesis 等仿真平台，以及大规模并行训练。

- 有大规模分布式训练经验，比如 FSDP、DeepSpeed、千卡级集群。

- 交互方向：做过流式语音、口型或表情驱动(如 Audio2Face 类方法)、端侧推理优化。

我们看重什么

- 真机结果比仿真指标更有说服力：成功率、鲁棒性、泛化，要能在真机上复现。

- 研究品味：能判断哪些问题值得做，哪些方法会被规模和数据淘汰。

- 工程闭环：从想法到真机验证的周期短，能和数据、平台、硬件团队高效协作。
