## 职位描述

负责具身模型的产品规划与落地，覆盖预训练、后训练、评测、部署及 API 服务，推动研究成果转化为可使用、可交付、可持续迭代的模型产品。

岗位职责

1. 负责具身模型产品路线规划，面向内部业务、开发者及行业客户，明确应用场景、能力目标、产品规格与版本优先级。

2. 协同预训练、后训练团队，将场景需求转化为模型能力、数据需求和评测验收标准，推动通用能力与场景适配能力的产品化。

3. 负责模型部署与服务的产品设计，包括端云推理、私有化部署、API/SDK、模型微调与版本管理，完善开发文档和使用体验。

4. 联动算法、数据、Infra、评测及机器人业务团队，推进模型发布、场景试点与产品交付，协调解决落地中的关键问题。

5. 建立产品效果反馈机制，围绕任务成功率、响应时延、推理成本、服务稳定性和用户使用情况，推动持续迭代。

任职要求

1. 具备计算机、人工智能、自动化或机器人等技术背景，有 AI 模型、算法平台或开发者产品相关经验。

2. 理解大模型预训练、后训练、评测与推理部署流程，能够与算法及工程团队讨论技术方案和产品取舍。

3. 具备需求分析、产品设计和数据分析能力，能够将复杂技术能力转化为清晰的产品方案、使用流程及验收标准。

4. 具备较强的跨团队推进能力，能够管理需求优先级、版本节奏与交付风险；能够阅读技术文档、调用 API 并体验模型工具。

加分项

- 有具身智能、VLA/WAM、多模态模型或机器人产品落地经验。

- 有模型平台、推理服务、API/SDK 产品从零到一建设经验。
