## 职位描述

岗位职责

1. 负责具身机器人软硬件系统、算法及运行环境的部署、升级、配置与日常维护。

2. 根据算法和研发需求，制定并执行机器人功能、性能、稳定性及场景适应性测试，完成测试记录和报告。

3. 负责机器人运行状态监控、日志分析、故障排查及问题闭环，协助算法和研发团队定位、复现及解决问题。

4. 负责机器人设备的日常巡检、保养、传感器及执行器调试，确保设备处于安全、稳定、可用状态。

5. 负责客户现场及外勤场景下的机器人安装、部署、调试和技术支持，保障项目交付及现场运行。

## 任职要求

职位要求

1. 本科及以上学历，人工智能、机器人、计算机、软件工程、自动化、电子信息、通信工程等相关专业。

2. 熟悉 Linux 操作系统及常用开发运维工具，掌握 Python、C++ 或 Shell 等至少一种编程语言；了解 ROS/ROS2、Docker、Git 等技术者优先。

3. 具备机器人或智能设备的测试、部署、运维、系统集成或现场调试经验，了解传感器、执行器、控制系统、计算平台及网络通信等基本原理。

4. 具备较强的问题分析和故障排查能力，能够通过运行日志、测试数据及现场现象定位软件、硬件、网络或配置类问题。

5. 责任心强，具备良好的沟通协调、学习和团队协作能力，身体健康，能够适应外勤、出差及客户现场调试工作。

承担主要目标/关键任务

1. 保障机器人稳定运行：负责机器人设备、软件环境及运行系统的日常维护、巡检和保养，及时发现并处理潜在风险。

2. 完成算法部署与测试：根据研发及算法团队需求，完成算法部署、版本升级、参数配置及功能、性能和稳定性测试。

3. 提升问题处理效率：负责机器人运行数据和日志分析，快速定位异常问题，推动故障复现、解决及闭环管理。

4. 支持项目现场交付：承担机器人在客户现场、实验场地及外勤环境中的安装、调试、运行保障和技术支持工作。

5. 完善标准化运维体系：持续沉淀测试用例、部署流程、维护规范、故障案例和操作文档，提升机器人运维及测试效率。
