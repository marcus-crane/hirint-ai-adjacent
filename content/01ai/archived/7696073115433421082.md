## 职位描述

1、负责 PaaS 平台相关后端服务的设计、开发和维护，重点支撑 Agent Sandbox 基础设施；

2、参与 Agent Sandbox、Workspace、Workflow、Toolbox 等模块与云端沙箱的集成适配；

3、对接云端沙箱的 Session 生命周期、代码执行、浏览器操作、文件传输、日志及运行结果管理能力；

4、建设对齐 E2B、Daytona 的沙箱平台能力，包括：

- 多沙箱运行时接入（ docker / microVM ）；

- 兼容 E2B / Daytona 的 API 与 SDK 设计；

- 沙箱快速启动、快照恢复与持久化会话；

- 资源用量统计。

5、建设 API Key、租户、项目、配额、权限、计费和审计等平台能力；

6、负责服务的性能优化、可观测性和线上问题定位，保障高并发场景下的稳定性；

7、与产品、前端、运维及外部云服务团队协作，推进需求上线。

## 任职要求

1、计算机或相关专业本科及以上学历，3 年以上后端开发经验，掌握 Java、Go 中至少一种语言（以 Java 为主亦可）；

2、熟悉 Spring Cloud、Spring Boot、Dubbo、MyBatis Plus 等开发框架，熟悉 RESTful 架构风格设计，使用 Maven / Git 等工具；

3、精通多线程编程，熟悉常见的中间件、缓存、消息队列等，熟悉 PostgreSQL / MySQL，熟悉 Linux 下 DevOps；

4、熟悉 Linux、Docker，能够完成基本的容器化部署和故障排查；

5、具备良好的接口设计、问题分析和跨团队沟通能力；

6、对 AI Agent、模型 API 或云端执行环境有兴趣，能够快速学习相关技术；

7、了解 E2B、Daytona 等 Agent Sandbox 平台架构，有 Firecracker、gVisor、Kata Containers 或安全容器使用经验者优先。
