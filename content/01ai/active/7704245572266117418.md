## 职位描述

职位定位

参与大模型 Agent 的核心算法与效果优化，围绕真实任务中的规划、工具使用、检索和多步执行问题，设计实验、分析失败原因并验证改进效果。理解并运用现代 Agent Harness 方法，将模型、上下文、工具、执行环境与评测反馈协同起来，提升 Agent 在实际任务中的完成质量与稳定性。

职位描述

1、参与 Agent 核心能力研发，包括任务理解与拆解、规划、工具调用、上下文与记忆管理等，针对具体任务提升端到端完成效果；

2、理解并探索现代 Harness 的设计方法，包括 Agent 执行循环、上下文与状态管理、工具编排、执行反馈、验证与恢复等；结合任务特点选择或改进 Harness 机制，评估其对任务成功率、可靠性、效率和成本的影响；

3、建设和维护 Agent 评测数据与实验流程，结合任务成功率、结果质量、工具调用准确性、鲁棒性、响应时延及调用成本等指标，定位系统瓶颈并验证优化方案；

4、分析 Agent 执行轨迹与失败案例，区分模型、上下文、Harness、检索、工具接口或执行环境导致的问题，并设计针对性实验推动改进；

5、根据业务场景探索 RAG、提示与上下文策略、模型微调及偏好对齐等方法；在数据和问题适配时，参与 SFT、DPO 等后训练实验；

6、与产品、算法及工程团队协作，将验证有效的算法与 Harness 方案集成到应用中，并根据线上反馈持续迭代。

## 任职要求

1、2027 届应届毕业生，人工智能、计算机、统计、数学等相关专业，硕士及以上学历；

2、具备扎实的机器学习、深度学习和算法基础，理解 Transformer 与大语言模型基本原理；熟练使用 Python 及 PyTorch 或 TensorFlow；

3、理解 Agent 基本机制和现代 Harness 的作用，了解上下文与状态管理、工具编排、执行反馈和结果验证等关键设计，能结合任务分析其优势与局限；

4、具备实验设计和问题分析能力，能基于数据或执行轨迹提出假设、设计验证，并清楚说明结果及局限；

5、能主动运用 Agent 与 Harness 技术探索解决实际问题，快速验证方案并总结效果；有 Agent、RAG、Harness 或模型微调相关项目、科研实践者优先；

6、具备良好的沟通协作能力和英文技术文档阅读能力；有开源项目、技术写作或竞赛经历者优先。
