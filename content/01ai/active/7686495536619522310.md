## 职位描述

这是一个面向海外客户真实 AI 场景的技术岗位。你会与 FDE、Consulting、产品和研发团队一起，从客户调研、Use Case 识别，到 AI Agent / Demo / POC 开发、数据与系统集成、评测和交付，参与企业 AI 项目的完整落地过程。

职位描述

1、参与海外客户访谈、业务调研和 Use Case 分析，将模糊问题逐步转化为可验证的 AI 场景；

2、基于 LLM、Agent、RAG、Tool Use、Workflow 等技术快速开发 Demo / POC / AI 应用；

3、参与后端 / 全栈开发、API 与数据处理、系统集成、部署测试和问题排查；

4、协助开展 Agent Eval、效果优化和生产验证；

5、沉淀代码、Agent、Prompt、Eval、知识库和交付方法等可复用资产；

6、与 FDE、Consulting、产品、研发、销售及客户团队协同推进项目。

## 任职要求

职位要求

1、本科以上学历，海外学习背景，计算机相关专业优先；

2、熟悉 Python / Java / Go / Node.js / SQL / API / Git 等部分技术栈，具备扎实的后端或全栈开发能力；

3、开发过 LLM / AI Agent / RAG / Tool Calling / Workflow 等项目，有 Eval、MCP、Multi-Agent 等经验优先；

4、主动、有 Ownership，学习速度快，能适应需求模糊、快速迭代的创业环境；

5、英语流利，可直接参与英文会议和技术沟通。
