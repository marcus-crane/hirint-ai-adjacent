## 职位描述

1、参与领域知识图谱的本体/Schema 设计，定义实体、关系、属性、事件体系。

2、基于 LLM Agent 构建自动化知识抽取 Pipeline：文档解析、切分、实体识别、关系抽取、事件抽取、三元组生成。

3、设计 Agent 工作流，包括任务规划、工具调用、记忆、反思与结果校验，提升抽取准确率和覆盖率。

4、参与知识融合与消歧：实体对齐、冲突检测、质量评估，并将结果写入图数据库。

5、结合 GraphRAG / KGQA，让 Agent 利用知识图谱进行检索、推理和多跳问答。

6、跟踪 LLM Agent、知识图谱、GraphRAG 前沿进展，完成实验复现与内部技术分享。

## 任职要求

1、计算机、人工智能、NLP、数据科学等相关专业本科及以上在读。

2、熟悉 Python，具备良好的代码规范和独立调试能力。

3、理解知识图谱基础：实体、关系、三元组、本体、RDF/OWL、SPARQL/Cypher 等。

4、必须懂 Agent： 理解 Planning、Tool Use、Memory、Reflection、Multi-Agent 等基本范式。

5、使用过至少一种 Agent/LLM 框架：LangChain、LlamaIndex、AutoGen、CrewAI、Dify、Coze 等。

6、熟悉 Prompt Engineering，能调用 OpenAI / Claude / Qwen / DeepSeek 等大模型 API。

7、了解 NLP 基础任务：NER、关系抽取、事件抽取、文本分类、向量检索。
