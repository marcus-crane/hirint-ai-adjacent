## 职位描述

1. 平台产品（指导研发实施）：定义数据平台边界与路线图（接入、存储加工、元数据与血缘、权限审计、质量监控、数据集版本）；输出方案与验收标准，指导平台研发团队落地， 对质量、节奏与采用率负责。

2. 数据工具（研发负责）：负责采集、清洗、标注、评测、验收、版本、交付的工具链； 采集覆盖软件与硬件 Agent（浏览器/云手机/桌面自动化、端侧与设备）；做自研/采购/开源的取舍，把验收做成可配置、可复现的工具能力。

3. 数据集全生命周期：规划—采集—标注—采购—验收—交付；标注规范与一致性阈值、合同中的数据权利与验收条款、交付含版本与数据说明卡。

## 任职要求

1. 5–8 年数据经验，其中 2 年以上同时管产品与研发团队；主导过平台或工具从 0 到 1，说得出采用率、成本或周期的改善数字。

2. 跑通过至少一个数据集交付闭环，能说清一致性、错标率怎么测、谁判定、什么阈值放行。

3. 有供应商与采购经验，谈得清数据权利（授权范围、再分发、跨境）与验收条款。

4. 有互联网或 AI 行业业务产品或运营经验，能把业务场景翻译成采集、标注、验收要求。

5. 能高水平使用 Agent，并具备 Agent 开发能力：用 Agent 实际完成采集、清洗、标注、评测等工作，能自己搭建或改造工具型 Agent（工具编排、评测与回归），不只是会用现成产品。

【加分】硬件/端侧采集经验；多语言数据集建设；合规（个保法、跨境）。
