## **About the role**

As our security programme grows, we need a scalable way to measure control effectiveness, automate evidence collection, and provide continuous visibility into our security posture.

As our Security Analyst, you’ll join the Security team and build the data and automation capabilities that underpin our security programme. You’ll work across Security to design scalable data pipelines, data models, integrations, and automations that transform security data into insights that inform decision making. Your work will enable better operational decision making, reduce manual effort, and strengthen our ability to support customer, auditor, and regulatory commitments.

You’ll help make security governance continuous. You’ll partner with Security Engineering, IT, and Engineering teams to automate evidence collection, measure control effectiveness, and establish the foundations for a data-driven security programme.

This is a rare opportunity to build Wayve’s security analytics capability from the ground up. You’ll define the architecture, data models, and automations that become the foundation for how we measure and improve security.

We’d love to hear from you if you’re motivated by replacing manual processes with scalable engineering solutions and believe security data should be automated, continuously available, and actionable.

## **Key responsibilities**

### **Build our security data platform**

* Design, build, and maintain scalable data pipelines that collect, transform, and enrich security data from systems across our business.
* Integrate data from identity, cloud, engineering, and security platforms to create a unified view of Wayve’s security posture.
* Build robust data models that provide high fidelity datasets for security analytics, operational reporting, and measuring control effectiveness.
* Design analytics products and visualisations that provide meaningful insights into the health, maturity, and performance of the security programme.
* Ensure data quality, lineage, reliability, observability, and maintainability across our security analytics platform.

### **Drive automation and continuous assurance**

* Build automated evidence collection capabilities that reduce manual effort across governance, customer assurance, and security operations.
* Develop analytics that support continuous control monitoring and demonstrate control effectiveness through measurable outcomes.
* Partner with stakeholders across Security to translate security controls into measurable, automated indicators where practical.
* Design and implement automation that replaces repetitive operational processes with scalable engineering solutions.

### **Enable data-driven security decisions**

* Partner with SMEs to develop meaningful KPIs and metrics that help Security understand performance, risk, trends, and operational health.
* Work with stakeholders across Security to understand analytical requirements and translate them into scalable technical solutions.
* Continuously improve how security data is collected, modeled, and consumed across the organisation.

## **About you**

### **Essential**

* Experience designing and operating reliable data platforms or analytics engineering solutions in production environments.
* Experience building production-quality data pipelines and automation using Python, SQL, or similar technologies.
* Experience modeling data for analytical use cases.
* Strong understanding of modern data engineering practices, including data modeling, ETL/ELT, API integrations, data quality, and observability.
* Experience working in cloud-native environments and integrating data from cloud platforms and SaaS sources.
* Experience building integrations and automation using APIs rather than relying solely on out-of-the-box platform capabilities.
* Strong analytical and problem-solving skills, with the ability to translate complex technical data into actionable insights.
* Experience designing dashboards and metrics that support operational or business decision making.
* Excellent communication skills and the ability to collaborate effectively across Security, Engineering, and other technical teams.

### **Desirable**

* Experience working within cybersecurity, security engineering, or security governance.
* Awareness of security frameworks such as TISAX, ISO 27001, NIST CSF.
* Experience measuring control effectiveness, building security metrics, or implementing continuous assurance capabilities.
* Familiarity with security telemetry, identity systems, cloud platforms, endpoint security, or vulnerability management tooling.

## **What success looks like**

During your first year you will:

* Establish the foundations of Wayve’s security analytics and automation capability.
* Establish security data pipelines that provide continuous visibility into the health and effectiveness of our security controls.
* Deliver automated evidence collection for selected key security controls, significantly reducing manual effort across the Security organisation.
* Develop KPIs, and metrics that enable Security to make data-driven decisions and clearly demonstrate control effectiveness.
* Create reusable security data products and automation that become the foundation for reporting, continuous assurance, and operational excellence across the Security organisation.
* Help transform the Security programme from periodic assessment to continuous measurement, providing timely, reliable insights that support its growth and maturity.
