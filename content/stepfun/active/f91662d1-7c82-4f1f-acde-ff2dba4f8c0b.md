岗位职责：

**• 从 0 搭建标注团队**：按产能规划招聘、面试标注员与质检员，搭建"培训 → 考核 → 上岗"流程，直接或通过交付经理管理数十人团队。

**• 产能与排期**：把交付目标拆解到周 / 日产能，做排班与人效管理，用看板监控进度、质量与瓶颈，提前预警风险并补位。

**• 培训体系**：组织手册宣讲、判例演练与上岗考核，把新人上手周期压到一周以内；与策略、质检组长联动更新培训材料。

**• 交付管理**：批次管理、返工调度、交付节点对齐；向上同步进度、质量、人力三张表。

**• 供应商管理**：外采下单、驻场对接、进度跟踪与结算管理。

**• 团队管理**：绩效、激励与留存，处理标注员的申诉与状态波动；落实数据安全与保密要求。

任职要求：

• 3 年以上标注 / 审核 / 内容运营团队管理经验，带过 10 人以上团队并对交付结果负责；语音或大模型数据项目优先。

• 有从 0 到 1 组队或产能爬坡的完整经历：招人、培训、上岗、稳定产出，说得出当时的人效数字。

• 会做产能测算与排期（人时 / 条、爬坡曲线、缓冲），Excel 熟练，能自己搭日报 / 周报看板。

• 沟通与抗压：能同时对上（交付节点）、对下（人员状态）、对外（供应商），冲突时能给方案而不是只报问题。

• 理解质量指标的含义，不用产能换质量：知道什么时候该停线返工。

**加分项**

• 数据服务商项目经理 / 交付经理背景（语音项目优先）。

• 有供应商管理与结算经验。

• 有培训体系搭建或 HRBP 相关经验。

• 用过标注平台的任务分配、进度与质量统计功能。

• 有大模型数据（SFT / 评测集）交付经验。
