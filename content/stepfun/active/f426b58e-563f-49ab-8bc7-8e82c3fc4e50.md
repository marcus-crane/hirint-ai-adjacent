岗位职责

\*\*资源交付与需求统筹\*\*

- 负责模型 API 资源的需求归集与交付统筹，协调资源分配与接入落地，推动交付闭环

- 承接内部各团队与平台侧流转的资源类需求，配合商务完成企业客户的资源开通与交付

\*\*资源接入与配置运营\*\*

- 负责各类资源的上下线与运营配置（权限、额度、限流等），保障各业务方资源稳定、可用、可控

- 跟踪资源版本、配额与供给状态，及时发现异常并推动处置

\*\*渠道准入与供给治理\*\*

- 建立并执行渠道准入标准与稳定性评估机制，完成新渠道测试验证与存量渠道质量监测、履约跟踪

- 关注供给质量、成功率与成本水位，参与资源调度、切换与优化的策略制定，重大调整及时上报

\*\*供应商管理与成本对账\*\*

- 对接供应商与采购，管理供给渠道与合作关系，跟进履约与质量，保障供给的稳定性与性价比

- 负责资源预算与成本的运营管理及对账，建立并执行对账机制，保障成本口径清晰、账目准确

## 任职要求

- 本科及以上学历，3 年以上资源运营、供应链 / 采购 / 商务运营或成本运营相关经验

- 流程严谨、数字敏感，有对账 / 额度 / 预算 / 成本类精细化运营经验

- 理解资源调用的计量与计费口径，能看懂用量数据、做量化分析并形成调度与优化的策略建议

- 较强的跨团队协调与商务对接能力，能同时对接内部多团队与外部供应商、采购

- 自驱力强，结果导向，有较强的推进与闭环能力，能适应快速变化与关键时段响应

## 加分项

- 有 AI / 大模型 API、云资源、算力 / 成本管理（FinOps）相关运营经验

- 有多渠道比价与切量经验，理解不同厂商 token 计量与计费口径的差异

- 熟悉主流资源供给生态，有供应商采购 / 渠道管理经验，或 toB 企业客户交付经验

- 能用 AI 编程工具或脚本将对账、取数等重复工作自动化
