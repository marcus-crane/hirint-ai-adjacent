岗位职责

负责 AI 产品的整体视觉体验建设，从品牌视觉到产品 UI 落地，建立统一、专业、有辨识度的设计体系。

1. 品牌与视觉体系设计

* 负责产品整体品牌视觉风格的设计与持续迭代，包括 Logo、品牌色、字体、图形语言、IP 形象等；
* 建立统一的品牌视觉规范，保证官网、产品、市场物料、对外宣传等不同场景下视觉表达一致；
* 结合 AI 产品特征与目标用户，对产品的视觉定位和品牌调性进行持续探索，提升产品辨识度与专业感；
* 支持重要发布、市场宣传、活动等场景的核心视觉设计。

1. 产品 UI 设计

* 与产品经理、交互设计、研发团队协作，完成 Web、App、桌面端等产品界面的视觉设计；
* 基于产品需求输出高质量 UI 方案，包括页面布局、视觉层级、组件状态、动效及细节设计；
* 重点参与围绕 AI 工作台内复杂产品场景的设计工作；
* 在保证美观的同时，关注信息密度、操作效率与复杂业务场景下的可读性。

1. 设计系统与规范建设

* 搭建并持续维护产品 Design System，包括：
* 色彩、字体、间距、栅格等基础规范
* Button、Input、Table、Card、Modal 等基础组件
* 图标库、插画库等视觉资产
* 组件不同状态与使用规范
* 推动设计规范在产品和研发中的统一落地，提升设计与开发效率；
* 持续优化现有产品视觉一致性和细节体验。

任职要求

* 3 年以上视觉设计 / UI 设计 / 产品设计相关经验，有完整线上产品项目经验；
* 具备较强的视觉基本功，对版式、色彩、字体、图形语言、信息层级有较好的判断力；
* 既能做品牌视觉探索，也能完成复杂产品 UI 的高质量落地；
* 熟练使用 Figma 等主流设计工具，能够搭建设计组件和 Design System；
* 对复杂 ToB / 工具型产品有一定理解，能够处理高信息密度页面，而不是只擅长偏 C 端的营销型视觉；
* 具备较好的沟通和协作能力，能够与产品、研发共同推进方案落地；
* 对细节敏感，有较强的审美判断和设计自驱力。

加分项

* 有 AI / Agent / SaaS / 金融科技 / 企业服务产品设计经验；
* 有从 0 到 1 建立品牌视觉体系或 Design System 的经验；
* 有 Logo、IP、品牌视觉等完整品牌设计案例；
* 有数据可视化、Dashboard、复杂工作台类产品设计经验；
* 对 AI 原生产品的交互和视觉趋势有持续关注。
