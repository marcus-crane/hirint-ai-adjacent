岗位定位：负责大模型增强搜索业务，融合传统搜索与 LLM 能力，主导搜索 Query 理解、召回、排序、生成回答策略迭代，通过评测、badcase 分析驱动搜索效果持续优化，提升搜索满足率、CTR、留存等核心指标。

岗位职责

1. 负责大模型增强搜索全链路策略设计：包括 query 意图识别、query 改写、多源召回、排序融合、LLM 生成回答、引用溯源、幻觉抑制等模块的策略方案设计、实验落地与效果迭代。

2. 深度分析线上搜索 Case、badcase，完成问题归因，区分检索侧问题 / 模型侧问题 / 策略侧问题，输出可落地优化策略，推动算法、工程团队落地。

3. 设计搜索效果评估体系，结合人工评测、自动化评测、线上 AB 实验，搭建 GSB/DCG 等评估指标，对齐离线评测与线上业务指标。

4. 挖掘长尾、复杂、多轮搜索场景痛点，设计场景化策略；平衡相关性、时效性、真实性、安全性，抑制模型幻觉，提升生成答案可信度。

5. 跟踪业界搜索 + 大模型前沿方案，做竞品分析、方案 POC，输出策略迭代 Roadmap，对搜索满足率、换 query 率、CTR、用户留存等业务指标负责。

6. 跨团队协同算法、评测、工程、运营，推动策略上线、灰度、全量，沉淀策略迭代 SOP。

任职要求

1. 本科及以上，2年以上搜索策略、NLP 策略产品经验，有大模型搜索 / AI 搜索实战经验优先。

2. 深刻理解搜索全链路：query 理解、召回、排序、rerank、生成式搜索，熟悉 GSB、DCG、搜索质量评估方法论。

3. 具备 badcase 深度归因能力，能够从真实用户 Case 拆解根因，输出可落地策略方案；有完整 AB 实验从设计‑执行‑复盘闭环经验。

4. 熟练 SQL/Python，能够做数据分析、指标拆解，用数据驱动策略决策。

5. 懂 LLM 基础能力边界，理解 RAG、Prompt 工程，能够区分模型能力问题与策略问题。

6. 强跨团队协同，目标导向，能够对业务结果负责。

加分项

- 做过 NL2SQL、智能问数、搜索 Agent；有 Vibe Coding 工具使用经验；有搜索 Benchmark、评测集搭建经验。
