岗位职责：

**• 搭建质检体系**：设计分层抽检方案、二审流程、退回与返工闭环、争议上升路径；为转写、时间戳、说话对象归属、决策点等各层定质量红线（一致率、字准、时间戳误差）。

**• 日常质量运营**：按能力项、标注员、批次出质量报表并预警，主持每周质量复盘，把退回原因归类后同步给策略组长合入手册。

**• 标注员校准与考核**：设计上岗考核与定期校准测试（在任务流里混入隐藏金标样本），维护标注员质量档案与分级。

**• 组织评测层标注**：模型跑完黄金样本后，组织"逐决策点给模型打分"的评估标注，保证不同评测员打分的一致性。

**• 外采验收**：制定供应商交付的抽检与验收标准，执行验收并输出质量报告。

**• 数据安全**：落实脱敏、保密与权限规范的日常检查。

任职要求：

• 2 年以上数据质检 / 审核经验，独立设计过抽检方案与质量报表；语音、音频类项目优先。

• 数字敏感：会算一致率、合格率、抽检比例这类基本统计，能用表格把质量问题定位到人、到批次、到具体规则。

• 听感好：疑难判例（多说话人重叠、低语、嘈杂环境）能自己戴上耳机复核并给出结论。

• 原则性强、沟通得体：退回有理有据，能在产能压力下守住质量红线，也能把"为什么退"讲到标注员服气。

• 能读懂 JSON 标注结果与自动校验报告，会和平台对自动校验规则。

**加分项**

• 统计 / 数学 / 质量管理相关背景。

• 做过大模型评测相关质检：人工评估、偏好标注、评分一致性管理。

• 会 Python / SQL 自动出质量报表。

• 有供应商交付验收经验。

• 做过内容审核 / 语音审核的质量管理。
