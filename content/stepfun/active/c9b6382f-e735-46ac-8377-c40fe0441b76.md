负责 agent runtime 的核心运行时，支撑 Agent 的稳定、高效执行，具体职责与要求如下。

（一）岗位职责

1. 负责 agent runtime 的核心运行时：循环调度、会话状态管理、工具执行环境
2. 负责 agent loop 的运行时实现、子代理编排调度与会话状态持久化
3. 负责工具执行与沙箱：工具调用的执行环境、代码运行沙箱、隔离与安全
4. 保障 runtime 的性能、稳定性与可观测性

（二）任职要求

1. 计算机相关专业本科及以上，5 年以上后端研发经验
2. 有运行时系统或执行引擎开发经验（如工作流引擎、Serverless 运行时、容器编排）
3. 精通高并发、分布式系统，有状态管理系统开发经验者优先
4. 熟悉沙箱技术（容器隔离、gVisor、Firecracker 等）者优先
5. 对 Agent 运行时（durable execution、长任务断点续传）有理解者优先
