**职位描述**

1. 面向全双工语音与 Agent 任务数据，拆解业务目标、用户场景、任务状态和验收条件，建立数据需求、人员任务、质量问题及交付产物的业务模型，形成可执行的数据规格。
2. 建设采集、合成、重放、筛选与交付 pipeline，贯通台本、语音、工具调用、环境事件和执行记录；支持批量调度、失败重试与版本追踪，保证样本可重现、过程可排查。
3. 搭建数据业务 Agent 与工作流，将需求规格编写、案例扩展、数据整理等高频工作产品化；明确人工判断与自动执行的边界，通过真实案例验证效果、成本和适用范围。
4. 开发或生成可用的标注工具、质检界面和人员监控看板，让业务同学能够配置任务、处理异常、查看产能与质量；持续维护工具，减少流程断点和重复操作。
5. 与业务 POC 共建数据标准、评测集及自动校验器，检查工具参数、执行结果、状态变化和时间线一致性；结合人工抽检分析误判与漏检，推动问题回流和规则迭代。
6. 维护数据来源、使用范围、版本及流转记录，落实去重、训练与评测隔离、访问权限和敏感信息处理，支持交付追溯与问题样本定位。
7. 统筹工程需求、优先级、里程碑及协作人员，与算法、业务和供应商完成联调验收；指导实习生承担明确模块，对所负责链路的可维护性和日常运行负责。

**职位要求**

1. 具备计算机、软件工程等相关背景，拥有扎实编程基础及实际项目交付经验，能够独立解释方案和代码中的关键设计。
2. 熟练使用 Python 或 TypeScript，掌握 SQL、API 和结构化数据处理，能完成主责方向的开发、调试与部署；工具与看板方向需具备必要的前后端实现能力。
3. 有 Agent 或复杂 Workflow 搭建经验，理解 Prompt、工具调用、上下文与状态管理，能分析失败原因并设计恢复路径。
4. 能从业务案例定义数据结构、规则和验收标准，具备评测、实验对比及质量归因能力，避免只以流程跑通判断成功。
5. 能设计模块接口、日志和版本机制，重视复现、异常处理与维护成本；具备数据来源和权限边界意识。
6. 是 AI 工具的重度用户，能展示真实作品及本人贡献，既能用 AI 加速开发，也能独立检查代码与结果。
7. 具备需求澄清、项目推进与协作统筹能力；有合成数据、语音处理、评测工具或标注平台经验者优先，无须同时精通全部方向。
