岗位职责

1. 分层差异化的业绩规则体系设计：独立负责事业部业绩核算口径、业绩归属规则、业绩判定标准的制定、发布、执行跟进与持续迭代。以客户分层体系（战略客户 / KA / 中腰部 / 中小微 / 渠道）为轴心，建立分层差异化的核算口径与归属规则——覆盖各层级客户的业绩确认口径（签约 / 回款 / 消耗 / 续费）与时点、LTC 各阶段判定标准、铁三角及跨团队分成比例、折扣与特批政策适用边界；确保规则清晰、严谨、可落地，贴合云计算 ToB 业务场景与前线作业模式。
2. 账号体系变更的业绩归属治理：针对账号体系的新建、合并、拆分、集团母子关联、跨区域 / 跨行业转移、冻结、关停等变更场景，建立标准化的业绩归属判定规则与例外处理机制；主导账号变更引发的历史业绩追溯、客户保护期冲突、跨团队分配、分层升降级后政策衔接等复杂问题的独立研判与闭环解决，确保账号体系调整不产生管理漏洞与激励扭曲。
3. 一线业绩问题闭环：解决一线销售在业绩判定、归属、核算、账号异常中的各类问题，主动发现风险点（如抢单 / 塞单、虚假升层套取政策、账号囤积、绕报备），独立研判、自主推动解决、全程闭环。
4. 公司层面规则协同：对接公司层面业绩管理要求与账号体系规则，从事业部业务特性与客户分层实际出发，参与公司层面业绩规则讨论与优化，平衡公司统一规则与事业部业务实际，确保规则公平、合理、可执行。
5. 风险识别与前置管控：主动识别业绩规则漏洞、判定风险、核算偏差、账号变更与分层调整中的特殊场景风险，建立风险识别与前置管控机制（如账号变更分级审批、分层升降级校验、归属争议仲裁、规则影响评估），保障业绩管理全过程合规、公平、可追溯、无管理漏洞。
6. 业务实战视角的规则迭代：深度理解 ToB LTC 全流程、铁三角协同作业模式与前线作业模式，结合客户分层运营策略与账号体系运行数据，从业务实战角度持续优化业绩规则逻辑。

任职要求

1. 本科及以上学历，5 年及以上工作经验；具备大型 ToB / 科技 / 云计算行业销售业绩管理、销售运营（Sales Ops）或 CRM / 账号体系治理相关经验者优先；有客户分层运营或账号体系变更项目经验者优先。
2. 具备 ToB 商务 / 前线业务认知，深度理解 LTC 流程与销售实战场景，熟悉战略 / KA / 中腰部 / 中小微等不同层级客户的差异化销售模式与协同机制，能从业务视角做规则设计。
3. 能主动发现问题、独立分析、自主闭环，具备在模糊、争议场景下快速形成判定原则并推动落地的能力。
4. 具备风控意识与公平性思维，擅长识别规则漏洞、账号变更引发的归属争议、套利行为与管理风险。
5. 开放视角，能在公司、事业部、一线之间做平衡与专业判断；具备优秀的跨部门沟通能力与规则文档撰写能力。
