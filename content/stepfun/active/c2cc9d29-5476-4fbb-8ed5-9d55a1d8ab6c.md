**职位描述**

1. 结合用户场景和角色要求制定声音质量标准，覆盖清晰度、噪声、响度、失真、自然度、韵律、情绪与角色适配，形成可试听的正反例及缺陷分级。
2. 建立录制、语音合成、清洗、剪辑与混音规范，明确采集环境、音轨、格式和验收要求；在保证可用性的同时保留业务需要的真实环境声与重叠语音。
3. 诊断并处理音频生产中的噪声、削波、音量失衡、拼接和时间对齐问题，与工程同学改进批处理及自动校验，验证处理是否损伤语义或交互事件。
4. 设计盲听、对比评测和评测员校准，结合听感、声学指标与用户任务判断问题，区分采集、合成、后处理和模型表达缺陷，跟进修复效果。
5. 参与 business case 和脚本评审，判断不同任务对音色、语速、情绪、反馈时机的要求，明确哪些声音问题会影响理解、任务完成或角色可信度。
6. 负责声音专项的排期、人员培训与质量验收，指导录制人员、标注员及外部资源，处理疑难样本和返工，平衡效果、成本与交付进度。
7. 使用 AI、Prompt 和基础 Workflow 辅助生成测试文本、整理缺陷、批量处理与评测，保留人工试听和检查环节，沉淀可复用的声音生产流程。

**职位要求**

1. 有录音、混音、音频工程、声音设计或语音质量评测实践，可提供试听作品或真实项目案例，说明问题判断、处理过程和效果。
2. 在声音工程或语音感知与表达评价中至少有一个扎实主专长；熟悉 DAW、音频处理软件或 Python 音频工具，能够独立解决具体问题。
3. 听辨能力好，能识别噪声、失真、音量异常、韵律不自然与角色不一致；理解多轨音频、时间对齐及重叠语音对交互评价的影响。
4. 能把主观听感写成可执行标准，组织试听校准和质量评测；理解客观指标的适用范围，能够用样本和证据说明取舍。
5. 能理解用户任务与产品需求，分析声音方案的业务价值、生产条件和质量边界；能够独立推进一个声音专项，并指导协作人员执行。
6. 是 AI 的深度用户，使用过语音合成、语音交互或相关生成工具；具备基础 Prompt 与 Workflow 能力，能验证生成结果并识别工具局限。
7. 有 TTS、全双工语音、语音学、表演配音或情绪表达评价经验优先；Agent 任务理解、对话设计和轻量自动化可作为副专长，不作全栈要求。
