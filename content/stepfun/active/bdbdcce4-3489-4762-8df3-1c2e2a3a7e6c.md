岗位定位

负责 IoT 配套 App 在普通 iPhone 上的系统能力、原生 SDK 与跨平台集成，确保设备互联、音频、数据和智能交互在真实系统约束下稳定运行。

岗位职责

1. 原生平台与设备接入：开发和集成 CoreBluetooth 设备连接、控制、同步与 OTA 能力，处理异步状态、超时重试和设备切换。

2. 音频与系统生命周期：实现音频会话、路由、中断、权限、后台任务、通知与分享，验证前台、锁屏、挂起、终止及用户强退时的行为。

3. 跨平台集成：负责 Swift/XCFramework、KMP Agent SDK 与 Flutter 插件的集成，维护消息、事件、取消、内存和线程边界。

4. 数据与性能：建设本地数据、安全存储和可恢复任务链路，优化启动、卡顿、内存、功耗及长录音处理体验。

5. 交付与质量：参与设备/云端/算法联调，建设真机兼容与回归，维护隐私声明和 App Store 上架质量。

任职要求

必须具备

1. 计算机或相关专业本科及以上学历，4 年及以上 iOS 研发经验。

2. 必须具有 IoT 设备配套 App 开发经验，参与过蓝牙或其他硬件连接类应用的真机联调与正式发布。

3. 熟练掌握 Swift、并发、内存管理和 iOS 生命周期，具备清晰的模块与接口设计能力。

4. 熟悉 CoreBluetooth，并具备 AVAudioSession、音频播放/录音或后台任务等相关经验。

5. 能够使用 Instruments、日志和真机实验定位连接、路由、性能与系统行为问题。

6. 理解 iOS 后台和权限的实际限制，具备数据恢复、隐私合规及上架维护经验。

加分项

1. 有 Flutter Plugin、KMP、XCFramework 或 C++ 共享核心集成经验。

2. 有耳机、录音、语音助手、端侧推理等产品经历。

3. 具备 App 架构或技术带队能力，可承担 App 技术负责人；该职责在现有 App 岗位内配置，不重复招聘。
