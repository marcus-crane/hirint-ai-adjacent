岗位定位

负责将录音、转写与交互数据转化为有证据、可更新的个人记忆，提升 Agent 对用户和任务的理解。该岗位是 2 个记忆算法/Agent 名额之一，侧重算法效果、持续评测及端云集成。

岗位职责

1. 个人记忆建模：设计实体、事件、偏好、项目及时间信息的提取和组织，区分事实、推断与任务，建立来源和有效期。

2. 检索与更新：建设查询理解、混合召回、重排和上下文选择，处理重复、冲突、否定、指代、时效及用户纠错。

3. Agent 集成开发：开发记忆提取/检索工具及服务接口，参与上下文、任务和工具链路实现，支持端侧与云端 Agent 使用。

4. 数据与效果评估：建立连续用户样本、标注和回放评测，量化提取、召回、证据一致性、纠错/删除传播及任务收益。

5. 资源与产品优化：在模型效果、延迟、成本与端侧资源间做取舍，与本地数据、云平台及产品团队持续迭代。

任职要求

必须具备

1. 计算机、人工智能或相关专业本科及以上学历，3 年及以上 NLP、检索、记忆或相关 AI 研发经验。

2. 必须具有记忆/RAG/信息提取/知识组织相关实践，同时具备 Agent 开发或集成经验，能够交付算法代码与服务接口。

3. 熟悉 LLM、Embedding、检索重排、结构化提取及上下文管理，具备实验设计和误差分析能力。

4. 熟练使用 Python 与常用模型/算法工具，具备服务化、数据处理和工程联调能力。

5. 能够处理时间、实体、来源证据、事实冲突等长期数据问题，重视授权、纠错与删除。

6. 具备将效果指标与真实用户体验关联的能力，不以单次演示或离线单一指标作为交付标准。

加分项

1. 有长期记忆、对话理解、知识图谱、多模态或音频转写数据处理经验。

2. 有 SFT、RL 或其他 Post-Train 实践，并能说明其对真实产品效果的改善。

3. 有相关论文、竞赛成果、高影响力开源贡献，或 Kotlin/KMP/端侧模型工程经验。
