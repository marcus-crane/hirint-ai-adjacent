岗位职责

1、负责AI应用 PC 客户端整体架构和技术路线，覆盖 Windows/macOS，保障性能、稳定性和可扩展性。

2、主导音频采集/播放、系统音频、会议录音、设备通信、实时传输及 Agent Runtime 等核心能力建设。

3、负责 PC 与硬件设备通信方案及协议设计，推动软硬件一体化能力落地。

4、持续推进客户端架构演进、性能优化、稳定性治理、安全加固及研发效能提升。

5、负责 PC 研发团队招聘、培养及绩效管理，并推动产品、算法、服务端、硬件等多团队协作。

岗位要求

1、5 年以上 PC/Windows 客户端开发经验，2 年以上团队管理经验，有复杂客户端产品从 0 到 1 经验。

2、熟练掌握 Electron、TypeScript/JavaScript，深入理解 Electron 多进程、IPC、生命周期及安全机制。

3、熟悉 C++/Native 开发，理解 Windows 系统机制，包括进程线程、内存、IPC、文件系统等。

4、熟悉音频采集、播放和编解码链路，了解 Windows Core Audio、FFmpeg、PortAudio、Opus、AAC、PCM 等。

5、具备较强的客户端架构设计、性能分析和复杂问题定位能力。

6、具备良好的团队管理和跨部门协作能力，对大模型及 Agent 技术保持持续关注。
