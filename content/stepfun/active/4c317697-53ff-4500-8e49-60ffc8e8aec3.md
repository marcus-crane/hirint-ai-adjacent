岗位职责：

1. 负责评测体系、评测集构建与迭代，覆盖基础模型和应用场景，推进模型和产品迭代进化；
2. 跟进最新学术研究与企业最佳实践，结合模型和产品发展阶段，明确模型迭代目标，定义 Bench；
3. 与算法研究、专家团队合作，构建评测集，推进评测执行并完成评测报告；
4. 参与产品需求评审与技术评审，在需求阶段提出可评测性要求；

任职要求：

1. 具备 2 年以上 LLM / 语音模型 / Agent 评测经验，能独立设计评测体系与指标，构建并持续迭代评测集；
2. 具备学术论文阅读与业务场景理解能力，能跟踪前沿研究和行业实践，结合模型与产品发展阶段，将迭代目标转化为评测方案与 Benchmark；
3. 具备跨团队协作与项目推进能力，能与算法研究、领域专家及产品团队合作，推进评测集建设与评测执行，并在需求和技术评审阶段提出可评测性要求、明确验收标准；
4. 具备评测分析与独立结论输出能力，能基于评测证据定位问题，输出评测报告与迭代建议，可以坚持客观的效果判断；
