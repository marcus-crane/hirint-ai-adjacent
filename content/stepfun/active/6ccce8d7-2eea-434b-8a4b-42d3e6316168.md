**岗位职责**

1. 负责 AI／Agent 云侧安全设计，明确用户、Agent、模型与工具之间的信任边界，制定身份授权、工具权限、执行隔离和数据保护措施，防范提示注入、敏感信息泄露及工具越权。

2. 负责设备接入、账号与设备绑定、端云接口及数据交互的安全设计，落实身份认证、访问控制、凭证管理和数据保护要求。

3. 负责安全组件与防护能力的开发和集成，覆盖认证授权、接口签名、防重放、密钥管理，以及 Agent 工具调用鉴权、参数校验和操作审计。

4. 负责代码审查、安全测试及第三方组件安全评估，覆盖业务接口、MCP Server、插件及软件依赖，推动安全问题修复并验证闭环。

5. 建立并完善 DevSecOps 安全检查与自动化评测能力，将代码扫描、依赖检查、凭证检测及安全回归测试融入研发和发布流程。

6. 负责云资源安全配置与加固，落实最小权限、网络隔离，以及主机、数据库和对象存储的安全基线。

7. 负责云侧安全监控与问题处置，通过日志审计和异常行为分析定位风险，完成影响范围分析、风险控制及整改验证。

**任职要求**

1. 本科及以上学历，计算机、信息安全、人工智能等相关专业；具备 3 年及以上服务端研发、云安全或安全工程相关工作经验。

2. 了解大模型与 Agent 的基本架构及调用流程，理解 Function Calling、MCP、RAG 等常见机制，能够识别提示注入、数据泄露、工具越权等风险并落实防护措施。

3. 具备扎实的安全基础和良好的安全意识，理解最小权限、纵深防御和信任边界，能够结合业务流程、数据流及调用链开展模块级威胁分析与安全设计。

4. 熟悉身份认证、访问授权、Token、请求签名及防重放机制；理解 TLS、证书和常见密码技术的应用，了解 KMS 与凭据管理，能够落实凭证保护、密钥管理及数据保护。

5. 熟悉 Java、Go、Python、C/C++ 中至少一门语言，熟悉 Linux、网络协议及常见数据库，能够独立开发安全组件、检查脚本或测试工具，完成联调和问题定位。

6. 熟悉常见 Web／API 安全风险及防护方法，具备代码审查、安全测试和漏洞修复能力，能够设计覆盖认证授权、提示注入及工具调用等场景的安全测试用例。

7. 了解 SDL／DevSecOps 和安全自动化实践，能够使用现有工具或自研脚本，将安全扫描、配置检查及回归测试接入 CI/CD 流程。

8. 有主流公有云或私有云使用经验，熟悉 IAM、VPC、安全组等配置，了解 API 网关、WAF 及主机安全等防护能力，具备日志分析和安全问题处置能力。

9. 具备良好的学习、沟通和执行能力，能够与终端研发、云侧研发及运维团队协作推动方案落地。

**加分项**

* 有手机、IoT 或其他设备端云协同业务经验，接触过设备身份、设备证书、设备绑定／解绑、设备凭证更新或设备接入安全。
* 有认证授权、API 安全、KMS／凭据管理接入、数据保护或云安全加固等项目的实际开发与落地经验。
* 有 Docker／Kubernetes 安全实践，了解 RBAC、网络策略、Secret 保护、容器最小权限及镜像漏洞管理。
* 有安全自动化工具开发经验，或将安全扫描、基线检查及安全测试接入 CI/CD 的实践经验。
