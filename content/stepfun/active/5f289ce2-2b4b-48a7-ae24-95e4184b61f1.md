**工作职责**

* 负责手机 AOS 系统端侧搜索算法的研发与优化，建设面向全局搜、相册、文档等个人本地内容的多模态检索能力，提升系统搜索体验；
* 负责 Agent 检索与信息查询相关算法，结合大模型与搜索技术，提升 Agent 的信息获取效率与回答质量；
* 负责智能推荐方向的算法研发，结合用户情境与偏好提升内容与服务的推荐效果，并探索更自然的主动式服务体验；
* 建设数据与评测闭环，通过模型和策略迭代，持续提升搜索、问答及主动服务的效果；
* 与产品、系统及工程团队协作，推动算法在端云协同场景落地，兼顾用户体验、运行效率与隐私安全。

**岗位要求**

1. 计算机、人工智能、数学、统计学等相关专业本科及以上学历，具备扎实的数据结构、算法、机器学习与深度学习基础；
2. 熟练掌握 Python 及至少一种主流深度学习框架（如 PyTorch、TensorFlow），具备良好的代码实现、数据分析与实验设计能力，能够独立完成算法验证、模型训练及效果分析；
3. 熟悉搜索或推荐系统的核心原理，在查询理解、语义召回、相关性排序、个性化推荐等至少一个方向有深入实践；
4. 具备数据驱动的优化意识，能够设计评测集与指标、分析典型失败案例，通过实验定位瓶颈并推动改进，关注真实用户体验，能够协同工程团队处理算法效果、性能及资源占用之间的取舍；
5. 具备良好的沟通协作、问题拆解与自主学习能力，能够将搜索、推荐及大模型领域的新方法转化为可验证、可落地的业务方案。

**加分项**

1. 有手机系统搜索产品的算法落地经验；
2. 有 Agentic Search、联网问答或多源搜索策略优化实战经验；
3. 有个性化推荐、用户理解或智能服务相关算法实践，具备从算法验证到业务落地的经验；
