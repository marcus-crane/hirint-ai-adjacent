基于 RTOS(FreeRTOS / RT-Thread / ThreadX 等)进行智能音频设备的固件开发与调优,保障音频链路的实时性与稳定性;

负责音频通路开发:麦克风采集、编解码、录音存储 / 缓存、播放与提示音等;

负责音频外设的驱动与调试(I2S / PDM、Codec、麦克风阵列等),完成软硬件联调;

对接端侧音频算法(AEC / NS / AGC / VAD 等),配合完成音频效果调优;

基于 RTOS 做音频任务调度、缓冲(环形缓冲)管理与异常恢复;

参与量产问题排查(音频卡顿、丢帧、噪声、死机等),定位根因并输出解决方案。

任职要求

本科及以上学历,电子 / 通信 / 计算机等相关专业;

3 年左右嵌入式开发经验,熟悉 C 语言;

熟悉至少一种主流 RTOS(FreeRTOS / RT-Thread / ThreadX),有多任务开发经验;

熟悉音频接口与链路(I2S / PDM / Codec / DMA / 环形缓冲等),有音频外设调试经验;

了解常见音频编解码(Opus / AAC / ADPCM 等)或 AEC / NS / AGC / VAD 中的至少一类;

具备基本的问题定位能力(会用示波器 / 逻辑分析仪 / 日志排查)。

加分项

有消费级 / 可穿戴音频产品(录音笔、耳机、对讲、会议麦、工牌等)开发经验;

熟悉麦克风阵列 / 远场拾音;

有低功耗录音、边录边传、断点续录等经验;

有云端 ASR / 语音服务对接经验。
