岗位职责

1. **内核核心子系统研发。**负责调度器（CFS/EAS、调度延迟与优先级）、内存管理（THP、内存分层、回收策略、NUMA balancing）、网络栈（RoCE 与 TCP、拥塞控制、XDP/eBPF）、I/O 栈（io\_uring、blk-mq、NVMe 多队列）与文件系统（ext4、overlayfs 及分布式文件系统客户端）的特性开发与缺陷修复。
2. **AI 与 HPC 场景性能优化。**降低调度与 I/O 的尾延迟抖动，优化大页、内存带宽与 NUMA 亲和；改进 CPU 亲和与隔离、中断与软中断处理；优化 RDMA 内核旁路路径与驱动的协同，以及 GPUDirect、NVMe-oF、GPU Direct Storage 等主机侧数据通路。
3. **大规模集群稳定性治理。**定位并修复 panic、hung task、soft lockup、OOM、内存泄漏等疑难问题，完成 crash dump 与 vmcore 分析；建设 kprobe、ftrace、eBPF 工具链，形成线上问题的根因分析与闭环修复机制。
4. **版本与发行版工程。**负责内核版本选型、CVE 修复、补丁管理与 backport，参与龙蜥（Anolis）、openEuler 及上游社区贡献，保持内部版本与社区的同步演进。
5. **虚拟化与轻量隔离优化。**负责 KVM/QEMU、Kata Containers等虚拟化与虚拟化容器方案的内核侧支撑，优化 vCPU 调度与抢占、内存虚拟化（EPT/NPT、virtio-balloon、DAX 大页）以及 virtio、vhost-net/vhost-user 数据通路，压降虚拟化开销。
6. **容器运行时与安全加固。**负责 runc/containerd、cgroup v2、namespace的内核侧支撑，推进 livepatch/kpatch 热升级能力，收敛多租户与不可信代码执行场景下的内核攻击面。
7. **硬件平台适配。**支持新服务器平台的 BSP 适配，覆盖 x86、ARM 及国产 CPU 平台，完成网卡、存储、GPU 驱动与 ACPI/BIOS/BMC 固件的联调。
8. **技术沉淀与输出。**建设内核知识库与性能调优指南，承担内部培训，推动专利、技术文章与社区影响力建设。
9. **Agentic 负载内核支撑。**面向 Agent 编排产生的大量短生命周期沙箱与容器实例，优化 fork/exec、namespace 建立、cgroup 挂载等创建与销毁路径，改进 overlayfs、erofs 及按需加载（lazy loading）的镜像挂载效率，缩短沙箱冷启动时间；治理秒级启停节拍下的 PID 与 inode 泄漏、临时文件系统压力及 page cache 抖动。
10. **GPU 与加速器虚拟化。**支撑 GPU/NPU 的多租户切分与共享，参与 vGPU、MIG、SR-IOV 及基于 vfio 的用户态驱动直通方案的内核适配；优化设备直通下的中断亲和、IOMMU 映射与 NUMA 亲和，保障虚拟化环境中的算力供给与 RDMA 通信性能。
11. **Agentic 沙箱安全治理。**面向 Agent 大规模执行不可信代码的场景，设计并落地沙箱安全策略：按 Agent 类型细化 seccomp 与 LSM 规则集，管控 namespace 逃逸面与内核接口暴露，配合安全团队完成漏洞响应、攻击样本分析与加固基线沉淀。

任职要求

1. 3 年以上 Linux 内核或系统级软件开发经验，在调度、内存、网络、存储等子系统中至少一个有深度积累，有合入上游 kernel 或主流发行版的 patch 记录。
2. 精通 C 语言与内核编程模型，深入理解并发原语、锁机制、内存序与 RCU；能熟练阅读 x86\_64 或 arm64 汇编。
3. 熟练使用 perf、ftrace、bcc/bpftrace、crash、gdb、systemtap 等工具，具备独立定位线上疑难问题的能力。
4. 理解计算机体系结构：缓存一致性、NUMA、PCIe、TLB、内存带宽与延迟；理解 GPU 主机侧交互机制（GPUDirect RDMA、P2P、NVLink 与 PCIe 拓扑识别）。
5. 深入理解 Linux 虚拟化栈（KVM、virtio、vhost、IOMMU、EPT/NPT）或容器隔离机制（namespace、cgroup v2）中的至少一个方向，并有生产环境的性能优化或问题治理经验。
6. 理解 AI 推理服务与 Agent 编排的负载特征（短生命周期实例、冷启动敏感、请求规模混合），能够把负载特征转化为内核侧的优化目标与验收指标。
7. 熟悉 RoCE/InfiniBand 协议栈与内核网络路径，有网络性能调优经验。
8. 熟悉 Git 工作流与内核社区协作流程，了解 kernel selftest、0-day 与 syzkaller 等质量保障体系。
9. 能流畅阅读英文技术文档与社区讨论，具备书面技术表达能力。

加分项

1. 内核子系统 maintainer 或活跃贡献者。
2. 有 AI/HPC 场景下的内核优化实战经验。
3. 熟悉 eBPF 生态并有生产环境落地案例
4. 有 KVM、Kata、或 Serverless 沙箱等轻量虚拟化方向的内核开发经验。
5. 有 vGPU、MIG、SR-IOV 或 GPU 直通（vfio）适配和落地经验。
