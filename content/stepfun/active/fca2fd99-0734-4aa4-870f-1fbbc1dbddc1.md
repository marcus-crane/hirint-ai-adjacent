岗位职责：

1. **行业产品规划与场景挖掘：**深入零售行业，调研产业链上下游角色业务模式、需求与痛点，识别 Agent 高价值落地场景。
2. **产品设计与迭代** ：参与零售行业垂直 Agent 的产品设计，将复杂零售业务抽象为可执行的 Agent 任务链路，并持续迭代，不断突破产品的能力上限。同时保持对国内外零售 AI Agent 竞品、行业最佳实践的关注，输出竞品分析。
3. **推动产品落地应用：**参与同客户的售前沟通，推动产品上线及规模化应用、付费，解决落地过程中的业务与技术阻碍，保障 Agent 在真实零售业务中得到应用。

任职要求：

1. 本科及以上学历，计算机相关专业，2年以上产品经理工作经验
2. 具备良好的逻辑思维，可高质量完成PRD撰写、流程设计
3. 不需要会写代码，但需要了解基本的编程知识，可以和技术、算法团队高效沟通
4. 理解Agent核心原理，清楚大模型能力边界
5. 业务导向，为产品最终的商业化结果负责
6. 有大型电商/新零售/选品/商品推荐相关产品设计经验者优先
7. 有AI Agent产品落地经验，完整参与过产品从0‑1过程者优先
