负责 Android 端侧数据采集与上下文感知平台建设，打通系统各领域的数据获取、处理、治理、存储与安全链路，为上下文理解、长期记忆和主动 AI 服务提供可靠的数据基础。

岗位需要兼具系统底层开发、数据链路建设、方案设计和工程落地能力，能够承担跨模块工作，而非仅负责单一系统模块维护或应用层功能开发。

岗位职责

1. 系统级数据采集

深入 Android Framework、Native 及系统服务，在业务必要性和用户授权范围内，建设应用生命周期、窗口与交互、通知、多媒体、位置与传感器、网络连接及设备状态等领域的数据采集能力。

2. 采集调度与生命周期管理

统一管理采集源、订阅关系、采集频率和触发条件，协调多个业务消费者，处理后台运行、进程退出、系统重启及资源受限场景，避免重复采集、资源竞争和无效数据获取。

3. 数据处理与治理

设计并实现清洗、标准化、过滤、去重、聚合和异步处理链路，建设 Schema、版本演进、质量校验、来源追踪、有效期和新鲜度管理机制，保障数据语义明确、可靠、可追溯。

4. 数据存储与可靠性

建设结构化、文件、全文及向量数据的存储与检索能力，处理增量更新、跨存储一致性、容量控制、幂等、异常补偿、快照恢复和数据回放，保障长期运行下的数据完整性与可恢复性。

5. 数据安全与脱敏

设计覆盖采集、处理、落盘、检索及对外使用全过程的数据安全方案，建设敏感数据识别、分类分级、脱敏、访问控制、加密存储与传输、日志保护和安全审计能力。在保护隐私的同时，保持必要的数据可用性及实体关联能力。

6. 授权撤回与数据删除

落实用户授权、最小化采集及多用户／账号隔离，保证撤回授权和删除请求能够贯穿原始数据、摘要、索引、向量及其他派生结果，并处理异常恢复或快照恢复后的数据有效性问题。

7. 上下文感知与主动服务支撑

与算法及业务团队协作，从系统事件和历史数据中形成实体、关系、状态与时间窗，处理信息冲突、过期、缺失和不确定性，为长期记忆、Agent 和主动服务提供可验证的上下文接口。

8. 性能优化与工程化交付

控制端侧 CPU、内存、功耗、时延和存储开销，建设自动化测试、数据质量指标、可观测性、故障诊断与灰度发布能力，推动方案从原型验证到稳定交付。

任职要求

1. 5 年以上 Android 系统或基础平台开发经验，具备独立负责核心模块、平台能力或跨模块项目的经历。

2. 熟悉 Android Framework 与系统服务架构，对进程管理、窗口与交互、输入、音频／多媒体、通知、位置或传感器等相关领域有深入实践，能够沿跨进程、跨模块链路定位和解决问题。

3. Java／Kotlin、C／C++ 基础扎实，熟悉 Binder、AIDL、JNI、多线程、异步任务和进程间通信，能够完成 Framework 与 Native 层协同开发。

4. 具备数据采集、事件处理、存储或基础设施平台的实际建设经验，理解数据模型、质量治理、幂等、一致性、状态恢复和异常补偿等工程问题，不局限于简单 CRUD 或数据上报。

5. 熟悉端侧存储与检索技术，具备 SQLite／Room／ObjectBox、文件存储、全文检索或向量检索等相关实践，能够根据业务需求、资源预算和可靠性要求进行技术选型。

6. 具备数据安全与脱敏的方案设计或落地经验，理解敏感数据识别、分类分级、规则／模型结合的脱敏方式、假名化或去标识化、密钥管理及日志安全，能够权衡隐私保护、处理成本与数据可用性。

7. 理解 Android 权限、应用沙箱、SELinux、多用户隔离和访问控制机制，能够将安全要求落实到接口、数据流和生命周期，而不只是停留在规范层面。

8. 具备复杂方案设计与工程落地能力，能够明确系统边界、拆解阶段目标、制定验证指标，并推动跨团队协作和持续迭代。

9. 熟练使用日志、Perfetto／Systrace、dumpsys 等工具，具备性能优化、稳定性治理和复杂问题排查经验。

加分项

1. 有系统级持续感知、事件总线、用户行为数据、上下文平台或端侧数据治理经验。

2. 有文本、图像、音频等多模态敏感信息识别与脱敏经验，能评估漏检、误处理及脱敏后的可用性。

3. 有数据血缘、派生数据清理、跨存储删除、授权撤回或快照恢复安全治理经验。

4. 有 ASR、OCR、Embedding、本地模型、长期记忆或 Agent 数据链路的集成经验。

5. 有低功耗后台任务、低内存设备、多用户／应用分身或多设备协同经验。
