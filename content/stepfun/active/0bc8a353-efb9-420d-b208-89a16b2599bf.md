**工作职责**

1. CLI、Browser Use 与 Computer Use 等能力建设：面向公开 Benchmark 与真实用户体验，让模型能通过 Playwright 操作浏览器、操作手机 App 完成日常任务。

2. 产物生成：围绕 Game、App、视频等形态，建设模型基于代码的产物交付能力；覆盖游戏、3D 与前端生成、Video2Code，code2video，以及产物的编辑与迭代。

3. Agent、Harness 开发：探索 Personal Agent 场景下的统一 Agent、Harness 系统设计（CLI、Browser、Mobile），并实践 User-Agent 协作方案。

4. Envs Scaling：参与大规模沙盒环境合成与真实环境建模，探索 Environment Scaling 与 Agent Harness 的联合优化。

**岗位要求**

1. 工程能力强，能独立把想法跑通到可用；有 Agent 相关经验更佳。

2. 了解或参与过以下任一方向的模型能力提升：Coding Agent、CLI、Browser、Mobile Use、3D 或游戏开发、Personal Agent、Lifelong Learning。

3. 对“模型如何真正完成任务”有工程直觉，愿意直面真实环境的复杂性与不确定性。
