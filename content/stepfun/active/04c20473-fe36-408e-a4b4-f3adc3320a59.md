**职位描述**

1. 围绕 Personal Agent 分析用户任务，明确多模态能力的使用场景、价值与验收目标，形成数据需求及场景覆盖方案。
2. 动态理解方向：设计视频、屏幕与环境变化的数据，覆盖事件识别、时间顺序、状态更新及其对任务行动的影响，保证信号与任务关联真实。
3. 图像／视频生成方向：建设生成与修改任务，明确指令遵循、内容正确性、审美、时序和角色一致性等标准，组织专业样本生产与评审。
4. HTML 工具与产品生成方向：设计可实现的页面、工具及交互任务，验证生成结果的运行、布局、功能与使用体验，记录操作过程和缺陷。
5. 在主专长方向制定数据标准、正反例与边界判例，建设训练数据和独立评测集，组织评审校准、质量分析及问题回流。
6. 运用 Prompt 与 Workflow 搭建生成、修改、检查和评测流程，结合自动校验与人工判断提升效率，保留样本来源、版本和执行记录。
7. 统筹项目排期、人员与外部专家资源，组织试产、培训、复核和返工，协调产品、研究及工程团队完成数据交付与持续改进。

**职位要求**

1. 具备相应的多模态模型、视觉内容、设计、人机交互或前端实践，能在真实工具中验证结果；HTML 方向需能运行、检查 HTML／CSS／JavaScript。
2. 能独立分析 business case，从用户任务出发判断内容或工具是否有用，识别产品与技术边界，将需求转为可执行的数据方案。
3. 具备数据标准与评测能力，能区分功能错误、内容缺陷和主观偏好，建立评价规则与判例，组织校准并分析模型问题。
4. 具备 Prompt 与 Workflow 实操能力，能够配置、复现和改进生成及评测流程，检查 AI 输出，理解自动判断的适用范围。
5. 具备项目与人员统筹能力，能安排排期、培训和产能，协调不同专业人员，对质量复核、返工及交付结果负责。
6. 是 AI 深度用户，持续使用相关生成或 Agent 产品解决真实问题，了解常见失败模式；具有其他方向的可验证能力者加分。
