岗位职责

1. **系统 owner**：对网关的整体架构、技术路线和迭代优先级负责，把控设计方案和代码质量。
2. **稳定性**：建设并维护监控告警、巡检、压测、灰度和回滚机制，主导线上故障的定位、复盘和长期治理。
3. **计费与资金正确性**：负责额度、计费、结算、对账的一致性（幂等、并发、迟到结算、故障恢复），维护渠道定价和成本核算。
4. **组织与审批对接**：对接 SSO、主数据和飞书审批，处理调岗、离职、部门调整下的额度和权限治理。
5. **上游接入与成本优化**：负责多供应商、多渠道的接入、健康检查和故障转移，提升缓存命中率，降低综合成本。
6. **技术演进**：持续跟进协议兼容（OpenAI / Claude / Gemini）、Agent 与 MCP 调用、可观测性等方向。

任职要求

1. 本科及以上学历，985 / 211 或双一流院校（硕士优先），计算机相关专业。
2. 5 年以上后端开发经验，且具备一线或二线互联网大厂经历（如阿里、腾讯、字节、美团、京东、拼多多、快手、网易、B 站、小红书等），在职期间绩效评价为优秀档（如 A / 3.75+ / 超出预期或同等档位），并有核心项目主导或晋升记录；有独立负责过核心系统或平台的经历。
3. 精通 Go，熟悉 Gin / GORM；熟悉 TypeScript / React，能独立完成前后端开发、联调和需求落地。
4. 熟悉 PostgreSQL 和 Redis，有高并发、事务一致性、分布式锁、幂等设计和数据库优化（如读写分离）的实战经验。
5. 有支付、计费、额度、账务或其他资金敏感系统的建设经验，理解对账和故障恢复。
6. 熟悉容器化和 K8s 部署，掌握 OpenTelemetry / Prometheus / 日志平台，能独立搭建监控、告警和压测体系。
7. 有线上故障处理和复盘的经验，责任心强，对数据正确性有敏感度。
8. 了解大模型 API（OpenAI、Claude 等）的调用方式、流式响应和 Token 计费规则。

加分项

1. 做过 API 网关、模型网关或类似代理系统，熟悉主流模型供应商的接入。
2. 熟悉飞书开放平台、SSO / OAuth、主数据或 HR / 组织架构类系统对接。
3. 有 AI Agent、MCP 或 RAG 的落地经验，善用 AI 编程工具提升效率。
4. 有开源项目二次开发和上游版本合并的经验。
