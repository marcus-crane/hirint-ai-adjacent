岗位职责

1. 熟悉财务、法务、行政、IT、人事等业务领域的流程与数据模型，能够基于业务理解参与系统的设计与开发。
2. 负责公司各类内部业务系统的建设与迭代，覆盖需求分析、方案设计、开发实现到上线运维的完整过程。
3. 参与 AI 相关应用的建设，具备将大模型、RAG 等 AI 能力与内部业务场景结合落地的能力（根据业务需要开展）。
4. 善于借助 AI 编程工具以 vibe coding 方式高效推进开发，保障交付效率与代码质量。
5. 负责系统前后端架构设计、性能优化与技术选型，持续提升系统稳定性与扩展性。
6. 与产品、业务（财务、法务、行政、人事等）及数据团队紧密协作，推动需求高效交付。

任职要求

基础要求

1. 计算机相关专业本科及以上学历，3年以上开发经验。
2. 扎实的前后端工程能力，熟练掌握以下技术栈：
3. **后端**：Python、Go、Java、Node.js，具备良好的 API 设计、数据库设计与系统架构能力。
4. **前端**：熟练掌握 React 及现代前端工程化体系。

核心经验（重点）

1. 熟悉企业级业务系统，在财务、法务、行政、IT、人事等领域中的一个或多个有业务理解，熟悉相关业务流程与数据模型。
2. 有企业级业务系统的完整落地经验，能独立承担模块从需求分析、技术方案设计到开发上线的全过程。
3. 熟悉 RAG（检索增强生成）实现原理，并在实际项目中有完整落地经验，了解文档处理、检索召回、与大模型结合的工程实践。
4. 在 vibe coding（AI 辅助编程）方面有一定的沉淀与实践，能熟练借助 AI 编程工具提升开发效率与质量。

加分项

1. 有财务、法务、行政、IT、人事中多个领域的系统建设经验。
2. 熟悉飞书开放平台及 API 集成（审批、考勤、通讯录、人事、财务等模块），有实际对接经验。
3. 有 AI 应用、智能问答、知识库系统的建设经验，了解 AI Agent 的工具调用与任务编排机制；熟悉主流大模型 API（OpenAI 兼容接口、Claude 等）的调用与工程化。
4. 有应用安全经验：熟悉 OWASP Top 10 及常见 Web 安全漏洞（越权、注入、XSS 等）的原理与防护；熟悉 SAST / DAST 等安全扫描工具并集成到 CI/CD 流程者优先。
5. 有权限与数据安全经验：设计落地过统一身份认证与权限体系（SSO、OAuth 2.0 / OIDC、RBAC / ABAC），或熟悉数据分类分级、加密与脱敏、敏感信息保护；了解等保 2.0、数据安全法与个人信息保护的相关要求。
