岗位职责

基于主流 RTOS(FreeRTOS / RT-Thread / ThreadX 等)进行系统移植、适配与功能开发,保障系统实时性与稳定性;

负责 RTOS 内核模块的裁剪、配置与调试(任务调度、中断处理、内存管理、消息队列、信号量等);

负责设备互联与通信链路开发,包括 UART / SPI / I2C 等板级通信,以及 BLE / Wi-Fi 等无线连接能力的对接与调试;

基于 RTOS 搭建软件任务框架,配合硬件团队完成软硬件联调;

参与量产问题排查(死机、死锁、内存泄漏、实时性不足、连接异常等),定位根因并输出解决方案。

任职要求

本科及以上学历,电子 / 通信 / 计算机 / 自动化等相关专业;

3 年左右嵌入式开发经验,熟悉 C 语言;

熟悉至少一种主流 RTOS(FreeRTOS / RT-Thread / ThreadX / LiteOS),有内核裁剪、移植或调试经验;

熟悉 Cortex-M 架构及常用外设通信协议(UART / SPI / I2C 等),具备软硬件联调能力;

了解 BLE / Wi-Fi 等无线连接协议中的至少一种,有实际对接经验优先;

具备基本的问题定位能力(会用示波器 / 逻辑分析仪 / 日志排查)。

加分项

有智能硬件 / 穿戴设备 / IoT 产品的量产落地经验;

熟悉低功耗设计、多任务架构优化;

有 BLE / Wi-Fi 协议栈深度调试或联网通信经验。
