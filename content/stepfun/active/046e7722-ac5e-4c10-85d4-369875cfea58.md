岗位定位

负责公司语音大模型多语种方向的数据能力建设，覆盖 **ASR（语音识别）、TTS（语音合成）、语音对话模型（Speech Interaction）** 等方向。

该岗位需要深入理解不同语言的语言学特点和语音特点，建立多语种数据、评测和语言专家体系，将语言知识转化为可规模化的数据资产，支撑模型训练、评测及商业化落地。

岗位职责

* 负责多语种语音模型数据体系建设，负责公司多语种 ASR / TTS / 对话 数据规划和建设，建立不同语言的数据建设优先级和长期规划。
* 建设多语言 Benchmark 和评测体系，与语音算法和产品团队共同设计多语言模型评测框架。 负责将语言能力要求转化为具体 Benchmark 条目。
* 建设多语言专家体系：负责建立和管理多语言专家资源池，负责专家筛选和管理、质量审核机制建设，将专家能力沉淀为、 标注规范、评测标准、语言知识库、Hard Case库
* 建设语音资产体系：负责支持语音 API 商业化的多语言声音资产建设，包括：多语言音色矩阵规划、音色标签体系设计、说话人属性体系建设，负责音色数据采集、音色评测、音色资产运营
* 管理多语言数据生产流程：负责多语言数据供应商管理、标注任务设计、数据验收标准和数据质量分析，确保不同语言数据达到模型训练和评测要求。

任职要求

* 多语言语言学能力（核心要求）满足以下之一：精通至少一种非英语外语，并具备专业语言背景； 有多语言 NLP / Speech AI 数据经验； 有语言学、语音学、本地化、翻译相关背景。 优先日语 / 韩语 / 法语 / 德语 / 阿拉伯语 / 泰语 / 印尼语等语言能力
* 深入理解语言与语音特点：理解音系学（Phonology）、音素体系（Phoneme）、重音/声调系统、韵律结构（Prosody）、语言变体和文化差异；
* 具备大模型数据、语音/NLP数据、Benchmark设计、人工评测体系建设经验；
* 能够协调算法、产品、语言专家、数据供应商和商业团队，推动复杂多语言项目落地。

加分项

* 有 ASR/TTS/语音大模型项目经验。
* 有多语言 TTS 数据、音色库建设经验。
* 有国际化产品、本地化经验。
* 掌握多个目标语言。
* 有语言专家团队管理经验。
