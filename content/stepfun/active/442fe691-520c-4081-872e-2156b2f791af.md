岗位职责：

1、Android Framework 层开发与定制，负责 Android 系统核心框架层（如ActivityManager,WindowManager,InputManager, Sensor,指纹人脸 等）的模块开发、功能定制和性能优化。

2、根据产品需求，进行 AOSP 的深度定制和移植，适配不同硬件平台（SoC）。

3、开发或扩展 Framework 层的新 API 和服务，支持上层应用的特殊需求。

4、跟踪 Android 最新版本（如 Android 15，16）的新特性、新框架和技术演进方向。

5、与硬件/BSP/驱动团队协作，确保硬件与系统的良好协同，与应用开发团队协作，提供 Framework 层支持，解决应用遇到的系统兼容性或性能问题。

6、编写清晰的技术设计文档、接口文档、问题分析报告和知识库文档。

职位要求

1、计算机科学、软件工程、电子工程或相关专业本科及以上学历；

2、年及以上 Android 系统开发经验；

3、精通 Java 和 Kotlin： 深入理解面向对象设计、多线程、并发编程。

4、深入理解 Android Framework 架构： 对 AOSP 架构、核心服务、Binder 通信机制、Zygote 进程模型、AMS、WMS、PMS、Input、Sensor、指纹、人脸等模块有深刻理解。

5、熟练的 C/C++ 能力： 能够阅读、修改和调试 Native Framework 层代码（如 JNI、部分系统服务）

6、熟练运用 adb, logcat, systrace, perfetto, bugreport, GDB/LLDB 等工具进行复杂问题定位
