**岗位职责**

* 作为内部业务团队使用 AI 模型服务的对接人，受理资源与接入需求，理解业务场景，协调相关方落地并跟进闭环。
* 基于业务用量做资源预估，跟踪使用与履约情况，推动资源合理使用与调剂。
* 对业务反馈的问题做初步判断与分流，转交对应责任人并回复闭环。
* 向业务方同步规则、变更与保障安排；收集一线反馈，推动规则与流程迭代。
* 用 AI / Agent 工具搭建需求跟进、信息同步与问题分诊的自动化流程，提升对接效率。

**任职要求**

* 本科及以上学历，3 年以上业务运营、技术服务、项目管理或需求对接相关经验；
* 理解 API 调用、模型用量与额度等基本概念；
* 沟通与推进能力强，能同时对接多个业务方并在冲突中做优先级沟通；
* 熟练使用 AI 对话与 Agent 类工具，能把它们用进日常运营工作；
* 责任心强，能配合关键时段的响应安排。

**加分项**

* 有大模型、云平台或 API 服务相关的运营或支持经验；
* 了解模型训练等算法相关流程；
* 能用 AI 编程工具或低代码方式自己做小工具、看板、机器人。
