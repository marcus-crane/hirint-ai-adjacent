岗位定位

负责设备与 App 之间的协议和 SDK 底座，提供稳定的身份认证、能力发现、控制、媒体和文件传输能力，并推动 ODM 集成与多端互通。

岗位职责

1. 互联协议与状态机：设计发现、配对、认证、重连、能力协商、多设备/组合设备管理及协议版本兼容。

2. 控制与可靠传输：开发命令回执、实时媒体、分块校验、断点续传、去重、持久化确认及 OTA 传输机制。

3. SDK 研发与平台协作：建设公共协议、设备侧与手机侧 SDK 接口；与 Android/iOS 工程师完成平台适配，与 RTOS/ODM 完成设备集成。

4. 安全与异常恢复：对接设备身份、加密会话及防重放，处理断连、重启、满盘、异常版本等场景。

5. 测试与诊断工具：建设模拟器、协议一致性测试、抓包/日志与链路指标，推动现场问题复现和质量闭环。

任职要求

必须具备

1. 计算机、电子或相关专业本科及以上学历，5 年及以上相关研发经验。

2. 必须具有 IoT 设备互联开发经验，独立承担过蓝牙/BLE 产品协议或 SDK 的设计、开发和量产联调。

3. 熟悉 BLE/GATT、MTU、连接参数、吞吐、重连及抓包分析，能区分系统栈、链路与业务问题。

4. 熟练掌握 C/C++、Kotlin、Swift 中至少一种，理解异步并发、内存/缓冲、事件驱动和 SDK 生命周期。

5. 熟悉序号、流控、校验、确认、幂等和断点恢复，具备版本兼容与接口设计能力。

6. 具备与移动端、嵌入式和 ODM 团队联合定位问题的经验。

加分项

1. 有耳机、录音、可穿戴产品，或同时覆盖设备和 App SDK 的经验。

2. 有蓝牙音频、Wi-Fi 高速传输、设备证书/加密或 OTA 经验。

3. 有硬件在环、自动化互通、协议模拟器或低功耗优化经验。
