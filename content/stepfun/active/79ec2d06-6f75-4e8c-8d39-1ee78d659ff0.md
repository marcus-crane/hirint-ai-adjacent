岗位职责

1. **业务系统建设**：负责财务、法务、采购等企业内部业务系统（如 B2P 业务到付款：采购申请、合同、订单、验收、对账、付款）的需求梳理、方案设计、开发和上线。
2. **流程与数据模型**：设计业务流程、状态流转和数据模型，落地审批流、权限控制、审计留痕等合规能力。
3. **系统集成**：对接 ERP、财务系统、飞书审批、主数据、SSO 等内外部系统，保证数据一致、可对账、可追溯。
4. **端到端交付**：独立完成需求澄清、方案评审、试点验证、上线和使用培训，在业务定制与平台通用化之间取得平衡，让交付结果可复制，不依赖一次性人工操作。
5. **稳定性与质量**：负责线上监控、问题定位和故障复盘，编写单测与集成测试，参与 Code Review，推进灰度发布和回滚机制。

任职要求

基础要求

1. 本科及以上学历，985 / 211 或双一流院校（硕士优先），计算机相关专业。
2. 5 年以上后端开发经验，且具备一线或二线互联网大厂经历（如阿里、腾讯、字节、美团、京东、拼多多、快手、网易、B 站、小红书等），在职期间绩效评价为优秀档（如 A / 3.75+ / 超出预期或同等档位）。
3. 熟悉 Java 或 Go 之一（团队同时使用两种语言），并具备另一种语言的阅读与迁移能力。框架生态：Java — Spring Boot / Spring Cloud、MyBatis；Go — gin / gorm / gRPC。
4. 熟悉 MySQL / PostgreSQL（索引设计与慢查询治理）、Redis、Kafka / RocketMQ。
5. 熟悉分布式锁、事务、幂等、最终一致、重试与补偿；掌握并发编程、网络编程、REST / gRPC API 设计，以及鉴权与权限模型。
6. 能读懂并改动 React 中后台页面，了解现代前端工程化（非硬性要求）。
7. 具备线上问题定位能力，能独立使用日志、链路追踪、指标进行排查。
8. 熟悉发布链路（CI/CD、灰度、回滚），编写单测与集成测试，参与 Code Review，工程质量习惯良好。
9. 沟通与方案表达能力良好，能独立做需求澄清、方案评审和交付培训。

核心经验（重点）

1. 财务、法务、采购等企业内部业务系统的建设经验：有 B2P（业务到付款）等完整业务的端到端落地经验，独立完成过需求梳理、流程与数据模型设计、审批与权限控制、与 ERP / 财务等外部系统对接及上线运行。
2. 熟悉业务流程与合规要求：理解审批流、合同与订单管理、对账与付款、审计留痕、权限分离等控制要点。
3. 强一致业务处理：在计费、配额、账务、付款、库存等涉及资金或数据一致性的场景中，具备幂等、对账和失败补偿的实践经验。
4. 独立负责过中大型业务系统，有 Owner 经历：能讲清模块边界、数据模型与关键状态流转，而不只是“参与开发”。

加分项

1. 有 OA、费控、合同管理、供应商管理或采购平台等系统的建设经验；熟悉飞书开放平台与审批集成。
2. 接触过 AI 网关、模型接入平台或 LLM API 工程化（OpenAI 兼容接口、Claude、流式转发、Token 计量）；了解 Agent / RAG 的工程实现，有合同审查、单据识别、智能问答等场景落地经验。
3. 有多租户 SaaS 经验；有可观测体系（OpenTelemetry / Prometheus / Grafana）与压测基建经验。
