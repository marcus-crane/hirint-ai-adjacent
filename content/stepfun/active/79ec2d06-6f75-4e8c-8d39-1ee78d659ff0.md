岗位职责

1. 熟悉 EHR / 人事核心业务（组织架构、员工全生命周期管理、招聘、考勤假期、薪酬绩效、入职离职等）的流程与数据模型，能够基于业务理解参与系统的设计与开发。
2. 负责 EHR 人事系统及 AI Agent 相关应用的建设，具备将大模型、Agent、RAG 等 AI 能力与实际人事业务场景结合落地的能力（根据业务需要开展）。
3. 善于借助 AI 编程工具以 vibe coding 方式高效推进开发，保障交付效率与代码质量。
4. 负责系统前后端架构设计、性能优化与技术选型，持续提升系统稳定性与扩展性。
5. 与产品、HR 业务、数据团队紧密协作，推动需求高效交付。

基础要求

1. 计算机相关专业本科及以上学历，3 年以上开发经验。
2. 扎实的前后端工程能力，熟练掌握以下技术栈：
3. **后端**：Python、Go、Node.js、Java，具备良好的 API 设计、数据库设计与系统架构能力。
4. **前端**：熟练掌握 React 及现代前端工程化体系。

核心经验（重点）

1. 熟悉 EHR、HR SaaS 或人事系统，或财务、采购、ERP 等其他企业级业务系统，理解相关业务流程与数据模型。
2. 有 AI Agent 的完整落地经验，熟悉工具调用（Function Calling）、任务规划与编排、记忆管理、多轮交互等 Agent 核心机制，了解 MCP 协议及主流 Agent 框架（LangGraph、LangChain、LlamaIndex、Dify 等）。
3. 熟悉 RAG（检索增强生成）实现原理，并在实际项目中有完整落地经验，了解文档处理、检索召回、与大模型结合的工程实践。
4. 在 vibe coding（AI 辅助编程）方面有一定的沉淀与实践，能熟练借助 AI 编程工具提升开发效率与质量。

加分项

1. 熟悉飞书开放平台及 API 集成，有实际对接经验。
2. 有 AI 应用、智能问答、知识库系统的建设经验；有 HR 场景落地经验（如智能 HR 助手、简历解析、员工政策问答、绩效数据分析等）优先。
3. 熟悉主流大模型 API（OpenAI 兼容接口、Claude 等）的调用与工程化，了解 Prompt 工程、效果评测与推理成本优化。
