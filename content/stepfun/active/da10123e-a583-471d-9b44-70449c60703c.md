岗位定位

负责用户专属云端 Agent 的运行管理与工程交付，将开源 Agent 框架接入可运营的平台，而不仅是完成一次部署或模型调用。

岗位职责

1. 实例管理与接入：建设用户到 Agent 实例的映射、认证路由、实例创建、启动、休眠、恢复、升级及销毁能力。

2. 安全隔离与资源控制：实现运行环境、文件、凭证、网络出口和工具权限隔离，建设 CPU/内存/并发/调用额度等限制。

3. 任务与持久化：开发异步任务、定时唤醒、检查点、用户工作区与持久数据管理，支持实例重建及失败恢复。

4. 框架适配：接入 OpenClaw 等 Agent 框架，通过版本化接口和必要插件对接工具、记忆和模型服务，控制上游升级影响。

5. 平台可观测与发布：建设实例监控、Trace、日志脱敏、成本分析、镜像发布与灰度回退，优化启动时延和资源利用率。

任职要求

必须具备

1. 计算机或相关专业本科及以上学历，4 年及以上软件研发经验。

2. 具有云端 Agent 平台、AI 应用运行平台，或具备隔离执行需求的 IoT 云平台开发经验。

3. 熟练使用 Python、TypeScript、Go、Java 中至少一种语言，能够独立完成服务开发、联调与问题定位。

4. 熟悉 Linux、Docker/Kubernetes 或虚拟机/沙箱技术，理解进程、网络、文件和用户凭证隔离。

5. 熟悉任务队列、资源调度、超时重试、持久化、幂等与状态恢复，具备运行服务而非只部署 Demo 的经验。

6. 理解 Agent 会话、工具调用、流式消息与权限风险，能够与算法、后端及 App 团队协作。

加分项

1. 有 OpenClaw、microVM、安全沙箱、工作流引擎或多租户托管经验。

2. 有工具调用授权、防提示注入、插件管理、实例休眠唤醒或冷启动优化经验。

3. 有 SRE、云成本优化、镜像漏洞治理或生产故障演练经验。
