**职位描述**

1. 分析真实用户的生活情境与业务案例（business case），从 Need、Intent 到 Task 拆解需求、意图和任务，明确数据建设要解决的问题与用户价值。
2. 构建包含生活环境、关系、偏好、目标、记忆及外部事件的用户世界，设计可信的用户画像，使对话与任务有连续、具体的情境依据。
3. 设计跨会话、跨时间的对话故事线和长程任务，覆盖聊天、陪伴、主动服务及任务执行；结合产品能力与工具条件，保证故事合理、任务可实现。
4. 制定对话与用户建模的数据标准、正反例和边界判例，明确自然度、个性化、记忆一致性、用户意图及任务完成等维度的判断规则。
5. 建设训练样本与独立评测集，组织试标、评审校准和质量分析，定位模型在理解、表达、记忆或行动上的问题，将结果用于改进数据。
6. 使用 Prompt 与 Workflow 完成场景扩展、对话生成、样本检查和问题归类，结合人工判断提高效率，保留数据来源与版本记录。
7. 统筹项目排期、人员与专家资源，开展培训、质量复核和返工跟进，协调产品、研究及工程人员，推动数据按标准完成交付。

**职位要求**

1. 具备心理学、剧作、用户研究、对话产品或相关实践经验，能够理解人物动机、关系变化与真实需求，并将其转化为可用的数据方案。
2. 是 AI 深度用户，持续使用对话或 Agent 产品解决真实问题，了解其优势与局限，能够判断何时需要澄清、使用工具或由人介入。
3. 能独立分析 business case，区分用户需求、表达意图和可执行任务，理解现实约束，不以丰富情节替代真实价值。
4. 具备数据标准制定与评测能力，能把主观体验转化为清晰规则，处理边界案例和评审分歧，依据证据分析问题。
5. 具备 Prompt 编写和 Workflow 搭建能力，能够复现、检查和改进生成过程，对 AI 输出保有判断力。
6. 具备项目与人员统筹能力，能协调排期、培训、产能、质量和沟通，推动多人协作完成可验收的交付。
7. 表达清晰，善于研究用户与编写连续场景，对隐私、用户自主性及情感陪伴边界有判断；兼具 Agent 任务设计能力者加分，不要求多种背景兼备。
