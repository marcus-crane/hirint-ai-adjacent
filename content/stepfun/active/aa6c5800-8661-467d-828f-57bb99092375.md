**职位描述**

1. 从生活、工作中的真实需求开展 business case 分析，明确用户意图、交互条件、任务价值和模型能力缺口，制定场景覆盖、难度分层与样本优先级，识别脱离产品能力的脚本。
2. 制定全双工交互的数据标准，覆盖开口、继续、停说、让话、等待、打断与恢复，以及多说话人、背景声和重叠语音；将模糊判断转为判定树、正反例和边界判例。
3. 设计训练样本与评测案例，组织对话脚本、语音、交互事件及任务状态的生产，检查文本、时间戳、说话对象、标签与工具执行记录的一致性。
4. 建立评分规则、金标与试标校准机制，组织人工评测和错误复盘，区分理解、交互决策、执行与声学问题，形成可回流生产的改进清单。
5. 使用 Prompt 与 Workflow 完成场景扩展、样本生成、预标注和质检辅助，设置人工检查与验收环节，记录版本和失败案例，提升合格样本的生产效率。
6. 统筹项目排期、人力、产能和交付风险，组织标注员培训、质量校准及返工；对接内部团队与外部生产资源，对所负责项目的质量和进度负责。
7. 与产品、算法、声音和 Agent 同学对齐验收标准，结合模型评测反馈调整数据分布与生产策略，验证数据改动是否改善目标场景表现。

**职位要求**

1. 有语音数据、语音交互产品或模型数据与评测相关实践，能够说明自己负责的项目、关键判断和结果，具备独立推进一个业务场景的能力。
2. 理解全双工对话中的话权、重叠、打断和恢复，能分析真实录音及疑难案例；能读懂 JSON、时间戳和结构化标注结果。
3. 能从用户需求分析任务价值与可实现性，把业务问题转为数据要求，识别不真实的用户动机、错误假设和缺失的执行条件。
4. 能独立编写可执行的标准与评分规则，设计抽检和校准，解释合格率、一致率等结果，并依据证据定位错误原因。
5. 是 AI 的深度用户，有持续使用语音或 Agent 产品解决实际问题的经验；能编写 Prompt、搭建基础 Workflow，并检查输出质量和使用边界。
6. 有项目或人员统筹实践，能拆解任务、估算产能、组织培训、处理质量争议；文档表达清楚，能够推动多方形成一致口径。
7. 以语音交互为主专长；具备 Agent 任务设计、复杂对话、用户建模或轻量脚本能力属于加分项，不要求同时具备全部副专长。
