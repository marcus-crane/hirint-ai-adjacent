岗位介绍

我们正在打造 Stepcode，让 Agent 在代码开发与日常工作中，不止能回答问题，更能可靠地完成任务。

你将负责提升 Agent 在真实场景中的执行效果：理解用户如何使用 Agent，识别任务成功与失败的关键因素，深入探索阶跃模型的能力边界，推动模型与 Harness 的共同进化。

这里的 Harness，是让模型持续执行任务的运行机制与产品系统，包括上下文管理、工具调用、任务规划、记忆、多智能体协作，以及执行过程中的权限、反馈与恢复机制。

我们希望你不仅是 Agent 产品的深度用户，更能把“这次做得好不好”的直觉，转化为可分析、可验证、可迭代的产品判断。

工作职责

1. **发现值得解决的真实任务**
2. 深入代码开发与日常工作场景，理解用户的目标、工作流程和使用障碍，识别适合 Agent 完成的任务，参与制定 Stepcode 产品路线图与迭代优先级。
3. **定义并评估 Agent 的执行效果**
4. 建立真实任务案例与评估方法，从任务完成质量、执行可靠性、用户干预程度、耗时与成本等维度，衡量产品表现，验证迭代是否真正改善用户体验。
5. **分析失败，推动模型与 Harness 协同优化**
6. 跟踪用户任务的完整执行过程，分析上下文、规划、工具调用和执行恢复等环节的问题；与研究员、工程师协作，区分模型能力、Harness 机制与交互设计带来的影响，并推动改进。
7. **将实践判断转化为产品方案**
8. 围绕上下文管理、工具与 Skills、多智能体协作、长任务执行等关键能力，形成产品方案、验收标准和实验设计，持续验证效果。
9. **连接用户与开源社区**
10. 与高频用户、开发者及开源社区保持紧密交流，从反馈中识别高价值信号，推动问题闭环，并将有效的使用实践沉淀为产品能力。

任职要求

1. **是 Agent 产品的深度用户**
2. 深度使用过 Claude Code、Codex、Cursor、OpenCode、Manus 等代表性产品中的一种或多种，并将其用于真实任务。能够结合具体案例，解释产品之间的差异、能力边界和使用取舍，而不只是罗列功能。
3. **理解 Agent 的基本工作机制**
4. 理解 Agent Loop、工具调用、规划、上下文管理、Skills、MCP、Memory 和 Subagent 等机制，能够结合执行过程分析问题；对 Prompt Engineering、Context Engineering 或 Harness Engineering 有第一手实践。
5. **对执行质量和用户体验有判断力**
6. 能识别“看起来完成了”和“真正解决了问题”的区别，对异常分支、边界条件和失败场景敏感，关注用户在等待、干预、确认与恢复过程中的体验。
7. **能把模糊问题变成可验证的改进**
8. 能从具体任务与用户反馈出发，提出问题假设、定义评估标准、设计验证方式，并根据结果调整判断，而不是仅凭个人偏好推动功能。

加分项

* 有 Developer Tools、IDE、CLI 或其他开发者产品经验。
* 有与模型研究团队深度协作，参与模型评估或效果优化的经验。
* 搭建过 Agent、Skills、MCP 工具或自动化工作流，并持续用于实际工作。
* 参与过开源项目，或有开发者社区运营与协作经验。

我们期待看到的实践

欢迎在简历中附上你最有代表性的 Agent 使用或构建案例，包括：

* 你希望完成什么任务，为什么选择使用 Agent；
* 执行过程中遇到了哪些失败，你如何定位和改进；
* 你做过哪些配置、工具或工作流设计，最终效果如何。
* **我们更看重真实实践、独立判断和持续验证的能力，而不是你熟悉多少工具名称。**
