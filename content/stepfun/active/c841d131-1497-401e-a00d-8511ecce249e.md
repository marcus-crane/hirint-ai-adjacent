岗位定位

负责 AI 耳机、录音设备等新品类的云端技术架构与核心开发，带领云平台工程师建设账号、设备管理、用户专属 Agent、模型接入和数据服务。在整体软件架构下统筹云端方案，亲自承担关键代码与上线交付。

岗位职责

1. 云平台架构与核心开发：设计账号、设备、Agent、内容与记忆、模型网关的模块边界和服务接口，亲自实现基础框架与关键链路，兼顾快速验证、可扩展性和长期维护。

2. 用户专属 Agent 托管：基于 OpenClaw 等框架建设用户专属运行环境，设计实例创建、路由、资源隔离、休眠恢复、版本升级及持久化方案，保障不同用户的数据与权限隔离。

3. 端云协同与平台接入：与 App、算法和设备团队定义会话、任务、工具、记忆及设备能力契约，支持端云协作与后续平台迁移，避免重复执行和数据不一致。

4. 安全、稳定性与成本：建设鉴权、工具授权、密钥管理、配额、模型费用和实例成本控制，完善监控告警、灰度发布、备份恢复与故障处置。

5. 团队协作与技术交付：负责云端技术拆解、设计和代码评审，推动公司基础服务复用；参与招聘与人才培养，对关键里程碑及线上质量负责。

任职要求

必须具备

1. 计算机或相关专业本科及以上学历，8 年及以上软件研发经验，具有技术负责人或核心架构设计经历。

2. 具备面向用户的云服务从 0 到 1 搭建、上线并持续运营的完整经验，能说明本人承担的核心代码与架构决策。

3. 熟悉分布式服务、数据库、消息队列、对象存储、鉴权、幂等、容灾与可观测体系，具备真实故障定位和稳定性治理经验。

4. 具备 IoT 平台或云端 Agent 系统的架构与落地经验，理解设备生命周期或 Agent 任务、工具、状态和资源管理。

5. 熟悉容器、虚拟机或沙箱的运行与隔离机制，能设计多租户权限、网络出口和持久化边界。

6. 熟练使用 Go、Java、Python、TypeScript 中至少一种语言，能够持续参与编码、调试和性能优化。

7. 具备带领研发人员协作交付的经验，能够与移动端、算法、硬件及基础平台团队明确接口和责任。

加分项

1. 有 AI 硬件、可穿戴、耳机、录音或消费级 IoT 产品经验。

2. 有 OpenClaw 或其他 Agent 托管平台、工具安全及端云协同实践。

3. 有模型网关、订阅权益、用量计费、个人数据治理或多地域服务经验。
