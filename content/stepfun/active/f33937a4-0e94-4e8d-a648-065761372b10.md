岗位定位

负责手机端轻量 Agent 的工程落地，围绕个人记忆、设备能力和云模型构建可恢复、可授权的智能交互。该岗位是 2 个记忆算法/Agent 名额之一，侧重 Kotlin/KMP 与端侧运行能力。

岗位职责

1. 端侧 Agent 核心：参考 nanobot 等框架，以 Kotlin/KMP 实现轻量 Agent loop、上下文管理、流式交互、工具调度和端云路由。

2. 任务与工具机制：建设任务状态、检查点、超时取消、重试和幂等回执，对接独立程序权限校验与用户确认机制。

3. 记忆与模型接入：参与记忆检索、上下文组装和效果优化，接入云模型及端侧轻量 ASR/基础指令能力，处理离线与资源降级。

4. 多端集成：与 Android/iOS 和互联团队定义 SDK、设备工具及数据接口，处理生命周期、并发与可恢复执行。

5. 评测与持续优化：建设任务回放、工具成功率、记忆使用质量、时延和成本评测，定位模型错误与工程错误。

任职要求

必须具备

1. 计算机、人工智能或相关专业本科及以上学历，3 年及以上软件或 AI 应用研发经验。

2. 具有 Agent 开发与记忆/RAG/上下文管理相关的实际落地经验，能说明本人实现的核心模块与效果。

3. 熟练掌握 Kotlin，具备跨平台或移动端研发能力，能够交付 Kotlin/KMP 共享核心；不能仅具备 Python 原型或提示词配置经验。

4. 熟悉 LLM 接入、结构化输出、Function Calling、上下文压缩、检索增强与评测方法。

5. 具备状态机、异步并发、持久化、错误恢复、授权及幂等的工程基础。

6. 能够与记忆算法、云端、客户端和设备团队协同，将算法方案落地为可测试的产品能力。

加分项

1. 有 KMP iOS 集成、nanobot/OpenClaw、端侧 Agent 或工具协议/MCP 实践。

2. 有轻量 ASR、端侧模型运行、量化或移动端资源优化经验。

3. 有个人记忆、语音交互、IoT 设备工具调用或高质量开源贡献。
