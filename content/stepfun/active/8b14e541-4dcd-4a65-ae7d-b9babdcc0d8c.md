【关于阶跃星辰与团队】

阶跃星辰（StepFun）致力于探索通用人工智能（AGI），在原生多模态视觉理解、三维空间感知、长程深度推理与 Code Agent 领域稳居行业第一梯队，并在智能汽车、手机及原生硬件终端构建了完整的“端云协同”生态。

面向物理世界通用智能，我们正在加速研发服务于通用机器人的「具身推理大脑（Embodied Brain）」与高保真数字试炼场。现阶段，我们以可扩展的物理仿真闭环与机器人代码智能体（Robotics Code Agent）为核心切口，让基座大模型深度掌握三维空间几何关系、接触动力学直觉、跨回合长期记忆与控制策略编程能力，在灵巧手操作、双臂协同、移动导航及复杂家务和工业装配等长程开放任务中实现任务拆解、技能合成与闭环失败恢复。我们寻找兼具机器人仿真和控制硬功底，也具备具身学习视野的同路人，共同塑造物理世界智能体的行业标准。

【岗位职责】

1. 具身任务谱系设计与核心原子能力拆解：围绕机器人操作（Manipulation）、多指灵巧手（Dexterous Hands）、运动与导航（Locomotion & Navigation）、动态物理交互及长程开放指令任务（精密装配、收纳整理、工具使用与物理谜题），系统拆解三维空间定位、可操作性（Affordance）、接触物理直觉、记忆机制与闭环纠错等核心原子能力。
2. 高保真物理仿真环境与 RLVR 基础设施（Sim & Execution Harness）建设：基于主流物理引擎与具身仿真框架（MuJoCo、NVIDIA Isaac Sim / Isaac Lab、ManiSkill、SAPIEN、RoboCasa、Newton / warp、Gazebo 等），构建高并发、确定性可复现的交互学习环境；封装标准化 Obs / Action / Reset 与控制抽象接口（IK/运动规划/力控/全身控制 WBC），设计防刷分（Anti-Reward-Hacking）自动化验收判据与奖励函数。
3. Robotics Code Agent 与闭环具身推理攻关：推进多模态推理基座模型通过编写控制策略代码、编排感知与规划工具库（ROS2 / MoveIt / 视觉伺服等）并根据环境执行反馈自主重规划的新范式；建设高区分度具身评测基准，深入开展仿真与策略失败轨迹的根因归因。
4. 高质量可交互资产治理与具身合成数据飞轮：联合多模态预训练与 Agent RL 团队，推进 Real2Sim 可交互三维场景与关节资产（URDF / MJCF / USD）构建、物理参数校准（定位并消除穿模、抖动与接触失稳）、自动化轨迹扩增及失败恢复演示数据的合成与质检，协同推进外部具身生态合作。

【任职要求】

1. 扎实的机器人学或 AI/图形学背景：机器人工程、自动化、控制科学与工程、机械电子、计算机科学、计算机图形学或人工智能等相关专业本科及以上学历（硕博，或具备头部具身智能团队、知名机器人实验室核心研发经历者优先）。
2. 深度的物理仿真与机器人系统实战：深入掌握至少一种主流机器人物理仿真框架（MuJoCo、NVIDIA Isaac Sim / Isaac Lab、SAPIEN / ManiSkill、OmniGibson、Newton、Gazebo 等）；熟悉刚体与关节动力学、碰撞接触摩擦模型、多模态传感器流（RGB-D、点云、本体状态、力/触觉）及仿真资产转换与物理调优全流程。
3. 过硬的系统实现与 AI-Native 开发能力：精通 Python（熟悉 C++/ROS2/Linux 容器化并行调度者更佳），熟练运用 Claude Code / Codex 等现代 AI 编程工具高效开展大规模并行仿真环境封装、规划控制接口对接与评测管线性能优化。
4. 前沿算法判断力与实验品味：熟悉具身智能与机器人学习核心范式（Embodied Code Agent、视觉语言动作模型 VLA、世界模型 World Models、强化学习 RL、模仿学习 IL、TAMP 或 Real2Sim2Real），能严谨区分“仿真资产/底层控制误差”与“模型高层感知规划缺陷”。

· 具备机械臂、灵巧手、双臂移动机器人或人形机器人的真机部署、遥操作数采、系统辨识与虚实一致性（Sim-to-Real Alignment）校准经验，或在顶级机器人竞赛中取得突出成果；
