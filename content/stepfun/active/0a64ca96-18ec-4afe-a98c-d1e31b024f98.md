岗位职责：

•把标注策略写成人人能执行的手册：基于产品与算法给定的标注策略，细化切句、转写、时间戳、"这句话是说给谁的"、重叠与打断、事件与决策点等口径，配判定树、正反例与边界判例，用大白话写到新标注员能直接上手。

•组织试标与校准：新口径先小批量试标，统计双人标注一致率，主持口径仲裁会，把有争议的判例连同结论写回手册，管理手册的版本与生效日期。

•参与金标评审：与产品、算法一起评审黄金样本的逐决策点金标——"此刻助手该做什么"的最优、可接受与禁止边界，保证标准在标注侧可执行、可检验。

•沉淀常见错误库与培训素材：从质检退回数据里归纳高频错误，输出示范标注、练习题与上岗考核题库，支撑新人培训。

•与标注平台协作：把可自动化的规则（字段校验、时间合法性、枚举约束、预标注）提给平台，持续压缩人为出错空间。

•输出外采标准：把内部口径转成供应商可执行的下单说明与验收标准。

任职要求：

•3 年以上数据标注相关经验，其中至少 1 年负责过标注规范 / 口径制定或质检标准建设；语音、对话、音频类项目优先。

•听感好、耐得住细节：能在多说话人、有背景噪声、语音重叠的录音里准确切分句子、判断说话对象与截断点，对 0.1 秒级的时间戳差异敏感。

•逻辑与文档能力强：能把模糊的判断规则写成一步步可执行的判定树和检查清单，表达是大白话，标注员看得懂、照着做结果一致。

•能读懂 JSON 格式的结构化标注结果，理解字段、枚举与引用关系，能与算法同学对齐数据格式。

•主持过口径仲裁或争议判例讨论：在"两个人都有道理"的时候能拍板，并给出可复用的理由。

•普通话标准，中文书面表达好。

加分项

•语言学 / 语音学 / 中文 / 心理学 / 计算机相关专业背景，了解会话分析、语用学的基本概念。

•做过 ASR 转写、说话人分离、音频事件、对话意图或情绪类标注项目，了解字准率、Kappa / 一致率等质量指标。

•有大模型数据经验：SFT 指令数据、偏好 / 评测集、人工评估 rubrics 的制定或质检。

•会用 Python / 正则 / 表格函数做批量口径核对或质检脚本。

•用过主流标注平台或自研多轨时间轴标注工具。
