**岗位一：AIOS 产品经理（系统交互方向）**

**岗位使命**

负责 AIOS 系统框架与 SystemUI 的产品定义和持续演进，让桌面、锁屏、通知、控制中心、状态栏、多任务等系统级体验既稳定、流畅、一致，也能自然承接 Agent 的感知、执行、状态展示与人机协作。

**岗位职责**

1. 负责 AIOS Framework / SystemUI 方向的产品规划、版本路线和需求管理，覆盖桌面、锁屏、通知中心、控制中心、状态栏、灵动岛、多任务、系统导航等核心系统界面。

2. 具备系统性思维，优秀的交互体验设计能力和美学品味，能主导定义新的系统级交互，AI 与 OS 的融合方式。

3. 将复杂方向拆成可交付的产品范围，建立需求池、优先级、版本里程碑、Owner、验收标准和风险台账，推动从概念、冒烟评审到上线验证的完整闭环。

4. 与交互、视觉、研发、模型与 Agent、硬件、测试和项目团队密切协作，提前识别技术约束、性能功耗、安全权限与版本依赖。

5. 建立系统体验质量基线和指标体系，持续改善核心链路的任务成功率、响应速度、动效流畅度、状态可理解性、稳定性和一致性。

6. 组织竞品研究、用户走查与内部 Dogfooding，把问题转化为可验证的产品假设和明确的优化优先级。

7. 推动团队采用 AI 原生工作方式，使用 AI 工具完成研究、分析、原型、需求拆解、评测和跨团队协作，并沉淀可复用的方法。

**岗位要求**

1. 5 年以上智能手机、移动 OS、系统框架、SystemUI 或复杂终端产品经验；有核心系统模块从规划到规模交付的完整经历。

2. 有 AI 手机、Agent OS、系统级 AI 助手、原子能力 / Tool Calling、端云协同或多模态交互项目经验优先。需理解大模型、Agent、RAG、MCP / 工具调用、评测集、上下文、记忆、权限与 Human-in-the-loop 等基本概念。

3. 擅长把抽象愿景转化为可验收结果，能够输出清晰的需求范围、状态机、关键流程、异常分支、指标和验收标准。

4. 对交互细节、系统一致性、性能功耗和稳定性敏感，能在体验收益、工程成本、版本风险之间做判断。

5. 有较强的跨团队推动能力，能通过冒烟评审提前对齐关键方并锁定资源，而不是等待方案全部完成后再推进。

6. 能熟练使用 Codex、Claude、ChatGPT 等 AI 工具直接完成研究、原型、数据分析、文档和工作流自动化

**岗位二：AIOS 产品经理（系统应用体验方向）**

负责 AIOS 一方系统应用的整体体验与 AI 化升级，让文件管理、设置、通话、联系人、短信、输入法、换机、帮助与反馈等高频基础能力好用、一致、可靠。对系统应用能力进行 AI friendly 改造，成为 Agent 可理解、可调用、可验证的系统服务。

**岗位职责**

1. 负责 AIOS 一方系统应用的产品规划、版本路线和需求管理。从高频用户任务出发梳理跨应用体验链路，解决应用体验问题。

3. 推动一方应用与 AI / Agent 的融合，定义哪些能力应开放为原子能力或工具、如何描述参数与权限、如何返回执行状态，以及何时由 Agent 调用、何时交还用户。

4. 建立一方应用体验标准与一致性机制，能协同 Design System 推进控件、排版、亮暗模式、动效、材质和无障碍体验在应用中的落地。

5. 与应用研发、系统框架、云服务、账号、模型 / Agent、安全、测试和设计团队协作，推动关键需求完成冒烟、资源锁定、开发、验收和数据复盘。

6. 建立应用级与任务级指标，持续跟踪任务成功率、完成时长、错误率、留存 / 使用率、用户反馈和 Agent 调用质量。

7. 通过用户研究、竞品对标、内部 Dogfooding 和真实反馈识别问题，形成有优先级的体验改进计划。

8. 使用 AI 工具提高研究、内容整理、需求拆解、原型、测试用例、反馈聚类和跨团队协同效率，并推动团队形成可复用实践。

**岗位要求**

1. 5 年以上移动端、系统应用、工具产品或复杂消费级产品经验；至少完整负责过一个高频应用或跨应用任务链路。

2. 对 OS 中文件、通信、设置、输入、账号、数据迁移等核心基础体验有深入理解，能从用户任务而不是功能列表出发定义产品。

3.有 AI 应用、Agent、智能助手、一方应用 AI 化、原子能力 / Tool Calling 或 RAG 项目经验。有跨应用服务化、能力平台化、API / 原子能力设计或应用与系统框架协同经验。

4. 具有较强的体验判断力和细节敏感度，能够识别“功能可用但体验不成立”的问题，并推动跨模块修复。

5. 有跨设计、研发、测试、云服务和业务团队推进复杂项目的经验，能够提前对齐关键方、锁定资源并控制范围。

6. 数据意识和用户意识兼备，能结合行为数据、用户反馈、问题单和定性研究判断优先级。
