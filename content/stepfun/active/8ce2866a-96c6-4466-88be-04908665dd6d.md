**岗位定位**

负责公司大模型在**零售行业的业务整体经营与发展**，围绕 Agent 产品创新、行业场景落地及商业化增长，带领产品、销售、解决方案、运营等组成的综合团队，探索并跑通大模型在零售行业的规模化商业路径。

这是一个兼具**产品思维与业务经营思维**的岗位，需要既能判断“什么产品值得做”，也能解决“产品如何真正进入客户场景并形成商业价值”。

**岗位职责**

1. **业务经营与战略**

* 负责零售行业业务整体规划与经营，对业务方向、产品布局、商业化目标及核心经营结果负责；
* 深入理解零售行业及大模型发展趋势，识别高价值场景和市场机会，形成清晰的业务策略及阶段性目标；
* 推动产品、市场与客户需求形成正向循环，持续探索可复制、可规模化的商业模式。

1. **Agent 产品创新**

* 围绕零售行业真实场景，推动大模型及 Agent 产品创新，包括但不限于消费者服务、营销增长、导购、运营提效等方向；
* 能够从客户需求和行业痛点出发定义产品，而非单纯承接客户项目；
* 与模型、技术及产品团队协同，持续提升产品竞争力和行业适配能力。

1. **商业化与客户落地**

* 负责零售行业重点客户拓展及商业化落地，建立标杆客户和标杆案例；
* 推动从客户洞察、产品方案、PoC 到正式商业化及持续运营的完整闭环；
* 沉淀标准化产品、解决方案及销售打法，推动业务从项目型交付逐步走向产品化、规模化增长。

1. **团队管理**

* 管理约 10 人左右的综合业务团队，覆盖**产品、销售、解决方案、运营**等职能；
* 建立跨职能协作机制，统一产品目标与商业目标，提升团队整体作战能力；
* 负责团队关键人才引入、培养及梯队建设。

**任职要求**

* 具备较强的**产品思维 + 商业思维**，能够同时从用户价值、产品竞争力和商业结果三个维度思考问题；
* 有零售、消费、互联网平台或相关行业经验，对零售行业客户、业务链路及核心场景有较深入理解；
* 有 AI / 大模型 / Agent / SaaS / 企业服务等相关产品或业务经验优先；
* 有从 **0→1 产品创新、商业化验证，再到规模化复制**的实际经验；
* 具备较强的 ToB 商业化能力，能够与大型客户核心决策者沟通，并推动复杂项目落地；
* 具备跨职能团队管理经验，有产品、销售、解决方案、运营等复合团队管理经验优先；
* 对大模型及 Agent 带来的产业变化有较强判断力和热情，愿意亲自深入产品和客户一线。

**我们希望找到的人**

不是单纯的销售负责人，也不是单纯的产品负责人。

我们希望 TA 能像一个**业务 GM** 一样思考：既能看行业、看客户，也能看产品、看技术；既能找到新的 Agent 产品机会，也能带着团队把产品卖出去、落下去、运营起来，并最终形成规模化的业务。
