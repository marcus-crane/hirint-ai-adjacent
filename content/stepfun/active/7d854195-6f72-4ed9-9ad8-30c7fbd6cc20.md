1.端侧 AI 功耗优化工程师

岗位定位：负责AI相关模型，端侧AI交互等场景功耗设计、验证与优化，从全局维度降低整机功耗、保障体验。

岗位职责：

负责 Android 平台端侧 AI 模型推理场景的功耗分析与优化，降低 AI 功能能耗与发热，提升运行能效；

建立大模型、多模态及语音场景的功耗评测方法，分析模型推理各阶段的计算、访存及系统资源使用特征，定位能耗瓶颈；

结合 AI 推理负载特征，优化 CPU/GPU/NPU 资源调度、频率策略及电源管理策略，在响应时延、吞吐和模型效果约束下提升能效；

分析持续推理及实时语音交互场景中的温升、热降频与能效变化，协同优化温控和推理执行策略；

与算法、推理框架及芯片平台团队协作，评估模型量化、计算后端选择、硬件加速及算子执行方案的能耗收益，推动优化落地；

建立功耗回归验证机制，以单次任务能耗、单位 Token 能耗、实时语音处理能耗及温升等指标跟踪优化效果。

任职要求：

计算机、电子信息或相关专业本科及以上学历，具备 Android/Linux 平台功耗分析与优化经验；

熟悉移动平台电源管理机制，具备资源调度、DVFS、系统唤醒或温控策略相关的优化实践；

熟练使用功耗仪及 Perfetto、simpleperf、ftrace 等分析工具，能够结合功耗曲线与系统 Trace 完成问题定位、能耗归因和优化验证；

理解 LLM 及 MoE 等典型模型架构与推理原理，熟悉 Attention、KV Cache、专家路由及稀疏激活等机制，能够分析 Prefill、Decode 等阶段的计算、访存特征及其对功耗的影响；

理解 Omni 多模态模型及 TTS、ASR 等语音模型的工作原理，熟悉流式推理、跨模态交互及实时处理中的负载特征，能够结合业务场景识别能耗瓶颈并制定优化方案；

熟悉 C/C++，具备 Android Native、HAL 或 Linux Kernel 相关模块的开发与调试经验；

具备数据驱动的问题分析能力，能够独立推进功耗问题的定位、方案实施及效果验证，并与算法、系统和芯片平台团队有效协作。

加分项：

有端侧大模型、多模态模型或实时语音交互场景的功耗优化经验；

有 Qualcomm、MediaTek 等移动芯片平台的 AI 能效调优经验；

熟悉 QNN、LiteRT、MNN、llama.cpp 等推理框架或 SDK；

有模型量化、算子融合、KV Cache 管理或异构计算相关优化实践；

有量产产品中的 AI 能耗、温升或续航优化成果。

2.功耗工程师（温升优化方向）

岗位定位：负责整机热管理（温升）体系的架构设计与优化，在温升约束下平衡功耗与性能释放，保障高负载场景的帧率稳定性与握持体验。

工作内容：

负责 Android/Linux 平台热管理子系统（Thermal Framework）的架构设计与核心代码开发，主导温升、发热类问题的定位、优化与闭环；

主导 IPA（Intelligent Power Allocator）智能功耗分配算法的移植、定制与调优，实现基于热预算（Thermal Budget）的动态功耗管控，平衡性能释放与发热控制；

深入优化 CPUFreq/DVFS 子系统，制定 schedulutil、温度器等参数策略，确保游戏、视频、相机等高负载场景的帧率稳定性；

负责极端场景下的温升降额（Throttling）策略设计，治理降额导致的卡顿、掉帧问题，输出软硬件协同优化方案；

搭建温升与功耗测试、数据分析体系（热成像 / 电流 / powerrail / Perfetto），输出标准化优化与验收规范，支撑新品立项、试产、量产全流程温升标准落地；

跟进手机行业温控技术趋势，对标竞品热管理方案，持续提升产品发热竞争力。

任职要求：

计算机、电子工程、自动化或相关专业本科及以上学历，3 年以上 Android 整机系统功耗 / 热管理经验；

精通 C 语言，具备扎实深入的底层开发基础；

深入理解 Linux 内核架构，有内核开发、调试实战经验（CPU 调频 / 调度、thermal 驱动等）；

熟悉 Android 完整热管理框架（thermal HAL、thermal-engine、IPA），有整机温升系统开发、温升调优落地项目经验；

熟悉温控与性能策略制定，能基于温升约束平衡功耗与性能，有温升分析或统一温控经验；

具备系统性休眠 / 唤醒流程全链路排查能力，能独立完成功耗数据采集、瓶颈分析与优化落地；

能够阅读 ARM 官方架构手册、内核源码，逻辑清晰，具备较强的问题拆解与根因定位能力；

有高通 / MTK 平台深度调优经验者优先。

加分项：

有端侧大模型、多模态模型或实时语音交互场景的功耗优化经验；

有 Qualcomm、MediaTek 等移动芯片平台的 AI 能效调优经验；

熟悉 QNN、LiteRT、MNN、llama.cpp 等推理框架或 SDK；

有模型量化、算子融合、KV Cache 管理或异构计算相关优化实践；

有量产产品中的 AI 能耗、温升或续航优化成果。

3.功耗工程师（DoU / 续航优化方向）

岗位定位：负责整机续航（DoU）场景功耗的度量、拆解与优化，制定并达成产品续航指标，支撑产品续航与使用体验落地。

工作内容：

场景功耗度量与拆解：提炼真实用户的耗电与发热场景，用功耗板 / powerrail、电流波形与 Perfetto/systrace 做软硬件双向拆解，定位到具体子系统与代码路径；

待机与灭屏功耗优化：负责待机与灭屏静态电流的分析优化，覆盖 suspend 通路与各子系统休眠、外设 power domain、GPIO/I2C 漏电、regulator 静态电流、buck 转换效率，并对齐原理图验证；

动态功耗优化：针对 CPU/GPU/DDR/IO 的调压调频与开发度设计并落地优化方案，在温升与性能约束下拿到可量化收益，并配套待机回退策略；

DoU 续航标准与达成：主导 DoU / 续航测试模型与标准制定，拆解各子系统功耗预算，推动优化方案从问题发现到量产验收全程闭环；

竞品对标与端到端闭环：对标竞品的系统与芯片低功耗特性，识别差距与机会，输出改进方案并跟踪落地；

行业对标预研：跟进手机行业功耗技术趋势，持续提升产品续航竞争力。

任职要求：

本科及以上学历，5 年以上 Android 整机系统功耗优化经验，完整负责过量产项目的 DoU / 续航指标达成；

具备独立定位与自研能力：能自主定位到内核 / 驱动或 framework 的具体代码路径，并产出可落地的方案与代码改动（看重自研深度，而非问题分流与项目跟踪）；

以下两个方向至少熟悉其一：

硬件级：熟悉手机底层硬件工作特性与 SoC 低功耗机制（power/clock gating、多电压域、retention、低功耗时钟域），有底电流调校与硬件功耗拆解实操经验；

调度级：熟悉内核调度与能效模型，有 CPU/DDR 调度策略、cluster 能效拐点、调频调压策略的自研改动经验；

精通 C 语言，具备扎实深入的底层开发基础；

具备系统性休眠 / 唤醒流程全链路排查能力，可独立完成功耗数据采集、瓶颈分析与优化落地；

能够阅读 ARM 官方架构手册、内核源码，逻辑清晰，具备较强的问题拆解与根因定位能力。

加分项：

有 DoU / 续航标准制定经验；

有端侧大模型、多模态模型或实时语音交互场景的功耗优化经验；

有 Qualcomm、MediaTek 等移动芯片平台的 AI 能效调优经验；

有量产产品中的 AI 能耗、温升或续航优化成果。

4.功耗工程师（器件功耗优化方向）

岗位定位：负责屏幕、相机、音频、传感器、充电、射频等核心器件的功耗设计、验证与优化，从器件维度降低整机功耗、保障体验。

工作内容：

负责整机器件级功耗方案设计与优化，覆盖显示屏、摄像头、音频、传感器、充电 / 电源管理（PMIC/Charger）、射频（RF/Modem）、连接（WiFi/BT/GNSS）等模块；

负责器件上下电时序、复位、时钟、供电网络（LDO/DC-DC）与负载开关的设计与审查，确保功能安全与功耗指标达成；

负责器件驱动程序开发与调试，优化器件工作模式 / 休眠唤醒配置、寄存器默认值与动态调参，确保器件达到低功耗目标；

负责器件功耗分解、静态电流验证，以及亮灭屏、拍照、录像、通话、游戏等动态场景的功耗验证；

搭建器件功耗度量与数据分析体系（功耗板 / 电流波形 / 总线抓包），定位器件级异常功耗与漏电问题，输出软硬件协同优化方案；

与器件原厂 / FAE 协同，评估器件低功耗特性与 datasheet 指标，参与器件选型与替代评估，推动器件维度功耗优化落地；

编写功耗相关设计文档、调优手册、测试规范，支撑产品迭代与量产功耗指标达标。

任职要求：

电子工程、计算机科学、自动化或相关专业本科及以上学历；

3 年以上功耗底层软件开发经验，有整机或器件级功耗项目经验；

熟悉 ARM 体系结构、Linux 低功耗框架，有时钟、电源域控制等优化经验；

熟悉手机核心器件（显示、摄像、音频、传感器、充电、射频等）的工作原理与低功耗机制，至少精通其中 1-2 类器件的驱动与功耗调优；

熟悉示波器、逻辑分析仪、功耗分析仪等硬件调试工具，能独立完成器件级设计和开发；

熟悉器件 datasheet 解读、寄存器配置、上下电时序与静态 / 动态功耗验证方法；

良好的问题解决能力，强大的团队合作精神和沟通能力，可协调跨团队资源推进器件功耗目标达成。

加分项：

有器件原厂 FAE 协同或供应商管理经验；

熟悉 DVFS/AVS/Thermal/PMIC 等模块。

有端侧大模型、多模态模型或实时语音交互场景的功耗优化经验；

有 Qualcomm、MediaTek 等移动芯片平台的 AI 能效调优经验；

有NPU器件功耗拆解和优化经验。
