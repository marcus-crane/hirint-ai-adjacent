**职位描述**

* 负责企业级通用 Agent 解决方案的产品规划与落地，覆盖 Cowork、Voice Agent等核心产品形态，包括产品定位、需求拆解、原型设计与迭代推进
* 深入理解 Agent 技术能力与边界（任务规划、多 Agent 协同、工具调用、人机协同审批等），将前沿能力转化为可落地的产品方案，持续提升任务完成率、用户体验与产品稳定性
* 探索通用 Agent 的新范式，定义可解释、可控的长链路工作流与实时语音交互体验，平衡自动化程度与用户控制感，打磨产品差异化
* 与研发、算法团队紧密协作，跟踪行业动态与竞品，推动产品从 0 到 1 及规模化落地，沉淀可复用的行业解决方案

**任职要求**

* 本科及以上学历
* 熟悉常见的产品设计方法论，包括但不限于用户研究、需求分析、原型设计、数据驱动迭代等
* 熟悉 AI Agent 相关产品与技术趋势，了解 Agent 产品形态（如 Cowork 类工作 Agent、Voice Agent、Coding Agent 等），对 Agent 交互范式、人机协同、上下文工程等有深度思考
* 有 AI 产品或 Agent 产品经验者优先；对多模态交互（语音、GUI、文档等）有敏感度，具备良好的跨团队协作与推进能力
