**岗位职责：**

需求对接与对外运营

* 作为语音API产品需求的统一对接窗口，承接公司内部各业务团队及外部企业客户的接入与使用需求
* 深入理解并归集多方诉求，协调产品、技术与资源侧推动落地，保障各业务方顺畅接入与稳定使用
* 负责企业客户的接入对接、配置开通与使用陪跑，对客户的接入与使用体验负责，沉淀场景与最佳实践
* 负责语音API产品的宣发、用户增长与服务等运营功能

平台服务与运营支持

* 负责平台语音API相关日常运营，响应内外部使用、配置与问题排查类需求，快速定位、协同处置并推动闭环
* 完成必要的后台配置与运行跟踪，关注可用性、响应时效、问题闭环率等指标，保障关键时段服务连续性
* 依据业务发展与规划，制定API上线发布、宣发、增长和售后服务的规划并具体落地执行

机制沉淀与体验运营

* 沉淀知识库、FAQ 与处理 SOP，建设并优化自助与智能答疑、问题分流机制，降低重复问题、提升自助解决率
* 基于运营与问题数据做归因分析，输出体验洞察，反哺产品与服务运营决策

**任职要求：**

* 本科及以上学历，4 年以上互联网 / SaaS / 云服务 / toB 服务相关平台运营、服务运营或客户成功经验
* 熟悉 AI 大模型行业生态，了解 模型 API服务、语音API服务其一
* 善于与多类业务方打交道：既能服务好内部团队与企业客户，又能守住平台规则，有优秀的跨团队沟通协同与推动能力
* 具备技术理解力，能读懂 API 文档与基础代码示例（Python / cURL），能读日志并完成后台配置
* 有规则、流程或服务体系的搭建经验，能把多方博弈的场面理成可执行的机制
* 良好的中英文书面表达能力，结果导向，具备数据分析意识

**加分项：**

* 有 AI / 大模型 / 云厂商 / API 平台相关运营经验，有 语音AI产品经验
* 有 toB 客户成功、技术支持或服务运营经验，搭建过服务响应体系、知识库或自助答疑机制
* 熟悉主流语音API产品生态（OpenAI、MS Azure、Google、AWS、ElevenLabs、MiniMax、国内其他主流厂商等）
* 能用 AI 编程工具或脚本自建小工具（答疑 bot、数据看板、自动取数等），将重复工作自动化
