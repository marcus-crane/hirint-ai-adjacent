**【岗位职责】**

1. **基础UI能力构建**：负责Android系统基础UI能力的规划、设计与构建，主导系统级动效框架、特效算法的研发与演进。
2. **核心框架定制**：负责 ViewSystem、HWUI、SurfaceFlinger 等核心显示与渲染框架的底层定制开发与深度优化。
3. **公共控件建设**：负责系统公共控件（公控控件）的封装、维护与体验升级，制定UI规范，提升系统UI的一致性与各业务线的开发效率。
4. **快稳省深度优化**：针对系统动画、特效等重渲染场景，主导“快、稳、省”（极致流畅、高稳定性、低功耗/低内存）的深度优化，突破动画效果对性能和功耗的依赖瓶颈。
5. **前沿技术预研**：跟进Android前沿UI/动效技术（如物理引擎、3D动效、光追渲染等），结合业务场景进行技术预研与创新落地。

**【任职要求】**

1. 计算机、软件工程等相关专业本科及以上学历，3年以上 Android Framework/系统开发经验。
2. 精通 Java/Kotlin 及 C/C++，深入理解 Android 系统架构，熟悉 Framework 层核心运行机制。
3. 精通 ViewSystem 渲染机制，深入理解并熟悉 HWUI、SurfaceFlinger、RenderThread 等显示与图形渲染框架的底层原理。
4. 具备丰富的系统级动效开发经验，熟悉贝塞尔曲线、物理引擎、粒子系统等特效算法，有优秀的复杂动画落地能力。
5. 具备扎实的“快稳省”优化经验，熟练使用 Systrace、Perfetto、Snapdragon Profiler 等性能分析工具，能独立解决复杂的掉帧、卡顿、功耗异常问题。
6. 有系统公共控件开发经验，或主导过大型 App/系统 UI 架构重构者优先。
7. 对极致用户体验有强烈追求，具备良好的沟通协作能力和技术驱动力。
