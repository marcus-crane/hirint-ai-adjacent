1）全平台账号矩阵运营（核心）

a、负责抖音、小红书、微博、微信公众号 / 视频号、B 站、知乎等官方账号日常维护。

b、制定账号月度 / 季度运营计划：内容排期、发布节奏、粉丝增长目标、互动率提升。

c、日常执行：内容发布、评论 / 私信回复、粉丝互动、舆情监控、账号数据看板（粉丝数、阅读 / 播放、点赞 / 评论、转发）。

d、新品预热 / 发布会传播、机型卖点种草、系统更新推送、用户问题答疑、品牌口碑维护。

2. 线上活动策划与全流程执行（核心）

a、策划节点活动：新机上市、618 / 双 11、节日（春节 / 国庆）、品牌日、系统版本更新活动。

b、策划互动活动：话题挑战赛（如 #我的 XX 手机 #）、抽奖 / 福利、征集活动（壁纸 / 文案 / 使用技巧）、直播活动（发布会直播、体验直播）。

c、全流程：方案撰写→预算申请→素材对接（设计 / 视频）→活动上线→数据监控→用户答疑→活动复盘（效果总结、问题优化）。

d、跨部门协作：对接市场、产品、设计、客服，确保活动与品牌节奏、产品卖点一致。

3. 内容策划与创作（支撑账号 + 活动）

a、结合手机行业热点、数码圈动态、竞品动作，策划爆款选题。

b、产出适配各平台内容：

抖音 / 视频号：短视频脚本（卖点展示、功能教程、趣味剧情）、口播稿。

小红书：图文笔记（颜值 / 拍照 / 续航 / 性能测评、使用技巧）。

微博：短内容、话题运营、热点借势、互动抽奖。

B 站：深度测评、拆机、系统功能详解、长视频内容。

内容优化：根据数据（完播率、互动率、转化率）调整内容方向，提升传播力。

4. 数据分析与策略优化

a、每日 / 每周监控核心数据：粉丝增长、内容播放 / 阅读、互动率、活动参与人数、转化率、ROI。

b、输出周报 / 月报 / 活动复盘报告，总结亮点、问题，提出优化建议。

c、竞品分析：跟踪友商账号运营、活动玩法、内容策略，借鉴优势、规避风险。

学历：本科及以上，市场营销、新闻、广告、新媒体等相关专业优先。

经验：2年以上新媒体 / 社媒运营经验，有手机 / 数码 / 3C 行业经验优先；优秀应届生可放宽（需有账号运营 / 内容创作案例）。

核心技能（硬性）

平台精通：深度熟悉抖音、小红书、微博、视频号、B 站等平台规则、算法、用户调性、爆款逻辑。

文案能力：扎实的文案功底，能独立撰写各平台文案（短平快 / 深度 / 趣味），懂数码话术优先。

内容制作：会基础图文排版（秀米 / 135）、图片处理（PS/Canva）、视频剪辑（剪映 / PR），能独立完成简单内容制作。

活动策划：具备线上活动全流程策划与执行能力，有成功活动案例（参与人数 / 转化达标）。

数据分析：会看数据看板，能做基础数据分析，用数据优化运营策略；熟悉微信指数、巨量算数、蝉妈妈等工具优先。

软素质（关键）

网感强：对AI行业、数码圈热点、网络流行梗、年轻人喜好敏感，能快速借势热点。

沟通协作：跨部门沟通能力强，能对接设计、产品、市场、达人，高效推进工作。

创意 + 执行：脑洞大、创意活跃，同时执行力强、细心负责，能落地细节、把控质量。

抗压 + 自驱：能适应多任务、快节奏工作（如新品期密集内容 / 活动），主动学习、跟进行业新玩法。

加分项

懂数码、AI行业：了解大模型、国内外大模型竞争趋势、会用AI；同时对手机硬件参数、系统功能、行业动态，有玩机 / 测评经验优先。

账号案例：有0-1 账号起号、爆款内容打造、活动从 0 到 1 落地成功案例。
