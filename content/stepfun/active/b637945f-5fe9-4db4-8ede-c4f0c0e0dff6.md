岗位职责

一、企微社群体系搭建与运营

1. 负责企业微信社群的从0到1搭建，制定社群分层运营策略（新客群 / 会员群 / VIP群 / 大促群），建立完整的社群SOP体系

2. 日常社群维护：内容发布、话题引导、互动活动策划、答疑解惑，保持社群活跃度与用户粘性

3. 设计社群用户生命周期管理路径：拉新→留存→活跃→转化→裂变，制定各阶段运营动作与转化漏斗

4. 企微SCRM工具运营：标签体系搭建、客户画像完善、自动化SOP配置、朋友圈营销内容规划与执行

5. 搭建社群数据监控看板，跟踪群人数、活跃率、转化率、客单价、复购率等核心指标，持续优化运营策略

二、微信生态私域运营

1. 负责微信私域流量池的整体运营，包括个人号、公众号、视频号、小程序商城的联动运营

2. 策划微信社群专属活动：限时秒杀、群接龙、拼团、抽奖、新品试用等，驱动社群GMV增长

3. 制定朋友圈内容日历，结合电商大促节奏（618 / 双11 / 年货节等）提前规划内容与活动节奏

4. 运营微信社群裂变体系：老带新、分销、助力等裂变玩法的策划与执行，实现低成本获客

5. 小程序商城与社群的联动运营，优化从社群到下单的转化路径

三、小红书社群与内容运营

1. 负责品牌小红书账号矩阵的日常运营，制定内容策略与发布计划，持续产出种草笔记、测评合集、好物推荐等内容

2. 运营小红书品牌群 / 粉丝群，策划群内互动话题、福利活动，提升群成员活跃度与品牌忠诚度

3. 小红书KOC合作与素人种草：筛选匹配KOC、内容brief输出、投放效果追踪与复盘

4. 关注小红书平台算法变化与流量分发机制，优化笔记曝光与互动数据

5. 小红书数据分析：笔记阅读量、互动率、涨粉量、种草转化等维度的数据追踪与策略调整

四、抖音社群与内容运营

1. 负责品牌抖音号的日常运营，策划短视频内容与直播预告，配合直播间引流社群蓄水→直播爆发"的运营闭环

2. 抖音短视频内容策划与脚本撰写，配合热点话题、挑战赛等提升账号曝光与粉丝增长

3. 抖音直播与社群联动：直播前社群预热、直播中社群互动导流、直播后社群复购转化

4. 抖音数据分析：视频播放量、完播率、互动率、粉丝增长、直播间场观与转化等维度追踪

五、跨平台社群协同与数据复盘

1. 统筹微信、小红书、抖音三大平台的社群运营节奏，制定跨平台内容矩阵与活动日历

2. 各平台社群数据周报 / 月报输出，含活跃度、转化率、ROI等核心指标分析与优化建议

3. 竞品社群运营动态监测，定期输出竞品分析报告，保持运营策略的竞争力

4. 配合电商大促（618 / 双11 / 双12等）制定社群作战计划，承担大促期间社群GMV目标

5. 沉淀社群运营方法论与SOP文档，建立可复用的社群运营知识库

任职要求

1.2年以上社群运营经验，有电商/手机3C数码行业社群运营经验者优先

2.平台经验：熟悉以下至少两个平台的社群运营体系—— ◦ 企业微信：熟悉企微SCRM工具，有企微社群从0到1搭建经验 ◦ 小红书：熟悉小红书内容分发机制与品牌号运营，有KOC合作或素人种草实操经验 ◦ 抖音：熟悉抖音粉丝群运营与直播联动玩法，有短视频内容策划能力 ◦ 微信生态：熟悉个人号、公众号、视频号、小程序商城的私域联动运营

3. 内容能力：具备较强的文案撰写能力，能独立产出社群文案、小红书笔记、抖音短视频脚本

4. 数据能力：熟练使用Excel / 数据看板进行社群数据分析，能从数据中发现问题并输出优化策略
