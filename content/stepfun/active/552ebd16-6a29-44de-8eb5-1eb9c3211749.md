岗位方向：移动安全 · 逆向工程 · 风控对抗

核心职责:

1. 头部 App 逆向与风控机制还原

对国内外目标 App（社交、电商、游戏、金融等）进行逆向分析，完成脱壳、混淆还原、协议抓取与加密算法还原，重点拆解其设备指纹生成链路、风控 SDK 的检测逻辑、环境判定触发点。输出可落地的分析报告与对抗方案，而非停留在“能逆向”层面。

2. 云手机 / 虚拟机场景下的风控对抗

深入研究 App 针对模拟器、云手机、容器环境的检测手段（QEMU/虚拟化特征、硬件信息异常、传感器缺失、系统属性异常、虚拟机探测等），设计并调优改机参数、环境仿真策略与 Hook 方案，保障大规模设备在目标 App 风控下的存活率与运行稳定性。

3. 防御机制突破与工具链建设

针对目标 App 的反调试、反 Hook、SSL Pinning、代码混淆、完整性校验等防护，输出动态 Hook、协议模拟或运行时篡改方案。基于 Frida / Xposed / Ghidra 等工具搭建自动化逆向分析平台或对抗测试管线，提升对抗迭代效率，缩短从“风控规则更新”到“方案输出”的响应周期。

4. 风控态势感知与对抗策略沉淀

跟踪黑灰产工具链与头部 App 风控策略的演进，对新增检测点、新增风控维度进行快速研判与原理拆解。建设或维护**\*\*风控态势感知能力\*\***，将个案对抗经验提炼为可复用的特征库、检测规则或对抗方法论，反哺防御侧或业务侧的决策。

任职要求:

- 具备 Android 逆向实战经验、独立完成 Java 层与 Native 层逆向分析的能力。

- 深入理解 Android 设备指纹的生成原理：硬件标识、系统属性、传感器、网络特征、应用痕迹等维度，能够定位风控触发点并设计对应的环境仿真或改机方案。

- 熟悉 云手机/模拟器环境下的对抗特殊性，了解 QEMU/VirtualBox 特征、虚拟机检测常见信号，有改机参数调优、IMEI/IMSI/机型伪造、代理 IP 池等技术的实际使用经验者优先。

- 熟悉 脱壳、混淆对抗、SSL Pinning 绕过、反调试对抗等常见防护机制的突破方法；有 OLLVM/VMP 对抗经验者优先。

- 具备脚本/工具开发能力（Python 为主），能够将重复性逆向分析、Hook 注入、环境修改等操作自动化。

- 有逆向分析平台或自动化对抗工具链建设经验者优先。

- 对攻防对抗有持续的技术兴趣，能够跟踪国内外安全社区与黑灰产动态，快速理解新检测机制的原理。

- 具备合规意识：本岗位服务于正规业务的设备环境保障与安全评估。

加分项:

- 有主流 App 风控对抗的实际案例。

- 有云手机/ARM 虚拟化相关工作经验，了解 Android Framework 层定制与设备仿真。

- 掌握 Flutter / React Native 等跨平台框架的逆向方法。

- 有协议自动化脚本、离线分析工具或对抗测试框架的开发经验。

- 在安全社区、逆向论坛有技术分享或开源贡献。
