**职位描述**

* 负责企业工作台 AI Agent 基础设施（Agent Infra）的设计、研发与持续演进，建设稳定、高效、可扩展的 Agent 运行与编排平台。
* 负责 Agent Runtime 核心能力建设，包括任务生命周期管理、上下文管理、会话状态持久化、任务规划与执行、流式响应、任务中断/恢复及结果回传等。
* 负责 Agent 工具调用与执行框架建设，支持 MCP、Function Calling、本地/远程工具接入、工具注册与发现、权限控制、调用编排、超时控制、重试、幂等与异常恢复。
* 设计并实现复杂任务的工作流编排、多任务并行、长任务异步执行、子 Agent 协作、状态机管理及任务可观测能力，保障 Agent 在复杂企业场景中的可靠交付。
* 建设端云协同能力，支持 Agent 与桌面客户端、本地文件系统、浏览器、企业应用及第三方服务之间的安全通信与任务协作。
* 负责 Agent 平台的模型接入与统一治理能力，包括多模型路由、模型调用封装、上下文窗口管理、限流熔断、成本控制、调用监控及质量评估。
* 建设 Agent 运行时安全体系，包括身份认证、权限校验、租户隔离、数据脱敏、工具调用审计、敏感操作确认及风险控制。
* 负责平台的稳定性与可观测性建设，完善日志、链路追踪、指标监控、运行回放、故障诊断、告警与应急机制。
* 与产品、客户端、算法、模型平台及基础架构团队紧密协作，将复杂业务需求抽象为标准化、可复用的 Agent Infra 能力，并推动高质量落地。
* 持续关注 AI Agent、LLM 应用、Agent Runtime、MCP、Workflow 等领域技术发展，推动前沿能力在企业办公场景中的工程化实践。

**任职要求**

* 本科及以上学历，计算机、软件工程或相关专业。
* 5 年及以上后端或基础架构研发经验，精通 Go、Java、Python、Rust 等至少一种服务端编程语言，具备扎实的计算机基础与工程实践能力。
* 有 AI Agent、LLM 应用平台、任务调度平台、工作流引擎或分布式任务系统相关研发经验。
* 深入理解 Agent Runtime 的关键技术问题，包括上下文管理、工具调用、任务编排、状态持久化、长任务执行、流式通信、多 Agent 协作及失败恢复等。
* 熟悉 MCP、Function Calling、OpenAPI、Webhook、RPC 等工具或服务集成方式，具备复杂外部系统接入与治理经验。
* 熟悉分布式系统设计，具备高并发、高可用服务建设经验，理解消息队列、缓存、任务队列、服务治理、限流熔断、一致性及容错机制。
* 熟悉 MySQL、PostgreSQL、Redis、Elasticsearch 等常用存储与检索系统；了解向量数据库、知识库/RAG 或非结构化数据处理能力者优先。
* 具备良好的领域建模、架构抽象与系统设计能力，能够将复杂、快速变化的 Agent 产品需求拆解为边界清晰、可维护、可扩展的平台能力。
* 具备优秀的问题定位和技术攻坚能力，能够针对复杂问题进行跨服务、跨组件、跨端链路排查，并推动根因解决。
* 具备良好的沟通协作能力、责任心和结果导向，能够在多团队协作中推进复杂项目落地。

* 有 MCP Server / Client、工具市场、插件体系、Agent Skill 体系或工具权限治理相关经验。
* 有 RAG、向量检索、知识库构建、文档解析、Embedding/Rerank、模型评测或 Prompt 工程经验。
* 有多租户、权限体系、数据安全、审计合规、隐私保护或企业级 SaaS 平台建设经验。
* 具备开源项目贡献、技术文章、技术分享或 AI Infra 相关社区影响力。
