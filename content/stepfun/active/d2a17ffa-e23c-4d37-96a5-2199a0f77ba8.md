**职位描述**

* 负责企业级 AI Agent 基础设施建设，支持 Agent 的开发、评测、部署与运行；
* 负责 Agent Harness 架构设计，建设模型调用、工具执行、上下文管理、权限控制等核心能力；
* 负责 Agent Loop 与 Graph Engineering，支持任务规划、状态流转、多 Agent 协同、异常重试与长任务执行；
* 建设 Agent 可观测性和效果评测体系，持续提升系统稳定性、执行效率与可扩展性；
* 跟进 Agent 前沿技术，推动相关能力在业务场景中落地

**任职要求**

* 本科及以上学历，计算机相关专业，熟练掌握 Golang、Python 等至少一种编程语言；
* 熟悉分布式系统及服务化、高可用、异步化、任务调度等架构设计；
* 熟悉 Agent Harness、Agent Loop、Graph Engineering，理解任务规划、工具调用、多 Agent 协同及上下文工程；
* 了解 Function Calling、RAG、MCP、模型路由、记忆系统及 Agent 评测；
* 具备良好的系统设计和复杂问题解决能力；有 Agent 平台、LLM Infra 或工作流引擎建设经验者优先
