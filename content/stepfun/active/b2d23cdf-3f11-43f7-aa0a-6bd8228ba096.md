**岗位职责**

* 负责 AI 产品的交互与视觉设计，完成从用户流程、原型到高保真界面的设计与落地。
* 面向海外用户，结合产品定位与使用习惯，打造有辨识度、易用且精致的产品体验。
* 使用 AI Coding 工具快速实现可交互原型或 UI 页面，与产品、研发协作推进上线和迭代。

**任职要求**

* 有海外视野，持续关注海外 AI 产品与设计趋势，理解不同市场的审美和用户习惯。
* 审美优秀、视觉能力突出，对排版、色彩、布局与细节有成熟判断，并能通过作品体现。
* 具备扎实的 UI/UX 基础，熟练使用 Figma 等设计工具，能独立完成核心页面与交互流程设计。
* 有使用 Codex、Claude Code、v0 等 AI Coding 工具实现 UI 的实际经验，能将设计转化为可运行、可验证的界面。
* 沟通清晰、主动性强，能结合用户反馈和业务目标持续优化设计。

**投递要求**

请附设计作品集及至少一个 AI Coding 实现的 UI 案例，注明个人负责的内容；可提供在线链接、演示视频或代码。
