**职位描述**

1. 分析 Personal Agent 的真实业务场景，将用户需求拆解为意图、任务目标和成功条件，明确任务价值、产品能力、工具权限及执行边界，制定场景分类、难度分层和数据覆盖方案。
2. 设计单步、多步及长程任务，构建用户背景、环境状态、工具定义和必要上下文，覆盖信息澄清、任务切换、记忆使用、主动服务及异常恢复，保证任务能够在指定环境中执行和验证。
3. 制定 Agent 数据标准、标注手册和验收规则，明确工具选择、参数、依赖、调用顺序、结果引用与任务终止条件；沉淀金标、正反例及边界判例，组织试标、校准和争议处理。
4. 建设训练样本与独立评测集，结合最终任务结果和执行过程开展评测，定位规划、工具使用、状态更新及回复中的问题，与算法、产品共同确定补数和迭代方向。
5. 设计并迭代 Prompt 和工作流，协同工程人员完成任务生成、环境构造、执行重放及质量检查，记录真实执行与模拟数据的来源，保留复现证据和版本。
6. 统筹项目排期、人员分工、培训和产能，组织内部及外部生产团队交付，跟踪合格率、返工、周期和成本，对场景真实性、数据质量和项目结果负责。

**职位要求**

1. 具有 Agent 应用、模型数据与评测、AI 产品策略或业务自动化相关项目经验，能够具体说明自己承担的职责、解决的问题及交付结果。
2. 是 AI 产品的深度用户，有实际搭建和使用 Agent 或工作流的经历；能够判断何时需要澄清、调用工具、等待或结束任务，并识别当前工具无法完成的需求。
3. 具备业务案例分析和任务设计能力，能从用户目标推导可检验的成功条件，将理想体验落实为真实可执行的任务，而非仅生成形式完整的对话。
4. 能阅读 API 文档、工具 schema、JSON 和执行日志，理解输入输出、状态、时序与依赖，能够区分接口失败、模型错误和环境问题。
5. 能独立制定数据标准与评测规则，组织金标评审、抽样复核和一致性校准；熟悉训练集与评测集隔离、问题归因及标准版本管理。
6. 能使用 Prompt、工作流工具及表格完成批量任务和质量分析；具备项目与人员统筹能力，能组织培训、分工、进度跟踪和返工闭环。
7. 有复杂聊天、用户画像、跨会话记忆、浏览器操作或多模态任务经验者优先；能够用 Python 或 SQL 进行数据处理者优先，副专长不替代核心能力要求。
