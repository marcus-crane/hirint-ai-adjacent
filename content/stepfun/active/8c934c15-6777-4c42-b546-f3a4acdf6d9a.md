**工作内容：**负责 StepCode 的客户端和 Web 端开发，参与 Agent Harness 的设计和实现，和算法团队一起把模型能力做成开发者每天会用的产品。

**岗位职责**

1. 负责 StepCode 桌面客户端（Electron）、Web 端和 CLI 的全栈开发，包括 Agent 交互界面、任务执行过程展示、开放平台配置接入等，持续迭代优化开发者使用体验。
2. 参与 Agent Harness 核心模块的设计和实现，包括任务调度、Skills / Tools 管理、MCP 接入、Memory 与上下文管理、权限与安全沙箱、状态持久化与异常恢复、端云协同链路。
3. 和算法团队紧密协作，参与 bad case 分析，参与评测体系建设和Harness 效果调优。从开发者体验出发，提升 Coding 任务的完成质量和协作效率。
4. 理解并分析用户反馈，参与 StepCode 开发者社群的运营和交流。
5. 探索 AI 驱动的下一代软件研发方式和工程工作流。

**任职要求**

1. 本科及以上学历，计算机相关专业，2 年以上软件开发经验，有完整产品从 0 到 1 或持续迭代的经验。
2. 熟练掌握 JavaScript / TypeScript 和主流前端框架（React / Vue 等）
3. 熟悉 Electron 桌面应用开发，深入理解主进程 / 渲染进程、进程间通信、窗口管理、应用生命周期、自动更新和安全机制。
4. 熟悉主流 Agent / Harness 的架构和原理（如 Claude Code、Codex、Pi、LangGraph 等），理解 ReAct、Plan & Execute、Tool Use、Memory、MCP 等关键机制。
5. 是 Agent 产品的重度用户：深度使用过代码类和通用类 Agent 产品，并且已经把它们用进自己的日常工作和生活；对模型行为有判断力和品味，对开发者体验敏感。
6. 了解用户体验、交互设计和需求分析，有一定的产品意识。

**加分项**

1. 有个人开源作品，或者是活跃的开源社区贡献者；持续贡献过主流 Agent / Harness 开源框架的优先。
2. 了解沙箱、容器等隔离技术，或者做过云端 Agent 运行环境。
3. 有桌面端产品或者终端工具（TUI / CLI）开发经验。
