**岗位职责**

1. 负责 GPU 驱动开发、移植与维护：内核态驱动（KMD）与用户态驱动（UMD）的开发、调试与性能优化，适配不同 SoC/GPU IP 平台。
2. 负责图形栈（Graphics Stack）底层开发与集成：OpenGL ES / Vulkan / EGL 图形接口的驱动层实现、扩展与问题攻关，对接 Android 图形框架（SurfaceFlinger / Gralloc / HWComposer / BufferQueue）。
3. 负责 GPU 相关的显存管理、命令提交（Command Submission）、上下文调度、同步机制（Fence/Sync）等核心模块的开发与优化。
4. GPU 性能与功耗调优：DVFS 调频调压、负载均衡、渲染管线瓶颈分析与优化，提升图形性能并降低功耗。
5. 疑难问题定位攻关：GPU hang/复位、渲染异常（花屏/闪屏/掉帧）、内存踩踏/泄漏、驱动崩溃等底层问题的根因分析与解决。
6. 与硬件/IP、Kernel/BSP、上层框架及应用团队协作，完成软硬件联调、Bring-up 及量产落地；跟踪 GPU 图形领域前沿技术并预研导入。
7. 编写驱动设计、接口、调试与问题分析等技术文档。

**任职要求**

1. 本科及以上学历，计算机、电子、软件或相关专业，3 年及以上 GPU 驱动 / 图形栈 / 底层图形渲染开发经验。
2. 扎实的 C/C++ 基础，熟悉 Linux/Android 内核驱动开发机制（内核态/用户态交互、内存管理、DMA、中断、同步）。
3. 深入理解 GPU 图形渲染管线与至少一类图形 API：OpenGL ES / Vulkan / EGL；熟悉 GPU 驱动架构（KMD/UMD 分层）。
4. 熟悉 Android 图形显示子系统（SurfaceFlinger / Gralloc / HWComposer / BufferQueue / Fence）或 Linux 图形栈（DRM/KMS、Mesa、GBM）。
5. 熟练使用 GPU/图形调试与性能分析工具：Perfetto、systrace、RenderDoc、GPU Profiler、adb、GDB/LLDB、ftrace 等。
6. 具备独立定位 GPU hang/复位、渲染异常、驱动崩溃、显存问题的能力，能输出优化方案。
7. 熟悉高通 Adreno / ARM Mali / Imagination PowerVR 等主流 GPU 平台者优先。

**加分项**

* 有 GPU 驱动从 Bring-up 到量产的完整落地经验；
* 熟悉 DRM/KMS、Mesa（Panfrost/Freedreno 等开源驱动）、Vulkan 驱动实现；
* 有 GPU 功耗/性能专项优化、异构计算（OpenCL/GPGPU）、GPU 编译器（Shader Compiler）经验；
* 参与过图形标准（Khronos）相关工作或有开源图形项目贡献。
