岗位定位：市场与品牌部的运作中枢。负责部⻔预算、采购、验收、营销委员会和营销 IT 体系的建设

与运营；作为部⻔接⼝对接财经、采购、质量运营；保障营销业务⾼效、合规、可衡量。

岗位职责

1. 预算管理：负责部⻔年度、季度预算的编制与刷新，按项⽬和科⽬分解；跟踪预算执⾏、预提与结

算，定期输出费⽤分析与预警；作为部⻔接⼝对接财经 BP，⽀撑资源分配和投⼊产出评估。

2. 采购流程：管理营销采购需求从⽴项、PR、寻源⽐价、合同到 PO 的业务侧全流程，落实“先审批

后执⾏”；与采购部⻔共建营销品类策略、框架合同和供应商（Agency、媒体、KOL 机构、活动、

制作等）资源池。

3. 项⽬验收：按营销科⽬制定验收标准与交付材料要求，组织验收、复核与打分；打通“需求―合同

―交付―验收―付款”链路；建⽴供应商绩效评价、分级与退出机制。

4. 营销委员会运作：建⽴内部营销委员会议事规则和决策清单（预算、重⼤⽅案、供应商准⼊等）；

负责议题收集、材料预审、会议组织、决议发布和闭环跟踪。

5. 营销 IT 与数字化：规划部⻔营销运作系统（预算台账、采购与验收电⼦流、KOL / 媒体资源库、项

⽬看板等），定义需求并推动与 IT 共建上线；推动 AI ⼯具在运作流程中落地。

6. 内控与合规：落实事权与财权分离、职责分离（SOD）；识别业务流程中的关键⻛险和红线，组织

整改；配合审计与质量运营的检查。

7. 经营分析与赋能：输出部⻔运营报告，涵盖预算、项⽬、供应商和流程效率；向业务团队培训流程

与⼯具，持续优化流程体验，减少不必要的环节。

任职要求

1. 5年以上营销运作、营销运营管理、营销费⽤财经 BP、营销采购或业务运作相关经验，⼿机、消费电

⼦等终端⼚商背景优先；从 0 到 1 搭建过⾄少 1 套部⻔级预算、采购或验收流程，并推动上线运

⾏。

2. 懂营销业务：了解品牌、PR、社媒、KOL、媒介采买、活动、创意制作等模块的运作⽅式、成本结

构和交付标准，能判断报价与交付是否合理。

3. 懂财务与采购：熟悉预算编制、预提、成本中⼼、PR/PO、合同关键条款、验收与付款规则，能与

财经、采购部⻔专业对话。

4. 流程设计能⼒强：能把业务问题拆成流程、⻆⾊、规则和系统需求，兼顾合规与效率。

5. 推动⼒与原则性：能在业务时间压⼒下守住合规红线，在没有直接汇报关系的情况下推动多部⻔协

同。

6. 数据与⼯具：能熟练⽤ Excel / BI 做费⽤分析；有 ERP、费控、采购系统或低代码平台（如⻜书多

维表格）的使⽤或搭建经验；⽇常使⽤ AI ⼯具提效。

加分项

1. 有华为、荣耀等终端企业营销体系（营销运作、营销费⽤管理、营销采购、流程 IT 与质量运营）的

⼯作经验；

2. 有营销财经 BP 或营销采购的轮岗或专职经历；

3. 有新部⻔、新品牌运作体系从 0 到 1 的搭建经验；

4. 有内控、审计或质量管理经验，持有 PMP、CPSM、CMA 等证书；

5. ⾃⼰搭过费⽤台账、验收电⼦流或⾃动化报表，⾯试时可以演⽰。
