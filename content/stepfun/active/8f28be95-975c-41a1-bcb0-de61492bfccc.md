**岗位职责**

**一、服务运营与技术支持**

* 负责 AI 模型服务的日常运营与客户/内部技术支持，及时响应使用、配置、服务保障类需求，保障服务顺畅运行与良好体验。
* 跟进服务运行中的各类问题，快速定位、协同处置并推动闭环，持续提升响应效率与用户满意度。

**二、资源配置与运行保障**

* 负责模型服务的后台资源配置与运行保障（模型/渠道配置、额度限流、路由调度与切换等），支撑业务平稳落地。
* 跟踪模型版本、配额、稳定性等关键运行状态，及时发现并处置异常，保障关键时段服务的连续性与稳定性。

**三、服务质量与稳定性运营**

* 关注服务可用性、响应时效、问题占比等核心指标，建立并优化监测与预警机制。
* 基于运营与问题数据做归因分析，推动服务质量与稳定性的持续改进。

**四、问题运营与机制沉淀**

* 梳理并沉淀服务知识库、FAQ 与处理 SOP，持续优化自助答疑与问题分流机制，降低重复问题。
* 用数据驱动改进，反哺资源配置与服务运营决策。

**五、客户服务与交付支持**

* 面向 B 端企业客户的接入对接、配置开通与使用支持，协同产品、研发保障客户平稳落地与稳定使用。
* 跟进客户使用情况与问题反馈，持续优化服务与交付体验，沉淀行业与场景案例。

**任职要求**

* 本科及以上学历，3 年以上互联网 / SaaS / 云服务 / toB 技术服务相关经验；
* 了解 AI 大模型行业生态，熟悉 MaaS、模型 API / 网关或 toB 技术服务其一；
* 具备技术理解力与动手能力，能读懂 API 文档与基础代码示例（Python / cURL）、能读日志并完成后台配置；
* 有技术支持、服务运营或客户成功相关经验，响应及时，有较强的服务意识与问题闭环能力；
* 良好的中英文书面表达能力，能独立产出对外沟通与服务支持材料；
* 较强的跨团队协作与项目推进能力，结果导向，具备数据分析意识；
* 认同服务型岗位节奏，能灵活适应业务需要。

**加分项**

* 有 AI / 大模型 / 云厂商 / API 平台 相关运营或技术支持经验；
* 有 MaaS / AI 模型路由（中转）产品的运营或技术经验；
* 有 toB 客户成功、服务运营或技术支持相关经验；
* 熟悉主流模型供应商生态（OpenAI、Anthropic、Google、国内主流厂商等）；
* 数据敏感，能自主看板驱动、量化服务效果。
