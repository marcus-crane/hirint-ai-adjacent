岗位职责

1. 负责基础模型预训练项目的端到端交付：从立项、数据准备、算力排期、训练启动到模型验收与复盘，制定里程碑与排期，把控进度、质量与风险；
2. 拉通跨团队协作：协调预训练数据工程、算法、训练框架 / Infra、算力资源、评测、安全合规等多方，梳理依赖关系、识别关键路径、推动阻塞问题解决；
3. 建立并沉淀预训练项目的流程机制，包括数据准入与配比评审、训练变更管理、实验与 Checkpoint 记录规范、故障响应与复盘（Postmortem）、模型发版流程；
4. 跟踪大规模训练任务（千卡 / 万卡级）的运行状态，关注算力利用率、训练吞吐、loss 异常与中断等风险信号，组织故障止损与恢复预案，维护项目风险台账；
5. 搭建项目度量体系与看板：数据规模与质量、MFU / 训练成本、实验迭代效率、交付准时率等，用数据支撑决策与资源诉求；
6. 负责向上与跨部门沟通，定期同步项目进展、风险与取舍，组织技术评审与阶段复盘，沉淀可复用的方法论与文档。

任职要求

1. 本科及以上，计算机、软件工程、人工智能等相关专业，或具备同等技术背景；3 年以上技术项目管理 / 研发管理经验，主导过大型 AI、分布式系统或基础设施类项目；
2. 理解大模型预训练全流程：数据采集与清洗、Tokenizer 与数据配比、分布式训练（TP / PP / DP / ZeRO）、Checkpoint 管理、评测与发布，能与算法和 Infra 团队进行实质性的技术对话；
3. 具备「技术判断力」：能读懂训练日志、实验配置与评测报告，识别风险信号，不需要亲手训模型，但要能判断项目是否跑偏；
4. 有大规模算力 / GPU 集群项目管理经验，理解资源排期、配额、成本与效率之间的约束与取舍；
5. 强跨团队推动力与沟通协调能力，能在无直接汇报关系的情况下驱动交付；结构化思维清晰，能产出高质量技术文档与管理层汇报；
6. 熟练使用项目管理工具与数据看板，能适应高频迭代、不确定性强的研发节奏。

加分项

1. 完整参与过千亿 / 万亿参数级模型预训练项目，或大规模预训练数据工程项目；
2. 有算法、MLE、Infra / SRE 背景后转型 TPM，熟悉 PyTorch / Megatron / DeepSpeed、Ray / Spark、WandB / MLflow 等工具栈；
3. 有从 0 到 1 搭建研发流程、实验管理规范或项目度量体系的经验；
4. 有大规模集群稳定性治理、训练中断恢复、算力成本优化的项目经历；
