负责 harness 核心引擎研发，覆盖 agent loop 与上下文工程两大方向，具体职责与要求如下。

（一）岗位职责

1. 负责 agent loop 核心：推理-行动-观察循环、子代理编排、错误恢复机制
2. 负责引擎抽象层与可替换接口设计，支撑核心模块的持续自研演进
3. 负责上下文工程：compaction（上下文压缩）、记忆管理、检索策略，优化长程任务的上下文保持能力
4. 与 Agent Runtime 协同，保证引擎在运行时的稳定执行

（二）任职要求

1. 计算机相关专业本科及以上，5 年以上后端研发经验
2. 深入理解 Agent 循环机制（ReAct、Plan-and-Execute 等），有 Agent 框架开发或使用经验（LangGraph、Claude Agent SDK、AutoGen 等）
3. 深入理解 Context Engineering：上下文窗口管理、compaction、RAG、记忆系统
4. 精通 Python/Go/TypeScript 至少一门，有复杂状态机或工作流引擎开发经验者优先
5. 有向量数据库、检索系统或记忆系统开发经验者优先
6. 是 AI 编程工具（Claude Code、Cursor、Copilot 等）的重度用户，对其原理与局限有切身认知
