岗位定位

负责 IoT 设备云端业务底座，支撑耳机、录音盒和录音设备的注册、绑定、状态、能力管理及远程升级，为 App 与 Agent 提供稳定、安全的设备服务。

岗位职责

1. 设备生命周期：开发设备身份、注册激活、用户绑定、解绑转售、注销及凭证管理，处理设备所有权与通信配对的差异。

2. 设备模型与状态：建设设备能力描述、耳机与盒等组合关系、在线状态、期望与实际状态管理，提供统一查询和控制接口。

3. 远程升级与配置：实现 OTA 元数据、发布、灰度、版本兼容、远程配置和升级状态回收，与设备及 SDK 团队联调。

4. 账号与权限集成：对接公司账号、鉴权及通知等基础服务，落实接口访问控制、幂等、错误处理和操作审计。

5. 质量与运行维护：建设接口测试、监控告警、诊断与运营支持工具，定位设备、App 和云端之间的问题。

任职要求

必须具备

1. 计算机或相关专业本科及以上学历，4 年及以上后端研发经验。

2. 具有 IoT 平台或消费级智能硬件云端业务开发经验，实际参与过设备注册、绑定、状态管理、鉴权或 OTA 等功能。

3. 熟练掌握 Go、Java、Python、TypeScript 中至少一种后端语言，熟悉数据库、缓存、消息队列和 API 设计。

4. 理解 HTTP、MQTT 或其他设备通信机制，熟悉重试、超时、幂等、状态一致性和离线设备处理。

5. 具备生产系统的监控、故障定位和安全意识，能够处理越权、并发绑定、账号注销与设备转售等边界。

6. 具备与嵌入式、移动端及测试团队联合交付的经验。

加分项

1. 做过多设备组合、设备孪生、制造身份注入、固件灰度或百万级设备平台。

2. 熟悉设备证书、密钥轮换、设备网关及多品牌设备接入。

3. 有 AI 硬件设备能力开放或 Agent 工具接口建设经验。
