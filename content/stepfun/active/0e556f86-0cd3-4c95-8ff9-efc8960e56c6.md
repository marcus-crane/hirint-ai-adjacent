【关于阶跃星辰与团队】

阶跃星辰（StepFun）成立于 2023 年 4 月，是行业领先的通用人工智能（AGI）基础大模型公司，汇聚海内外顶尖 AI 科学家与系统工程专家，研发人员占比超 80%。公司自研了能力全面的 Step 系列原生多模态、深度推理与智能体（Agent）基座模型矩阵，并在智能汽车、手机与原生 AI 硬件终端形成了深厚的产业落地生态，坚定践行“智能阶跃，十倍每一个人的可能”。

我们希望让基座大模型走出纯数字文本，真正深入真实、复杂的物理与工业工程场景，独立解决高价值的实际工程问题。为此，我们正在组建 AI for Engineering 核心跨界团队，构建高质量的工程训练环境与评测体系，让前沿多模态与推理大模型真正读懂复杂的二维或三维工程图纸与技术规范、编写可编辑的参数化 CAD 与工程计算代码、调用 CAE/EDA/系统仿真工具验证物理合理性并不断改进设计方案。在这里，你将定义最有价值的工程真问题、建立评判结果的标准，直接推动下一代 AGI 基座模型工程能力的跃迁。

【岗位职责】

1. 真实工程任务提炼与能力拆解：从机械设计、电气与硬件工程（电路/PCB）、结构/土木、航空航天或先进制造的真实生产研发场景中，提炼有价值、有挑战的核心任务（如需求理解、工程识图与 GD&T 公差配合、设计计算书撰写、三维参数化建模与装配、多物理场仿真分析、设计评审与 BOM 交付），明确输入条件、工具环境与物理验收标准。
2. 强化学习工程环境与自动验证器（Environment & Verifier）构建：与算法及架构工程师配合，围绕 CAD/CAE/EDA/系统建模软件搭建专业工具链与自动化验证流程（例如基于 CadQuery / OpenSCAD / PythonOCC / FreeCAD / Blender、有限元和流体求解器、Modelica 或电路仿真工具），检验模型生成结果的几何无干涉性、参数化可编辑性、物理守恒与规范合规性，设计抗作弊的客观奖励信号。
3. 高区分度工程评测基准（Benchmark）与专家准则（Rubric）设计：主导构建覆盖概念设计、多视图建模、装配约束与复杂工程计算的抗污染评测体系与可执行评分细则（Rubrics）；深入分析模型在需求理解、工具调用与工程交付中的幻觉与短板，排查“钻评分空子”案例。
4. 多模态工程数据飞轮与 Debug 闭环建设：结合评测结果与真实工程反馈，规划原生 CAD 特征树、修改迭代历史、图纸对比及仿真轨迹的采集、合成与质检；重点将建模重建报错、装配干涉、网格畸变、求解发散、DRC/ERC 违例等真实工程缺陷转化为带专家诊断推理链的高质量训练数据，并参与工业软件及制造生态合作。

【任职要求】

注：本岗位不要求候选人具备大模型训练前置经验，我们提供「资深工业研发/工业软件专家」与「AI×工程交叉人才」双通道评估：

1. 问题抽象与工程基本功：机械工程、电气工程、航空航天、工程力学、土木/结构、精密仪器、自动化、材料/制造或应用物理等相关理工科本科及以上学历；具备极佳的问题分析与抽象能力，能将实际工程约束、建模假设与验证方法转化为清晰的任务、可复现的过程和可检验的标准。
2. 专业工程软件与工具链实战（在以下至少一个方向具备扎实经验）：· 机械设计与 CAD/CAE 方向：熟练使用 SolidWorks、CATIA、NX（UG）、Creo、FreeCAD、Onshape、中望/皇冠 CAD 等三维设计软件，或 Ansys、Abaqus、COMSOL、OpenFOAM、Modelica 等仿真软件；或熟悉代码化参数建模与几何内核（CadQuery / OpenSCAD / Rhino Grasshopper / PythonOCC / STEP / B-Rep）。· 电气、硬件与芯片/EDA 方向：熟悉模拟/数字电路设计、原理图与 PCB 布局布线（Altium / Cadence / KiCad）、电气系统规范、信号/电源/热可靠性分析，或硬件描述语言与 EDA 仿真验证流程。
3. 编程自动化与 AI 工具感知：具备 Python（或 MATLAB/C++/TCL）基础编程与数据处理能力；深度使用过主流大模型或 AI Coding Agent（如 Claude Code / Codex / Cursor 等），对模型能力的优劣边界有敏锐直觉，善于借助 AI 工具高效编写自动化校验脚本。
4. 实物闭环意识与跨团队沟通：治学与工程态度严谨，能用通俗精准的语言与机器学习研究员高效协作。

【加分项（满足任一即可）】

· 完整实物工程闭环经验：经历过从概念计算、三维建模出图、仿真校核到加工装配与实物测试的全过程（例如主导过复杂工业装备或硬件产品研发，或在 RoboMaster、大学生方程式汽车大赛（FSAE）、全国电子设计竞赛等硬核赛事中担任机械或电控核心主设）。

· 工业软件与计算几何研发经验：具备 CAD/CAE/CAM/EDA 软件研发、API 插件二次开发、程序化建模或科学计算求解器开发经验。

· AI 交叉实践经验：有大模型训练数据合成、专业评测基准（Benchmark/Rubric）设计、几何深度学习（Geometric DL / Physics AI）或 Agent 工作流搭建经验。
