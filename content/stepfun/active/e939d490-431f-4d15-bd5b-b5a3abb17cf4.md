岗位职责

负责 OS 基础体验方向的交互设计工作，深入参与新一代 Agent OS 的体验构建，围绕系统基础能力、一方应用及 Agent 能力，探索人与 AI、人与设备之间全新的交互范式，打造自然、高效、智能且一致的系统体验。

1. 负责 OS 基础体验核心场景设计

* 负责 OS 桌面、系统手势导航、通知、控制中心、锁屏、系统状态等基础体验场景的交互设计；
* 从用户任务、使用场景及系统能力出发，建立清晰、连贯、高效的系统交互体验；
* 梳理并优化系统核心任务链路，持续提升 OS 基础体验的易用性、效率与一致性；
* 参与系统级新能力设计，探索传统操作系统向 Agent OS 演进过程中的新交互模式。

1. 负责 OS 一方应用的体验设计与优化

* 负责或参与系统核心一方应用的交互设计与体验优化，包括但不限于设置、电话、短信、相册、文件管理、时钟、日历等；
* 从 OS 整体体验视角出发，理解一方应用与系统基础能力之间的关系，推动系统与一方应用在交互逻辑、信息架构及设计语言上的统一；
* 针对历史体验包袱、复杂功能及高频使用场景进行体验诊断，推动一方应用的信息架构、任务流程及交互体验重构；
* 关注一方应用与系统能力、AI Agent 能力之间的协同，探索 AI 能力在核心应用场景中的自然融入；
* 持续发现和解决一方应用体验问题，推动核心应用体验质量提升。

1. 负责体验规范与设计质量建设

* 建立并持续完善基础体验及一方应用领域的交互规范、设计原则和体验标准；
* 关注系统体验的一致性、连续性、可理解性及可用性；
* 参与系统 Design System、交互模式及组件规范建设，推动设计标准在 OS 及一方应用中的落地；
* 对核心体验进行持续评估和优化，提升整体系统体验质量。

任职要求

1. 设计类专业本科及以上学历，2 年以上交互设计、用户体验设计相关工作经验；
2. 具备较强的**系统性思维、逻辑思维及产品思维**，能够从复杂系统和业务中梳理清晰的信息架构与交互逻辑；
3. 具备手机 OS 或大型互联网产品的交互设计经验，对系统级产品、复杂产品及高频核心场景有较深入的理解；
4. **具备一方应用体验设计与优化能力**，能够独立负责或参与设置、电话、短信、相册、文件管理等系统核心应用的体验设计；
5. 能够从 OS 整体体验视角出发，理解**系统基础能力、一方应用与 AI 能力之间的关系**，推动跨产品、跨场景的体验一致性；
6. 具备复杂信息架构、功能梳理及任务流程设计能力，能够针对历史包袱较重的产品进行体验诊断、重构和优化；
7. 对用户体验具备高度敏感性，关注产品细节，能够持续发现问题并推动体验质量提升；
8. 对 AI、Agent、多模态交互、自然语言交互及智能终端等前沿技术有较强兴趣，愿意探索 AI Native 产品体验；
9. 具备良好的跨团队沟通和协作能力，能够与产品、研发、算法及其他设计团队高效合作；
10. 对设计有热情，具备较强的责任心、主动性和抗压能力，能够适应快速变化的产品环境。
