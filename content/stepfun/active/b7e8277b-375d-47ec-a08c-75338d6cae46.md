岗位职责

* 负责语音大模型实时交互方向的算法工程体系建设，带领团队推进模型从算法方案到推理部署、服务化及线上交付的完整落地；
* 负责实时语音模型的工程优化与系统建设，围绕低延迟、流式处理、高并发、稳定性及资源效率等核心指标，持续优化模型推理与服务性能；
* 带领算法工程团队解决线上实时语音交互中的效果、性能、稳定性和资源成本问题，推动问题从定位、分析到解决的闭环；
* 与算法、产品等团队协作，负责算法工程侧技术方案设计与项目推进，确保模型能力高质量、稳定地交付；
* 跟踪语音大模型及实时语音交互领域的工程技术发展，推动相关技术预研与工程能力建设。

任职要求

* 计算机、软件工程、电子、人工智能等相关专业，本科及以上；
* 具备较强的算法工程和系统工程能力，有语音 / 音频 / 多模态模型相关算法工程经验；
* 有流式 / 实时语音处理或大模型推理部署经验，深入理解低延迟场景下的推理、服务和系统优化问题；
* 熟悉 Python，具备较强的GO工程能力，能够独立完成算法服务、推理模块及相关系统的设计与开发；
* 熟悉 PyTorch 等主流深度学习框架，理解模型推理、部署及线上服务链路；
* 熟悉模型服务化和工程部署，具备模型从研发环境到线上生产环境完整交付经验；
* 具备较强的系统设计、问题定位和技术方案能力，能够针对性能、稳定性、资源利用率等问题进行系统性优化；
* 具备团队技术带队经验，能够进行技术规划、任务拆解、项目推进及团队成员培养；
* 具备较强的跨团队协作能力，能够推动算法、工程、产品等团队完成复杂项目落地。

加分项

* 有完整交付对外 API / 大规模线上模型服务的经历，熟悉服务治理、监控、告警、灰度发布、版本管理等生产环境能力；
* 熟悉推理加速与部署技术，如 vLLM、量化、KV Cache、流式推理等；
* 有实时语音大模型、Voice Agent、全双工语音交互等相关工程经验；
* 有 3 人以上算法工程团队管理或技术带队经验。
