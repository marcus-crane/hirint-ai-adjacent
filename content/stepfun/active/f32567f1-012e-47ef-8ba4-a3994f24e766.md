岗位职责：

1. 负责数据平台(数据采集、离线/实时计算、数据服务、调度系统等)的功能测试、接口测试、集成测试与回归测试;
2. 设计数据质量校验方案,保障数据链路端到端的准确性、完整性、一致性(如对账、字段校验、血缘影响面分析);
3. 参与性能测试与稳定性测试,验证海量数据场景下平台的高并发与容错能力;
4. 跟踪缺陷生命周期,做好线上问题复盘与根因分析,推动质量问题闭环;
5. 推动 CI/CD 流水线中的质量卡点建设,提升平台发布效率与稳定性。

岗位要求：

1. 本科及以上学历，计算机相关专业，3 年及以上测试开发经验；
2. 具备良好的代码能力,熟练掌握 Python / Java 至少一门,熟悉 Git、Linux、SQL 等基本工程能力；
3. 熟悉 Hadoop / Hive / Spark / Flink / Kafka 等大数据组件中的一项或多项,了解实时数仓或湖仓架构者优先(数据平台开发岗普遍要求);
4. 具有良好的沟通能力，执行力强，主动推动问题解决闭环，自驱力强；
5. 有AI First思维，熟练应用各类Agent工具，善用 AI 工具提升测试效率、缺陷预测等实践。
