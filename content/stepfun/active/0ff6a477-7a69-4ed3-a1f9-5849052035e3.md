岗位定位

建设覆盖设备、App、云端与智能功能的自动化质量体系，支撑双产品持续集成、真实场景验证与量产发布。

岗位职责

1. 跨端测试体系：制定设备、Android/iOS、云服务和 Agent 的分层测试与准入标准，维护机型、系统状态和版本兼容矩阵。

2. 设备与故障自动化：开发协议/设备模拟、自动化脚本及必要的硬件在环环境，覆盖断连、断电、满盘、重启、OTA 和长稳测试。

3. App 与数据验证：验证权限/后台、文件同步、录音完整性、数据库恢复、端云冲突、纠错、删除及换机流程。

4. 智能功能评测：联合算法团队建设回放数据和评测，覆盖 Agent 工具授权、幂等回执、任务恢复及记忆证据一致性。

5. 发布与线上质量：接入 CI 和质量看板，推动问题定位、回归和 ODM 验收，参与灰度、回退及故障演练。

任职要求

必须具备

1. 计算机、电子或相关专业本科及以上学历，4 年及以上测试开发或自动化测试经验。

2. 具有 IoT、智能硬件或设备连接类移动应用测试经历，能够结合真机和服务端定位问题。

3. 熟练掌握 Python 或其他自动化语言，熟悉接口测试、移动自动化、日志分析和 CI 集成。

4. 理解蓝牙/网络、异步状态、持久化及错误恢复，能设计可重复的故障注入测试。

5. 具备性能、稳定性或兼容性验证经验，能够建立清晰的测试报告与发布门禁。

6. 能够与开发和算法协作建立自动化判定，不局限于手工点击测试。

加分项

1. 有音频质量/功耗测试、HIL、仪器联动或设备产测经验。

2. 有 LLM、RAG、Agent 或长期记忆的评测实践。

3. 有多用户安全隔离、云端实例恢复或 OTA 量产验收经验。
