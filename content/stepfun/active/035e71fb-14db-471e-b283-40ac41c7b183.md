岗位职责

* 负责模型仓库管理体系的整体架构设计与技术路线规划，制定模型下载、断点续传、校验、版本管理、OTA 和回滚的方案选型与架构规范
* 负责 GGUF、safetensors、INT4/INT8 等模型格式管理方案设计，制定算力卡适配标注的技术标准与评估体系
* 设计端云路由策略架构方案，按复杂度、隐私、延迟、成本和负载制定推理路径选择的技术路线与降级兜底方案
* 负责多家云 API 适配方案选型与架构设计，制定敏感数据禁止出端与审计的技术方案与规范
* 制定 OpenAI 兼容接口（chat/embeddings/audio/images）的技术方案，规划流式输出、排队、取消和超时的架构设计
* 设计 API 网关架构方案：鉴权、限流、配额、优先级队列、日志和用量统计的技术选型与方案评审
* 制定推理引擎对接方案（vLLM/Ollama/llama.cpp/TensorRT-LLM 等），设计运行层接口架构规范，不直接操作显存和设备
* 负责端侧 NPU 模型部署方案选型与推理性能优化技术路线规划

任职要求

* 本科及以上学历，计算机/AI/电子等相关专业
* 3 年以上 AI 模型部署或推理服务领域经验，有模型部署架构设计与方案选型经验
* 熟悉 LLM 推理引擎（vLLM/Ollama/llama.cpp/TensorRT-LLM）方案选型，有部署调优方案评审经验
* 熟悉模型量化（INT4/INT8/GGUF）方案选型与格式转换（safetensors/ONNX）技术路线规划
* 有端侧 NPU 部署方案选型经验（瑞芯微/爱芯元智/安霸等）者优先
* 有 API 网关架构设计或高并发后端服务方案设计经验
* 熟悉 Docker/Kubernetes 容器化部署方案选型与架构设计
* 有 OpenAI 兼容接口架构设计经验者优先
* 具备系统架构设计能力、技术方案评审能力与跨团队技术协调能力
