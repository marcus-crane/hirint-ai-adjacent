1. **负责 Android/Linux 平台系统级功耗分析与优化**，覆盖待机、轻载、前后台运行及持续高负载场景，降低整机能耗与发热，提升续航和运行能效。
2. 建立整机及关键子系统的功耗评测与归因方法，结合功耗曲线、系统 Trace 和硬件遥测，定位异常唤醒、资源常驻、频繁调频、无效计算及访存等问题。
3. 围绕 CPU 调度、CPUIdle、CPUFreq/DVFS、Wakeup/Wakelock、设备运行时电源管理及休眠唤醒链路开展优化，推动 Framework、Native、HAL、驱动与 Kernel 层问题闭环。
4. 分析 CPU/GPU/NPU 等计算资源及相关设备的负载与电源状态，优化资源使用、性能提示和频率策略，在响应时延、吞吐与稳定性约束下提升能效。
5. 负责温升、热降频及持续负载下的性能功耗分析，协同芯片平台和系统团队优化温控与性能策略，兼顾短时响应和长期稳定体验。
6. 支持端侧 AI 推理、大模型及实时语音等场景的能耗优化，分析模型加载、数据处理、推理和结果呈现等阶段的系统开销，协同算法与推理框架团队优化执行后端、资源生命周期及任务调度。
7. 建立功耗自动化测试、回归与准入机制，跟踪待机功耗、场景能耗、唤醒次数、温升及持续性能等指标，推动多机型适配与量产问题闭环。

**任职要求**

1. 计算机、电子信息或相关专业本科及以上学历，具备 **Android/Linux 平台功耗分析与优化经验**，有可验证的系统级优化成果。
2. 熟悉 Android/Linux 电源管理与调度机制，在以下一个或多个方向具有深入实践：

* CPU 调度、CPUFreq/DVFS、CPUIdle；
* Suspend/Resume、Wakeup Source/Wakelock；
* Runtime PM、设备时钟与电源状态管理；
* Android Power HAL、性能提示或 Thermal 管理。

1. 熟练使用功耗仪及 Perfetto、simpleperf、ftrace、perf 等工具，能够对齐功耗曲线与系统事件，独立完成问题定位、能耗归因和优化验证。
2. 熟悉 C/C++，具备 Android Native、HAL、Linux Kernel 或驱动相关模块的开发与调试经验；能够通过代码和系统行为分析定位问题，而不仅限于测试与报告输出。
3. 理解功率、任务能耗和能效指标的区别，能够设计可复现的实验，控制温度、频率、后台负载等变量，并评估性能、能耗与稳定性之间的取舍。
4. 理解移动平台 CPU/GPU/NPU 异构计算的基本执行与同步机制，能够分析数据搬运、资源争用、忙等、频繁唤醒和资源释放不及时等系统开销。
5. 具备良好的数据分析与跨团队协作能力，能够独立推进问题复现、方案实施、回归验证及量产落地。

* 熟悉 Python/Shell，具备功耗测试、Trace 分析及回归工具开发经验。
