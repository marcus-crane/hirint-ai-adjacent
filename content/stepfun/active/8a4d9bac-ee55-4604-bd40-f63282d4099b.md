**岗位概述**

我们正在建设支撑公司商业化收入的计量计费平台，覆盖大模型 Token、API 调用、GPU 算力时长等多类资源的用量采集、实时计价、账单出具与财务对账全链路。

**岗位职责**

1. 负责计量计费平台的整体架构设计与核心模块研发，构建从用量采集、清洗聚合、计价出账到财务对账的端到端链路；
2. 负责多维计费模型的设计与实现，支持按量计费、阶梯定价、订阅套餐、预付额度、后付费及优惠策略等形态，保证计价规则的可配置化与可追溯；
3. 负责账单系统全流程建设，包括账单生成、拆分合并、重出账、账单明细与消费可解释性，支撑客户侧账单查询与争议处理；
4. 负责用量与资金链路的数据一致性与准确性保障，针对高并发、乱序、重复上报、上游漏报等场景设计幂等、补偿与校验机制，控制资损风险；
5. 负责配额、限流、余额扣减、欠费停服等策略能力的研发，并建设面向财务与运营的自助对账、差异排查工具；
6. 与产品、财务、前端、QA 及上下游研发团队协作，参与技术方案评审与代码评审，推动需求按期高质量交付。

**任职要求**

1. 计算机、软件工程或相关专业本科及以上，5 年以上后端研发经验；
2. 精通 Go / Java / C++ 中至少一种，具备扎实的并发编程、性能分析与工程实践能力；
3. 具备交易类或账务类系统的生产级研发经验，熟悉支付、订单、账户、清算、计费等领域中至少一类业务的建模方式与常见风险点；
4. 熟悉 MySQL / PostgreSQL、Redis、Kafka，能处理事务、索引、缓存、消息可靠性与分布式数据一致性问题；
5. 具备复杂分布式系统设计能力，理解最终一致性、幂等、补偿、对账的适用边界并有落地经验；
6. 具备较强的线上问题定位能力，能结合日志、指标与链路追踪完成分析与修复验证；
7. 具备良好的抽象能力与协作意识，能将业务诉求转化为清晰的数据模型、状态机与接口契约。

**加分项**：云平台 / IaaS / PaaS / MaaS 的计量计费账单对账经验；Token 计量、API 调用量、GPU 异构算力时长计费实践；ClickHouse / Doris / Flink 实时聚合；K8s 云原生治理。
