**一句话描述**：建设平台侧风险识别与策略体系，保障模型 API 服务安全、稳定、公平地被使用。

**岗位职责**

* 建设针对模型 API 服务的风险识别能力：分析异常调用行为，建立特征提取、规则引擎与异常识别体系，识别刷量、盗刷、数据倒卖、批量爬取等滥用模式。
* 建设账号与访问安全策略：治理注册、登录、调用全链路风险，包括设备指纹、行为序列分析、多账号关联识别与异常会话处置。
* 运营限流与配额策略：设计多维度限流、分级配额与动态防控机制，在保障正常用户的同时遏制自动化滥用。
* 分析大规模访问日志，通过对照实验与离线回放评估策略效果，持续优化召回率、误伤率与处置成本。
* 主导复杂风险事件的排查与处置，推动跨团队落地，沉淀风控方法论与工具链。

**任职要求**

* 计算机或网络安全等相关专业本科及以上，具备风控、反欺诈或大规模服务交互系统核心研发经验。
* 精通 Python 或 Go，具备高并发服务、日志处理与规则引擎开发经验。
* 熟悉网络协议、鉴权与会话机制，熟悉常见黑灰产手法（代理、脚本、批量注册等）及其对抗思路。
* 具备大规模数据处理、行为特征分析及实验评估能力，能主导策略设计与复杂异常排查。
* 具备安全、隐私及合规意识，严格遵守数据安全与个人信息保护相关法规。

**加分项**

* 有风控策略平台、反欺诈系统或业务安全体系建设经验。
* 有机器学习在风控场景的落地经验（异常检测、图关联、序列模型等）。
* 有大型互联网平台黑灰产对抗经验。
