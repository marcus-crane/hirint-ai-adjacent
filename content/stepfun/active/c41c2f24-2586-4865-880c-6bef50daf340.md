**岗位职责：**

1. 负责数据平台的整体产品规划与设计，制定产品路线图，推动产品从需求到上线的全流程落地
2. 承担数据平台核心模块的产品设计，包括元数据管理、数据资产管理、数据检索、数据版本管理、数据血缘、数据服务 API 等
3. 推进数据治理相关能力的产品化建设，包括数据质量管控、数据标准统一、数据权限管理
4. 协同数据研发、工程研发、业务团队，深入了解用户需求，挖掘数据消费场景，输出可落地的产品方案
5. 负责数据运营相关工作，包括数据资产运营、用户运营和数据使用分析
6. 跟踪数据平台领域技术发展趋势，进行竞品调研，持续优化平台产品能力

**任职要求：**

1. 本科及以上学历，3 年以上数据产品经理经验，有数据中台/大数据平台产品经验优先
2. 熟悉数据开发平台、数据治理平台等产品形态，了解数据湖仓架构、ETL/ELT 流程等基本概念
3. 有元数据管理、数据血缘、数据质量、数据资产等模块的设计经验优先
4. 能与研发进行有效技术对话，了解主流数据技术栈（Hive/Spark/Flink 等）者优先
5. 具备较强的需求分析能力和产品文档撰写能力，能独立输出 PRD
6. 逻辑严谨，善于抽象复杂系统，有良好的跨团队沟通能力
