岗位定位

负责 IoT 配套 App 的 Android 原生能力与跨平台集成。首位资深人选可承担 App 技术负责人，主导 Flutter、KMP Agent 与原生 SDK 的模块协作，并亲自开发核心链路；如招聘第 2 位，侧重平台适配和业务交付。

岗位职责

1. App 平台与模块架构：设计 Android 平台模块、业务接口、SDK 产物和构建集成，与 iOS、Flutter、Agent 团队共同维护多端一致的能力契约。

2. IoT 设备与音频接入：集成蓝牙互联、设备控制、文件同步、OTA 及音频路由，处理连接状态、音频焦点、中断和错误恢复。

3. 跨平台 SDK 与桥接：接入 Kotlin/KMP Agent 和 Flutter 插件，维护类型化命令、事件流、取消及生命周期管理，避免高频数据低效跨层传递。

4. 系统适配与本地数据：实现权限、后台任务、前台服务、通知、安全存储和本地数据能力，覆盖主流三方手机与系统版本。

5. 性能与研发质量：优化启动、卡顿、ANR、内存和功耗，建设单元/集成测试、诊断与发布流程；技术负责人参与设计评审及关键问题攻关。

任职要求

必须具备

1. 计算机或相关专业本科及以上学历，5 年及以上 Android 研发经验；技术负责人需有模块架构或技术带队经历。

2. 必须具有 IoT 设备配套 App 开发经验，如耳机、可穿戴、录音、相机或其他智能硬件产品，参与过真实设备联调与上线。

3. 熟练掌握 Kotlin、协程、Android 生命周期及模块化开发，理解异步并发和状态恢复。

4. 具备蓝牙/BLE、音频、长任务或设备文件同步相关实践，理解权限、前台服务及厂商后台策略。

5. 熟悉本地数据库、网络与安全存储，能使用工具定位 ANR、内存、耗电和兼容问题。

6. 技术负责人人选需能够承担跨端接口、SDK 集成及核心代码开发；具备 KMP 或 Flutter 原生桥接经验者优先匹配负责人方向。

加分项

1. 有 Kotlin Multiplatform、JNI/C++、Flutter Plugin 或跨平台基础库经验。

2. 有双产品复用、音频设备、端侧模型或 Agent 集成经验。

3. 有架构演进、代码评审、自动化测试与团队培养实践。
