岗位职责

1、负责AI应用语音通话场景下 RTC SDK 的设计、开发和持续优化。

2、负责三方 RTC SDK 的接入、封装和统一能力建设。

3、持续优化 RTC SDK 的性能、稳定性、兼容性和可观测性，负责线上音频质量、延迟、弱网及异常问题定位。

4、与音频、客户端、服务端团队协作，推动语音 Agent 实时通信链路和 SDK 架构持续演进。

岗位要求

1、3 年以上音视频 SDK、RTC 或客户端基础架构相关开发经验，熟练掌握 C/C++。

2、有腾讯 TRTC、声网 Agora、ZEGO 等主流 RTC SDK 接入或二次封装经验。

3、熟悉 RTC 基本原理，理解音频采集、播放、编解码、弱网、Jitter Buffer、QoS/QoE 等核心概念。

4、具备良好的 SDK 架构设计和跨平台开发能力，能够设计稳定、易用、可扩展的统一接口。

5、具备较强的问题定位能力，能够分析跨平台兼容、音频质量、延迟及第三方 SDK 异常问题。
