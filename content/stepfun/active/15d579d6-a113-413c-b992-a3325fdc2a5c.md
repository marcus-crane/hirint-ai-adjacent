职位职责：

1. 作为 MP 的技术总架构师，负责平台整体架构设计和技术演进规划，把当前快速长出来的系统，重构成能支撑跨部门、大规模调用的平台
2. 设计多网关、多模型接入与流量调度体系：路由、限流整流、PTU + 按量资源组合、闲时队列、容灾切换
3. 主导计量 → 计价 → 扣费 → 双边账单链路的架构，保证费用算得准、对得上、可审计
4. 建立稳定性体系：可观测、SLA 监控、告警、故障定位与复盘机制，让线上问题从"靠人找"变成"靠系统发现"
5. 对关键技术方案拍板，带研发同学做技术分工和 code review，沉淀架构规范

职位要求：

1. 本科及以上，参考 10 年以上后端研发经验，其中至少 3 年大型系统架构设计经验
2. 大厂背景，主导过高并发、高可用的平台型系统（API 网关、云服务、中台、支付 / 计费类优先）
3. 对类似 MP 的业务有全链路理解：接入、路由调度、计量计费、监控、账单，能讲清每一段怎么设计、为什么这么设计
4. 技术过硬，Go / Java 至少精通一门，熟悉分布式、存储、消息、缓存，能下到代码和数据库层面定位问题
5. 规划性强：既能快速定位问题，也能给出 6-12 个月的技术演进路线，并推动落地
6. 抗压，能在快节奏、需求多变的环境里保持判断

**加分项**

1. 有 AI 网关、MaaS、LLM API 平台、云厂商模型服务的架构经验
2. 做过多租户计费 / 账单系统，或大规模流量调度与成本优化
3. 带过技术团队，或在跨团队项目里担任过技术负责人
4. 本身是 AI 工具的重度使用者，愿意用 AI 改造研发和运维方式
