岗位职责

* 负责 AI 语音助手在陪伴场景下的端到端体验，覆盖核心场景定义、人格与表达策略、评测标准定义与研发跟进
* 设计个性化回应策略，定义千人千面对话体验的产品方案与策略口径，定义主动服务的触发时机与分级机制
* 建立模型体验效果基线，与评测岗共同定义评测集与打分规范，按版本跟踪效果差距并定位模型短板。
* 制定交互样本的设计规范、正反例标准与验收口径，推动数据按周期交付并达成场景覆盖要求。
* 明确目标体验所需的模型与 Harness 能力，推动算法、工程、系统框架三方排期落地

任职要求

* 3 年以上 C 端产品经验，其中 1 年以上负责 AI 或对话类产品，有可量化的体验或指标改进结果。
* 熟悉大模型产品的能力边界，能基于数据分布而非单个用例判断效果。
* 具备优秀的抽象与结构化能力，能把模糊的体验问题拆解为清晰框架与可执行标准。
* 具备策略产品思维，能基于用户行为与画像数据设计分层、分人的体验策略。
* 具备独立输出交互方案的能力，可完成信息架构与关键对话流程设计。
* 具备跨团队推动能力，能高效协同算法、工程与设计完成交付。
* 表达清晰，文档结论先行，能在评审中完成取舍论证。
* 自驱力强，能持续高频使用产品，验证核心链路并主动发现问题。

加分项

* 有语音交互、全双工对话或实时音视频产品经验。
* 有个性化、用户画像或推荐类 C 端产品经验，理解如何用数据驱动千人千面的体验。
* 有模型评测集设计、数据规范制定或人格 / Prompt 调优的实际经验。
* 有系统级 Agent 或端侧模型相关产品经验。
