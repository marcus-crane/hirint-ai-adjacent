## 职位描述

1. 参与四足机器人的软硬件开发与系统集成，基于现有机械狗平台完成开发环境搭建、SDK 接入与真机调试，实现站立、行走、遥控及基础运动控制；

2. 负责机载计算设备、相机、激光雷达等设备的安装接入、驱动配置与通信调试，排查供电、网络、传感器及软硬件兼容问题，保障机器人稳定运行；

3. 基于 ROS / ROS 2 搭建机器人软件链路，打通传感器数据采集、状态反馈与运动指令下发，配合完成定位、建图、路径规划及避障功能的集成调试；

4. 配合算法团队接入视觉语言模型、导航模型等，将模型输出与机器人控制接口对接，实现自然语言指令驱动的目标搜索、目标到达等导航任务；

5. 参与真机数据采集、场景测试与问题复现，优化系统运行稳定性和导航效果，完善急停、限速及异常停止机制，沉淀部署文档、调试记录与演示案例。

## 任职要求

1. 本科及以上在校生，机器人、自动化、机械电子、电子信息、计算机等相关专业；

2. 熟悉 Linux 开发环境，掌握 Python 或 C++，了解 ROS / ROS 2，能够阅读技术文档、运行开源项目并进行接口开发与问题排查；

3. 具备较强的动手能力，有机器人、嵌入式或智能硬件相关项目经验，能够完成设备连接、驱动安装、通信调试及基础故障定位；

4. 了解机器人传感器、坐标变换及运动控制的基本概念；有相机、激光雷达、IMU 等设备接入经验者优先；

5. 有四足机器人、移动机器人、机器人竞赛或真机开发经验者优先；有 SLAM、自主导航、视觉语言导航或模型部署经验者加分；

6. 对具身智能与机器人开发有持续兴趣，学习主动，具备良好的沟通协作能力，能够围绕具体任务推进开发、测试与交付。
