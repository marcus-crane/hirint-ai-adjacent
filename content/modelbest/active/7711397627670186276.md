## 职位描述

职位描述

负责多模态大模型训练数据 Pipeline、DataLoader 及数据生产基础设施建设，推动数据接入、清洗、质检、训练交付流程的工程化、配置化和平台化。

岗位职责

1、负责大规模多模态数据（图文、音视频等）接入、解码、清洗、去重、采样及任务编排；

2、负责高性能多模态训练 DataLoader 设计与开发，优化在线预处理、动态 Packing、配比采样及高并发 IO；

3、建设标准化、配置化 Data Pipeline，将高频处理能力沉淀为可复用算子和自助生产能力；

4、建设数据版本、血缘、任务状态、异常恢复及质量追踪能力；

5、联动数据、质检、标注和实验平台，推动自动质检、验收及数据效果反馈链路建设。

## 任职要求

1、Python 工程能力扎实，熟悉大规模多模态数据处理；

2、熟悉 PyTorch 数据生态，具备大模型训练 DataLoader 设计开发与调优经验；

3、熟悉 Spark / Ray 等至少一种分布式计算框架；

4、熟悉对象存储、Parquet / JSONL / LanceDB / Tar 等数据格式及大规模 IO；

5、熟悉 Vibe Coding（如 Cursor / Claude Code 等），善于以架构设计驱动 AI 高效开发交付；

6、有多模态大模型数据、数据平台、Workflow、数据质量相关经验优先。
