## 职位描述

1. 产品规划：负责 VoxCPM 语音产品的规划与设计，结合用户需求与语音大模型技术能力，定义高价值语音应用场景，推动产品化落地；

2. 模型评测：搭建并完善语音模型在产品场景下的评测体系与 Benchmark，设计场景能力评测集，协同研发团队完成评测，持续驱动模型效果与产品体验提升；

3. 需求落地：深入调研、抽象用户需求，分析数据，与研发、设计团队紧密协作，确保产品高品质落地；

4. 产品原型：运用 AI 辅助研发工具（vibe coding）快速搭建可交互的产品原型，直观验证产品方向与场景价值；

5. 产品迭代：综合评估产品效果，持续关注用户反馈、行业进展与技术演进，基于数据与反馈推动产品迭代。

## 任职要求

1. 2 年以上产品经理从业经验，产品逻辑清晰，特别优秀的候选人可放宽年限；

2. 能进行语音科技市场分析，理解行业趋势（如大模型在语音中的应用现状、主要玩家、能力边界）、目标客户的痛点与付费意愿；

3. 具备从 0 到 1 或从 1 到 N 的产品规划、定义与设计能力，能将复杂需求与技术能力转化为清晰的产品愿景、路线图和功能定义；

4. 精通需求获取、分析、拆解、优先级排序和文档化（用户故事、PRD、流程图等）；

5. 熟练掌握 vibe coding，具备一定代码能力，能够在 AI 辅助下搭建原型应用；

6. Agent 产品的高强度用户，熟悉 Agent 产品的各种形态，深度使用过 Claude Code、Codex、Cursor、OpenCode 等类似产品，并将相关产品的使用融入到自己的工作和生活中；

7. 具备 UI/UX 设计素养，能够在 AI 辅助下完成产品原型图设计、UI 设计等产品侧设计工作；

8. 理解大模型及 Agent 的基本机制与技术原理，有第一手实践经验。

加分项

1. AI 行业核心岗位的从业经验，或拥有 AI 原生产品从 0 到 1 的落地经验，或明确的 AI 商业化落地成功案例；

2. 语音 / 音频方向（语音合成、语音识别、语音助手、音频内容平台等）的产品或技术从业经验；

3. 活跃于开发者社区，主导或作为核心骨干参与过优秀的开源项目；

4. 英文读写能力良好。
