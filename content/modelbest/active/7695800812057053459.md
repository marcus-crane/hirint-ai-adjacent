## 职位描述

1. 紧密配合海外商务团队，负责自研大模型（含端侧模型/轻量化模型）及Agent产品在海外市场的技术售前支撑，主导客户技术交流、架构答疑、需求梳理与技术可行性论证；

2. 针对海外客户的多样化场景（如智能硬件、个人/企业办公助理、多语言客服、本地化离线AI等），结合自研模型技术优势，输出针对性的端到端技术方案、架构图及ROI价值测算；

3. 具备极强的原型开发能力（如利用 Vibe Coding / Rapid Prototyping），能根据海外客户的技术指标要求，快速搭建并交付高保真Demo及POC，打消技术疑虑，加速销售转化；

4. 负责海外RFP/RFI的技术应答、竞品技术参数对标；结合不同法域（如数据出境、本地化隐私合规如GDPR、端侧数据不出设备等）提供合规的技术部署方案；

5. 输出标准化的海外版技术白皮书、API集成文档、部署拓扑及全球化POC模板；将海外客户的共性技术诉求与痛点结构化，反哺后端研发团队进行产品迭代。

## 任职要求

1. 计算机、软件工程、人工智能等相关专业本科及以上学历；英语听说读写流利，可作为工作语言，能无障碍进行跨国技术宣讲、代码/架构层面的深度交流；有海外留学/工作经历者优先；

2. 深度理解主流大模型技术原理（Transformer架构、RAG、Agent智能体机制）；对端侧/轻量化大模型落地有实际经验者优先（如端侧量化/剪枝、推理加速引擎如ONNX/TensorRT/llama.cpp、端云协同架构）；

3. 具备极强的 Vibe Coding / 敏捷开发能力，熟悉主流开发语言及大模型应用开发框架（如LangChain/LlamaIndex等），能借助AI工具极速搭建业务Demo及POC原型；

4. 2年以上AI、云厂商、出海SaaS或大型企业级软件的售前技术顾问（Pre-sales）、解决方案架构师（SA）经验，有操盘海外POC验证或全英文技术应答经验者优先；

5. 5. 逻辑清晰，具备极强的跨文化沟通能力、跨时区团队协作意识和自我驱动力，能适应海外出差支持项目拓展。
