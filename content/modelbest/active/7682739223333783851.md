## 职位描述

1. 负责智能体应用的设计、开发与迭代，对项目架构质量与交付质量负责；

2. 与产品、FDE 工程师协作，在杂乱的需求中找到共性，输出通用的产品/架构方案；

3. 应用 Vibe Coding 等 AI Native 开发方式，提升开发与交付效率；

4. 与算法、前端、后端、运维等团队协同，推动智能体项目高质量落地，保障合作方满意度；

5. 持续跟踪 Agent 技术生态（RAG、MCP、Tool Use、Function Call、Agent Skills 等），沉淀团队工程能力。

## 任职要求

- 重点大学本科及以上学历；

- 熟练掌握 Java/Python/TypeScript 等技术栈中的一种，并能快速迁移到其它技术栈；

- 熟练掌握 Vibe Coding 技能；

- 熟悉常见的分布式高可用架构设计范式；

- 了解 Agent 架构，熟悉 RAG、MCP、Tool Use、Function Call、Agent Skills 等典型模式原理与应用；

- 有产品 sense 与架构 sense，能够在杂乱的需求中找到共性，给出通用的产品/架构方案；

- 有 AI 应用落地与迭代经验。

加分项

- 能够技术驱动业务问题解决或者产品优化；

- 有复杂项目架构治理和升级经验；

- 深入理解主流 Agent 框架及其优缺点，有 Agent 效果优化经验。
