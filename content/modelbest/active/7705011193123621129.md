## 职位描述

1.深入客户业务现场，负责智能体应用的设计、开发与交付，对交付目标完成度与项目交付质量负责；

2.与项目经理、解决方案、产品及客户关键用户协作，理解并转化客户需求为可落地的产品/技术方案，保障合作方满意度；

3.与算法、前端、后端等团队协同，推动智能体项目高质量交付落地，推动 PoC 快速验证并迭代为可上线的生产系统；

4.应用 Vibe Coding 等 AI Native 开发方式，提升开发与交付效率；

5.建立场景评测集与验收指标，通过 Bad Case 分析持续优化 Prompt、检索策略、工具设计与流程编排；

6.确保客户成功与知识迁移，帮助客户团队具备自主运营能力。

## 任职要求

1.重点大学本科及以上学历；

2.熟练掌握 Java/Python/TypeScript 等技术栈中的一种，并能迁移到其它技术栈；

3.熟练掌握 Vibe Coding 技能；

4.熟悉 Agent 架构，熟悉 RAG、MCP、Tool Use、Function Call、Agent Skills 等典型模式原理与应用；

5.了解 Agent 评测方法与评测集设计，有 Agent 效果优化经验；

6.有 toB 系统交付经验及AI 应用落地与迭代经验。

加分项

1.能理解客户模糊的输入并转化成明确的产品/技术需求；

2.熟悉 Agent 评测方法与技术；

3.了解大模型训练与微调技术。
