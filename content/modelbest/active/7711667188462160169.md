## 职位描述

1.策略方案与场景运营：与产品、算法及业务团队协作，将业务目标和标准转化为可规模化执行的评测方案，明确测哪些任务、怎么抽样、观察哪些过程、依据什么判定。通用能力覆盖多轮澄清、知识检索、工具调用、记忆和任务恢复。行业场景覆盖企业知识问答、智能教研、制度审核和财务审批等任务，围绕角色权限、业务规则、例外处理和最终业务状态设计用例。

2.Benchmark 与数据资产建设：负责真实样本采集、脱敏、分层抽样、难例挖掘、标准答案与判定证据建设，持续维护基准测试集、金标集、独立验收集和回归集。建立数据准入、版本冻结与更新机制，跟踪真实业务分布及能力覆盖变化，识别同源样本泄漏、重复及过时样本，保证历次结果可比。

3.人机协同评测与质量治理：将评分细则转为可执行的评审指引、正反例和争议处理规则，建立试评、盲评、评审员校准、分层抽检及专家仲裁机制。根据任务风险和机评表现配置自动判分、人工抽检及专家复核，持续跟踪人评一致性、人机分歧和严重错误漏判，定位问题来自判据歧义、证据缺失还是评分器误判，并推动复测。

4.自动化与提效：识别样本生产、任务分发、质量检查、结果汇总及报告生成中的瓶颈，利用大模型、提示词和 Agent 工作流搭建或验证自动化方案。用人工基线核对自动化前后的质量、交付周期和单条有效样本成本，将验证有效的流程与研发团队共同沉淀为可复用的平台能力。

5.版本评测与问题闭环：组织模型选型、Agent 版本对照及多模态、端侧专项评测，结合逐题结果、执行轨迹、工具回执和人工反馈，分析关键场景的提升、退化和风险。对语音打断与任务恢复、视觉识别与界面操作等问题，明确失败发生的环节和可复现条件，与产品、算法及研发确认改进项，将复核后的坏例纳入回归集或策略优化数据。

6.行业验证与客户交付：与解决方案、交付和行业专家对齐评测范围、输入数据、运行环境及验收证据，组织售前验证、现场评测和修复复测。按场景输出业务任务完成情况、关键失败、适用条件与待补证事项，沉淀可复用的行业测试包和验收报告。

## 任职要求

1. 本科及以上学历，计算机、人工智能、统计学、数据科学或相关专业优先；具备大模型评测、AI 数据策略或智能产品质量运营经验，2 年及以上相关经验优先。

2. 有独立负责评测项目的经验，能够从业务需求出发设计样本、判据、执行流程和验收方案，并组织评审、复盘及后续迭代。

3. 熟悉分层抽样、数据集划分、金标建设和评审一致性评估，具备评测数据或质量体系建设经验，能识别样本偏差、口径漂移和数据污染对结论的影响。

4. 理解大模型能力边界和 Agent 的实际运行方式，熟悉提示词、检索增强生成、工具调用、上下文或任务编排中的至少两个环节，能根据执行轨迹和业务结果定位问题。有自动评分、数据合成或 Agent 工作流实践者优先。

5. 熟练使用 SQL 进行抽样、分层统计和误差分析，能使用 Python 完成数据处理、质检或自动化任务。具备同题对照和结果解读能力，能将评测发现转化为明确的改进项和复测要求。

6. 具备复杂业务拆解、文档表达和跨团队推进能力，能与产品、算法、研发、交付及行业专家对齐标准、处理争议并完成交付。有企业级 Agent、行业应用验收、语音或视觉多模态评测、端侧智能产品经验者优先。
