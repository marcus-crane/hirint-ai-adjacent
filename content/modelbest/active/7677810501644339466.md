## 职位描述

1. 智能体应用工程化开发：负责基于大模型的智能体（Agent）应用的架构设计、工程实现与迭代优化，涵盖任务规划、工具调用、多轮对话、记忆管理等核心能力建设，完成工作流编排、多 Agent 协作、Human-in-the-Loop 交互、RAG等功能的工程化落地与优化。

2. 前后端全栈开发：负责智能体应用的后端服务开发，基于 Python 或 Go 构建高可用 API 服务，实现流式输出、异步任务、模型服务调度等核心能力；负责前端交互界面开发：基于 React 或 Vue 3 构建智能体对话界面、任务可视化面板、管理后台等，实现前后端联调与数据交互；负责数据库设计（PostgreSQL/MySQL）、缓存策略（Redis）及系统集成，保障系统性能与数据一致性。

3. 系统部署与现场交付：负责基于 Docker/K8s 的容器化部署方案设计与实施，搭建 CI/CD 流水线，保障项目的高效迭代与稳定运行。承担项目到用户现场的部署交付工作，包括私有化环境适配、系统安装部署、性能调优、上线护航等。负责系统的运维监控体系建设，保障生产环境的稳定性与可观测性。

4. 需求协同与技术沉淀：对接产品与业务团队，拆解客户需求并转化为可落地的技术方案。协同算法团队完成模型服务化封装与推理优化，推动 AI 能力的产品化落地。沉淀工程化最佳实践，参与团队技术能力建设与知识沉淀。

## 任职要求

1. 教育背景与经验：硕士及以上学历，计算机、软件工程、人工智能等相关专业。3 年以上全栈开发经验，有 AI 产品或智能体应用落地经验者优先。

2. 技术能力

- 智能体与大模型工程：熟悉 LLM 应用开发框架，具备 Agent 工作流编排、工具链开发的实践经验。了解 RAG 系统构建流程，熟悉向量数据库（Milvus/FAISS/Chroma 等）的使用与优化。熟悉 Prompt 工程、多模型调度、流式输出等大模型工程化技术。

- 后端开发：精通 Python，熟悉 FastAPI/Flask/Django 等后端框架，具备异步编程与微服务架构经验。熟悉数据库设计与优化（PostgreSQL/MySQL），了解 Redis、消息队列等中间件。

- 前端开发：熟练掌握 React 或 Vue 3 等主流前端框架，能独立完成交互式 Web 界面开发。

- 部署运维：熟悉 Docker/K8s 容器化部署，具备 CI/CD 流水线搭建经验。熟悉 Linux 运维、Nginx 配置、服务监控等基础运维技能。

3. 综合素质

- 具备良好的需求拆解与问题排查能力，能独立完成从需求分析到交付上线的全流程。

- 具备 To B 项目或私有化交付经验者优先。

- 具备强烈的 Owner 意识与跨团队协作能力。

- 善用 AI 编程工具（如 Cursor、Copilot 等）提升开发效率。

四、加分项

- 有防务、政企等行业项目交付经验。

- 熟悉模型服务化部署框架（vLLM、Ollama 等）及推理加速技术。

- 有大规模 Agent 系统或多智能体协作项目的完整落地与迭代经验。

- 参与过开源大模型 / Agent 框架社区贡献，或有相关赛事获奖经历。
