## 职位描述

岗位职责

一、基础设施建设

1、独立规划并搭建生产级 K8s 集群，设计高可用架构。

2、维护容器镜像仓库（Harbor、Docker Registry）和 CI/CD 流水线。

二、应用部署与优化

1、将传统应用迁移至容器化环境，优化资源利用率。

2、部署和调优大模型服务，确保低延迟和高吞吐量。

三、监控与故障处理

1、构建全方位监控体系，快速响应和解决生产环境问题。

2、定期进行系统巡检和容量规划，预防潜在风险。

四、自动化与工具开发

1、开发运维工具（如资源自动扩缩、故障自愈）提升效率。

2、编写文档和培训团队成员，推动最佳实践落地。

## 任职要求

一、容器与编排技术

1、精通 Docker 容器化技术，熟悉镜像构建、容器生命周期管理。

2、熟练掌握 Kubernetes (K8s) 集群搭建、配置、扩缩容及故障排查，熟悉 StatefulSet、Deployment、Service 等核心资源。

3、具备 Helm Chart 开发与维护经验，能实现应用的标准化部署。

二、Linux 系统与网络

1、精通 Linux 系统管理（CentOS/Ubuntu），熟悉 Shell 脚本、系统调优。

2、熟悉网络原理（TCP/IP、DNS、负载均衡），能排查网络故障。

三、大模型部署经验

1、熟悉大语言模型（如 GPT、LLaMA）的部署架构，了解 GPU 资源管理、模型并行技术。

2、具备 TensorFlow、PyTorch 等框架的容器化部署经验，能优化模型推理性能。

四、监控与日志系统

1、掌握 Prometheus + Grafana 监控栈，能自定义指标和告警规则。

2、熟悉 ELK Stack 或 Loki + Promtail 日志收集方案，具备日志分析能力。

五、自动化与开发能力

1、具备一定的开发能力，熟悉 shell、golang、python、java 一种以上编程语言，能开发运维工具。

2、熟悉常用的开源组件的部署和运维，包括：redis、mysql、kafka、milvus 等。
