## 职位描述

1.负责面壁智能体平台的产品管理，包括开发框架、工具链、Runtime、性能测试平台等组件。

2.服务面壁内部各产品研发团队、交付团队和合作伙伴的研发团队，帮助他们基于开发平台完成面向不同场景、不同功能、不同形态的 Agent敏捷开发、测试、部署与持续观测。

3.跟踪收集内外部客户团队的使用反馈和需求，持续研究 Agent 从开发、部署到运行的实际问题，持续迭代产品、丰富组件、提升性能、优化体验。

4.支撑内部内外部各客户团队的智能体产品持续优化与商业化，将面壁智能体平台的底层技术优势转化为终端客户的业务价值。

5.持续跟踪 Agent Infra 行业趋势、主流产品与技术框架的演进，形成独立的市场判断、竞品分析和差异化产品策略。

## 任职要求

1.本科及以上学历，计算机或相关工科专业背景，5年以上工作经验。

2.有扎实的技术背景和独立技术判断能力；做过面向开发者的平台型或工具型产品，例如云基础设施、PaaS、API 或工程工具链。

3.深刻理解 Agentic AI、AI Agent、Agent Harness 的核心价值与前沿技术进展。能够与工程师在产品和技术架构层面有效沟通。

4.熟悉主流 Agent Framework、Agent SDK 或相关开发生态。有实际 Agent 开发、原型验证或相关的技术实践经验。

5.深入参与过至少一个智能体的性能测评与调优工作，对系统提示词、工具、上下文管理、记忆等机制对智能体的性能与稳定性的影响有深入理解。

6.具备较强的客户洞察、需求抽象、产品设计能力。能够平衡技术成本、产品体验、市场竞争和产品长期演进。

7.持续关注和跟进行业进展，有自驱力、学习能力、动手实践能力。
