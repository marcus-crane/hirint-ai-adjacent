## 职位描述

1. 负责面向高安全等级与关键任务场景的智能体产品与解决方案的设计与需求定义，输出 PRD 与产品规划；

2. 深入特定行业重点客户，能够支撑客户访谈与需求洞察，提炼不同客户的共性诉求，沉淀可复制的解决方案与交付方法论；

3. 把客户的业务流程拆解为可被智能体承接的"场景 / 任务"，定义智能体的技能、能力边界与人设；

4. 设计智能体应用的价值度量体系（采纳率 / 解决率 / 工时节省 / ROI），支撑售前讲解与交付验收；

5. 作为业务与研发之间的枢纽，负责需求优先级、节奏把控与跨团队协同；

6. 参与重点企业级项目的售前方案与落地交付，承担关键节点的需求确认与风险排查职责。

## 任职要求

1. 有ToC/ToB端大模型/RAG/Agent产品、企业数字化转型方案设计经验；

2. 极强的结构化思维与文档 / 表达能力，能把模糊、复杂的业务场景提炼为层次清晰的框架模型；

3. 有 B2B / 企业级软件 / SaaS / AI 产品相关经验，理解企业级交付的复杂度；

4. 卓越的客户沟通与项目推动能力，能直面客户决策层、独立推进需求确认与方案共识；

5. 深入理解 Agent / RAG / 知识库 / 工作流等技术概念，能与研发高效对话；

6. 对大模型与智能体有热情和基本理解，愿意持续跟踪学习领域前沿知识。

加分项

1. 拥有特定高安全行业（如战略支援、公共应急、重型装备运维等）的深厚领域知识或直接客户合作资源；

2. 主导过从 0 到 1 的产品或解决方案；

3. 具备较强的数据建模与分析能力，能基于有限样本数据构建可靠的效果评估模型，驱动产品迭代方向。
