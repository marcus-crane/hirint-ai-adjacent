## 职位描述

加入面壁智能采购部，独立负责硬件产品（硬件一体机、存储、网络设备、AI 芯片等）的寻源、选型与价格谈判，作为硬件中台核心成员支持推动"千行百业万端"项目落地。

核心职责

1. 硬件选型与评估

根据业务方（算法 / 具身 / 数据 / 商业化）需求，完成硬件选型采购

覆盖范围：、存储系统（全闪 / 混闪 / NAS）、网络设备、AI 芯片、配套硬件

2. 供应商寻源与价格谈判

开发新供应商（OEM / ODM / 芯片厂商 / 代理渠道），建立并维护供应商池

独立完成芯片厂商价格谈判（GPU / AI 芯片 / 国产芯片优先）

商务条款：价格、付款、交期、售后、违约责任

供应商关系日常维护，处理报价 / RFQ / 对账

3. 项目支持

支持"千行百业万端"项目硬件落地

协同硬件中台负责人按项目节奏交付

4. 采购流程

推进合同从寻源 → 谈判 → 审批 → 签约 → 交付 → 验收全流程

维护采购台账、供应商档案

配合 SRM 系统建设与优化

## 任职要求

1. 3 年以上硬件采购经验

2. 熟悉至少 2 类硬件（硬件工作站一体机/ 存储 / 网络 / 芯片）

3. 有芯片厂商直接谈判经验

4. 独立完成过千万级合同

5. 本科及以上

加分项

1. 主动出击，能独立扛指标

2. 技术对话能力（能和算法 / 工程师聊需求）

3. 跨部门协作，节奏感强

4. 抗压
