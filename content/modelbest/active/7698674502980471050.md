## 职位描述

负责面向多模态实时交互场景的 Agent 平台工程研发：

1、设计并实现 Agent Runtime：会话状态管理、工具调用调度、多模态流（音频/视频/文本）的并发处理与同步

2、负责云端实时 API 网关：协议转换（WebSocket 全双工协议适配）、多模型路由、故障切换、延迟链路追踪

3、设计 Agent 的上下文管理、中断/恢复机制、工具回调与异步事件处理

4、从本地 PoC 到可交付的线上服务，包括可观测性、压测基准、灰度发布

5、参与硬件端与云端服务的接口协议设计

## 任职要求

1、本科及以上，计算机相关专业

2、3 年以上后端工程经验，有生产级服务交付经历

3、有实际 Agent / LLM 应用开发经验，理解 Function Calling、工具调用调度、上下文窗口管理的工程细节

4、有 WebSocket / 流式协议的实际开发经验，理解全双工通信的状态机设计

5、熟悉 Python 或 Go，有异步/并发编程实际经验（asyncio / goroutine）

6、能设计延迟/错误率指标，会用结构化日志和 tracing

加分项

1、有过 Runtime 框架或 SDK 设计经验

2、了解语音/视频流处理（PCM 重采样、帧同步、AEC/VAD 的工程集成）

3、有端云协同架构的实际经验
