## 职位描述

1.产品策略建设：负责Agent产品在各行各业场景下的端到端功能设计，覆盖核心场景定义、产品策略、评测标准定义与研发跟进，同时设计各环节产品策略，与产解、客服落地具体的产品与策略方案，同时定义交互样本的设计demo、正反例标准与验收口径，推动整体业务按周期交付并达成场景覆盖要求。

2.评测体系搭建：面向真实业务场景，设计覆盖基模选型、端到端 Agent、端侧硬件落地及用户体验等场景的评测框架和标准，保障评测可解释可复现，并主导 Benchmark 数据集构建与持续迭代，防控数据污染与评测失效，建立模型原子能力、Agent 工程链路、产品端到端、行业业务结果之间的分层关系，明确各层评什么、如何使用结论；

3.自动化评测和数据工程：通过 Agent judge 等自动评测流水线和多评委协作机制，控制评测偏见，持续提升自动评测与人工标注的一致性，推动评测提效，设计评测数据合成方案，建立数据规范与质检体系，同时与评测运营和数据团队协作，保障规模数据生产的稳定性与准确性

4.平台系统建设：面向不同业务场景的 Agent 和软硬件产品情况，设计可配置可复用可运营的产品平台功能，包括评测任务管理、数据集管理、Rubrics 标签体系、评估器配置、人评/机评协同等功能，推动评测方法沉淀为标准化产品能力

5.优化产品迭代：将模型维度拆解为用户可感知的体验维度（对话理解深度、记忆连贯性、多轮推理准确性、多模态识别精度、端侧推理速度）、Harness维度（深入理解Agent Harness框架的核心机制，比如工具调用策略、ReAct循环、上下文管理、记忆加载策略、多Agent路由与编排、端云协同等）、同时负责业务的体验指标设计（将模型准确率、推理延迟、工具调用成功率、ReAct循环轮次等技术指标映射为用户任务完成率、交互顺畅度感知、等待容忍度等体验指标，确保模型选型和Harness配置决策有用户体验数据支撑）。

## 任职要求

1.计算机、人工智能、统计学、软件工程或相关专业，本科及以上学历，2 年 Agent 评测或 Agent 策略产品工作经验以上优先；

2.对当前主流AI模型生态有系统认知、对云端模型的能力边界和迭代趋势和端侧模型的部署约束和性能特征，多模态模型（视觉/语音）在硬件场景的适用性有了解；

3.对Harness有认知理解，了解Agent Harness框架的核心架构（如工具调用机制、ReAct循环设计、Context窗口、Momery策略、多Agent协作与路由模式，了解至少一个主流Harness框架的实际运作方式；

4.有Agent产品、效果策略、模型评测或复杂业务系统经验，能够独立负责从需求分析到效果验证的完整项目。

5.关注业界前沿 AI 模型和产品发展，可以根据前沿评测方法发展转化为内部评测实践，并且能够熟练借助 AI 工具进行快速验证，具备 Vibe coding 或自动化流程搭建能力，支持方案快速验证与落地迭代。
