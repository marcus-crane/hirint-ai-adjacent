## 职位描述

岗位定位：负责公司企业信息化战略、企业应用体系及跨系统信息协同建设，打通 CRM、ERP、财务、人力、OA 等系统，为每位员工及其 AI Agent 构建完整、可信、可操作的工作上下文；不承担算力、训练、推理、模型数据及评测平台建设。

岗位职责：

1. 战略与架构规划：制定企业信息化规划和企业架构，明确系统优先级、自研与采购边界及生命周期管理机制。

2. 核心系统建设：统筹 CRM、ERP、财务、人力、OA 等系统的选型、实施、集成、运营和持续优化。

3. 流程与信息治理：推动端到端流程线上化与自动化，建立主数据、业务对象、信息标准和跨系统协同机制。

4. AI 原生能力建设：建设面向 Agent 的企业信息与业务动作工具，支持信息查询、上下文构建、建议和授权操作。

5. 服务运营与体验：建立需求管理、服务台、发布变更、故障复盘和用户反馈闭环。

6. 团队与结果管理：组建企业信息化团队，对系统采用率、信息质量、员工体验及业务价值负责。

## 任职要求

任职要求：

1. 学历与经验：本科及以上学历，相关专业；8 年以上企业信息化或数字化转型经验，3 年以上团队或大型项目管理经验。

2. 系统建设经验：具备 ERP、CRM、财务、人力、OA 等系统从规划、选型、实施到运营优化的完整实践。

3. 架构与治理能力：熟悉企业架构、主数据、API / 事件集成、流程引擎和企业应用服务运营。

4. 业务推动能力：具备优秀的业务洞察、高层沟通、跨部门协同和变革推动能力。

5. AI Agent 理解：理解 AI Agent 的上下文获取、工具调用和企业流程落地。

6. 加分项：有成长型科技公司信息化从 0 到 1、多系统整合或 AI Agent 接入企业应用的实战经验；熟悉 SAP、Oracle、用友、金蝶、Salesforce、飞书等主流企业软件；持有 TOGAF、PMP、ITIL、CISA 等认证。
