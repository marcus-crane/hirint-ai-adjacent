## 职位描述

作为企业信息化建设的研发人员，负责公司内部业务系统、流程平台和集成能力的设计、开发、上线与持续运营。将销售、交付、财务、人力、采购、法务等跨部门流程沉淀为稳定、易用、可审计的平台能力，并为员工及 AI Agent 提供标准化的信息与业务动作接口。

岗位职责

企业应用研发：参与 CRM、ERP、财务、人力、OA、采购、合同、项目管理等系统的自研、扩展开发与持续迭代，独立承担需求分析、技术设计、编码、测试、发布和运行维护。

流程平台建设：将审批、采购、合同、预算、项目交付、员工服务等业务流程线上化和自动化，建设表单、流程引擎、规则配置、消息通知、任务中心和运营看板等通用能力。

系统集成与身份权限：通过 API、Webhook、事件总线或集成平台打通企业应用，建设统一身份、单点登录、组织同步、RBAC、审计日志和异常补偿机制，保障跨系统数据一致性与链路可追踪。

业务数据与主数据落地：围绕组织、员工、客户、项目、合同、供应商和预算等核心对象，落实数据模型、主数据标准、校验规则、同步任务和质量监控，减少重复录入与信息孤岛。

AI Agent 工具化：将企业信息查询和业务动作封装为权限受控、可审计的标准 API 或 Agent 工具，支持 Agent 获取工作上下文、发起流程、更新业务对象和反馈执行结果。

稳定性与用户体验：完善自动化测试、监控告警、发布回滚、故障排查和用户反馈闭环，对所负责系统的可用性、数据正确性、交付质量和员工使用体验负责。

## 任职要求

本科及以上学历，计算机、软件工程、信息系统等相关专业优先；3 年及以上企业应用、业务中台、内部平台或复杂业务系统研发经验。

熟练掌握 Java、Go、Python、TypeScript 中至少一种后端技术栈，熟悉 React、Vue 等主流前端框架，能够独立交付端到端业务功能。

熟悉 REST API、Webhook、消息队列、定时任务和第三方系统集成，理解 OAuth 2.0、OIDC、SSO、RBAC、幂等、重试及数据一致性等机制。

熟悉 MySQL、PostgreSQL 等关系型数据库及 Redis 等常用组件，具备良好的领域建模、接口设计、测试、可观测性和安全意识。

能够深入业务现场，将跨部门需求抽象为清晰的流程、数据模型和系统能力，并与业务负责人、产品、实施顾问及外部供应商推动交付闭环。

理解大模型、AI Agent、工具调用和知识检索的基本原理，能够使用 AI 辅助研发工具提升需求分析、编码、测试和运维效率。

加分项：

有飞书开放平台、企业微信、钉钉、Salesforce、SAP、Oracle、用友、金蝶等企业系统的开发或集成经验；熟悉工作流、BPM、低代码、RPA、iPaaS、主数据管理或数据治理；有 Agent 工具、MCP Server、企业知识库或权限审计能力的落地经验。
