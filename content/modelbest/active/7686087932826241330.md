## 职位描述

负责公司内部业务系统的设计、开发、上线与持续运营，将销售、交付、财务、人力、采购、法务等跨部门流程沉淀为稳定、易用、可审计的平台能力；同时建设 AI-native 的 Agent Harness 层——把企业信息查询与业务动作封装为受控工具，把上下文、执行链路、失败兜底与效果评测做成平台能力。

岗位职责

1. 企业应用研发：参与 CRM、ERP、财务、人力、OA、采购、合同法务等系统的自研、扩展与迭代，独立承担需求分析、技术设计、编码、测试、发布与运行维护；能把 AI 能力原生嵌入业务流程。

2. 系统集成与身份权限：通过 API、Webhook、事件总线或集成平台打通企业应用，建设统一身份、RBAC、审计日志与异常补偿，保障跨系统数据一致性与链路可追踪。

3. 数据与主数据落地：围绕组织、员工、客户、项目、合同、供应商与预算等核心对象，落实数据模型、主数据标准、校验规则、同步任务与质量监控，减少重复录入与信息孤岛。

4. Agent 工具层：把企业信息查询与业务动作封装为权限受控、幂等、可审计的标准 API 或 Agent 工具（含 MCP Server）；设计工具契约——命名、描述、参数 schema、错误语义、幂等键、权限边界，并建设工具发现与路由，让 Agent 稳定完成"查—办—反馈"闭环。

5. Agent Harness 工程化：建设 Agent 运行时与工程体系——上下文组装与裁剪、多步执行与终止条件、失败重试与降级兜底、会话与记忆、全链路 trace 与 token 成本、评测集与回归门禁；以评测数据驱动工具描述与 Prompt 迭代，而不是靠单次对话调优。

6. 稳定性与体验：完善自动化测试、监控告警、发布回滚、故障排查与用户反馈闭环，对所负责系统的可用性、数据正确性与交付质量负责。

## 任职要求

1. 本科及以上，计算机、软件工程、信息系统等相关专业优先；3 年及以上企业应用、业务中台、内部平台或复杂业务系统研发经验。

2. 熟练掌握 Java、Go、Python、TypeScript 中至少一种后端技术栈，熟悉 React、Vue 等主流前端框架，能独立交付端到端业务功能。

3. 熟悉 REST API、Webhook、消息队列、定时任务与第三方系统集成；理解 OAuth 2.0、OIDC、SSO、RBAC、幂等、重试与数据一致性；熟悉 MySQL、PostgreSQL 及 Redis，具备良好的领域建模、接口设计、测试、可观测性与安全意识。

4. 能深入业务现场，把跨部门需求抽象为清晰的流程、数据模型与系统能力，并与业务负责人、产品、实施顾问及外部供应商推动交付闭环。

5. 大模型应用工程：熟悉 Prompt 与上下文工程、Function Calling 与工具调用协议、RAG 检索与重排以及 LLM 评测方法；有把大模型能力落入生产并持续稳定运行的经验，不止于调用 API 或完成 Demo。

6. Agent 工程实操：实际设计过 Agent 的工具契约与调用链路（工具定义、参数校验、超时重试、结果回灌），在生产中处理过工具误用、幻觉、死循环、超时与越权等真实问题；理解 Agent 的权限模型与审计要求，能清楚界定哪些业务动作可自动执行、哪些必须人工确认。

加分项

1. 企业系统生态：有飞书开放平台、企业微信、钉钉、Salesforce、SAP、Oracle、用友、金蝶等企业系统的开发、集成或运维经验。

2. Agent 平台能力：有 MCP Server 开发、Agent 平台或工具市场建设、多 Agent 编排经验。

3. 度量与安全：能对 Agent 的效果、成本、延迟做量化度量与持续优化——评测集与回归集、A/B 对比、token 成本治理、P95 延迟优化、失败归因；有 Agent 可观测性（trace / 成本看板）与安全实践（prompt 注入防护、工具白名单、权限沙箱、红队测试）的落地经验
