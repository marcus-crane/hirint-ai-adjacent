## 职位描述

1. 负责企业级 Agent Harness 框架内核设计与开发，实现 Agent 主循环（ReAct）、Agent 状态管理、Memory /Context 管理、Orchestrator 任务编排、Skill/Tools 插件体系、子 Agent spawn 派生、嵌套深度/并发数量限流等核心能力，保障框架可扩展、安全可控；

2. 对接权限和账号体系、安全策略与风控审计组件、沙箱机制、对象存储、数据库、消息队列、遥测/链路追踪组件，提供灵活、可靠的 Agent 部署能力；

3. 负责框架对外SDK、插件规范、API设计，支撑合作伙伴快速接入，编写开发者文档、示例，配合行业应用团队完成落地、联调与问题排查。

4. 跟进Agent领域技术演进，调研前沿多智能体架构、评估新模型适配，持续优化框架稳定性、token成本、执行延迟；

5. 参与生产环境问题定位，负责框架版本迭代、灰度发布，保障企业客户业务的高可用。

## 任职要求

1. 本科及以上，计算机、软件工程相关专业，扎实的数据结构、操作系统、网络、分布式系统基础。

2. 熟悉至少一种主流Agent Harness/智能体框架（ClaudeCode、Codex、Pi、OpenCode、AgentScope 等），深刻理解Agent的技术演进路线，能拆解框架底层原理。

3. 熟悉Agent核心技术：ReAct 推理循环、任务规划Orchestrator、Tool/Skill工具调用、多Agent协同、Memory/上下文窗口管理、状态持久化、子Agent派生与生命周期管理。

4. 熟悉云原生体系，了解K8s、容器、对象存储、数据库、链路追踪/遥测、安全沙箱等云组件，具备分布式后端开发经验。

5. 熟练掌握至少一门高级编程语言：Java / Go / TypeScript，具备良好工程能力、接口设计、并发编程经验。

6. 具备良好的架构拆解能力，能独立完成模块设计，擅长复杂系统问题排查，具备ToB/企业软件交付意识。

加分项

1. 参与过生产级Agent Harness/智能体平台的开发、落地或客户实施，有真实多Agent项目上线经验，做过Agent性能、成本、稳定性优化。

2. 有云原生私有化部署、大客户交付、伙伴SDK开放平台建设经验。

3. 开源社区知名Agent框架 Contributor。
