**【团队使命】**

DeepSeek 的运营团队，是模型能力与真实世界之间的接口：把前沿的模型能力，通过产品、开源代码与模型 API 服务，交付给用户、开发者与客户；同时把真实世界里的每一次使用、每一份反馈，完整带回研究、工程与产品设计的一线。运营的可靠性、及时性与专业性，直接决定了模型能力被理解、被信任、被使用的速度和广度。

我们在寻找那个在一线把事情做起来、对用户和开发者真诚、并已经把 AI 融入自己工作和生活的你。

**工作地点以北京为主，部分岗位或可选择杭州。**

**招聘方向【实习/全职】：技术运营、开发者关系、产品运营**

**投递时请注明希望加入的方向，我们会根据你的背景与意愿确认方向，也可能在面试过程中随着互相的了解调整定位。**

**【你是谁】**

1.你能把模糊的需求和混乱的局面，梳理成清楚的问题并亲手解决、落地到底；对自己负责的事情有交付到底的自觉，不让事情掉在地上。

2.这里没有只做协调、不沾业务的岗位：每个角色都要亲手解决真实问题。

3.你乐于研究用户和开发者真正怎么使用产品与模型：技术网站、开源社区、高质量技术群聊，都是你常去的地方；你愿意把复杂的事情讲清楚，让技术被更多人理解和用起来。

4.你更愿意用结果、数据和可复核的证据说话，而不是凭感觉和口头汇报。

5.你谦逊坦诚，愿意倾听不同意见，对自己的判断有坚持。

6.熟练使用 AI Agent 工具进行日常工作（文档、数据、调研、沟通、代码等），用 AI 放大自己的人均产出。

7.即便把大量执行交给 AI，你仍然亲自主导方向、判断质量；当 AI 给出有问题的结果时，你能够敏锐地发现并及时介入。

8.你习惯把重复性、流程性的事情沉淀为可复用的方法、模板与规范，让团队做得更快、更标准。

**【方向划分】**

**技术运营方向**

加入 DeepSeek 运营团队，面向 DeepSeek 的模型 API 客户与开源模型部署合作伙伴，承担技术对接的主力角色：让模型能力被可靠接入、稳定使用，让一线技术问题被快速解决，也让真实反馈被完整带回团队。

**岗位职责**

1.负责模型与 API 相关的技术对接：与 API 客户、合作伙伴的技术团队沟通，理解需求，给出可落地的接入与使用方案。

2.承担 API 及相关技术问题的一线响应与排查：结合日志、文档与工具定位问题，给出清晰结论，不让事情掉在地上，并及时同步进展与闭环。

3.快速掌握公司系统调度、业务规则等核心逻辑，在对接中独立完成问题判断与处理，避免工作断档。

4.把一线反馈转化为系统与产品的改进输入：异常、边界情况、性能问题等，整理成可复现、可执行的报告，反哺推理框架与产品团队。

5.沉淀对接与排查经验：文档、FAQ、案例、工具与流程，让团队的响应更快、更标准、可复用。

**岗位要求**

1.本科及以上学历，计算机相关专业背景。

2.具备一定的开发与代码理解能力：能够独立阅读代码与技术文档，完成基础的问题验证与排查。

3.学习能力强，能快速掌握公司系统调度、业务规则等核心逻辑。

4.对技术问题有耐心与责任感：能够独立对接、负责到底，沟通清楚、及时同步。

5.良好的中文沟通能力，能够面向客户与合作伙伴做清晰的技术表达。

**加分项**

1.AI / 大模型行业经验，熟悉大模型 API 的使用与接入。

2.熟悉 LLM 与 Agent 基本机制（API、上下文、工具调用等）。

3.有面向企业客户、合作伙伴的技术支持、解决方案或售前售后经验。

4.有开源基础设施或开发者工具的使用、排查经验。

5.能用英文与海外客户、合作方进行技术沟通。

6.其它超乎常人的与此工作相关的才能。

**开发者关系方向**

加入 DeepSeek 运营团队，面向全球开发者生态（DeepSeek Harness、模型 API、推理框架与开源模型），建设社区与沟通体系，让开发者实践和反馈持续反哺产品迭代，提升开发质量与速度。

**岗位职责**

1.建设和维护 DeepSeek 开发者社区，包括 GitHub、官方微信群、X、Discord 等用户社群，完善社区规则与协作机制。

2.与研发团队和运营同学合作，向社区准确传达产品方向、路线图和版本变化，完成相关内容在开发者社区中的传播。

3.发现、筛选和整理高质量的社区开源作品与真实使用案例，推动其在社区中传播。

4.收集、整理和提炼社区反馈，补充使用场景与必要的技术信息；协助研发团队分析和解决问题，并向社区同步进展与结果。

5.从开发者视角辅助研发团队评审官方文档和示例，参与文档与教程的撰写与维护，发现内容缺口、理解障碍及常见误区。

6.围绕推理框架、开源模型等方向组织开发者活动与内容，连接社区与相关团队。

**岗位要求**

1.本科及以上学历，计算机相关专业背景优先。

2.具备一定的软件开发经验，能够独立阅读代码和技术文档，并完成基础的问题验证和排查。

3.对开发者工具和开发者体验有较强感知，能够发现使用障碍，并将零散反馈整理成准确、清晰、可供开发团队采取行动的信息。

4.中英文均可作为工作语言，能够进行技术写作、社区沟通和公开表达。

5.熟悉 GitHub，有开源项目或社区协作经历。

6.对开源有持续热情，沟通真诚、克制且有耐心，认同通过技术价值、公开协作和长期信任建设开发者社区。

7.面对负面反馈与社区冲突，能保持真诚、克制与建设性，在用户、社区、产品与研发之间建立信任。

8.不要求必须具有 DevRel 职位经历。开发者、开源社区参与者、技术内容作者或其他相关背景均可。

**加分项**

1.深度使用或开发过 AI、LLM、Agent、开发者工具或开源基础设施。

2.有 DeepSeek Harness 插件开发经历，熟悉 DeepSeek Harness 的插件机制和开发流程。

3.有开源项目维护或核心贡献经验。

4.具有国际视野，能够理解不同文化背景开发者的沟通习惯；有面向全球受众的英文写作经验。

5.其它超乎常人的与此工作相关的才能。

**产品运营方向**

加入 DeepSeek 运营团队，面向 DeepSeek 的产品与广大用户，站在用户视角为最终用户体验负责：主动收集真实反馈、识别重要问题，并推动它们被真正解决。

**岗位职责**

1.热情主动贴近用户，想尽办法从各渠道（社群、访谈、问卷、工单、社交媒体等）收集用户反馈，深入了解用户遇到的问题与想法，而非被动处理。

2.建设与维护用户社群及反馈渠道，把零散信号整理成准确、清晰、可供产品与研发团队采取行动的信息；以用户为导向审视和改造现有运营流程（信息同步、异常响应、发布评估等），推动建立事前评估与事后跟进机制，并跟踪闭环。

3.建立运营与产品数据体系：定义与衡量“产品是否真的在更多场景、更深入地帮助到更多人”的指标，分析用户行为、使用场景与核心问题，为产品决策提供依据；与数据分析、研发团队协作完善用户相关监控与预警，主动发现并推动解决异常。

4.协调产品、研发、研究及相关团队资源，跟进项目进度与风险，推动从发现问题到落地解决的闭环。

5.配合产品发布与版本变化，面向用户完成清晰的传达、引导与帮助内容。

6.站在用户视角与产品、研发、模型团队沟通讨论，能够识别对用户真正重要的问题，并推动问题闭环解决。

**岗位要求**

1.本科及以上学历。

2.靠谱、负责，能够主动推进、及时同步并把事情做完。

3.喜欢做用户与社区相关的工作，愿意长期把琐碎但重要的事情做扎实。

4.对用户与产品有强感知力，能从碎片信息中识别真实需求与关键问题。

5.具备用户研究、数据分析和项目管理能力。

6.熟悉 AI 与 Agent 产品，对 AI 和模型产品有热情，是相关产品的高强度用户。

7.中文沟通能力优秀，能用英文进行书面沟通。

**加分项**

1.AI 行业从业经验、AI 相关产品运营经验。

2.能使用 Agent、SQL、Python 等工具提升工作效率。

3.有小团队综合项目推进经验。

4.深度参与过技术社群、用户社群或社区运营。

5.不要求背景完全对口，可以是把某一件真正热爱的事做到极致的经历。

6.其它超乎常人的与此工作相关的才能。
