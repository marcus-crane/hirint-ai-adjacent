加入 DeepSeek 产品团队，探索和定义下一代 AI 产品形态。

**【团队使命】**

每一次技术革命，最终都要通过产品抵达人们的生活。我们正在以研究、工程、产品相结合的方式，把 DeepSeek 的模型能力转化为有影响力的创新产品。

DeepSeek 产品团队负责公司全线产品，包括 DeepSeek Harness、Chat 网页端、移动端、开放平台等，以及将来发布的新产品。我们站在模型与世界之间，负责将最前沿的模型能力转化为融入亿万用户工作与生活的产品体验。

从一个按钮、一次对话，到全新的产品形态，你的每个决策都可能影响广大 DeepSeek 用户的使用习惯。你将与研究、工程和运营团队共同探索，做有影响力的创新 AI 产品，最大化给用户提供的价值总和。

**招聘方向【全职】**：用户产品经理方向、生态/增长产品经理方向、产品设计师方向

**用户产品经理方向（社招）**

**【主要职责】**

1.负责 DeepSeek 全线产品的产品规划，连接工程师、研究员、开源社区与广大用户，洞察用户需求，判断产品价值与优先级，制定并推进产品路线图。

2.理解判断用户的最真实需求，定义与衡量“AI 是否真的在更多场景下更深入的帮助到更多的人”的指标。

3.与用户和开发者保持直接交流，通过真实任务观察、用户访谈、社群反馈和行为数据，发现值得解决的问题，验证产品需求。

4.帮助产品落地，持续跟踪真实场景下的用户任务。推动产品创新和体验优化。

5.综合运用数据分析、用户反馈和定性观察，从真实用户需求和使用场景出发，定位并拆解产品问题，降低用户使用门槛，提升用户体验，最大化给用户提供的价值。

6.与模型训练团队的研究员深度沟通与合作，实现模型与产品的共同进化。

**【任职要求】**

1.2年以上产品经理从业经验，产品逻辑清晰。特别优秀的候选人可放宽年限。

2.知名高校本科学历及以上。

3.有产品经历或完整的从需求到落地的交付经验，AI / 对话 / Agent 类产品经验优先。

4.能够使用 vibe coding 写代码，不一定需要技术背景。

5.具备 UI/UX 设计素养。能够在 AI 辅助下完成产品原型图设计、UI设计等相关的产品设计工作。

6.是 Agent 产品的高强度用户，熟悉 Agent 产品的各种形态，对 Agent 有极大的热情，对模型行为有品味有判断力，对开发者体验及用户体验有强感知。深度使用过各种 Agent 产品，并将相关产品的使用融入到自己的工作和生活中。

7.理解 LLM 以及 Agent 基本机制及其技术原理，包括 LLM API、KV Cache、Agent Loop、Tool Use、Reasoning、Planning、Skills、MCP、Memory、Subagent、Multi-Agent 等相关知识。对 Prompt Engineering、Context Engineering、Harness Engineering 等课题有第一手实践。

8.能够设计系统性的收集数据的方法（包括问卷、访谈、A/B测试、灰度测试等），并使用统计学的工具严谨科学的分析数据。对此有系统性的思考和实践。

9.对产品细节有强感知力，对异常分支、边界条件和失败场景有敏锐的嗅觉。

10.优秀的中文沟通能力。能用英文与开源社区、用户社群书面沟通。

**【加分项】**

1.AI 行业从业经验、AI 相关产品经验。

2.作为小团队中的产品经理主导产品路线的经验。

3.与研究员深度协作的经验。

4.其它超乎常人的与此工作相关的才能。

**生态/增长产品经理方向（社招）**

**【主要职责】**

1.围绕用户的高价值任务，规划 DeepSeek 全线产品的插件与开发者生态，把生态路线图与产品路线图、模型能力演进对齐，敏锐判断需求的优先级。

2.设计插件与开发者生态的收益和激励机制，帮助有价值的能力获得相应的激励反馈；验证机制对用户体验和优质供给的实际影响，并把机制沉淀为可持续迭代的平台能力。

3.负责 DeepSeek Harness 的生态与增长方案，推动方案从定义、评估、上线到复盘落地。

4.建立闭环的数据体系，综合运用用户行为数据、成本与收益数据、用户反馈与定性观察，定位增长瓶颈与流失环节，设计并验证增长实验，用统计学方法严谨判断结果是否可信，形成可复盘的结论。

5.维护开发者与用户社群，从海量用户和开发者中提取反馈、识别信号，反哺产品运营的策略迭代。

**【任职要求】**

1.5 年以上产品经理从业经验，产品逻辑清晰。特别优秀的候选人可放宽年限。

2.知名高校本科学历及以上。

3.有生态 / 增长 / 商业化相关经验，具备完整经历从定义、设计到商业结果落地的方案经验；有开发者平台、应用市场、插件生态、SaaS 集成或 AI 工具生态经验者优先。

4.具备扎实的数据分析与商业建模能力，能独立使用 SQL、表格或代码分析用户行为、成本与收益，设计实验并判断结果是否可信。

5.深刻理解大模型与 Agent 的基本工作方式、用量与成本特征（LLM API、Token 计费、Agent Loop、Tool Use、MCP、Memory 等），能够借助 AI 工具完成研究、分析和原型验证。

6.是 AI 产品的高强度用户，深度使用过各种 Agent 产品，对开发者体验、用户体验和模型行为有强感知，能将相关产品融入自己的工作和生活。

7.具备良好的产品判断力与商业敏感度，能从真实用户任务出发判断需求的必要性、优先级与成功标准，在用户价值、技术可行性与商业目标之间做清晰权衡。

8.优秀的中文沟通能力，能用英文与开发者社区、用户社群书面沟通。

**【加分项】**

1.有从零到一建立商业机制、平台生态、创作者收益体系的相关经验，或有生态从零到一冷启动经验。

2.有开发者平台、应用市场、插件生态、SaaS 集成或 AI 工具生态的产品与合作经验。

3.与研究员 / 模型训练团队深度协作的经验。

4.深度参与开源社区或维护开源社区关系的经验。

5.其它超乎常人的与此工作相关的才能。
