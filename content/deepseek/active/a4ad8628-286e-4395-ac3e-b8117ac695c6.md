**【团队使命】**

Code 定义了 Agent 的能力边界，是 Agent 和物理世界交互的纽带。理解需求、设计方案、实现、验证，在完整的问题解决过程中，每一步都要求精确可运行。Code 能力是模型在这一过程中从“能分析”到“能执行”的关键要素，而模型在真实复杂场景中解决工程问题的能力则是通用智能最务实的度量标准。我们要做的，是通过高质量的训练环境与精准评估体系，系统性地推高这一能力的上限，直到模型真正能独立驾驭复杂软件工程的开发，那将会是我们可以预见的 AGI 临界点之一。

这是一个 AI 时代的新型工程师岗位。你不需要写业务代码、交付产品，而是用独到的经验和品味，去发现问题、定义评测标准、改进训练数据，教大模型更好地写代码。

**招聘方向【实习/全职】**：**前端专项、移动端专项、后端专项、Web 3D 与渲染专项、游戏开发专项、网络安全专项**

**【工作职责】**

1.构建强化学习环境：将真实的代码工程、网络安全或科研场景转化为可训练的 RL 环境，设计合理的奖励信号，与研究员紧密合作探索不同环境设计对模型 Agent 能力的影响。

2.评估模型的 Agent 能力：在个人擅长的方向上设计高质量评测任务，量化模型在复杂真实场景中的表现。

3.补全模型的能力短板：基于真实用户数据与反馈，定位模型当前的能力缺陷，针对性构建训练环境与数据，推动模型在弱项上持续进步。

**【岗位通用要求**】

1.AI编程经验：具备 Claude Code、Codex 等一线 AI 编程工具的重度使用经验。对大模型有一定基础认知。

2.自驱力：能独立发现、明确定义并推动解决问题。

**【岗位细分要求】**

**前端：**3年以上前端一线开发经验。有一个你能称之为“主场”的技术生态（React/Vue/Node 全栈/小程序/Electron/数据可视化（ECharts 等）均可），投递时请注明。我们不要求广度，但要求你在主场生态里有足够深的理解，满足下列要求中至少一项：

1.能解释你“主场生态”框架的核心机制（渲染与更新、响应式原理、构建产物），并识别常见误用。

2.长期负责复杂业务模块：能讲清楚状态设计、组件边界、异常与边界情况的取舍依据。

3.在你“主场生态”下主导或深度参与过技术选型、架构设计。

4.有公开可查的开源贡献或技术输出。

5.其他能证明你有真正深度的经历。

**移动端：**3年以上移动端一线开发经验。有一个你能称之为“主场”的技术域（Android 原生、iOS 原生、Flutter、React Native 均可），投递时请注明；跨端框架背景需对至少一端的原生层有真实排障经验。我们不要求广度，但要求你在主场技术域里有足够深的理解，满足下列要求中至少一项：

1.能讲清楚你“主场技术域”的核心机制（应用生命周期与线程模型、构建与打包链路、跨端框架的原生桥接原理等），并识别常见误用。

2.长期负责复杂移动业务模块或线上应用质量：多机型多系统版本兼容、崩溃与 ANR 治理、性能优化。

3.在你“主场技术域”下主导或深度参与过技术选型、架构设计。

4.有独立开发并上架的 App、公开可查的开源贡献或技术输出。

5.其他能证明你有真正深度的经历。

**后端**：3年以上后端一线开发经验。有一个你能称之为“主场”的技术生态（Java、Python、Go、PHP、Rust、C#/.NET 均可），投递时请注明。我们不要求广度，但要求你在主场生态里有足够深的理解，满足下列要求中至少一项：

1.能讲清楚你“主场生态”的核心机制——框架层（请求生命周期、依赖注入/中间件模型、ORM 工作方式）或语言运行时层（并发调度、GC、内存模型），并识别常见误用。

3.在你“主场生态”下主导或深度参与过技术选型、架构设计（微服务拆分、接口契约、分库分表取舍）。

4.有公开可查的开源贡献或技术输出。

5.其他能证明你有真正深度的经历。

**Web 3D 与渲染**：3年以上Web 3D 或图形渲染一线开发经验。有一个你能称之为“主场”的技术域——引擎与框架层（Three.js/Babylon.js 深度使用）、图形 API 层（WebGL/WebGPU）、着色器编程（GLSL/WGSL）、大规模场景与点云渲染均可。投递时请注明主场，附作品或 Demo 链接者优先处理。我们不要求广度，但要求你在主场技术域里有足够深的理解，满足下列要求中至少一项：

1.熟悉实时渲染管线关键环节（顶点处理、光栅化、片元着色、深度测试与混合），并据此定位过真实项目中的渲染错误或画面异常。

2.长期负责 3D 场景或大规模数据渲染模块，能基于 Profiling 定位 CPU/GPU 瓶颈，做过实打实的性能优化（DrawCall 合批、实例化渲染、LOD、纹理与几何压缩等）。

3.在主场技术域下主导或深度参与过渲染架构设计、3D 技术选型，能讲清楚当时的约束与取舍。

4.有可展示的 3D 作品：线上 Demo、Shadertoy 着色器作品、个人项目或效果视频均可。

5.其他能证明你有真正深度的经历。

2.长期负责核心玩法系统（战斗/技能/网络同步）或性能优化专项（DrawCall/合批、GC 与内存池、真机调优）。

3.在你“主场引擎"下主导或深度参与过技术选型、框架搭建或工具链建设（编辑器扩展/插件、构建自动化管线、热更新方案 xLua/HybridCLR 等）。

5.其他能证明你有真正深度的经历。
