**【团队使命】**

DSec 是我们为 Agent 量身定制的弹性计算平台，托管着成千上万个沙箱环境，正有序推进着下一代模型的迭代。为了增加可靠性和效率，DSec 需要修改整个系统栈：从操作系统到虚拟机，再到各级网络和存储，一直上到应用层调度和管控面服务。

在这里，理解需求是一切的起点——很多事情前人没有做过，没有现成的答案可抄。你将与顶级的开发者和研究员们一起讨论、了解、推进、满足用户最根本的需求，并用尽可能优雅的方式把需求融入到不断迭代的 Agent 弹性计算平台上，使其能与前沿模型共同演进。

同时，也需要解决小到自旋锁，大到跨区域数据一致性的各类系统问题，并应对无监管全自动运行 Agent 带来的安全挑战——过往对负载、隔离、用量、安全的假设不再成立，需要另辟蹊径。

**【岗位类别】：实习/全职**

**DSec 下设平台开发和底层系统两个方向，投递时不限方向，我们会根据你的背景与意愿确定具体方向，也可能在面试过程中随着互相的了解调整定位。**

**【方向划分】**

**平台开发和维护**

在这个方向，理解需求是一切的起点。你将与顶级的开发者和研究员们一起讨论、了解、推进、满足用户最根本的需求，并用尽可能优雅的方式把需求融入到不断迭代的 Agent 平台上，使其能与前沿模型共同演进。很多事情前人没有做过，没有现成的答案可抄——你需要在需求还只是模糊想法时就把它捕捉出来，亲手把它变成稳定、好用的平台能力。

**岗位职责**

1.需求理解与落地：深入研究员与开发者一线场景，主动识别真实需求，把尚未被满足、前人尚未做过的需求抽象为清晰的方案，并推动从定义到上线的全过程。

2.接口与接入：设计与开发各类 API、SDK 与管控面服务，把复杂的底层系统能力抽象为稳定、清晰、易用、可演进的接口，服务于不同平台和用户。

3.节点管理：开发节点的注册、状态维护、上下线与生命周期管理，保障大规模节点池的稳定运转。

4.数据采集链路：建设 Log / trajectory / metrics 的采集、上报与流转能力，为调度、计费、可观测和模型训练提供可靠的数据基础。

5.稳定性建设：以生产环境为第一现场，构建覆盖服务与链路的可观测能力，主动发现、定位并根治影响平台稳定性的问题，确保前人踩过的坑不再重演。

**岗位要求**

基本背景：

1.计算机或其他相关专业，本科及以上学历。

2.扎实的编程与工程能力（Rust / C++ / Python 等均可），以及对简洁明了、可维护代码的基本美学素养。

3.能有效捕捉用户的需求，把模糊的想法抽象成清晰的方案，并将未来需求有序地融合到大型系统的开发进度中。

4.有良好的沟通能力和团队协作能力。

满足下列任意一条即可：

1.开发或长期维护过面向用户的 API、SDK 或服务端系统，对接口设计、数据建模与版本演进有实际理解。

2.深入了解大规模分布式系统的组织方式，清楚架构瓶颈产生的原因和与之相关的 trade-off。

3.熟练运用压测和可观测性工具，具备在生产环境中定位复杂问题、直击根因的能力。

4.理解可靠系统的设计，对系统稳定性有强烈的责任心，并且有意识地确保前人的事故不会在当下重演。

5.有过大型系统的自动化运维、应急响应经验，或建设过 Log / metrics / trace 等数据采集与可观测链路。

**加分项**

下面这些每一条都可以加分，但其实没有也没关系：

1.有过大型高可用、高并发系统的开发经验。

2.设计或维护过大规模 SDK、客户端库或公共接口。

3.从 0 到 1 开发部署过需要水平扩展才能撑住的数据密集型应用。

4.与研究员深度协作的经验或科研经验也很好。

**底层调优和攻坚**

**岗位职责**

1.操作系统：深入内核与用户态，围绕进程调度、内存管理、文件系统、系统调用等操作系统的方方面面进行开发、调优与问题攻坚。

2.虚拟化/容器化：加固隔离、缩小逃逸面、降低沙箱资源占用量；适配用户多种多样的需求以支持更高效的模型训练。

3.存储：设计专供沙箱的块设备和共享卷方案，以及相关的底层存储软件。

4.网络：部署超大规模虚拟网络，允许 Agent 在不离开物理边界的前提下互相通信。

5.底层系统软件：开发与优化贴近硬件与内核的各类系统组件与工具链，把关键路径的性能压榨到极限。

**岗位要求**

基本背景：

1.计算机或其他相关专业，本科及以上学历。

2.扎实的系统编程能力（倾向 Rust / C / Python），以及对简洁明了、可维护代码的基本美学素养。

3.对底层机制有着深厚的好奇心，同时热衷于搞懂事物的基本运行原理。

4.有良好的中文沟通能力和团队协作能力。

满足下列任意一条即可：

1.深入了解计算机体系结构，例如能够清晰描述一次文件写入从调用开始到落盘的全过程以及潜在瓶颈。

2.深入了解 Linux 操作系统的运行机制，熟悉内核或用户态某一子系统（调度、内存、文件系统、网络栈等）的实现原理。

3.熟练运用 Linux 的压测和可观测性工具分析、定位涉及多个层级的复杂系统问题。

**加分项**

下面这些每一条都可以加分，但其实没有也没关系：

1.在 OSDI、SOSP、EuroSys、NSDI、ATC 等系统顶会发表过 OS、存储、网络、容器或虚拟化方向论文。

2.有过活跃的开源项目贡献，或者有拿得出手的个人系统项目。

3.设计或部署过大规模 VPC 网络、存储系统、沙箱集群。

4.曾经把某些操作系统组件的性能压榨到 SOTA，或者干脆直接压到硬件极限。

**你会得到**

1.你来决定新时代 Agent 基础设施的形态，以及 Agent 们的生活环境。

2.可以和顶尖的系统工程师和模型研究员一起工作。

3.你的工作直接决定了 Agent 模型训练的多样性和效率。
