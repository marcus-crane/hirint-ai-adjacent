**【关于这个岗位】**

LLM 的成功是 AI 基础设施的成功。在训练 / 推理框架、算子和编译器、文件系统这些「单点极致」之外，还需要有人把整个系统栈串起来。我们不设限于具体的技术栈或语言 —— 我们在寻找的是那种对计算机系统（从机房里的铁疙瘩到内核再到上层框架）有广泛好奇心、动手能力极强的系统工程师（Hacker / Geek）：各种领域都懂一点、在不少领域懂很多，遇到问题不挑活儿，撸起袖子就能解决。

**【工作职责】**

1.深入研发工程链路的各个层面 —— 大型集群管理、运行时、文件系统、构建与打包分发、环境与镜像更新维护、即时编译（JIT）和 CI/CD 等 —— 发现并解决影响团队迭代效率和稳定性的各类问题。

2.积极搭建和维护各类自动化工具和工程基础设施，让研究和工程团队跑得更快、更稳。

3.作为团队的粘合层，与训练 / 推理框架、算子和编译器等团队协作，定位跨层疑难杂症，推动系统性改进落地。

**【基本要求】**

1.具备扎实的编程能力、优秀的系统设计能力和代码品味，有强烈的责任心与自驱力。

2.不限定编程语言 —— Python、C/C++、Rust、Go 或其他皆可，重要的是对编程语言和系统原理的深入理解和快速上手新技术的能力。

3.对工程链路中的杂事有热情且有积累：文件系统、打包与分发、编译与 JIT、运行时优化、自动化工具建设等，涉猎越广越好。

4.有跨层问题排查能力：能从表象深入到运行时、系统库乃至硬件层面定位根因。

5.在开源社区上保持活跃：请在简历中附上 GitHub 主页，我们看重的不是 star 数，而是 commit 记录 —— 无论是对大型开源项目的贡献、长期维护的个人项目，还是热心帮人排查 issue 的历史，都是极好的证明。

**【加分项】**

1.在知名开源项目（如 CPython / PyTorch / LLVM / Linux 内核等）有实质性贡献，或长期维护有影响力的个人开源项目。

2.有多硬件后端工程适配或大型项目 CI 体系建设经验。

3.动手能力强、见到问题就想修：喜欢用自动化消灭重复劳动；有 homelab、硬件改造、3D 打印、芯片逆向、安全攻防、古法配环境等折腾经验。

4.具有开阔的架构视野，能针对系统不足主动提出改进方案并推动实现。
