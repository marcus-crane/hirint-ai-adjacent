**【团队使命】**

**以算法与系统协同优化的全局视角，贯通数据、算法、训练、评测和系统链路，解决大模型研发过程中影响模型效果、训练效率与迭代速度的关键问题，推动研究方案高质量、高效率地落地。**

**【岗位类别】：**实习/全职

**【岗位定位】**

**这是一个靠近研究员的大模型系统工程岗位，需具备扎实的系统设计与开发能力，以及模型研发背景和研究理解能力。**

**你将与研究员和系统工程师紧密协作，承接模型研究方案，分解并解决模型迭代过程中的工程复杂度，推动研究方案落地和相关系统的持续优化。**

**【岗位职责】**

1.与预训练、后训练研究员紧密协作，理解模型、数据和训练方法的设计目标，把复杂工程问题分解并做成长期稳定、可复用的系统能力。

2.围绕 Agent 能力迭代，拆解任务设计、训练数据、模型行为、工具调用及 Reward／Verifier 等环节的问题；与研究员及相关工程团队协作，将问题定位和评测结论转化为可执行的模型与系统改进方案并推动工程实现。

3.建设和完善数据产出和管理、 Agent 训练与评测流程，与研究员协作验证模型能力变化，推动数据、训练方法和评测体系持续迭代。

**【岗位要求】**

1.具备大模型训练的实际经验，理解预训练或后训练的基本方法，能够参与模型与 Agent 迭代。

2.具备扎实的深度学习基础和编程能力，熟悉 系统设计与开发，能够独立完成算法的工程实现与系统优化。

3.对 Agent 的运行机制及模型评测有实践经验或深入理解，能够围绕任务表现分析问题，并推动模型与系统层面的改进。

4.具备较强的问题分析与解决能力，能够与研究员和工程师协作，推动模型迭代中的复杂问题落地解决。

5.具备良好的沟通协作能力和工程意识，关注系统的正确性、可靠性、可维护性以及对于模型迭代的实际效果。

**【加分项】**

1.有从零搭建或显著优化大模型训练流程的经验。

2.有大规模复杂系统的架构设计和工程开发经验。

3.在相关领域发表过高质量论文、参与过有影响力的开源项目，或在高水平竞赛中取得优异成绩。
