**【团队使命】**

文字延伸了记忆，印刷术延伸了知识传播，互联网延伸了感官与连接。我们相信，Agent 将成为对人本身的又一次「延伸」—— 以工具触达数字世界的疆域，在屏幕方寸之间运筹帷幄，让人与 AI 的关系从对话走向托付，从而真正解放人的行动力与创造力，构建「人机共生」的新文明。

**招聘方向【实习/全职】：**办公 Agent、Computer Use Agent

**【工作职责】**

1.**识别 Agent 能力短板**：定义并推进大模型在不同场景的 Agent 能力，持续识别 Agent 在真实环境中的能力瓶颈，驱动模型迭代优化。

2.**构建多维度评测体系**：围绕 Agent 自主任务执行的全流程，设计并落地多维度自动化评测与归因体系，建立能真正区分“能用”与“好用”的评测标准，覆盖端到端任务完成度与过程行为质量，打通人工评估与自动化评估，精准定位模型短板。

3.**建设高质量数据**：针对各类 Agent 任务，定义产物理想态，设计并迭代高质量、高多样性的数据生产管线，系统性提升 Agent 交付产物的准确性、完整性和用户体验。

**【岗位通用要求】**

1.拥有主流 Agent 产品的深度使用经验，熟悉当前主流 Agent 架构与产品形态，能够敏锐感知模型能力差异，定位背后的数据需求与问题。

2.对模型产出有清晰的判断标准与内在追求，对“好”有明确的界定能力，能精准辨识输出质量的层级差异，并能将主观感受拆解为可传达、可检验的具体维度。

3.理解模型训练与优化的基本原理，熟悉模型评测方法，精通 Prompt Engineering 和 Vibe Coding；动手能力强，有丰富的使用自动化手段解决真实问题的经验。

4.对 AI Agent 领域有真实的热情，持续关注前沿进展，对 AI 能力的边界保持探索欲与想象力。相信 Agent 终将深度改变人机协作的方式，让工作更高效，让创造更自由。

**【岗位细分要求】**

**办公 Agent**

负责工作场景下的 Agent 能力建设，核心聚焦文档、PPT、电子表格等交付物的理解与生成，同时持续拓展新模态新场景，探索面向未来的工作产出和协作方式。希望候选人满足下列至少一项要求：

1.对工作任务中的知识创造、信息表达与设计美学有深入理解和独到追求，热衷于探索如何将复杂的信息与想法转化为清晰、优雅、富有洞察力的作品。

2.在以下至少一个方向上有深度实践经验：专业工作产出（PPT、研究报告、技术文档、数据分析/建模/可视化 etc.）、创意内容（脚本、策划方案、音视频、视觉设计 etc.）或其他形式工作成果，不限于传统办公软件与文件形态。

3.熟悉 Agent 后训练数据生产与评测流程，有将具体场景诉求转化为可落地数据方案的实操经验。

**Computer Use Agent (CUA)**

负责 CUA 的模型能力优化，定义 CUA 的评估标准和典型场景，持续提升 Agent 在复杂、真实的电脑操作环境下产出高质量交付物的能力。希望候选人满足下列至少一项要求：

1.深度使用过 CUA 产品，或对 CUA 的能力边界、适用场景有深刻理解和强烈兴趣。

2.对某类场景的常用软件或工作流有深入了解和使用经验，包括但不限于：设计/建模/视频制作等专业场景、游戏/音乐/旅游出行等生活场景，能敏锐感知 CUA 在该场景下的能力短板，并据此制定有区分度的评估标准和优化方案。

3.曾参与 Computer Use / Browser Use Agent 的测评，有相关数据生产经验更佳。
