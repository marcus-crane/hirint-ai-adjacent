加入 DeepSeek Harness 团队，探索 Agent Harness 方向的未知前沿。

**【团队使命】**

Model + Harness = Agent

我们正在以研究、工程、产品相结合的方式，把 DeepSeek 的模型能力转化为前沿的科研突破与领先的 Agent 产品。

你将加入 Harness 团队，探索 Harness 领域的研究、工程与产品前沿，定义 DeepSeek 对 Harness 的理解。

**招聘方向**：**研究员**、**研发工程师**、**开发者关系**、**产品经理**、**项目经理**、**产品运营**。
