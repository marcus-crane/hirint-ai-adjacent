**【团队使命】**

技术始终为人而生：研究拓展可能，工程与产品实现可能，运营则让可能抵达每一个人。

我们是 DeepSeek 与用户之间的全部触点：连接每一位普通用户、开发者与商业伙伴，不断拓展触达的广度，深化连接的深度；把真实的世界带回产品，也把产品的能力与诚意带给用户。

你将站在离用户最近的地方，与研究、工程和产品团队共同探索，让每一次连接与改变，都通向人类的自主、创造与幸福。

**招聘方向【全职/实习】**：**产品运营方向、开发者关系方向**

**产品运营方向**

**【主要职责】**

1.从 0 到 1 建设并维护用户及开源社区，完善社区规则、协作机制和贡献者体系。

2.对接商业伙伴，理解需求，推动合适需求转化为运营或产品方案并落地。

3.通过社群、访谈、问卷等方式收集用户反馈，识别真实需求并推动产品改进。

4.建立运营和产品数据体系，分析用户行为、使用场景及核心问题，为产品决策提供依据。

5.协调产品、研发、研究及社区资源，管理项目进度和风险，确保项目落地闭环。

**【任职要求】**

1.知名高校本科学历及以上。

2.靠谱、负责，能够主动推进、及时同步并把事情做完。

3.有开源社区运营或深度参与经验，熟悉 GitHub 等协作方式。

4.具备用户研究、数据分析和项目管理能力。

5.熟悉 Agent 产品，对 AI 和开发者工具有热情。

6.中文沟通能力优秀，能够使用英文与开源社区书面沟通。

**【加分项】**

1.AI行业从业经验、AI相关运营经验。

2.深度参与开源社区或维护开源社区关系的经验。

3.能使用 Agent 等工具提升工作效率。

4.其它超乎常人的与此工作相关的才能。

**开发者关系方向**

**【主要职责】**

1.建设和维护 DeepSeek Harness 全球开发者社区，包括 GitHub、用户社群及线上或线下活动。

2.与开发团队和运营同学合作，向社区准确传达产品方向、roadmap 和版本变化，完成版本解读及相关内容传播。

3.发现、筛选和整理高质量的社区 Demo 与真实使用案例，并推动其在社区中传播。

4.收集、整理和提炼社区反馈，补充使用场景和必要的技术信息；协助开发团队分析和解决问题，并向社区同步进展与结果。

5.从开发者视角辅助开发团队评审官方文档和示例，发现内容缺口、理解障碍及常见误区。

**【任职要求】**

1.具备一定的软件开发经验，能够独立使用 DeepSeek Harness、阅读代码和技术文档，并完成基础的问题验证和排查。

2.对开发者工具和开发者体验有较强感知，能够发现使用障碍，并将零散反馈整理成准确、清晰、可供开发团队采取行动的信息。

3.中英文均可作为工作语言，能够进行技术写作、社区沟通和公开表达。

4.熟悉 GitHub，有开源项目或社区协作经历。

5.对开源有持续热情，沟通真诚、克制且有耐心，认同通过技术价值、公开协作和长期信任建设开发者社区。

6.不要求必须具有 DevRel 职位经历。开发者、开源社区参与者、技术内容作者或其他相关背景均可。

**【加分项】**

1.深度使用或开发过 AI、LLM、Agent、开发者工具或开源基础设施。

2.有 DSH 插件开发经历，熟悉 DeepSeek Harness 的插件机制和开发流程。

3.有开源项目维护或核心贡献经验。

4.具有国际视野，能够理解不同文化背景开发者的沟通习惯；有海外学习、工作或生活经历，或面向全球受众的英文写作经验。
