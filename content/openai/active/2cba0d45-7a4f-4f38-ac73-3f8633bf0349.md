# About the Role

Codex lets engineers work on many changes in parallel. That changes the demands on the systems around the code: source control needs to handle more concurrent work, builds and tests need to provide fast, trustworthy feedback, and releases need to stay safe. Engineering Acceleration builds and operates those systems for the teams developing ChatGPT, the API, Codex, and OpenAI’s infrastructure.

Our work spans source control, code review, development environments, builds, CI, and delivery. One example is [Pando](https://openai.com/index/scaling-git-at-openai/), our Git-compatible backend built with Codex, which now powers development in OpenAI’s monorepo and serves nearly a petabyte of Git data a day. We’re also evolving Bazel build and test infrastructure, scaling CI, and making it easier for teams to ship reliable software.

You’ll own projects within one or more of these areas, from technical design through adoption and operation. The work combines distributed systems engineering with a product mindset: understand where developers lose time or confidence, build a better default, and measure whether it actually helps. You’ll also use our models and coding agents to build the platform itself and explore what engineering workflows can become.

# In This Role, You Will

Depending on your focus, you could:

* Scale source control and our in-house code review and merge platform for large repositories and concurrent work by engineers and coding agents.
* Make Bazel builds reproducible and fast, improve test selection and failure diagnosis, and design efficient CI scheduling, remote execution, and caching systems.
* Build development environments and self-service workflows that make it easy to get started, reproduce CI failures, and use reliable infrastructure by default.
* Evolve deployment platforms with progressive rollouts, automated health evaluation, and rollback mechanisms that help teams release safely.
* Use AI to improve engineering workflows, from diagnosing failures and debugging flaky tests to helping validate and remediate changes.

Across these areas, you will work directly with engineers to identify high-impact problems, use telemetry and feedback to evaluate results, and own your systems in production, including an on-call rotation.

# You Might Thrive in This Role If You

* Have 7+ years of software engineering experience, including building infrastructure, developer tools, or distributed systems.
* Have designed, shipped, and operated production software in at least one relevant area, such as source control, build systems, CI/CD, or developer platforms.
* Enjoy debugging across system boundaries and making thoughtful tradeoffs among performance, reliability, correctness, and cost.
* Care about developer experience and can turn user feedback and ambiguous problems into tools people choose to use.
* Are excited to build with coding agents and to design systems that support both human and agent workflows.

# Technical Environment

Our environment includes Git, Bazel/Starlark, CI systems such as Buildkite, distributed build infrastructure, containers, Kubernetes, Terraform, and services written in Python, Go, TypeScript, and Rust. We’re looking for depth in a relevant area, not experience with every technology.
