**About the Role**

We’re looking for a full-stack engineer to build features for ChatGPT on web and desktop. You’ll work across both clients and make the API and backend changes needed to ship features end to end. You’ll partner with product and design to make ChatGPT feel consistent across platforms while taking advantage of what each platform does well.

**In this role, you will:**

* Build and ship user-facing features across the ChatGPT web and desktop apps.
* Design and maintain the APIs and backend functionality that support those features.
* Improve responsiveness, accessibility, and reliability through testing, instrumentation, and staged rollouts.
* Use product feedback and production data to identify friction and improve features after launch.

**You might thrive in this role if you:**

* Have shipped and maintained production web applications and contributed to desktop software.
* Are comfortable owning a feature from the user interface through the API and backend, including debugging it in production.
* Can turn an ambiguous product problem into a series of changes you can ship, measure, and improve.
