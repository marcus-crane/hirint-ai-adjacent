## 职位描述

我们是芯片架构与软件应用的桥梁，作为GPU的首席翻译官，你将用户复杂多变的工作翻译成计算机看得懂的语言，主要负责提高GPU的运行性能并支持异构系统对AI的加速。

你的工作任务（Responsibilities）：

1. 设计、开发和维护GPU编译器，涵盖Graphics、CUDA、DSL Compiler等核心方向；

2. 负责前端MUSA IR的设计以及LLVM后端的开发与维护；

3. 设计并构建测试集，验证编译器实现的正确性、可靠性与稳定性；

4. 深入进行编译器性能优化，提升代码生成质量与运行效率；

5. 从编译器的角度参与GPU ISA（指令集架构）和微架构的前瞻性设计。

## 任职要求

我们希望你是这样的（Who we're looking for）：

1. 计算机科学或相关专业本科及以上学历，对编译器相关工作有强烈的意愿与兴趣；

2. 熟练掌握C++，具备优秀的工程设计能力，深刻理解并善于解决复杂问题，熟悉大型软件系统的功能设计和软件工程实践准则；

3. 具备良好的沟通表达能力和团队合作精神，以及优秀的英语听说读写能力；

4. 同时掌握Rust编程语言者优先。

让你脱颖而出的加分项（What makes you outstanding）：

1. 熟练掌握编译原理及其基本算法；

2. 熟悉CPU/GPU体系结构及底层运行机制；

3. 熟悉LLVM代码框架，有实际的开发或使用经验；

4. 熟悉主流图形与计算API标准，如DirectX / OpenGL / OpenGLES / Vulkan / CUDA / HIP / OpenCL等；

5. 熟悉PyTorch / TensorFlow / TVM等主流深度学习或编译框架；

6. 拥有ACM等知名算法大赛获奖记录。
