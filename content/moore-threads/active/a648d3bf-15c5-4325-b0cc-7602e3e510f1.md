## 职位描述

关于我们

测试开发团队不仅负责发现缺陷，更负责定义产品质量标准、建设自动化质量体系，为 GPU 驱动、计算库、AI 框架、图形渲染及音视频等核心能力提供持续质量保障。

在这里，你编写的不只是测试代码，而是决定 GPU 软件能否稳定支撑 AI 训练、推理、高性能计算和图形渲染的质量基石。你的工作将直接影响产品发布质量和数亿级芯片的软件可靠性。

岗位职责

● 负责 GPU 驱动、Runtime、Compiler、计算库、通信库等软件栈的自动化测试框架和测试平台建设，打造高质量持续验证体系。

● 面向 AI 训练/推理、图形渲染、音视频等真实业务场景，设计端到端测试方案，建立稳定、高效的回归测试能力。

● 深入分析复杂软件问题，定位驱动、编译器、运行时及应用层缺陷，与研发协同推动问题闭环，持续提升产品质量。

## 任职要求

我们希望你具备

● 计算机、软件、电子、自动化等相关专业，本科及以上学历。

● 熟练掌握 C/C++ 与 Python，具备良好的工程开发能力。

● 熟悉 Linux、操作系统原理及计算机体系结构，具备扎实的问题分析能力。

● 具备严谨的工程思维，关注边界条件，乐于解决复杂系统问题。

加分项

● 具备以下任一方向经验即可：

● GPU 图形（OpenGL / Vulkan / DirectX）

● CUDA / HIP / OpenCL 等异构计算

● PyTorch / TensorFlow / ONNX AI 推理

● FFmpeg / GStreamer 音视频处理

● GoogleTest / pytest、Jenkins / GitLab CI 等自动化测试与持续集成
