## 职位描述

对接财务、供应链等业务部门，梳理后台系统查询需求与数据场景，输出可落地的 AI 解决方案

负责多系统数据抽取、清洗与结构化加工，搭建企业业务知识库，建立知识更新、质量校验与权限管控机制

落地 RAG 智能问答与 Text-to-SQL 自助查询能力，覆盖制度解读、流程指引、数据口径答疑、自助取数等高频场景

跟进用户反馈与问题案例，持续优化检索效果、回答准确率与 SQL 生成质量，实现落地效果闭环迭代

## 任职要求

应届毕业生，本科及以上学历，计算机、软件工程、人工智能、信息管理等相关

熟练掌握 Python或Java，具备良好的代码规范与工程实现能力

了解大语言模型基本原理，有 RAG、Text-to-SQL、知识库搭建相关项目或实践经验

熟悉 SQL 语法，掌握 MySQL/PostgreSQL 等关系型数据库基本使用

具备业务理解能力与跨部门沟通意识，主动负责，对企业 AI 落地有浓厚兴趣

有 ERP、财务系统相关实习 / 项目经验，熟悉企业数字化业务逻辑

熟悉CLAUDE CODE CODEX等AI工具，有 Prompt 工程、Agent 开发、harness模式经验，完成过可运行的 AI 应用 Demo

有文档解析、表格结构化、知识库运营相关经验
