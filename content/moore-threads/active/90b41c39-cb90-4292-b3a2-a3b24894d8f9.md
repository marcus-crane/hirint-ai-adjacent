## 职位描述

● 设计和实现 AIOS / Agent Harness 的核心运行框架，支持多 Agent 调度、工具调用、状态管理与任务编排。

● 构建 Agent 与外部系统的集成能力，包括 API、MCP、Webhook、消息队列、数据库等。

● 负责 Agent 执行链路中的可靠性建设：重试、超时、幂等、异常恢复、观测与告警。

● 设计并优化 Agent 上下文管理、记忆管理、会话生命周期与权限控制机制。

● 协同产品、算法和后端团队，推动 AI Agent 从原型到生产环境落地。

● 编写技术方案、接口规范、测试用例和部署文档，保障系统可维护性与可扩展性。

● 持续跟踪 Agent 框架、工具调用协议、推理编排和评测体系的最新实践。

## 任职要求

● 本科及以上学历，计算机相关专业优先，3 年以上后端或平台开发经验。

● 熟悉 Python / Rust/ TypeScript ，具备扎实工程能力。

● 有分布式系统、任务调度、工作流引擎、消息系统等开发经验。

● 理解 LLM Agent 基本原理，熟悉工具调用、函数调用、ReAct、Planner-Executor 等模式。

● 熟悉 MCP、OpenAPI、SSE、Webhook、队列、缓存、数据库等常见集成方式。

● 具备较强的问题定位和系统设计能力，能独立负责从方案到上线的完整链路。

● 良好的沟通协作能力，能与算法、产品、前端、测试高效配合。
