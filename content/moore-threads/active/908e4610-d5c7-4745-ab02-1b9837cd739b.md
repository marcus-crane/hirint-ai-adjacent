## 职位描述

欢迎加入摩尔线程，和我们一起设计面向未来的（图形、AI、计算）全功能 GPU！你将参与构建 GPU 架构研发的核心软件系统和研发平台，包括架构仿真模型、硅前驱动（Driver/Compiler）和验证平台，以及相关的自动化工具，通过软件建模、功能验证、性能分析和工具开发，推动新架构和新特性从设计走向实现。

岗位职责

1. 软件系统研发工程师主要负责构建并持续优化 GPU 架构研发所依赖的软件生态，包括但不限于 validation driver、compiler、functional C model、performance model，以及 graphics/compute test platform。

2. 你将通过真实的工程问题，参与 GPU 新架构和新特性的开发验证，解决复杂系统中的功能、性能和稳定性问题，并持续改进研发工具、测试平台和自动化流程。

3. 我们希望你对工程实现有兴趣，对工程质量有执着，遇到问题会追根究底，也喜欢写代码、分析问题，并愿意深入理解大型软硬件系统的协同工作方式。

4. 通过该岗位，你可以快速了解一款 GPU 从架构设计、软件建模、功能验证到最终落地的完整研发流程。

## 任职要求

岗位要求

1. 善于独立推进开放性问题的解决，面对不熟悉的代码和缺少现成答案的问题，能主动查阅资料、阅读代码、设计实验并持续缩小问题范围，而不是等待他人给出完整步骤。

2. 责任心强，对自己负责的任务有较强的结果意识，有强烈意愿把问题跟到最终解决，并能在团队协作中共享信息、听取反馈和配合整体目标。

3. 熟练掌握 C/C++ 和一门脚本语言（如 Python），具备扎实的编码与调试能力。

4. 熟练使用 AI Coding Agent提升编码与调试效率。

5. 对代码质量和工程效率有持续改进的意愿与行动力。

6. 计算机相关专业，硕士以上学历优先，优秀本科亦可。

加分项

1. 有大型软件系统开发和维护经验。

2. 熟悉计算机图形学、GPU 渲染或 GPU 通用计算知识与工具。

3. 有 GPU（DirectX / OpenGL / Vulkan / CUDA / OpenCL）程序开发经验。
