## 职位描述

欢迎加入摩尔线程！聚焦大模型 Agent 技术研究与工程落地，探索任务规划、工具调用、记忆、多智能体协作等方向，同时参与 AI 应用系统建设，协同产品开展 AI 功能创新，支撑业务系统迭代落地。

岗位职责：

1、参与 Agent 系统架构设计与开发，实现任务规划、工具调用、记忆管理、多轮交互等核心能力，构建可用可靠的智能体系统。

2、调研 Agent 及机器学习平台前沿技术，完成方案分析与原型验证，探索代码助手、智能办公、知识问答等智能应用场景。

3、负责 AI 应用系统的设计、开发与维护，支撑 AI 业务高效迭代，协同产品开展 AI 创新功能实验。

4、持续优化平台能力，降低 AI 算法开发使用成本，搭建深度学习应用系统，推动技术业务落地。

5、参与 Agent 评测、提示词与工具链集成，编写维护技术文档，跨团队协同推进项目落地。

## 任职要求

任职资格：

1、计算机、信息技术、软件工程等相关专业，本科及以上学历。

2、了解 Agent 相关技术原理（规划、工具调用、记忆、多智能体）或具备大规模分布式、微服务后端系统开发经验。

3、熟练掌握 Python/Java/Golang/Rust/C++ 至少一门编程语言，具备良好工程实现能力。

4、掌握算法与数据结构基础，了解大模型、机器学习相关基础知识。

5、具备较强技术调研、问题分析能力，良好沟通协作与文档输出能力。

加分项

了解主流 Agent 框架原理，有 Prompt 调优、大模型 API、私有化模型实践经验

拥有 AI 业务后端 / 全栈项目、完整 AI 应用落地经验

有开源项目、科研论文、比赛获奖等相关经历
