## 职位描述

岗位职责

参与 GPU 虚拟原型平台搭建、扩展与优化，基于 QEMU 开展 CPU/GPU 功能建模，支撑芯片软硬件协同设计与功能验证工作。

参与 RISC-V 指令集模拟器开发、指令功能实现，持续优化模拟器运行精度与执行效率。

负责图形与通用计算 Trace 工具链研发，实现 API 捕获、回放、校验自动化能力，支撑 GPU 图形、光线追踪、通用计算场景验证。

协同芯片设计、硬件验证、驱动团队开展联合调试，定位软硬件交互问题，完成平台自动化回归、实验验证与性能调优。

持续完善开发工具链、自动化测试流程，沉淀技术文档，赋能团队开展芯片前期预研与验证工作。

## 任职要求

任职要求

计算机、电子信息、软件工程、图形学、高性能计算等相关专业本科及以上应届生。

扎实掌握 C/C++ 编程基础，具备良好代码阅读、调试与工程实现能力；熟悉 Python 脚本开发优先。

了解计算机体系结构，熟悉 CPU/GPU 基础架构，理解通用计算、内存管理、任务调度、软硬件协同基本原理。

了解 CUDA/OpenCL/HIP 任一通用计算编程模型，熟悉 GPU Kernel、内存拷贝、同步机制等基础概念。

良好跨团队沟通能力，责任心强，能够跟随项目节奏完成阶段性交付任务。

加分项

接触过 QEMU、指令集模拟器、虚拟化、芯片虚拟原型相关开发；了解 RISC-V 指令集架构。

使用过 RenderDoc、Nsight、apitrace 等图形调试、API 追踪、性能分析工具，阅读过相关开源项目源码。

具备图形渲染、光线追踪基础认知，熟悉 Vulkan、RT 相关图形接口更佳。

拥有自动化测试、CI 脚本、日志分析、性能数据处理相关实践经验。

有硬件仿真、芯片验证、GPU 驱动开发相关项目经历优先。
