#### **INFRASTRUCTURE SECURITY ENGINEER**

We are seeking a talented and motivated Infrastructure Security Engineer to join our security team. In this role, you will design, implement, and maintain secure cloud and hybrid infrastructure, and ensure the integrity of our cloud-native applications.

This role focuses on securing critical infrastructure across multi-cloud and hybrid environments, with work that may span platforms such as SpaceXSI, X Social, X Money and related systems. You’ll operate with an automation-first mindset: building secure foundations, hardening platforms at scale, and partnering closely with engineering teams so security is embedded in how we build and run systems—not bolted on after the fact.

#### **RESPONSIBILITIES:**

* Design and implement secure cloud architectures across AWS, GCP, and Azure
* Build and secure mission-critical applications in hybrid cloud and on-premises environments
* Develop and maintain Infrastructure as Code (IaC) templates with built-in security controls
* Support regular security assessments and audits of cloud infrastructure and services
* Implement and manage cloud security tools (e.g., CSPM, CWPP, CASB)
* Manage identities and roles across cloud and hybrid environments
* Monitor and remediate infrastructure for compliance with PCI, NIST CSF, GDPR, and HIPAA
* Design secure container standards and automation that keep developer workflows smooth
* Maintain Kubernetes security in line with current best practices
* Secure CI/CD pipelines with development teams and maintain code scanning platforms
* Monitor and respond to security events and incidents across cloud and hybrid environments
* Maintain SIEM data pipelines and build dashboards and alerts from security metrics
* Build and maintain security operations infrastructure using Python, Terraform, and Puppet
* Develop and maintain cloud security policies, standards, and procedures
* Own security projects end to end, from identifying issues to implementing solutions
* Stay current on emerging cloud security threats and mitigations

#### **BASIC QUALIFICATIONS:**

* Bachelor's degree
* Minimum 3+ years of experience in cloud security, infrastructure security, or other security roles
* Experience with Kubernetes and container security
* Experience implementing security controls for regulatory compliance (e.g., GDPR, HIPAA, PCI DSS, NIST CSF)

#### **PREFERRED SKILLS AND EXPERIENCE:**

* Strong understanding of cloud security principles, compliance frameworks, and best practices
* Proficiency in at least one cloud platform (AWS, GCP, or Azure) and associated security services
* Proven experience securing hybrid AWS/on-premises (or multi-cloud) environments, including IAM and overall security posture
* Familiarity with containerization technologies and their security implications
* Knowledge of network security concepts and protocols
* Proactive mindset with strong ownership, critical thinking, and problem-solving skills
* Relevant security certifications (e.g., CCSP, CSSK, AWS Security Specialty)
* Deep expertise in Kubernetes and container security
* Experience with multi-cloud environments and cloud-to-cloud security
* Knowledge of CI/CD best practices and tools
* Familiarity with and experience implementing security controls for regulatory compliance (e.g., GDPR, HIPAA, PCI DSS, NIST CSF)
* Strong proficiency with Python, Terraform, and configuration management (e.g., Puppet)
* Hands-on experience building GitHub Actions and workflows
* Experience with observability and security operations tooling (e.g., Prometheus, Grafana, CloudWatch, Karma; SIEM platforms such as Wazuh)
* Experience in building custom cloud security tools or integrations
* Interest in leveraging AI for cloud security monitoring and automation
* Contributions to open-source cloud security projects
* Experience with securing AI/ML workloads in cloud environments
* Experience in banking, money transmission, P2P payments, or similarly regulated financial platforms
