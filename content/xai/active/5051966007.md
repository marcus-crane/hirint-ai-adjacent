**SOFTWARE ENGINEER, VOICE MODEL**

You'll join the Grok Voice Model team as a software engineer. You'll design, build, and run the software systems behind Grok Voice, which delivers natural, low-latency, multilingual spoken interactions across devices and in real time. The team owns the full engineering stack behind the model, from large-scale data processing to distributed training to production deployment.

**RESPONSIBILITIES:**

* Design, build, and maintain large-scale distributed data pipelines that ingest, process, and annotate real-world and synthetic audio, so the training and evaluation systems get reliable, high-quality data
* Build and optimize the distributed training infrastructure and software for speech-language models in JAX and PyTorch, including the systems that run supervised fine-tuning and reinforcement learning at scale
* Build automated evaluation and testing systems that measure accuracy, audio quality, latency, and real-time performance, plus the experimentation infrastructure used to validate every model release
* Integrate voice models into production applications and real-time services, write the technical specifications for spoken interactions, and own deployment from prototype to global scale with a focus on stability, low latency, and reliability
* Profile and optimize system performance across training and inference, including throughput, latency, memory use, and compute efficiency

**BASIC QUALIFICATIONS:**

* Bachelor's degree in computer science, software engineering, computer engineering, electrical engineering, or another engineering discipline
* Experience building and running large-scale distributed training and inference systems on Kubernetes
* Experience implementing and optimizing model training and inference software in JAX or PyTorch
* Experience building automated testing, evaluation, and A/B experimentation pipelines for production systems

**PREFERRED SKILLS AND EXPERIENCE:**

* Expert-level Python, writing clean, efficient, production-quality code for large-scale systems
* Hands-on experience building distributed data processing systems with tools like Spark and Ray
* A proactive, self-driven attitude and the ability to deliver in a fast-paced, high-caliber team
