## ABOUT THE ROLE

Our electrical design toolchain covers PCB design tools, signal/power-integrity and RF analysis tools, an ECAD data-management server, a component and design-data sync into PLM, and an internally built integration platform that is replacing a legacy ECAD-to-PLM gateway. This role keeps that toolchain running day to day, fixes it when data goes wrong, and builds the automation and add-ins that remove manual work for hardware engineers.

We hire for fundamentals and train on our systems. If you can script, know at least one ECAD tool well as a user, and like tracing a problem from symptom to root cause, we will teach you the rest.

### WHAT YOU'LL DO

#### **ECAD Platform Administration**

* Administer the ECAD data-management server: user access, groups and permissions, SSO, backups, updates, and health monitoring.
* Test upgrades and configuration changes on a staging server before they reach production.
* Evaluate and configure ECAD design and analysis tools for users.
* Track license usage and produce usage reports that feed license planning.
* Work with IT and Information Security on servers, networking, identity, and access.

#### **Integration Operations**

* Maintain the scheduled jobs that sync component and design data from ECAD into PLM. Monitor runs, triage failures, and correct bad data.
* Support engineers publishing designs to PLM: publish errors, part-number problems, missing or wrong datasets.
* Run acceptance and regression testing on new integration releases. Report defects with reproducible evidence.
* Read logs, API responses, and database records to find where data went wrong.

#### **Tooling Development**

* Build and maintain add-ins and enhancements for our internal ECAD-to-PLM integration platform.
* Write scripts to automate administration, reporting, and data checks.
* Query tool APIs and databases to answer usage and data questions.
* Use version control, code review, and automated tests for everything you ship, including code written with AI assistance.

#### **ECAD↔MCAD Collaboration**

* Configure and maintain ECAD↔MCAD data exchange between PCB design tools and MCAD/PLM systems.
* Maintain attribute, layer, and keep-out mappings. Test exchange workflows with electrical and mechanical designers.

#### **Standards and Templates**

* Maintain design templates (schematic, PCB, PCBA, flex) and their parameter conventions, including CUI markings.
* Keep EE design standards, checklists, and work instructions current in the quality management system.
* Migrate legacy designs and data between tools and systems.

#### **Support and Documentation**

* Provide Tier 1–2 support to hardware engineers across the toolchain.
* Write runbooks and system documentation that someone else can follow without asking you.
* Train users on tool workflows and new releases.

### REQUIRED QUALIFICATIONS

* 2+ years in at least one of: PCB/ECAD design, ECAD or CAD/PLM administration, or engineering tools development.
* Working fluency as a user of at least one ECAD tool (Altium Designer, KiCad, OrCAD/Allegro, PADS/Xpedition, or similar).
* Scripting in Python or PowerShell for automation or data processing.
* SQL: write SELECT queries with joins and filters against a relational database.
* Windows administration basics: services, scheduled tasks, event logs, file shares, permissions.
* Git for day-to-day version control.
* Clear written documentation.
* Bachelor's degree in Electrical Engineering, Computer Engineering, Computer Science, or a related field, or equivalent experience.
* U.S. person status (export-controlled data).

### PREFERRED QUALIFICATIONS

* 4+ years in the areas above.
* Altium Enterprise Server, Altium 365, or a similar ECAD data-management server: administration experience.
* PLM experience (Teamcenter preferred; Windchill, Arena, Aras also relevant), especially ECAD-to-PLM integration.
* TypeScript/Node.js; REST and GraphQL APIs; OAuth 2.0/OIDC.
* ECAD↔MCAD exchange (IDX, IDF) with NX, SolidWorks, or Creo.
* Administration of signal/power-integrity or RF tools (HyperLynx, Ansys).
* KiCad, including Git-based design version control.
* IPC standards and PCB fabrication/assembly knowledge.
* Has supported a CAD tool migration or a data migration between systems.
* Uses AI coding and research assistants in an engineering workflow, with a habit of verifying their output.
