#### ABOUT THE TEAM

The [Barracuda](https://www.anduril.com/barracuda) Manufacturing Team is responsible for rapidly iterating and building cutting-edge defense hardware for the Warfighter. This responsibility includes everything in the manufacturing value-chain, including, but not limited to, Design for Manufacturability work, tool design & selection, process creation & optimization, vendor sourcing & interaction, quality planning, and work documentation associated with the hardware that the Manufacturing Engineer owns.

**ABOUT THE JOB**  
As a Software Manufacturing Test Engineer, you will build, scale, and maintain the software that drives our manufacturing test systems. In this role, your primary focus will be developing production software that directly tests complex hardware systems, integrates with laboratory instrumentation and DAQs, and manages the data these stations produce. You will bridge low-level hardware control with high-level test automation by writing robust, reliable production code in Python and C# targeting Linux/Unix (and ideally NixOS) runtime environments.  
To ensure our hardware meets mission-critical quality and production throughput demands, every Software Manufacturing Test Engineer is expected to derive software test requirements from hardware schematics and system specifications, author automated test sequences, and deploy complete software suites to factory test racks. You will work closely with development and firmware engineers to refine test coverage as product designs evolve, resolve complex hardware-software integration failures on the floor, and ensure deterministic software deployments across our manufacturing line.

**WHAT YOU'LL DO**

* Maintain ownership of software manufacturing test activities in production, ensuring test station uptime, operator usability, and smooth factory throughput
* Develop and maintain PLC-integrated station control software — commanding industrial controllers over Modbus TCP for rig actuation, interlocks, and sensor acquisition — and maintain the tag/address index as PLC programs evolve, including tooling that imports controller tag exports and validates them against the station's expected schema
* Build hardware-free simulation environments (containerized station images, virtual CAN replay, device simulators) so test software is developed and regression-tested without occupying hardware
* Design, build, and maintain production software manufacturing test suites primarily in Python (for hardware control, test sequencing, and instrument automation) and C# (for test executives, operator interfaces, and background services)
* Integrate software manufacturing test applications directly with sensors, DAQs, programmable power supplies, electronic loads, and vehicle compute hardware
* Implement low-level hardware communication using embedded protocols including UART, CAN, and RS-485 / RS-232 to command, flash, and validate devices under test (DUTs)
* Deploy, configure, and debug software manufacturing test systems running on Linux/Unix platforms using terminal command-line tools, SSH, and network debugging utilities
* Leverage Nix and NixOS to manage reproducible software manufacturing test environments, eliminating dependency drift between engineering development benches and production line stations
* Collaborate with hardware and firmware engineers during early-stage product development (NPI) to define software manufacturing test requirements, coverage, APIs, and pass/fail limits
* Automate software manufacturing test execution across various levels of assembly, from PCBA-level functional test (FCT) up to full-system and Environmental Stress Screening (ESS) checkouts
* Provide hands-on troubleshooting and root-cause analysis (RCCA) for complex electrical, firmware, and software manufacturing test issues found on the line
* Log parametric test data and integrate software manufacturing test stations with database systems (using SQL queries as needed) and Manufacturing Execution Systems (MES) to maintain complete hardware traceability
* Develop clear operator interfaces, error-handling mechanisms, and software manufacturing test troubleshooting logs to assist technicians during hardware failures
* Support continuous improvement initiatives to optimize software manufacturing test sequences, shorten cycle times, and increase test coverage without sacrificing quality

**REQUIRED QUALIFICATIONS**

* Bachelor’s degree in Computer Science, Computer Engineering, Electrical Engineering, or related fields
* 3+ years of relevant industry experience as a Software Manufacturing Test Engineer, or in an equivalent role with an emphasis on software development for hardware test automation, lab automation, or manufacturing environments
* Strong proficiency writing production code in Python for software manufacturing test automation, device control, and data handling
* Working knowledge of C# (.NET) for developing software manufacturing test applications, operator UIs, or system services
* Strong Linux/Unix systems knowledge, including terminal proficiency, shell scripting, SSH, and network configuration/debugging
* Demonstrated hands-on experience interfacing software manufacturing test suites with embedded communication protocols: UART, CAN, and RS-485 / RS-232

* Strong root-cause analysis skills for diagnosing hardware-software boundary issues using log files, terminal outputs, and basic bench tools
* Experience integrating software manufacturing test platforms with Manufacturing Execution Systems (MES) and database backends
* Excellent written, verbal, and interpersonal communication skills to collaborate with hardware, software, and operations teams
* Eligible to obtain and maintain an active U.S. Secret security clearance
