Saronic Technologies is a leader in revolutionizing autonomy at sea, dedicated to developing state-of-the-art solutions that enhance maritime operations through autonomous and intelligent platforms.

# **Job Overview**

We are seeking a Senior Test Automation Engineer responsible for designing, developing,

and maintaining the automated testing frameworks, test suites, and quality gates for our

internal software platforms. You will join the Integrated Business Tools team within

Enterprise Technology, which builds the systems Saronic uses to run its business.

Leveraging your expertise, you will collaborate with cross-functional teams to embed

testing throughout the software development lifecycle and help engineers deliver reliable

software faster.

At the Senior level, you will own test automation for a significant functional area: leading

the testing strategy, driving its adoption across multiple teams, and initiating

improvements without guidance from a lead. You will work on complex challenges at the

intersection of technology and defense, and play a significant role in the future of

maritime operations.

# **Responsibilities**

* Lead the testing strategy and drive consistent adoption across multiple teams, serving as the team's subject matter expert on testing.
* Design, build, and maintain automated testing frameworks and reusable test libraries, utilities, fixtures, and helpers for use across applications.
* Develop automated unit, contract, integration, functional, regression, and end-to-end tests for frontend and backend services, applying the test pyramid to select the right type of test.
* Ensure tests are reliable, maintainable, and scalable, and identify and eliminate flaky tests.
* Create mocks and fakes to isolate tests from external dependencies such as third- party APIs.
* Identify opportunities to automate manual testing and support user acceptance testing with stakeholders.
* Shift testing left by embedding it early in the software development lifecycle to find issues sooner and reduce cycle time.
* Review technical designs, user stories, and acceptance criteria with engineers and stakeholders to gather and define testing requirements.
* Define quality gates and integrate automated tests into CI/CD pipelines as pull request and deployment gates.
* Maintain tests across development, staging, and production environments, including smoke tests for post-deployment verification.
* Optimize test execution through parallelization, sharding, and selective execution.
* Investigate and troubleshoot CI/CD and test failures to determine root causes, and implement logging that supports debugging in test and production environments.
* Capture testing and code coverage metrics, identify testing gaps, and create reports on results.
* Communicate testing risks, coverage gaps, and release readiness to stakeholders.
* Participate in technical design reviews and pull request reviews.
* Enable and mentor software engineers to write automated tests as part of their development workflow and to apply testing best practices.
* Evaluate emerging testing technologies and recommend improvements to our development processes and tools.
* Participate in Agile development methodologies, including sprint planning, daily stand-ups, and retrospectives, to ensure timely delivery of features and enhancements.

# **Qualifications**

* Bachelor's degree in Computer Science, Engineering, or related field, or equivalent practical experience.
* 5-7 years of experience in software test automation or software engineering, including leading testing efforts for a significant project or functional area.
* Strong understanding of the test pyramid, including unit, contract, integration, end-to-end, and user acceptance testing.
* Proven experience designing and building automated testing frameworks for frontend and backend applications.
* Experience with end-to-end testing frameworks (Playwright, Cypress, or Selenium a plus).
* Experience with unit and component testing frameworks (Vitest, Jest, or React Testing Library a plus).
* Experience with API testing tools and techniques (Postman a plus).
* Experience integrating automated tests into CI/CD pipelines as quality gates (GitHub Actions a plus).
* Experience with test data management, mocking, and isolating external dependencies.
* Experience testing asynchronous systems and eventual consistency.
* Experience with performance and load testing.
* Familiarity with authentication and authorization standards (OAuth, OpenID Connect, and SSO a plus).
* Familiarity with containerization.
* Proficiency in version control systems (Git and GitHub a plus).
* Proficiency in at least one programming language (TypeScript and React a plus).
* Experience with security testing and scanning a plus.
* Experience with cloud and data platforms (AWS and Palantir Foundry a plus).
* Clear written communication and a track record of driving adoption of testing practices across teams.
