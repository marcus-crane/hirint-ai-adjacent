## 职位描述

1.负责 MiniMax 开放平台 / MaaS 相关服务端系统的设计、开发与迭代，支持大模型能力的对外服务化交付。

2.参与开放 API、网关调度、鉴权、配额、计费、流量治理、多租户隔离等核心平台能力建设。

3.负责模型能力接入与平台化封装，支持文本、多模态、Agent、RAG、Tool 等能力的统一接入与调用。

4.参与高并发、高可用、低延迟服务体系建设，持续优化系统稳定性、性能与成本。

5.协同算法、产品、前端及基础设施团队，推动平台能力落地和开发者生态建设。

6.负责日志、监控、告警、链路追踪、灰度发布、故障恢复等平台稳定性能力建设。

## 任职要求

1.本科及以上学历，计算机、软件工程或相关专业优先。

2.熟悉 Go / Java / Python 中至少一门后端语言，具备扎实的后端工程能力。

3.熟悉微服务架构、分布式系统、缓存、消息队列、数据库等常见后端技术栈。

4.具备高并发、高可用服务设计经验，理解服务治理、限流、熔断、降级、容灾等工程实践。

5.熟悉开放平台、API 平台、ToB 服务或企业级平台系统者优先。

6.具备良好的沟通协作能力，能够推动跨团队需求落地。

7.对 AI 大模型、Agent、RAG、工具调用、模型服务化等方向有兴趣，愿意长期投入。

【加分项】

1.有大模型开放平台、MaaS、模型推理服务、Agent 平台相关经验。

2.有 API 网关、鉴权、配额、计费、多租户、开发者平台建设经验。

3.有 RAG、Memory、Tool、Workflow、Multi-Agent 等 AI 应用平台经验。

4.有高并发网关、请求调度、任务编排、流式输出等经验。

5.有 ToB 经验者加分。

6.有从 0 到 1 搭建平台、或支撑大规模内部/外部接入经验者优先。
