## 职位描述

1.负责 MiniMax 开放平台 / MaaS 相关服务端系统的设计、开发与持续优化，支持大模型能力的对外服务化交付。

2.参与高并发、高可用、低延迟的 AI 服务架构建设，包括 API 网关、请求调度、限流熔断、鉴权计费、任务编排等核心模块。

3.参与模型服务的工程化落地，推动模型能力与业务场景的稳定接入，提升平台的可用性、可扩展性和调用体验。

4.协同算法、产品、前端、运维等团队，推动 MaaS 平台能力迭代，支持内部及外部开发者高效接入。

5.关注系统稳定性、性能、成本与观测性，持续优化服务质量和资源利用效率。

6.参与平台基础设施建设，完善日志、监控、告警、链路追踪、灰度发布等工程能力。

## 任职要求

1.本科及以上学历，计算机、软件工程或相关专业优先。

2.具备扎实的后端开发能力，熟悉至少一门主流后端语言，如 Go、Java、Python 等。

3.熟悉常见后端基础组件与中间件，包括但不限于 MySQL、Redis、MQ、RPC、HTTP、K8s 等。

4.具备良好的系统设计能力，理解高并发、高可用、分布式系统、微服务架构等核心概念。

5.具备较强的问题分析和解决能力，对工程质量、性能优化和稳定性建设有责任感。

6.有较强的沟通协作能力，能够与算法、产品、前端等多个角色高效配合推进项目。

7.对 AI 基础设施、大模型平台、云服务化产品有兴趣，愿意长期投入该方向。

【加分项】

1.有大模型平台、AI API 平台、MaaS / PaaS / SaaS 平台相关经验。

2.有高并发 API 服务、计费系统、任务调度系统、鉴权系统、流控系统建设经验。

3.熟悉模型推理服务、推理加速、异步任务、流式输出、长连接等场景。

4.有云原生、容器化、Kubernetes、可观测性体系建设经验。

5.有 ToB 产品或企业级平台经验者优先。

6.有从 0 到 1 搭建平台能力、或支撑大规模外部开发者接入经验者优先。
