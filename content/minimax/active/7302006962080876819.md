## 职位描述

为什么加入我们

1. 直面万卡级 GPU 集群，对支撑大模型训练与推理的核心硬件基础设施产生直接影响。

2. 从服务器选型引入、交付验收到运行维护，参与 GPU 服务器全生命周期管理。

3. 用数据、自动化和工程系统提升硬件 SLA，解决规模化集群中的复杂故障与效率问题。

4. 与服务器、GPU、网络、存储厂商深入协作，推动硬件能力与 AI 业务需求高效匹配。

我们在做什么

MiniMax 正在建设驱动下一代 AGI 的算力基础设施，管理数以万计的 GPU 及其配套服务器、网络和存储资源，为大模型训练和推理提供稳定、高效的算力供给。

这不是传统的服务器运维岗位，而是面向超大规模 GPU 集群的硬件运营与稳定性工程。团队工作覆盖硬件选型、测试验证、资源交付、集群运维和运营治理等方向。我们不要求一个人覆盖全部环节，而是希望你在其中 1–2 个方向具备扎实经验，并愿意逐步拓展能力边界

你将做什么

1. 建设服务器、GPU、硬盘、内存、网卡等硬件运营指标体系，对集群硬件 SLA、故障率、恢复时长和可用性负责。

2. 负责 GPU 服务器及相关硬件的测试选型、引入验证、批量交付、验收和生命周期管理。

3. 建立硬件故障分级、诊断、维修、RMA 和复盘机制，推动高频及疑难问题根因治理。

4. 建设硬件巡检、监控告警和健康画像能力，实现风险提前识别与预防性维护。

5. 基于 BMC/IPMI、Redfish、Python、Bash、Ansible 等技术建设自动化运维与远程管理能力。

6. 协同系统研发、集群运维、采购和硬件供应商，推动固件、驱动、配置及硬件兼容性问题闭环。

7. 沉淀硬件交付标准、验收规范、操作流程和供应商 SLA，持续提升规模化交付效率与质量。

## 任职要求

我们期待你

基础要求

1. 本科及以上学历，计算机、电子信息、自动化、通信等相关专业，具有 3 年以上服务器、IDC、硬件运维或基础设施相关经验。

2. 熟悉服务器硬件体系，理解 CPU、GPU、内存、硬盘、网卡、PCIe、RAID 等组件及常见故障。

3. 熟悉 Linux 系统，能够独立完成硬件故障定位、日志分析和系统级问题排查。

4. 熟悉 BMC/IPMI、Redfish 等带外管理技术，具备批量设备管理或自动化运维实践。

5. 掌握 Python、Shell 中至少一门语言，能够开发巡检、监控、诊断或批量操作工具。

6. 具备数据和 SLA 意识，能够通过故障率、MTTR、可用率、RMA 周期等指标推动问题持续改进。

7. 具备较强的 Ownership 和跨团队协作能力，能够协调采购、供应商、IDC 和内部技术团队推进闭环。

加分项

1. 有大规模 GPU 集群、AI Infra、HPC 或智算中心硬件运营经验。

2. 参与过 GPU 服务器、网络设备、存储设备的选型、PoC、批量引入和验收。

3. 熟悉 NVIDIA GPU、NVLink、PCIe、网卡及相关固件和驱动问题。

4. 有 Prometheus、Grafana、资产管理、硬件健康画像或故障诊断平台建设经验。

5. 有服务器厂商、OEM/ODM、设备供应商管理及硬件质量改进经验。

6. 有从人工运维向自动化、标准化和平台化演进的实践经验。
