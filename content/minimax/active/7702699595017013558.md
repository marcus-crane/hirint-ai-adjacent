## 职位描述

我们在做什么

我们正在建设海外算力基础设施，推动服务器与 GPU 集群在海外数据中心部署并投入业务使用。这个岗位面向真实的硬件与集群交付，不是以排期、汇报为主的传统项目管理岗。

为什么加入我们

1. 参与海外算力基础设施从设备部署到业务上线的完整交付过程。

2. 深入接触服务器、GPU 集群、网络、存储与数据中心现场问题。

3. 与研发、运维、IDC 和供应商协同，推动真实算力资源落地。

你将做什么

1. 推进服务器、GPU 集群从需求确认、资源准备、到货部署到验收上线的交付闭环，对进度和交付质量负责。

2. 协调海外 IDC、设备供应商及内部研发、运维团队，完成机柜、电力、制冷、网络等条件确认，以及设备上架、布线和联调。

3. 参与服务器、网络、存储及集群部署问题的排查，推动问题定位、解决和复测，确保算力资源达到业务可用状态。

4. 跟进跨境运输、清关、到货、备件和维修替换，及时识别交付风险并推动解决。

5. 建立交付计划、验收标准和 SOP，推动部署、配置校验及验收流程持续改进。

## 任职要求

基础要求

1. 本科及以上学历，3 年以上服务器、云基础设施、IDC 或集群部署交付经验。

2. 做过服务器或 GPU 集群的现场部署、网络/存储联调、集群上线或客户验收中的一项或多项；能清楚说明自己实际负责的环节。

3. 理解服务器、网络、存储及数据中心基础条件，具备现场问题定位和跨团队推进能力。

4. 英语可用于工作沟通，能够对接海外供应商或现场团队；接受海外出差及阶段性驻场。

加分项

1. 有 GPU 集群、AI 算力基础设施或多站点交付经验。

2. 有海外项目、跨境物流、清关或海外供应商协同经验。

3. 有 Shell / Python 脚本、自动化部署或交付流程建设经验。

4. 有目标国家或地区的长期工作经历或合法工作资格。
