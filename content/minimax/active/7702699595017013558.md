## 职位描述

1. 负责海外算力中心及 GPU 集群的端到端交付，统筹需求确认、机房就绪、设备到货、部署验收至业务上线，对交付周期和质量负责。

2. 协同 IDC 服务商确认机柜、电力、制冷及网络等条件，组织服务器、GPU、网络和存储设备的上架、布线与测试。

3. 协调研发及运维团队，完成系统部署、集群初始化、网络配置、监控接入和平台上线，推动算力资源达到业务可用状态。

4. 对接采购、物流、海外供应商及现场团队，跟进跨境运输、清关、到货及维修替换，解决交付过程中的风险和卡点。

5. 建立交付计划、验收标准、进度看板及 SOP，推动压测验收、配置校验等环节标准化、自动化，持续提升交付效率。

## 任职要求

1. 本科及以上学历，3年以上 IDC、服务器集群或基础设施交付经验，有海外项目或 GPU 集群交付经验者优先。

2. 熟悉服务器、网络及存储设备的交付流程，了解 Linux、集群部署及数据中心电力、制冷等基础条件。

3. 具备项目管理及跨团队协调能力，能够独立推进现场交付、问题处理和验收移交。

4. 中英文可作为工作语言，能够独立对接海外 IDC、供应商及现场工程师。

5. 适应跨时区协作、海外出差及阶段性驻场，具备便利的国际出行条件；拥有目标国家或地区合法工作资格者优先。

加分项

有海外算力中心从0到1建设、多站点交付或海外供应商管理经验。

有交付平台、自动化验收或流程工具建设经验，具备 Shell / Python 能力。

有长期海外学习或工作经历，熟悉当地协作方式及供应商生态。
