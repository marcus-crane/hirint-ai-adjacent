## 职位描述

【你会做什么】

1. 开发并开源 Agent Demo、开发者工具、CLI / SDK 示例。

2. 发布和维护 GitHub、Hugging Face、ModelScope 项目。

3. 完善 README、文档、示例、测试，处理 Issue 和 PR 反馈。

4. 跟踪开源 Agent、MCP、模型工具调用等方向，并快速做出可用原型。

## 任职要求

【我们希望你】

1. 2027 届及以后在读，每周可实习 3 天以上、连续 3–6 个月。

2. 熟练 Python，了解 Git、GitHub、HTTP / API；会 JS/TS 加分。

3. 对 LLM、Agent 或开源模型生态有实际动手经验。

4. 能用英文阅读文档、参与社区技术沟通。

5. 有开源社区心态：愿意公开协作、接受反馈、持续维护，不止做一次性 Demo。

【加分项】

1. 有 GitHub 项目、开源 PR、Hugging Face / ModelScope Demo、技术文章或开发者工具作品。

2. 熟悉 MCP、FastAPI、Docker、GitHub Actions、React / Next.js。

3. 投递请附 GitHub 或作品链接。我们更看重真实贡献、工程质量和维护意识，不只看 Star 数。
