## 职位描述

1. 推动云资源安全要求落地。 与安全团队协作，将云账号、身份权限、凭证、网络暴露、漏洞、日志审计、应急响应等要求转化为资源申请规则、配置基线、检查项和整改流程；跟踪问题责任人、整改进度及验证结果，在安全要求与业务交付效率之间做好协调。

2. 高效承接业务用云需求。 对接业务团队对计算、存储、数据库、网络及其他云产品的需求，梳理使用场景、容量、权限和交付时效；推动标准化申请、评估、开通、变更和回收流程，让业务能够清楚地提出需求、查询进度并获得合适的资源。

3. 建设 AI Agent 辅助的云资源运营能力。 结合云平台接口、资源台账、监控、账单和工单数据，利用 Agent 辅助完成需求归类与信息补全、资源方案建议、安全配置检查、异常发现、整改跟进及运营报告生成；持续评估建议质量，将有效做法沉淀为规则和自动化流程。

4. 治理存量资源与运营数据。 推动多云资源的标签、归属、权限、配额和生命周期管理，识别无主资源、闲置资源、异常使用及费用变化，协同业务负责人制定并落实治理方案，验证治理效果。

5. 建立可控的执行闭环。 为自动化和 Agent 能力设计权限边界、人工审批、操作审计、变更验证与回滚机制。资源关停、回收、权限调整等有业务影响的动作，须由相应责任人按既有流程确认，不由 Agent 自主决策执行。

## 任职要求

1. 熟悉至少一种主流云平台，理解常见云产品的使用场景，以及云账号、IAM、网络、存储等基础能力；能够与业务和技术团队讨论资源选型、权限及交付需求。

2. 理解云环境常见安全风险，能够将安全要求落实到配置规范、流程检查和问题整改中；不要求替代安全团队制定安全策略，但应具备推动跨团队落地的能力。

3. 具备较强的需求理解、流程设计和跨团队推动能力，能把业务诉求转化为明确的资源交付方案，并持续跟进效率、安全和治理效果。

4. 具备脚本或编程能力，能够使用 API、Shell、Python 等工具整合云资源及运营数据，改进重复性流程；有使用 AI Agent 构建业务工作流、工具调用或自动化能力的实践更佳。

5. 有生产环境风险意识，理解权限最小化、审批审计、变更验证和回滚的重要性；能识别 AI 输出的数据口径问题和错误建议，不将未经核实的结论直接用于生产操作。

5. 具备良好的跨团队沟通和协作能力，有较强的责任心、服务意识和问题闭环能力。
