## 职位描述

岗位职责

1. 主导核心业务系统的整体架构设计、技术选型与演进规划

2. 负责高并发、高可用、可扩展分布式系统的方案设计与落地

3. 参与关键技术决策，关注架构级难题（性能、数据一致性、稳定性等）

4. 关注端到端业务场景，基于场景完成最佳技术实践

5. 推动架构治理、技术规范、稳定性体系建设等长期工程效能工作

## 任职要求

任职要求

1. 本科及以上学历，5 年以上相关经验

2. 精通至少一种主流后端语言（Go / Java 等），对运行时、并发模型、网络有深入理解

3. 具备复杂分布式系统从 0 到 1 的设计经验，熟悉微服务、消息队列、分布式存储、缓存等核心组件

4. 能在业务、研发、成本之间做合理的技术权衡，具备良好的全局视野

5. 有从 0 到 1 搭建过中大型系统的完整经历者优先

6. 熟悉云原生、Service Mesh、可观测性等基础设施领域

7. 有开源项目、技术布道或跨团队技术影响力等优先
