## 职位描述

MiniMax 是国内领先的大模型公司，开放平台是模型能力连接开发者和企业客户、实现规模化商业落地的核心平台。

大模型的竞争不只发生在模型本身，也发生在如何将前沿模型能力快速、稳定、高效地交付给开发者。你将参与建设覆盖文本、视频、图像和音频的大模型开发者平台，连接模型、算力与商业系统，为全球开发者提供简单、可靠、高性能的 AI API 服务。

你的工作将直接影响模型能力的交付效率、开发者体验、算力利用率和平台商业化规模。

岗位职责

1. 负责大模型开发者平台的设计与后端研发，将文本、视频、图像和音频等前沿模型能力转化为稳定、易用的 API 产品。

2. 跟进主流大模型 API 生态演进，持续完善 OpenAI、Anthropic 等协议兼容能力，解决不同模型和供应商之间的接口差异。

3. 参与建设端到端高性能大模型网关链路，以zero overhead的原则构建整体链路，追求极致性能表现；

4. 建设统一的模型接入、服务治理和流量调度体系，持续提升平台的可用性、性能、扩展性和资源利用效率。

5. 参与开放 API、管理后台和部署运维工具链建设，支持公有云及企业私有化部署场景。

6. 建设模型用量、成本、配额、调用日志、账单和运营分析等平台能力，支撑开放平台规模化商业运营。

7. 参与平台安全与合规建设，包括身份鉴权、密钥安全、权限控制、审计和风险治理。

## 任职要求

1. 具备 2 年以上后端研发经验，熟悉 Go、TypeScript/Node.js、Python 中至少一种语言。

2. 熟悉 HTTP API、RESTful、流式响应和反向代理等相关技术，理解鉴权、限流、熔断、负载均衡等基础能力。

3. 熟悉 MySQL 或 PostgreSQL、Redis、消息队列等常用基础设施，具备良好的数据建模和分布式系统设计能力。

4. 有复杂后端系统的设计、研发和线上运维经验，关注系统的稳定性、性能、安全性和长期演进。

5. 具备良好的产品意识和开发者视角，能够将复杂的模型与基础设施能力转化为清晰、易用的 API。

6. 具备良好的问题分析、沟通协作和项目推动能力，能够推动跨团队复杂项目落地。

加分项

1. 深度使用或参与过 new-api、one-api、sub2api、LiteLLM 等相关项目。

2. 熟悉 OpenAI、Anthropic 等主流大模型 API 生态，了解不同模型厂商在接口协议、流式响应、工具调用、错误处理和用量计量等方面的差异。

3. 有大模型开发者平台、多模态生成平台、高并发 API 平台或商业化系统建设经验。

4. 有大规模流量调度、资源治理、容器化、私有化部署或可观测性平台建设经验。

5. 有开源项目贡献或复杂系统研发经验。

6. 有icpc、asc等竞赛获奖经验
