## 职位描述

团队简介

我们正在组建一支 AI 安全团队，使命是把顶尖的安全能力与大模型深度结合：一方面攻克高价值的安全难题，将专家经验沉淀为数据、Benchmark 与自动化框架，持续提升基础模型的网络安全能力；另一方面将这些能力落地到真实业务场景，守护公司安全水位，并用实战反哺模型迭代。 这是一支兼具研究深度与工程能力的团队，我们既欢迎在某一安全领域深耕多年的专家，也欢迎能够搭建安全平台与基础设施的资深工程师与架构师。

岗位职责

1、负责数据安全核心系统与基础设施的架构设计和研发，包括数据安全网关、敏感数据识别引擎、动态/静态脱敏、加解密与密钥管理（KMS）、审计日志等组件，保障高并发场景下的性能与稳定性；

2、构建数据安全中台与全链路治理平台，围绕数据分类分级、敏感数据扫描、DLP 引擎与 UEBA 行为分析，实现核心研发资产与业务数据的流转可视、可控、可追溯；

3、协同产品、研发与算法团队，将用户隐私保护、模型训练/推理数据安全、Prompt 及模型输出管控等需求转化为工程化能力，落地数据防泄漏、反爬虫等安全防护系统；

4、探索 AI for Security 在数据安全领域的应用，结合大模型与 Agent 研发智能化的数据分类分级、敏感语义检测与异常行为识别引擎，提升检测准确率与运营效率。

## 任职要求

1、工程能力扎实，熟练掌握 Golang、Python、Java、C/C++ 中至少一门语言，具备较强的软件架构与模块拆解能力，能独立完成高并发服务或平台系统的设计、实现与上线闭环；

2、熟悉数据安全技术体系，在数据分类分级、敏感数据识别、数据脱敏、加解密与 KMS、安全网关、DLP 或审计/UEBA 等至少一个方向有实际系统研发经验；

3、具备大规模日志或流量数据的工程处理能力，熟悉 SQL 及 Flink、Spark、ClickHouse、Elasticsearch 等常见组件中的一种或多种，能支撑海量审计与实时风险检测；

4、理解大模型训练、推理或 Agent 应用场景下的数据流转与安全挑战，能在安全水位、系统延迟与业务体验之间做好工程权衡；

5、AI Native，对 AI 有热情，习惯使用并行 Agent 与 AI Coding 工具放大个人产出；沟通协作与 Owner 意识良好。
