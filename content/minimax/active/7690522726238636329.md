## 职位描述

我们在做什么

大模型的商业化规则仍在形成。

Token 计费、订阅制、Agent、行业解决方案、生态分成……今天的主流模式，一年后可能就会被重新定义。

这个团队的使命，是站在模型能力、市场需求与产业生态的交汇处，与模型、产品和生态团队一起，从 0 到 1 找到下一种可规模化的商业模式，并真正把它跑通。这不是一个按照既有 Playbook 执行的传统 BD 岗位，你需要发现机会、设计模式、验证假设、推动签约，并将成功实践沉淀为可以全球复制的增长路径。

你将负责

1. 探索并验证新的商业模式

围绕大模型能力识别新的商业化机会，包括渠道合作、Coding Plan、订阅产品、行业解决方案、联合产品及收入分成等。推动机会完成从假设提出、商业测算、MVP 验证到规模化复制的全过程；

2. 推动全球市场突破

研究不同国家和地区的开发者、企业及渠道生态，识别高潜市场、关键场景与切入路径，推动 MiniMax 在重点区域实现客户、收入和生态影响力的突破；

3. 建设可持续的伙伴生态

与云厂商、算力伙伴、模型聚合平台、Agent及开发工具、系统集成商和行业 ISV 建立深度合作。设计兼顾双方价值的合作机制，形成长期、稳定且可复制的全球伙伴网络；

4. 驱动战略价值与跨团队落地

在收入之外，持续关注开发者认知、生态位、标杆案例、场景数据及模型反馈等长期价值，并建立清晰的衡量方式。连接业务、模型、产品、研发、财务和法务团队，将市场洞察转化为产品需求、商业决策与实际结果。

## 任职要求

我们希望你

1.具备商业化经验： 本科及以上学历，拥有2年以上商业化、战略、BD、增长或产品相关经验；有大模型、云计算、开发者平台或 SaaS 经验者优先；

2.拥有扎实的商业分析能力： 理解按 Token 计费的业务逻辑，能够拆解 API 定价、成本、毛利和单位经济模型，并独立完成商业测算；

3.具备全球市场经验： 在北美、东南亚、日韩或中东等至少一个海外市场拥有实际业务经验，英文可以作为工作语言；

4.能够把复杂机会变成结果： 擅长建立关系、设计合作方案和推动复杂谈判；具备较强的学习能力、商业判断、自驱力和跨团队执行力，能够在高度不确定的环境中持续交付结果；

5.我们不限定单一的职业背景。相比标准化履历，我们更看重你对商业世界的好奇心、快速理解新事物的能力，以及把想法真正落地的能力。

加分项

1.有海外开发者生态、渠道合作或平台型合作经验；

2.深度使用过主流大模型 API、Agent或 AI Coding 工具，并形成自己的产品判断；

3.具备技术背景，或能够与算法和工程团队高效沟通；

4.有创业、早期团队或从 0 到 1 业务建设经历。

你会获得

1.深度参与核心决策： 与模型、产品和研发团队直接协作，参与探索大模型行业下一种可规模化的商业模式。；

2.完整主导从 0 到 1： 不只是执行单点任务，而是完整负责机会判断、商业测算、方案设计、合作谈判和规模化验证；

3.对接全球核心伙伴： 与云厂商、模型聚合平台、开发者工具及行业头部公司共同设计并落地合作；

4.积累稀缺复合能力： 同时提升大模型商业化、全球 BD、单位经济分析和复杂项目推动能力。
