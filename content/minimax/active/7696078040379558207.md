## 职位描述

关于我们

我们自建 GPU 集群，对上提供 AI 推理裸金属服务。团队成员来自【头部云厂商、互联网大厂、硬件厂商等】，在大规模集群和高性能系统方面有深厚积累。

网络性能直接影响推理服务的时延、吞吐和稳定性。我们希望你在网卡与主机网络层面持续优化，全面提升集群的通信性能和可靠性。

岗位职责

1. 网卡与通信性能优化：深入网卡、PCIe、驱动和内核等层面，分析并优化单机内和多机间的 RDMA 通信性能，突破软硬件性能瓶颈，让带宽和时延逼近硬件上限。

2. 推理通信链路优化：面向大模型推理场景，优化 Prefill/Decode 分离下的 KV Cache 传输、跨节点并行通信（如 EP/TP 场景下的 All2All、AllReduce）、模型权重加载等关键链路，降低端到端时延和长尾时延。

3. 稳定性保障与问题攻关：负责丢包、时延抖动、慢节点、网卡异常等复杂问题的定位，从网卡、PCIe、驱动、内核到应用逐层分析根因，并推动问题闭环；沉淀排查方法和规范，建设集群监控告警、故障自动诊断、性能基线等能力。

4. 技术协作与演进：和推理框架、硬件等团队协作，提升系统整体性能；和网卡厂商深度合作，攻克关键技术问题；跟踪新一代网卡、RDMA 和 GPU 互联的技术趋势，推动新技术的验证和落地。

## 任职要求

1. 本科及以上学历，计算机、通信、电子工程相关专业，3 年以上相关经验。

2. 计算机网络和操作系统基础扎实，熟悉 RDMA 技术（QP、Verbs、内存注册、传输模式等），有 RoCEv2 或 InfiniBand 的实际使用、开发或问题定位经验。

3. 熟悉常见的集合通信算法（如 Ring、Tree、Halving-Doubling、All2All 等）。

4. 熟悉 Linux 系统和网络机制，了解 PCIe、NUMA 等主机架构对通信性能的影响。

5. 有复杂问题的分析能力，能独立完成性能调优和故障排查。

6. 熟悉 C/C++，并熟练掌握 Python、Go 或 Shell 中的至少一种，有工具或自动化开发能力。

加分项

- 对网卡架构有深入理解，比如网卡数据通路、固件与驱动、GPUDirect RDMA、硬件计数器与诊断机制等。

- 在网卡厂商（NVIDIA/Mellanox、Intel、Broadcom、国产网卡厂商）做过芯片、固件或驱动相关工作。

- 了解 NCCL、DeepEP、HCCL 等通信库中至少一种的实现原理，或有相关开发、调优经验。

- 熟悉 vLLM、SGLang、TensorRT-LLM 等推理框架，或做过 PD 分离、KV Cache 传输（Mooncake、NIXL 等）。

- 有大规模 GPU 集群网络相关经验。
