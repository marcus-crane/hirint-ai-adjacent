## 职位描述

我们正在寻找一位真正热爱开源、熟悉 AI 视频生成技术与开发者生态的 Open Source Ecosystem Lead，负责 MiniMax 视频模型的全球开源生态建设。

你将深入参与模型从研发、发布到社区增长的完整链路，与模型、推理、产品及市场团队紧密协作，将 MiniMax 视频模型打造为全球开发者社区广泛使用和持续贡献的开源项目。你将负责：

1. 视频模型开源生态整体策略

1）制定模型开源发布、社区建设及开发者生态发展策略；

2）围绕 GitHub、Hugging Face、ComfyUI、Diffusers 及主流推理框架建立完整生态。

2. 推动模型进入主流开源工具链

1）推动模型在 ComfyUI、Diffusers、主流推理框架及量化方案中的适配；

2）与开源框架维护者、开发者、研究者及基础设施团队建立长期合作；

3）推动第三方插件、Workflow、应用及社区项目围绕模型持续发展。

3. 建设全球开发者与贡献者社区

1）建立并维护核心开发者、Contributor、KOL、研究者等社区网络；

2）推动 GitHub PR、Issue、第三方项目、教程、Benchmark 等社区贡献；

3）代表 MiniMax 深度参与全球 AI 开源社区。

4. 深度参与模型发布与技术传播

1）深入理解视频生成模型架构、推理、量化、部署、ComfyUI Workflow、模型微调等技术；

2）围绕模型能力、技术创新和实际应用持续产出高质量技术内容；

3）与模型团队共同打造 Model Card、Demo、Benchmark、技术博客及开源项目。

5. 连接社区与模型研发

1）持续跟踪 MiniMax-H 系列，Wan、HunyuanVideo、CogVideo、LTX、Open-Sora 等视频开源项目及全球社区动态；

2）识别社区真实需求、技术趋势及生态机会，并反哺模型研发和产品决策；

3）建立从社区反馈 → 技术迭代 → 开源发布 → 生态扩张的完整闭环。

## 任职要求

1. 真正热爱开源社区，长期关注并深度参与 GitHub、Hugging Face、ComfyUI、Diffusers 等 AI 开源生态；

2. 对视频生成模型有深入理解和实际使用经验，熟悉 MiniMax-H系列，Wan、HunyuanVideo、CogVideo、LTX、Open-Sora 等主流开源视频模型中的一个或多个；

3. 具备较强的技术能力，理解模型推理、量化、部署、ComfyUI Workflow、模型微调等相关技术，能够与模型研发及工程团队进行深度技术沟通；

4. 有开源项目或开发者社区建设经验，曾作为 Contributor、Maintainer、Developer Advocate 或核心成员参与过有影响力的开源项目；

5. 具备优秀的开发者沟通和技术内容能力，能够将复杂的模型技术转化为开发者容易理解和使用的工具、文档、教程及案例；

6. 具备良好的英文技术交流能力，能够直接参与全球开发者社区，与海外开发者、研究者及开源项目维护者建立合作；

7. 强自驱力、强 ownership，能够在快速迭代的环境中独立发现问题、制定方案并推动落地。

【加分项】

1. 维护过有较大影响力的 GitHub / Hugging Face 开源项目；

2. 曾向 ComfyUI、Diffusers、VideoSys、xDiT、vLLM、SGLang 等开源项目贡献代码或推动模型适配；

3. 有 Wan、HunyuanVideo、CogVideo、LTX、Open-Sora 等视频模型深度实践经验；

4. 有模型量化、推理优化、GPU 部署或训练 / Fine-tuning 经验；

5. 在 GitHub、Hugging Face、YouTube、X、Reddit、Discord 等开发者社区具有一定影响力；

6. 有成功推动 AI 模型、工具或开源项目获得大规模开发者 adoption 的经验。
