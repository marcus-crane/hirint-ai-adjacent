岗位职责

1. 参与具身智能大模型（VLA/VLM 等）的训练、推理及部署基础设施建设，支撑算法模型高效运行。
2. 参与模型训练与推理性能优化，从计算、显存、通信、数据等维度分析性能瓶颈，提升 GPU 利用率及整体运行效率。
3. 参与分布式训练、推理系统及相关工具链建设，提升大规模模型训练和实验效率。
4. 参与模型数据处理、训练任务管理、实验管理、模型评测等基础能力建设，完善算法研发基础设施。
5. 针对模型训练及推理过程中出现的性能和稳定性问题进行分析与优化，推动问题闭环。
6. 与算法、软件、硬件及机器人团队协作，推动模型从算法实验走向真实机器人应用。

任职要求

1. 2027届本科及以上毕业生，计算机、软件工程、人工智能、自动化、机器人等相关专业优先。
2. 具备扎实的计算机基础，熟悉数据结构、操作系统、计算机网络等基础知识。
3. 熟练掌握 Python / C++ 中至少一种编程语言，具备良好的代码能力和工程实践能力。
4. 了解深度学习基本原理，熟悉 PyTorch 等主流深度学习框架，有模型训练、推理或相关项目经验。
5. 对 GPU 计算、并行计算、分布式系统或高性能计算有一定了解，并对系统性能优化具有兴趣。
6. 具备较强的问题分析和学习能力，能够从算法、框架、系统等不同层面分析和解决问题。
7. 对大模型、具身智能、机器人、VLA/VLM等方向有浓厚兴趣，有相关项目、科研或实践经历者优先。
