工作职责

1、参与 AI Agent 应用的开发和优化，包括任务规划、工具调用、记忆管理、工作流编排等

2. 基于 OpenAI、Claude、Gemini 或国产大模型 API 搭建智能体能力

3. 参与 RAG、知识库、Prompt、Function Calling 等模块的开发

4. 建设 Agent 的测试与评估体系，分析失败案例并持续优化效果

5. 跟进大模型与 Agent 领域的新技术，快速完成原型验证

6. 与产品和业务团队协作，将原型落地为可使用的功能

任职要求

1、计算机、软件工程、人工智能或相关专业在校生

2. 熟悉 c++ ，具备良好的编码习惯和基础工程能力

3. 了解大语言模型、Prompt Engineering、RAG 或 AI Agent 的基本原理

4. 熟悉 HTTP、REST API、Git 等常用开发工具

5. 具备独立分析问题、查阅文档和快速学习的能力

6. 对 AI 产品有热情，愿意主动尝试并持续迭代

7. 每周可实习 4 天及以上，连续实习 3 个月及以上
