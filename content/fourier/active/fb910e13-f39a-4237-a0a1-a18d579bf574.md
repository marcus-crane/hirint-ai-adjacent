岗位职责：

1. 参与机器人 Linux 软件系统的开发、集成与维护，包括系统服务、驱动、工具链及基础运行环境。

2. 参与机器人软件版本构建、打包、发布和升级流程建设，包括 Deb、Docker、系统镜像及 OTA 升级。

3. 协助搭建和维护 CI/CD 流水线，实现代码编译、自动化测试、制品生成和版本发布。

4. 编写 Shell、Python 等自动化工具，提高机器人软件部署、诊断和运维效率。

5. 参与机器人软件系统稳定性测试，完善日志、监控、故障恢复和问题定位机制。

任职要求：

1. 计算机、软件工程、自动化、机器人、电子电气工程等相关专业，本科及以上学历在读。

2. 熟悉 Linux 基本使用，能够使用常见命令完成文件、进程、网络和系统服务管理。

3. 掌握至少一种编程或脚本语言，如 Python、Shell、C 或 C++。

4. 了解 Git 基本操作，包括分支管理、代码合并和版本回退。

5. 具备基本的计算机网络知识，了解 IP、路由、DNS、DHCP、SSH 等概念。

6. 具备良好的问题分析能力，能够根据日志和报错逐步定位问题。

7. 具有较强的学习能力、责任心和团队协作意识。

8.每周可实习至少 4 天，连续实习 3 个月及以上。
